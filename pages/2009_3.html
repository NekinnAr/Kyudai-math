曲線 $C_1:\ y = \dfrac{x^2}{2}$ の点 $P\left(a,\ \dfrac{a^2}{2}\right)$ における法線と点 $Q\left(b,\ \dfrac{b^2}{2}\right)$ における法線の交点を $R$ とする。ただし，$b \ne a$ とする。このとき，次の問いに答えよ。

  1. (1)　$b$ が $a$ に限りなく近づくとき，$R$ はある点 $A$ に限りなく近づく。$A$ の座標を $a$ で表せ。
  2. (2)　点 $P$ が曲線 $C_1$ 上を動くとき，(1) で求めた点 $A$ が描く軌跡を $C_2$ とする。曲線 $C_1$ と軌跡 $C_2$ の概形を描き，$C_1$ と $C_2$ の交点の座標を求めよ。
  3. (3)　曲線 $C_1$ と軌跡 $C_2$ で囲まれた部分の面積を求めよ。

（2009 九州大学 前期 理系 第3問）

解答例

法線を「$x + a y = \cdots$」の形で書くと、$a = 0$（法線が $y$ 軸）の場合も含めて 1 本の式で扱えます。2 本の法線を連立して $b \to a$ とすれば $A$ が求まります。

解答例（タップで展開）

(1)

$y' = x$ より $P$ における接線の方向ベクトルは $(1,\ a)$。法線は $P$ を通りこれに垂直なので

$$(x - a) + a\left(y - \frac{a^2}{2}\right) = 0 \iff x + ay = a + \frac{a^3}{2}$$

$Q$ における法線 $x + by = b + \frac{b^3}{2}$ と辺々引くと $(a - b)y = (a - b) + \dfrac{a^3 - b^3}{2}$。$a \ne b$ で割って

$$y = 1 + \frac{a^2 + ab + b^2}{2},\qquad x = a + \frac{a^3}{2} - ay = -\frac{ab(a + b)}{2}$$

$b \to a$ とすると

$$A\left(-a^3,\ 1 + \frac32a^2\right)$$

(2)

$X = -a^3$，$Y = 1 + \frac32a^2$ から $a$ を消去すると、$a^2 = (a^3)^{2/3} = |X|^{2/3}$ より

$$C_2:\ y = 1 + \frac32|x|^{\frac23}$$

（$y$ 軸対称で、$(0,\ 1)$ で尖った曲線。$x = 0$ で微分できない。）

交点：$A$ が $C_1$ 上にある条件は $1 + \frac32a^2 = \frac{a^6}{2}$，すなわち $u = a^2$ として $u^3 - 3u - 2 = 0$，$(u - 2)(u + 1)^2 = 0$。$u \ge 0$ より $u = 2$，$a = \pm\sqrt2$。

$$\text{交点 } (2\sqrt2,\ 4),\ (-2\sqrt2,\ 4)$$

(3)

$|x| < 2\sqrt2$ では $C_2$ が上側（$x = 0$ で $1 > 0$）。$y$ 軸対称なので

$$S = 2\int_0^{2\sqrt2}\left(1 + \frac32x^{\frac23} - \frac{x^2}{2}\right)dx = 2\left[x + \frac{9}{10}x^{\frac53} - \frac{x^3}{6}\right]_0^{2\sqrt2}$$

$(2\sqrt2)^{\frac53} = 2^{\frac52} = 4\sqrt2$，$(2\sqrt2)^3 = 16\sqrt2$ より

$$S = 2\left(2\sqrt2 + \frac{18\sqrt2}{5} - \frac{8\sqrt2}{3}\right) = \frac{88\sqrt2}{15}$$

動く図解

$P,\ Q$ における法線（青・橙）の交点 $R$ が、$b \to a$ で $C_2$（緑）上の点 $A$ に近づく様子を見られます。

問題の背景

曲率中心と縮閉線

近くの 2 点での法線の交点の極限 $A$ は、点 $P$ における曲率中心です。$P$ のまわりで曲線に最もよく接する円（曲率円）の中心で、$|PA|$ がその半径（曲率半径）。曲率中心の軌跡 $C_2$ を縮閉線と呼びます。放物線の縮閉線は $y - 1 = \frac32|x|^{2/3}$ のような「半立方放物線」になり、頂点の真上で尖ります。

$C_1$ と $C_2$ を一緒に描くと、chopin 先生いわく「2 曲線の概形は、どことなくマツダのロゴっぽくなります笑」。

chopin 先生はほかに「(1) 方針自体は、法線の式をそれぞれ求めて連立させるというシンプルなものですが、$a,\ b$ がそれぞれ 0 になるか否かで場合分けが発生します」「(3) 素直に積分計算をして面積を求めましょう」とコメントしています。

法線は「接線の方向ベクトルとの内積 $= 0$」で書くと傾きが不要で場合分けが減る。近い 2 点の法線の交点の極限 ＝ 曲率中心。

類題紹介

放物線 $y = x^2$ 上の点 $(a,\ a^2)$（$a \ne 0$）における法線と $y$ 軸の交点を $B$ とする。$a \to 0$ のとき $B$ が近づく点を求めよ。

（自作）

略解

法線 $(x - a) + 2a(y - a^2) = 0$ に $x = 0$ を代入して $y = a^2 + \frac12$。$a \to 0$ で $B \to \left(0,\ \frac12\right)$。（頂点での曲率中心。曲率半径は $\frac12$。）

本問の点 $P$ と $A$ について，距離 $PA$ を $a$ で表し，その最小値を求めよ。

（九大 2009　魔改造）

略解
$$\overrightarrow{PA} = \left(-a^3 - a,\ 1 + a^2\right) = (1 + a^2)(-a,\ 1)$$

より $PA = (1 + a^2)\sqrt{1 + a^2} = (1 + a^2)^{\frac32}$。最小値は $a = 0$ のとき $1$。

（これは放物線 $y = \frac{x^2}{2}$ の曲率半径 $\dfrac{(1 + y'^2)^{3/2}}{|y''|}$ そのもの。頂点で最も曲がっている。）
