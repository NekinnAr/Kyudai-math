原点を中心とする半径 $3$ の半円 $C : x^2 + y^2 = 9\ (y \ge 0)$ 上の 2 点 $\mathrm{P}$ と $\mathrm{Q}$ に対し，線分 $\mathrm{PQ}$ を $2 : 1$ に内分する点を $\mathrm{R}$ とする。以下の問いに答えよ。

  1. (1)　点 $\mathrm{P}$ の $y$ 座標と $\mathrm{Q}$ の $y$ 座標が等しく，かつ $\mathrm{P}$ の $x$ 座標は $\mathrm{Q}$ の $x$ 座標より小さくなるように $\mathrm{P}$ と $\mathrm{Q}$ が動くものとする。このとき，線分 $\mathrm{PR}$ が通過してできる図形 $S$ の面積を求めよ。
  2. (2)　点 $\mathrm{P}$ を $(-3,\ 0)$ に固定する。$\mathrm{Q}$ が半円 $C$ 上を動くとき線分 $\mathrm{PR}$ が通過してできる図形 $T$ の面積を求めよ。
  3. (3)　(1) の図形 $S$ から (2) の図形 $T$ を除いた図形と第 1 象限の共通部分を $U$ とする。$U$ を $y$ 軸のまわりに 1 回転させてできる回転体の体積を求めよ。

（2018 九州大学 前期 理系 第2問）

解答例

R の軌跡を求めれば図形が分かる。(1) は R が楕円、(2) は R が円を描き、どちらも面積は積分なしで求まる。(3) は回転体を「円板 − 円板」で計算する。

解答例（タップで展開）

(1)

P，Q の $y$ 座標を $h\ (0 \le h \lt 3)$ とすると、$w = \sqrt{9 - h^2}$ として $\mathrm{P}(-w,\ h)$，$\mathrm{Q}(w,\ h)$。$\mathrm{R} = \frac{\mathrm{P} + 2\mathrm{Q}}{3} = \left(\frac w3,\ h\right)$。線分 PR は高さ $h$ の水平な線分 $-w \le x \le \frac w3$。$h$ を $0 \le h \lt 3$ で動かすと

$$S:\ -\sqrt{9 - y^2} \le x \le \frac13\sqrt{9 - y^2},\quad 0 \le y \lt 3$$

左側の境界は円 $x^2 + y^2 = 9$、右側の境界は $9x^2 + y^2 = 9$，すなわち楕円 $x^2 + \frac{y^2}{9} = 1$。S は「半径 3 の四分円」と「半軸 $1,\ 3$ の楕円の $\frac14$」を合わせた図形で

$$S\ \text{の面積} = \frac{9\pi}{4} + \frac{\pi\cdot1\cdot3}{4} = 3\pi$$

(2)

$\mathrm{Q}(3\cos\varphi,\ 3\sin\varphi)\ (0 \le \varphi \le \pi)$ とすると $\mathrm{R} = \frac{\mathrm{P} + 2\mathrm{Q}}{3} = (-1 + 2\cos\varphi,\ 2\sin\varphi)$。R は中心 $(-1,\ 0)$、半径 $2$ の上半円を描き、P$(-3,\ 0)$ はこの円の左端。線分 PR は、この半円板の弦を P から引いたもので、その通過範囲は半円板 $(x + 1)^2 + y^2 \le 4,\ y \ge 0$ 全体。

$$T\ \text{の面積} = \frac12\cdot\pi\cdot2^2 = 2\pi$$

(3)

第 1 象限では、S は楕円の内部 $0 \le x \le \frac13\sqrt{9 - y^2}$、T は $0 \le x \le -1 + \sqrt{4 - y^2}\ (0 \le y \le \sqrt3)$。$-1 + \sqrt{4 - y^2} \le \frac13\sqrt{9 - y^2}$ が成り立つ（$y = 0$ でともに $1$、それ以外では左辺の方が小さい）ので、T の第 1 象限部分は S に含まれる。

よって $y$ 軸まわりの回転体の体積は「S の第 1 象限部分の回転体」から「T の第 1 象限部分の回転体」を引いたもの。

$$V_1 = \pi\int_0^3\frac{9 - y^2}{9}\,dy = \pi\left[y - \frac{y^3}{27}\right]_0^3 = 2\pi$$ $$V_2 = \pi\int_0^{\sqrt3}\left(\sqrt{4 - y^2} - 1\right)^2dy = \pi\int_0^{\sqrt3}\left(5 - y^2 - 2\sqrt{4 - y^2}\right)dy$$

$\int_0^{\sqrt3}\sqrt{4 - y^2}\,dy$ は、半径 2 の円の扇形（中心角 $\frac\pi3$）と直角三角形の面積の和で $\frac{2\pi}{3} + \frac{\sqrt3}{2}$。よって

$$V_2 = \pi\left(5\sqrt3 - \sqrt3 - \frac{4\pi}{3} - \sqrt3\right) = \pi\left(3\sqrt3 - \frac{4\pi}{3}\right)$$ $$V = V_1 - V_2 = 2\pi - 3\sqrt3\pi + \frac{4\pi^2}{3}$$

動く図解

スライダーで P，Q を動かすと、線分 PR（赤）が動いて図形を塗っていきます。「(3) U」では、S（楕円部分）から T を除いた第 1 象限部分 U が表示されます。

問題の背景

楕円は「円を縮めたもの」

(1) で R の $x$ 座標は Q の $x$ 座標の $\frac13$ 倍です。つまり R の軌跡は、半円 C を $x$ 軸方向に $\frac13$ 倍に縮めた楕円。面積も $\frac13$ 倍になるので、楕円の面積公式 $\pi ab$ を知らなくても「四分円の $\frac13$」で $\frac{9\pi}{4}\cdot\frac13 = \frac{3\pi}{4}$ と求まります。

(2) の R の軌跡は、半円 C を点 P を中心に $\frac23$ 倍に縮小（相似拡大）したものです。

chopin 先生は「S，T の形状をきちんと図に描いてあげれば、典型的な問題になります」「登場する図形は円と楕円だけなので、積分なしに面積を計算できます」とコメントしています。

内分点・中点の軌跡は「元の図形の相似拡大・一方向への縮小」になることが多い。$\int\sqrt{a^2 - y^2}\,dy$ は扇形＋三角形の面積で計算する。

類題紹介

本問 (2) で，R を線分 PQ を $t : (1 - t)$ に内分する点（$0 \lt t \lt 1$）に変えたとき，線分 PR が通過してできる図形の面積を求めよ。

（自作）

略解

$\mathrm{R} = (1 - t)\mathrm{P} + t\mathrm{Q} = (-3 + 3t + 3t\cos\varphi,\ 3t\sin\varphi)$ は、中心 $(-3 + 3t,\ 0)$、半径 $3t$ の上半円を描き、P はその左端。通過範囲は半円板で、面積は $\dfrac{9\pi t^2}{2}$（$t = \frac23$ で $2\pi$）。

本問 (3) の図形 $U$ を $x$ 軸のまわりに 1 回転させてできる回転体の体積を求めよ。

（九大 2018　魔改造）

略解

$0 \le x \le 1$ で、U の $x$ における断面は $\sqrt{4 - (x + 1)^2} \le y \le 3\sqrt{1 - x^2}$。回転させると円環で、面積は

$$\pi\left\{9(1 - x^2) - 4 + (x + 1)^2\right\} = \pi(6 + 2x - 8x^2)$$ $$V = \pi\int_0^1(6 + 2x - 8x^2)\,dx = \pi\left(6 + 1 - \frac83\right) = \frac{13\pi}{3}$$
