いくつかの半径 3 の円を，半径 2 の円 $Q$ に外接し，かつ，互いに交わらないように配置する。このとき，次の問いに答えよ。

  1. (1)　半径 3 の円の 1 つを $R$ とする。円 $Q$ の中心を端点とし，円 $R$ に接する 2 本の半直線のなす角を $\theta$ とおく。ただし，$0 < \theta < \pi$ とする。このとき，$\sin\theta$ を求めよ。
  2. (2)　$\dfrac\pi3 < \theta < \dfrac\pi2$ を示せ。
  3. (3)　配置できる半径 3 の円の最大個数を求めよ。

（2008 九州大学 前期 理系 第5問）

解答例

中心間の距離は $2 + 3 = 5$ なので $\sin\frac\theta2 = \frac35$。(3) で (2) の評価を使うと「4 個か 5 個」までしか絞れないのが罠で、$\theta$ と $\frac{2\pi}{5}$ の大小を $\cos\frac{2\pi}{5} = \frac{\sqrt5 - 1}{4}$ を使って比べる必要があります。

解答例（タップで展開）

(1)

$Q$ の中心を $O$，$R$ の中心を $C$ とすると $OC = 5$。$O$ から $R$ への接線と接点 $T$ について $\triangle OCT$ は $\angle T = 90^\circ$，$CT = 3$ の直角三角形で、$\angle COT = \frac\theta2$。

$$\sin\frac\theta2 = \frac35,\quad \cos\frac\theta2 = \frac45,\qquad \sin\theta = 2\cdot\frac35\cdot\frac45 = \frac{24}{25}$$

(2)

$\sin\frac\theta2 = \frac35 < \frac{1}{\sqrt2}$ で $0 < \frac\theta2 < \frac\pi2$ より $\frac\theta2 < \frac\pi4$，$\theta < \frac\pi2$。

$0 < \theta < \frac\pi2$ で $\sin$ は増加し、$\left(\frac{24}{25}\right)^2 = \frac{576}{625} > \frac34$ より $\sin\theta > \sin\frac\pi3$。よって $\frac\pi3 < \theta < \frac\pi2$。

(3)

半径 3 の 2 円の中心 $C_1,\ C_2$ はともに $O$ から距離 5。$\angle C_1OC_2 = \varphi$ とすると $C_1C_2 = 10\sin\frac\varphi2$ で、2 円が交わらない $\iff C_1C_2 > 6 \iff \sin\frac\varphi2 > \frac35 \iff \varphi > \theta$。したがって $n$ 個配置できる $\iff$ 隣り合う中心の角がすべて $\theta$ より大きくとれる $\iff n\theta < 2\pi$。

(2) からは $4 < \frac{2\pi}{\theta} < 6$ しか分からないので、$\theta$ と $\frac{2\pi}{5}$ を比べる。

$\alpha = \frac\pi5$ とすると $3\alpha = \pi - 2\alpha$ より $\cos3\alpha = -\cos2\alpha$。$c = \cos\alpha$ として $4c^3 - 3c = -(2c^2 - 1)$，$(c + 1)(4c^2 - 2c - 1) = 0$。$c > 0$ より $c = \frac{1 + \sqrt5}{4}$，

$$\cos\frac{2\pi}{5} = 2c^2 - 1 = \frac{\sqrt5 - 1}{4}$$

一方 $\cos\theta = 1 - 2\sin^2\frac\theta2 = \frac{7}{25}$。$\frac{\sqrt5 - 1}{4} - \frac{7}{25} = \frac{25\sqrt5 - 53}{100}$ で、$(25\sqrt5)^2 = 3125 > 2809 = 53^2$ より正。よって $\cos\frac{2\pi}{5} > \cos\theta$，すなわち $\theta > \frac{2\pi}{5}$。

$5\theta > 2\pi$ なので 5 個は配置できない。$4\theta < 2\pi$（$\theta < \frac\pi2$）なので、中心を $O$ のまわりに $90^\circ$ ずつ並べれば 4 個は配置できる。最大個数は

$$4\ \text{個}$$

動く図解

外側の円の半径 $r$ を変えると、角 $\theta = 2\arcsin\frac{r}{2 + r}$ と並べられる最大個数が変わります。$r = 3$ では $\theta \approx 73.7^\circ$ で、$72^\circ$（5 個並ぶ限界）をわずかに超えるため 4 個しか置けません。

問題の背景

「あと 1.7°」の攻防

$\theta = 2\arcsin\frac35 \approx 73.74^\circ$ に対し、5 個並べるのに必要なのは $\theta \le 72^\circ$。差はわずか $1.7^\circ$ ほどで、(2) の誘導 $60^\circ < \theta < 90^\circ$ では到底判定できません。誘導に乗れば解けると思わせておいて最後に精密な評価を要求する、chopin 先生いわく「壮絶な罠」です。

$\cos\frac\pi5 = \frac{1 + \sqrt5}{4}$（黄金比の半分）は正五角形に関係する頻出の値で、「$3\alpha = \pi - 2\alpha$」から 3 次方程式を作る導き方は覚えておく価値があります。

chopin 先生は「少々意地悪な問題だと思いました」「(2) を使えば瞬殺と思いきや、(2) の評価が実はガバガバで評価がうまくできないという、壮絶な罠だったわけです！ 謀ったな九大め・・・」「次点の候補として $2\pi/5$ と $\theta$ の大小関係を比べてみましょう。…$\alpha = \pi/5$ とおいて、$\cos2\alpha + \cos3\alpha = 0$ になるという性質を使って調べる方法です」とコメントしています。

円を並べる問題は「中心角」に翻訳。$\cos\frac\pi5 = \frac{1 + \sqrt5}{4}$，$\cos\frac{2\pi}{5} = \frac{\sqrt5 - 1}{4}$。誘導の評価が粗いときは自分で次の候補と比べる。

類題紹介

半径 1 の円 $Q$ に外接する半径 $r$ の円 $R$ について，$Q$ の中心から $R$ に引いた 2 本の接線のなす角が $\frac\pi2$ となるような $r$ を求めよ。

（自作）

略解

$\sin\frac\pi4 = \dfrac{r}{1 + r}$ より $r = \dfrac{\sqrt2}{2}(1 + r)$，$r = \dfrac{\sqrt2}{2 - \sqrt2} = \sqrt2 + 1$。（このとき 4 個がちょうど互いに接して一周する。）

いくつかの半径 1 の円を，半径 2 の円に外接し，かつ，互いに交わらないように配置する。配置できる円の最大個数を求めよ。

（九大 2008　魔改造）

略解

同様に $\sin\frac\theta2 = \frac13$。$\frac\theta2$ を $\frac\pi{10} = 18^\circ$，$\frac\pi9 = 20^\circ$ と比べる。

$\sin18^\circ = \cos72^\circ = \frac{\sqrt5 - 1}{4} < \frac13$（$3\sqrt5 < 7$）より $\frac\theta2 > 18^\circ$，$10\theta > 2\pi$。

$x = \sin20^\circ$ は $3x - 4x^3 = \sin60^\circ = \frac{\sqrt3}{2}$ をみたす。$3x - 4x^3$ は $0 \le x \le \frac12$ で増加し、$x = \frac13$ での値 $\frac{23}{27} < \frac{\sqrt3}{2}$（$\left(\frac{46}{27}\right)^2 = \frac{2116}{729} < 3$）なので $\sin20^\circ > \frac13$，$\frac\theta2 < 20^\circ$，$9\theta < 2\pi$。

よって最大 9 個。
