座標平面に 3 点 $O(0,\ 0)$，$A(2,\ 6)$，$B(3,\ 4)$ をとり，点 $O$ から直線 $AB$ に垂線 $OC$ を下ろす。また，実数 $s$ と $t$ に対し，点 $P$ を $\overrightarrow{OP} = s\overrightarrow{OA} + t\overrightarrow{OB}$ で定める。このとき，次の問いに答えよ。

  1. (1)　点 $C$ の座標を求め，$|\overrightarrow{CP}|^2$ を $s$ と $t$ を用いて表せ。
  2. (2)　$s$ を定数として，$t$ を $t \ge 0$ の範囲で動かすとき，$|\overrightarrow{CP}|^2$ の最小値を求めよ。

（2009 九州大学 前期 理系 第1問）

解答例

$|\overrightarrow{CP}|^2$ は $t$ の 2 次関数。軸 $t = \frac{4 - 6s}{5}$ が定義域 $t \ge 0$ に入るかどうかで場合分けします（軸と定義域の位置関係）。

解答例（タップで展開）

(1)

$\overrightarrow{AB} = (1,\ -2)$。$C$ は直線 $AB$ 上なので $\overrightarrow{OC} = (2 + u,\ 6 - 2u)$ とおけて、$\overrightarrow{OC} \perp \overrightarrow{AB}$ より

$$(2 + u) - 2(6 - 2u) = 0 \quad\therefore\ u = 2,\quad C(4,\ 2)$$

$\overrightarrow{OP} = (2s + 3t,\ 6s + 4t)$ より $\overrightarrow{CP} = (2s + 3t - 4,\ 6s + 4t - 2)$。

$$|\overrightarrow{CP}|^2 = (2s + 3t - 4)^2 + (6s + 4t - 2)^2 = 40s^2 + 60st + 25t^2 - 40s - 40t + 20$$

(2)

$t$ について平方完成すると

$$|\overrightarrow{CP}|^2 = (5t + 6s - 4)^2 + 4(s + 1)^2$$

$t$ の 2 次関数としての軸は $t = \dfrac{4 - 6s}{5}$。

  • $\dfrac{4 - 6s}{5} \ge 0$，すなわち $s \le \dfrac23$ のとき：軸で最小、最小値 $4(s + 1)^2$。
  • $s > \dfrac23$ のとき：$t \ge 0$ で増加なので $t = 0$ で最小、最小値 $40s^2 - 40s + 20$。
$$\min|\overrightarrow{CP}|^2 = \begin{cases} 4(s + 1)^2 & \left(s \le \frac23\right) \\[4pt] 40s^2 - 40s + 20 & \left(s > \frac23\right) \end{cases}$$

動く図解

$s$ を固定すると、$P$ は点 $s\overrightarrow{OA}$ から $\overrightarrow{OB}$ 方向に伸びる半直線（緑）上を動きます。$C$ から半直線への最短距離が最小値。垂線の足が半直線からはみ出す（$s > \frac23$）と、端点 $t = 0$ が最も近くなります。

問題の背景

平方完成の 2 つの項の意味

$|\overrightarrow{CP}|^2 = (5t + 6s - 4)^2 + 4(s + 1)^2$ の 2 つの項は、図形的には「$\overrightarrow{CP}$ を $\overrightarrow{OB}$ 方向と、それに垂直な方向に分解したときの成分の 2 乗」です（$|\overrightarrow{OB}| = 5$）。$s$ を固定すると $P$ は $\overrightarrow{OB}$ に平行な直線上を動くので、第 2 項 $4(s + 1)^2$ は $C$ とその直線との距離の 2 乗。$t$ の範囲に制限がなければ、これが最小値です。

特に $s = -1,\ t = 2$ のとき $P = C$（$-\overrightarrow{OA} + 2\overrightarrow{OB} = (4,\ 2)$）で、確かに最小値 $0$ になります。

chopin 先生は「(1) $\overrightarrow{OC} = (1 - c)\overrightarrow{OA} + c\overrightarrow{OB}$ とおいて、$\overrightarrow{OC}$ と $\overrightarrow{AB}$ が内積 0 になるという条件を処理します」「(2) $CP^2$ は $t$ の 2 次式とみなせるので、平方完成して考えますが、$s$ の値による場合分けが必要です」とコメントしています。

定義域つきの 2 次関数の最小値は「軸が定義域に入るか」で場合分け。2 変数は1 文字を固定して平方完成。

類題紹介

本問で，$s,\ t$ が $s \ge 0,\ t \ge 0$ の範囲を動くとき，$|\overrightarrow{CP}|^2$ の最小値と，そのときの $s,\ t$ を求めよ。

略解

(2) の結果を $s \ge 0$ で最小化する。$0 \le s \le \frac23$ では $4(s + 1)^2$ は $s = 0$ で最小値 $4$。$s > \frac23$ では $40s^2 - 40s + 20 = 40\left(s - \frac12\right)^2 + 10$ は増加で、$\frac{100}{9}$ より大きい。よって最小値 $4$（$s = 0$，$t = \frac45$，$P\left(\frac{12}{5},\ \frac{16}{5}\right)$：$C$ から直線 $OB$ への垂線の足）。

略解

軸 $t = \frac{4 - 6s}{5}$ が $[0,\ 1]$ に入るのは $-\frac16 \le s \le \frac23$。

$$\min = \begin{cases} 40s^2 + 20s + 5 & \left(s < -\frac16\right)\ \ (t = 1) \\[4pt] 4(s + 1)^2 & \left(-\frac16 \le s \le \frac23\right) \\[4pt] 40s^2 - 40s + 20 & \left(s > \frac23\right)\ \ (t = 0) \end{cases}$$
