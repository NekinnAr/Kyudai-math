以下の問いに答えよ。ただし，$\sqrt2,\ \sqrt3,\ \sqrt6$ が無理数であることは用いてよい。

  1. (1)　$\sqrt2 + \sqrt3 = \sqrt{5 + 2\sqrt6}$ を示せ。また，$\sqrt2 + \sqrt3$ は無理数であることを示せ。
  2. (2)　$\sqrt2 + \sqrt3$ を解にもち，係数がすべて有理数の 4 次方程式を 1 つ求めよ。また，その 4 次方程式の解をすべて求めよ。
  3. (3)　$\sqrt2 + \sqrt3$ を解にもち，係数がすべて有理数の 2 次方程式は存在しないことを示せ。

（2026 九州大学 前期 理系 第4問）

解答例

(1)(2) は「2 乗して根号を 1 つずつ外す」定番処理。(3) は 2 次方程式があると仮定し、根号の係数を比較して矛盾を導く。

解答例（タップで展開）

(1)

$(\sqrt2+\sqrt3)^2 = 5 + 2\sqrt6$ であり、$\sqrt2+\sqrt3 \gt 0$ なので $\sqrt2 + \sqrt3 = \sqrt{5+2\sqrt6}$。

次に、$\sqrt2+\sqrt3 = r$（$r$ は有理数）と仮定すると、2 乗して $5 + 2\sqrt6 = r^2$ より

$$\sqrt6 = \frac{r^2 - 5}{2}$$

右辺は有理数なので、$\sqrt6$ が無理数であることに矛盾。よって $\sqrt2+\sqrt3$ は無理数。$\blacksquare$

(2)

$x = \sqrt2+\sqrt3$ とおくと、(1) より $x^2 - 5 = 2\sqrt6$。両辺を 2 乗して $(x^2-5)^2 = 24$、すなわち

$$x^4 - 10x^2 + 1 = 0$$

は $\sqrt2 + \sqrt3$ を解にもつ有理数係数の 4 次方程式である。

この方程式を $x^2$ について解くと $x^2 = 5 \pm 2\sqrt6 = (\sqrt3 \pm \sqrt2)^2$ なので、解は

$$x = \sqrt3+\sqrt2,\quad -\sqrt3-\sqrt2,\quad \sqrt3-\sqrt2,\quad -\sqrt3+\sqrt2$$

すなわち $x = \pm\sqrt2 \pm \sqrt3$（複号任意）。

(3)

$\alpha = \sqrt2+\sqrt3$ が有理数係数の 2 次方程式の解であると仮定する。$x^2$ の係数で割って、$p,\ q$ を有理数として $\alpha^2 + p\alpha + q = 0$ としてよい。$\alpha^2 = 5 + 2\sqrt6$ より

$$2\sqrt6 + (5+q) = -p(\sqrt2 + \sqrt3)$$

両辺を 2 乗すると、$s = 5+q$ として

$$24 + 4s\sqrt6 + s^2 = p^2(5 + 2\sqrt6)$$ $$\therefore\ (s^2 + 24 - 5p^2) + (4s - 2p^2)\sqrt6 = 0$$

$s^2+24-5p^2,\ 4s - 2p^2$ は有理数で、$\sqrt6$ は無理数なので

$$4s - 2p^2 = 0,\qquad s^2 + 24 - 5p^2 = 0$$

前者より $p^2 = 2s$。後者に代入して $s^2 - 10s + 24 = 0$、よって $s = 4,\ 6$。このとき $p^2 = 8,\ 12$ となるが、$p = \pm2\sqrt2,\ \pm2\sqrt3$ はいずれも無理数であり、$p$ が有理数であることに矛盾する。

したがって、条件をみたす 2 次方程式は存在しない。$\blacksquare$

動く図解

(3) により、$x^4 - 10x^2 + 1$ は有理数の範囲では2 次式の積に分解できません（くわしくは下の「背景」で）。ところが、整数を素数 $p$ で割った余りだけで計算する世界では、話がまったく変わります。素数 $p$ を選んで、$\bmod p$ での因数分解を見てみましょう。

※ 係数を $p$ で割った余りで考えたときの、モニックな多項式への分解を全探索で求めています。

問題の背景

(3) の別解：「根号の一次独立性」

実は、$a,\ b,\ c,\ d$ が有理数のとき

$$a + b\sqrt2 + c\sqrt3 + d\sqrt6 = 0 \ \Longrightarrow\ a = b = c = d = 0$$

が成り立ちます（証明は下の類題で）。これを認めると、(3) の式 $\alpha^2 + p\alpha + q = 0$ は

$$(5 + q) + p\sqrt2 + p\sqrt3 + 2\sqrt6 = 0$$

となり、$\sqrt6$ の係数が $2 \ne 0$ であることから、一瞬で矛盾が出ます。解答例の「2 乗して係数比較」は、この事実を手で確かめている作業だと言えます。

最小多項式と「共役」

(2)(3) と、$\sqrt2+\sqrt3$ が 1 次方程式の解にならない（＝無理数である、(1)）ことを合わせると、

$\sqrt2+\sqrt3$ を解にもつ有理数係数の方程式の最小次数は $4$ であり、$x^4 - 10x^2 + 1 = 0$ がその代表。

ということが分かります。このような多項式を $\sqrt2+\sqrt3$ の最小多項式といいます。（3 次方程式でもダメなことは、下の類題で確かめられます。）

(2) の 4 つの解 $\pm\sqrt2\pm\sqrt3$ は、$\sqrt2$ と $\sqrt3$ の符号をそれぞれ独立に反転したものになっています。有理数の立場からは $\sqrt2$ と $-\sqrt2$ は区別できない（どちらも $x^2=2$ の解）ので、この 4 つは「有理数から見ると見分けがつかない仲間」です。これらを $\sqrt2+\sqrt3$ の共役と呼びます。$a+b\sqrt2$ と $a - b\sqrt2$ が共役であるのと同じ発想を、根号 2 つに拡張したものです。

$\sqrt2+\sqrt3$ だけで $\sqrt2,\ \sqrt3$ が作れる

$\alpha = \sqrt2+\sqrt3$ とすると $\alpha^3 = 11\sqrt2 + 9\sqrt3$ なので、

$$\sqrt2 = \frac{\alpha^3 - 9\alpha}{2},\qquad \sqrt3 = \frac{11\alpha - \alpha^3}{2}$$

が成り立ちます。つまり、$\alpha$ と有理数から四則演算だけで $\sqrt2$ も $\sqrt3$ も作れます。「$\sqrt2$ と $\sqrt3$ の 2 つを有理数に付け加えた世界」は、「$\alpha$ 1 つを付け加えた世界」と同じなのです。大学の代数学では、これを原始元と呼びます。そしてその世界の「広さ」（次元）がちょうど $4$（基底 $1,\ \sqrt2,\ \sqrt3,\ \sqrt6$）であることが、最小多項式の次数 $4$ と対応しています。

素数で割ると必ず分解する

$x^4 - 10x^2 + 1$ は有理数の範囲では分解しないのに、上の図解のとおりどんな素数 $p$ で割った余りの世界でも必ず分解します。これは代数学でよく知られた例です。理由は、実数の範囲で

$$\begin{aligned} x^4 - 10x^2 + 1 &= (x^2 - 2\sqrt2\,x - 1)(x^2 + 2\sqrt2\,x - 1) \\ &= (x^2 - 2\sqrt3\,x + 1)(x^2 + 2\sqrt3\,x + 1) \\ &= (x^2 - 5 - 2\sqrt6)(x^2 - 5 + 2\sqrt6) \end{aligned}$$

と 3 通りに分解できることにあります。$\bmod p$ の世界で $2,\ 3,\ 6$ のどれか 1 つでも「平方数」になれば、対応する分解が使えます。そして「$2$ も $3$ も平方数でないなら、その積 $6$ は平方数になる」という性質（平方剰余の乗法性）があるので、3 つすべてが平方数でない、ということは起こらないのです。

「余りの世界で調べて分解しないなら、整数でも分解しない」は正しいですが、その逆は成り立ちません。本問の多項式は、その反例として有名なものです。

類題紹介

$a,\ b,\ c,\ d$ を有理数とする。$a + b\sqrt2 + c\sqrt3 + d\sqrt6 = 0$ ならば $a = b = c = d = 0$ であることを示せ。ただし，$\sqrt2,\ \sqrt3,\ \sqrt6$ が無理数であることは用いてよい。

（九大 2026　魔改造）

略解

$a + b\sqrt2 = -(c + d\sqrt2)\sqrt3$ と変形する。$c + d\sqrt2 \ne 0$ と仮定すると、$\sqrt3 = u + v\sqrt2$（$u,\ v$ は有理数）と書ける。2 乗して $3 = u^2 + 2v^2 + 2uv\sqrt2$ なので、$\sqrt2$ が無理数であることから $uv = 0$。

  • $v = 0$ なら $\sqrt3 = u$ が有理数となり矛盾。
  • $u = 0$ なら $\sqrt3 = v\sqrt2$ より $\sqrt6 = 2v$ が有理数となり矛盾。

よって $c + d\sqrt2 = 0$、$\sqrt2$ の無理性から $c = d = 0$。すると $a + b\sqrt2 = 0$ より $a = b = 0$。

$\sqrt2 + \sqrt3$ を解にもち，係数がすべて有理数の 3 次方程式は存在しないことを示せ。

（自作）

略解

そのような 3 次式 $g(x)$ があると仮定し、$f(x) = x^4 - 10x^2 + 1$ を $g(x)$ で割った余りを $r(x)$（2 次以下、有理数係数）とする。$f(\alpha) = g(\alpha) = 0$ より $r(\alpha) = 0$。本問 (3) と (1) から $r$ は 2 次でも 1 次でもなく、0 でない定数でもないので $r(x) = 0$。

すると $f(x) = g(x)h(x)$（$h$ は有理数係数の 1 次式）となり、$f(x) = 0$ が有理数解をもつ。しかし (2) の解 $\pm\sqrt2\pm\sqrt3$ はすべて無理数（(1) と同様）なので矛盾。

$\sqrt2 + \sqrt[3]{3}$ を解にもち，係数がすべて有理数の 6 次方程式を 1 つ求めよ。

（九大 2026　魔改造）

略解

$x - \sqrt2 = \sqrt[3]{3}$ の両辺を 3 乗すると $x^3 - 3\sqrt2\,x^2 + 6x - 2\sqrt2 = 3$。$\sqrt2$ を含む項を分離して

$$x^3 + 6x - 3 = \sqrt2\,(3x^2 + 2)$$

両辺を 2 乗して整理すると

$$x^6 - 6x^4 - 6x^3 + 12x^2 - 36x + 1 = 0$$

「消したい根号を片側に集めてから累乗する」のが、本問 (2) と共通する考え方です。
