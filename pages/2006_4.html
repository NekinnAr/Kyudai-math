関数 $f(x) = \left|\left|\sin x - \dfrac12\right| - \dfrac12\right|$ を考える。ただし，$-\pi \le x \le \pi$ とする。さらに，$0 \le a \le \dfrac\pi2$ に対して，$F(a) = \displaystyle\int_0^a f(x)f\left(x - \frac\pi2\right)dx$ とする。このとき次の問いに答えよ。

  1. (1)　$f(x) = 0$ となる $x$ を求めよ。
  2. (2)　関数 $y = f(x)$ のグラフの概形を描け。
  3. (3)　$F(a)$ を求めよ。

（2006 九州大学 前期 理系 第4問）

解答例

二重の絶対値は内側から外します。$\sin x \ge \frac12$ なら $f = 1 - \sin x$，$\sin x < \frac12$ なら $f = |\sin x|$。(3) では $0 \le x \le \frac\pi2$ のとき $f\left(x - \frac\pi2\right) = \cos x$ となり、$a$ と $\frac\pi6$ の大小で場合分けです。

解答例（タップで展開）

(1)

$f(x) = 0 \iff \left|\sin x - \frac12\right| = \frac12 \iff \sin x = 1$ または $\sin x = 0$。$-\pi \le x \le \pi$ より

$$x = -\pi,\ 0,\ \frac\pi2,\ \pi$$

(2)

$\sin x \ge \frac12$（$\frac\pi6 \le x \le \frac{5\pi}6$）のとき $0 \le \sin x - \frac12 \le \frac12$ なので $f(x) = \frac12 - \left(\sin x - \frac12\right) = 1 - \sin x$。

$\sin x < \frac12$ のとき $f(x) = \left|\frac12 - \sin x - \frac12\right| = |\sin x|$。まとめると

$$f(x) = \begin{cases} -\sin x & (-\pi \le x \le 0) \\ \sin x & \left(0 \le x \le \frac\pi6,\ \frac{5\pi}6 \le x \le \pi\right) \\ 1 - \sin x & \left(\frac\pi6 \le x \le \frac{5\pi}6\right) \end{cases}$$

グラフは、$[-\pi,\ 0]$ で高さ 1 のアーチ、$[0,\ \pi]$ では高さ $\frac12$ の山が 2 つ（$x = \frac\pi6,\ \frac{5\pi}6$ で尖り、$x = \frac\pi2$ で 0）となる（下の図解の黒い曲線）。

(3)

$0 \le x \le \frac\pi2$ のとき $-\frac\pi2 \le x - \frac\pi2 \le 0$ なので $f\left(x - \frac\pi2\right) = -\sin\left(x - \frac\pi2\right) = \cos x$。

$0 \le a \le \frac\pi6$ のとき

$$F(a) = \int_0^a\sin x\cos x\,dx = \frac12\sin^2a$$

$\frac\pi6 \le a \le \frac\pi2$ のとき　$F\left(\frac\pi6\right) = \frac18$ なので

$$F(a) = \frac18 + \int_{\pi/6}^{a}(1 - \sin x)\cos x\,dx = \frac18 + \left[\sin x - \frac12\sin^2x\right]_{\pi/6}^{a} = \sin a - \frac12\sin^2a - \frac14$$

動く図解

黒が $y = f(x)$，青の破線が $y = f\left(x - \frac\pi2\right)$（右に $\frac\pi2$ ずらしたもの），赤が積 $f(x)f\left(x - \frac\pi2\right)$ です。$a$ を動かすと塗られた面積が $F(a)$。

問題の背景

絶対値の入れ子は「内側から」

$||u| - c|$ のような入れ子の絶対値は、内側の符号で場合分けしてから外側を見るのが鉄則です。ここでは $\left|\sin x - \frac12\right|$ が $0$ から $\frac32$ まで動き、それから $\frac12$ を引いて折り返すので、「$\sin x$ が $\frac12$ を越える部分だけ逆さに折り返される」形になります。(3) は $f$ を $\frac\pi2$ ずらすと $\sin$ が $\cos$ に変わり、$\sin x\cos x$ の積分（$\sin^2$ の微分形）に持ち込めます。

chopin 先生は「(1) $\sin x - \frac12$ が $\frac12$ か $-\frac12$ になっていればよいです」「(2) $x$ の値による場合分けが当然発生することになります」「(3) $f\left(x - \frac\pi2\right)$ がどの形の関数になるかを考えないといけません。その形は $a$ の値によって変わりますので場合分けです」とコメントしています。

入れ子の絶対値は内側から。$\int\sin x\cos x\,dx = \frac12\sin^2x$，$\int\cos x\,dx = \sin x$ の組合せ。
