$t$ を $0 \lt t \lt 1$ を満たす実数とする。面積が 1 である三角形 $\mathrm{ABC}$ において，辺 $\mathrm{AB},\ \mathrm{BC},\ \mathrm{CA}$ をそれぞれ $2 : 1,\ t : 1 - t,\ 1 : 3$ に内分する点を $\mathrm{D},\ \mathrm{E},\ \mathrm{F}$ とする。また，$\mathrm{AE}$ と $\mathrm{BF}$，$\mathrm{BF}$ と $\mathrm{CD}$，$\mathrm{CD}$ と $\mathrm{AE}$ の交点をそれぞれ $\mathrm{P},\ \mathrm{Q},\ \mathrm{R}$ とする。このとき，以下の問いに答えよ。

  1. (1)　3 直線 $\mathrm{AE},\ \mathrm{BF},\ \mathrm{CD}$ が 1 点で交わるときの $t$ の値 $t_0$ を求めよ。

以下，$t$ は $0 \lt t \lt t_0$ を満たすものとする。

  1. (2)　$\mathrm{AP} = k\mathrm{AE}$，$\mathrm{CR} = l\mathrm{CD}$ を満たす実数 $k,\ l$ をそれぞれ求めよ。
  2. (3)　三角形 $\mathrm{BCQ}$ の面積を求めよ。
  3. (4)　三角形 $\mathrm{PQR}$ の面積を求めよ。

（2016 九州大学 前期 理系 第2問）

解答例

(1) はチェバの定理で即答。(2)(3) は $\vec b = \overrightarrow{\mathrm{AB}}$，$\vec c = \overrightarrow{\mathrm{AC}}$ で交点を表す定番計算。(4) は全体から 3 つの三角形を引く。

解答例（タップで展開）

(1)

チェバの定理より $\dfrac{\mathrm{AD}}{\mathrm{DB}}\cdot\dfrac{\mathrm{BE}}{\mathrm{EC}}\cdot\dfrac{\mathrm{CF}}{\mathrm{FA}} = 2\cdot\dfrac{t}{1 - t}\cdot\dfrac13 = 1$。よって $2t = 3(1 - t)$，$t_0 = \dfrac35$。

(2)

$\vec b = \overrightarrow{\mathrm{AB}}$，$\vec c = \overrightarrow{\mathrm{AC}}$ とおく。$\overrightarrow{\mathrm{AD}} = \frac23\vec b$，$\overrightarrow{\mathrm{AE}} = (1 - t)\vec b + t\vec c$，$\overrightarrow{\mathrm{AF}} = \frac34\vec c$。

P：$\overrightarrow{\mathrm{AP}} = k(1 - t)\vec b + kt\vec c$ が直線 BF 上 $\iff$ $\vec b$ と $\overrightarrow{\mathrm{AF}}$ の係数の和が 1：

$$k(1 - t) + \frac43kt = 1 \quad\therefore\ k = \frac{3}{3 + t}$$

R：$\overrightarrow{\mathrm{AR}} = \overrightarrow{\mathrm{AC}} + l\,\overrightarrow{\mathrm{CD}} = \frac{2l}{3}\vec b + (1 - l)\vec c$ が直線 AE 上 $\iff$ $\vec b,\ \vec c$ の係数の比が $(1 - t) : t$：

$$\frac{2l}{3}\cdot t = (1 - l)(1 - t) \quad\therefore\ l = \frac{3(1 - t)}{3 - t}$$

(3)

Q を CD 上に $\overrightarrow{\mathrm{AQ}} = \frac{2u}{3}\vec b + (1 - u)\vec c$ とおくと、直線 BF 上の条件は $\frac{2u}{3} + \frac43(1 - u) = 1$、すなわち $u = \frac12$。Q は CD の中点で（$t$ によらない）

$$\triangle\mathrm{BCQ} = \frac12\triangle\mathrm{BCD} = \frac12\cdot\frac13 = \frac16$$

(4)

$0 \lt t \lt t_0$ のとき、$\triangle\mathrm{ABC}$ は $\triangle\mathrm{ABP}$，$\triangle\mathrm{BCQ}$，$\triangle\mathrm{CAR}$，$\triangle\mathrm{PQR}$ に分割される。

  • $\triangle\mathrm{ABP} = k\,\triangle\mathrm{ABE} = k\cdot t = \dfrac{3t}{3 + t}$
  • $\triangle\mathrm{CAR} = l\,\triangle\mathrm{CAD} = l\cdot\dfrac23 = \dfrac{2(1 - t)}{3 - t}$
$$\triangle\mathrm{PQR} = 1 - \frac{3t}{3 + t} - \frac16 - \frac{2(1 - t)}{3 - t} = \frac{(5t - 3)^2}{6(9 - t^2)}$$

（$t = t_0 = \frac35$ で $0$ になり、検算になる。）

動く図解

$t$ を動かすと E が辺 BC 上を動き、真ん中の三角形 PQR（赤）が伸び縮みします。$t = \frac35$ で 3 直線が 1 点で交わり、PQR がつぶれます。

問題の背景

チェバの定理とラウスの定理

3 本のチェバ線（頂点と対辺上の点を結ぶ線分）で囲まれる真ん中の三角形の面積には、ラウスの定理という一般公式があります。各辺の比を $\frac{\mathrm{AD}}{\mathrm{DB}} = x$，$\frac{\mathrm{BE}}{\mathrm{EC}} = y$，$\frac{\mathrm{CF}}{\mathrm{FA}} = z$ とすると

$$\frac{\triangle\mathrm{PQR}}{\triangle\mathrm{ABC}} = \frac{(xyz - 1)^2}{(xy + x + 1)(yz + y + 1)(zx + z + 1)}$$

分子の $(xyz - 1)^2$ が 0 になるのがチェバの定理の条件です。本問の答えの分子 $(5t - 3)^2$ もまさにこの形です。

chopin 先生は「(1) は初等幾何で習うチェバの定理を使うのが最も手っ取り早い」「(3) 全体から BCQ，ABP，ACR の面積を引けばよい。答えは (1) の答えを入れると 0 になり、それ以外の $t$ で正になるので、妥当性も十分です」とコメントしています。

交点の位置ベクトルは「直線上の点 $\iff$ 係数の和が 1」で求める。答えが $t = t_0$ で 0 になるかで検算できる。

類題紹介

$\triangle\mathrm{ABC}$ の辺 AB を $1 : 2$，辺 BC を $3 : 1$ に内分する点をそれぞれ D，E とし，AE と CD の交点を P とする。$\mathrm{AP} : \mathrm{PE}$ を求めよ。

（自作）

略解

$\overrightarrow{\mathrm{AP}} = k\overrightarrow{\mathrm{AE}} = \frac k4\vec b + \frac{3k}{4}\vec c = \frac{3k}{4}\overrightarrow{\mathrm{AD}} + \frac{3k}{4}\vec c$（$\overrightarrow{\mathrm{AD}} = \frac13\vec b$）。直線 CD 上なので $\frac{3k}{4} + \frac{3k}{4} = 1$，$k = \frac23$。$\mathrm{AP} : \mathrm{PE} = 2 : 1$。

本問で $t_0 \lt t \lt 1$ の場合も，三角形 PQR の面積は (4) と同じ式 $\dfrac{(5t - 3)^2}{6(9 - t^2)}$ で表されることを示せ。また，$0 \lt t \lt 1$ における PQR の面積の取りうる値の範囲を求めよ。

（九大 2016　魔改造）

略解

$t_0 \lt t$ では 3 本の線分の交わり方が変わり、(4) の「4 つに分割」はそのままでは使えない。しかし (2)(3) の計算は $t$ の範囲によらず成り立つので、$\vec b,\ \vec c$ を基底とする座標で

$$\mathrm{P}\left(\tfrac{3(1-t)}{3+t},\ \tfrac{3t}{3+t}\right),\quad \mathrm{Q}\left(\tfrac13,\ \tfrac12\right),\quad \mathrm{R}\left(\tfrac{2(1-t)}{3-t},\ \tfrac{2t}{3-t}\right)$$

と表せる。$\triangle\mathrm{ABC}$ の面積が 1（基底 $\vec b,\ \vec c$ の平行四辺形の面積が 2）なので、$\triangle\mathrm{PQR} = |\det(\overrightarrow{\mathrm{PQ}},\ \overrightarrow{\mathrm{PR}})|$ で、計算すると $\dfrac{(5t-3)^2}{6(9-t^2)}$ となり、$t$ の範囲によらない（図解で $t \gt 0.6$ にして確認できる）。

$f(t) = \frac{(5t - 3)^2}{6(9 - t^2)}$ は $t = \frac35$ で最小値 0。$f'(t)$ の分子は $(5t - 3)\{10(9 - t^2) + 2t(5t - 3)\} = (5t - 3)(90 - 6t)$ で、$0 \lt t \lt \frac35$ で減少、$\frac35 \lt t \lt 1$ で増加。$f(0) = \frac16$，$f(1) = \frac1{12}$ なので、値の範囲は

$$0 \le \triangle\mathrm{PQR} \lt \frac16$$
