$\theta$ を $0 \lt \theta \lt \dfrac{\pi}{4}$ をみたす定数とし，$x$ の 2 次方程式

$$x^2 - (4\cos\theta)x + \frac{1}{\tan\theta} = 0\qquad\cdots\cdots (*)$$

を考える。以下の問いに答えよ。

  1. (1)　2 次方程式 $(*)$ が実数解をもたないような $\theta$ の値の範囲を求めよ。
  2. (2)　$\theta$ が (1) で求めた範囲にあるとし，$(*)$ の 2 つの虚数解を $\alpha,\ \beta$ とする。ただし，$\alpha$ の虚部は $\beta$ の虚部より大きいとする。複素数平面上の 3 点 $\mathrm{A}(\alpha)$，$\mathrm{B}(\beta)$，$\mathrm{O}(0)$ を通る円の中心を $\mathrm{C}(\gamma)$ とするとき，$\theta$ を用いて $\gamma$ を表せ。
  3. (3)　点 $\mathrm{O}$，$\mathrm{A}$，$\mathrm{C}$ を (2) のように定めるとき，三角形 $\mathrm{OAC}$ が直角三角形になるような $\theta$ に対する $\tan\theta$ の値を求めよ。

（2021 九州大学 前期 理系 第2問）

解答例

実数係数の 2 次方程式の虚数解は互いに共役なので、A と B は実軸に関して対称。よって外接円の中心 C は実軸上にある。(3) は $\mathrm{CO} = \mathrm{CA}$（ともに半径）に注目すると、直角になれるのは C の角だけ。

解答例（タップで展開）

(1)

判別式を $D$ とすると

$$\frac D4 = 4\cos^2\theta - \frac{\cos\theta}{\sin\theta} = \frac{\cos\theta}{\sin\theta}(4\sin\theta\cos\theta - 1) = \frac{\cos\theta}{\sin\theta}(2\sin 2\theta - 1)$$

$0 \lt \theta \lt \frac{\pi}{4}$ で $\frac{\cos\theta}{\sin\theta} \gt 0$ なので、$D \lt 0 \iff \sin 2\theta \lt \frac12$。$0 \lt 2\theta \lt \frac{\pi}{2}$ より $2\theta \lt \frac{\pi}{6}$。

$$0 \lt \theta \lt \frac{\pi}{12}$$

(2)

$\alpha,\ \beta$ は共役で、$\alpha = p + qi$，$\beta = p - qi$（$q \gt 0$）とおくと、解と係数の関係より

$$\alpha + \beta = 2p = 4\cos\theta,\qquad \alpha\beta = p^2 + q^2 = \frac{1}{\tan\theta}$$

A，B は実軸に関して対称なので、線分 AB の垂直二等分線は実軸。C はその上にあるので $\gamma$ は実数。$|\gamma| = |\gamma - \alpha|$ より

$$\gamma^2 = (\gamma - p)^2 + q^2 \iff 2p\gamma = p^2 + q^2 \iff \gamma = \frac{p^2 + q^2}{2p} = \frac{\cos\theta/\sin\theta}{4\cos\theta}$$ $$\gamma = \frac{1}{4\sin\theta}$$

(3)

C は円の中心なので $\mathrm{CO} = \mathrm{CA}$。もし $\angle\mathrm{COA} = 90^\circ$ なら斜辺 CA が CO より長くなり矛盾。$\angle\mathrm{CAO} = 90^\circ$ も同様に不可。よって $\angle\mathrm{OCA} = 90^\circ$。

$\gamma \gt 0$ で、$\overrightarrow{\mathrm{CA}}$ は $\overrightarrow{\mathrm{CO}} = -\gamma$ を $\pm90^\circ$ 回転したもの。$\alpha$ の虚部は正なので $\alpha - \gamma = \gamma i$、すなわち $\alpha = \gamma + \gamma i$。実部を比べて

$$p = 2\cos\theta = \gamma = \frac{1}{4\sin\theta} \iff 8\sin\theta\cos\theta = 1 \iff \sin 2\theta = \frac14$$

（このとき $q = \gamma$ も自動的に成り立つ：$p^2 + q^2 = 2p\gamma = 2\gamma^2$ より $q^2 = \gamma^2$。）$\sin 2\theta = \frac14 \lt \frac12$ で (1) の範囲内。$t = \tan\theta$ とおくと $\sin 2\theta = \dfrac{2t}{1 + t^2} = \dfrac14$ より $t^2 - 8t + 1 = 0$、$t = 4 \pm \sqrt{15}$。$0 \lt \theta \lt \frac{\pi}{12}$ より $0 \lt t \lt \tan\frac{\pi}{12} = 2 - \sqrt3 \lt 1$ なので

$$\tan\theta = 4 - \sqrt{15}$$

動く図解

$\theta$ を動かすと、虚数解 $\alpha,\ \beta$ と円の中心 C が動きます。$\theta \ge 15^\circ$ では実数解になり、図が消えます。∠OCA が $90^\circ$ になる $\theta$ を探してみましょう。

問題の背景

3 点 O，$\alpha$，$\bar\alpha$ を通る円

(2) の結果は、一般に「$\gamma = \dfrac{|\alpha|^2}{2\,\mathrm{Re}\,\alpha} = \dfrac{\alpha\beta}{\alpha + \beta}$」と書けます。解と係数の関係をそのまま使える形で、$\frac{1}{\gamma} = \frac1\alpha + \frac1\beta$ とも書けます（調和平均の半分）。

二等辺三角形なら直角は頂角だけ

chopin 先生は「直角になる角度が 3 通りあるので場合分けして検討しましょう」と解説していますが、三角形 OAC は $\mathrm{CO} = \mathrm{CA}$ の二等辺三角形なので、底角（$\angle$O，$\angle$A）が $90^\circ$ になることはありません。図形的な性質を使うと場合分けを減らせます。

実数係数の方程式の虚数解は共役 → 図形は実軸に関して対称。この一言で、外接円の中心が実軸上にあることが分かります。

類題紹介

複素数 $\alpha$（虚部は正，実部は正）について，3 点 $0,\ \alpha,\ \bar\alpha$ を通る円の中心 $\gamma$ を $\alpha$ と $\bar\alpha$ で表せ。

（自作）

略解

$\gamma$ は実数で $|\gamma| = |\gamma - \alpha|$。両辺を 2 乗して $\gamma^2 = \gamma^2 - \gamma(\alpha + \bar\alpha) + \alpha\bar\alpha$ より

$$\gamma = \frac{\alpha\bar\alpha}{\alpha + \bar\alpha}$$

本問の点 $\mathrm{O}$，$\mathrm{A}$，$\mathrm{C}$ について，三角形 $\mathrm{OAC}$ が正三角形になるような $\theta$ に対する $\tan\theta$ の値を求めよ。

（九大 2021　魔改造）

略解

$\mathrm{CO} = \mathrm{CA}$ なので、正三角形 $\iff \mathrm{OA} = \mathrm{OC} \iff |\alpha|^2 = \gamma^2$。$|\alpha|^2 = 2p\gamma$ より $2p = \gamma$、つまり $4\cos\theta = \dfrac{1}{4\sin\theta}$、$\sin 2\theta = \dfrac18$（(1) の範囲内）。$\dfrac{2t}{1 + t^2} = \dfrac18$ より $t^2 - 16t + 1 = 0$、小さい方をとって

$$\tan\theta = 8 - 3\sqrt7$$
