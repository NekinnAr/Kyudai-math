$f(x) = xe^x$ とおく。また $p$ を $p \ge 0$ を満たす数とし，曲線 $y = f(x)$ 上の点 $P(p,\ f(p))$ における接線の方程式を $y = g(x)$ とおく。ただし，$e$ は自然対数の底である。このとき，次の問いに答えよ。

  1. (1)　$x \ge 0$ において $f(x) \ge g(x)$ が成り立つことを示せ。
  2. (2)　$L$ を正の数とする。曲線 $y = f(x)$，接線 $y = g(x)$，および 2 直線 $x = 0$，$x = L$ で囲まれた部分の面積を $S(p)$ とするとき，$p \ge 0$ における $S(p)$ の最小値を与える $p$ の値を求めよ。

（2007 九州大学 前期 理系 第1問）

解答例

(1) は「下に凸な関数のグラフは接線より上」。(2) は $\int f$ が $p$ によらないので、$\int_0^L g\,dx$ を最大にすればよく、これを $p$ で微分すると $f''(p)\left(\frac L2 - p\right)$ というきれいな形になります。

解答例（タップで展開）

(1)

$f'(x) = (x + 1)e^x$，$f''(x) = (x + 2)e^x$。$g(x) = f'(p)(x - p) + f(p)$。$h(x) = f(x) - g(x)$ とおくと

$$h'(x) = f'(x) - f'(p),\qquad h''(x) = f''(x) > 0\ (x \ge 0)$$

$h'$ は $x \ge 0$ で増加し $h'(p) = 0$ なので、$0 \le x < p$ で $h' < 0$，$x > p$ で $h' > 0$。$h$ は $x = p$ で最小値 $h(p) = 0$ をとるので $h(x) \ge 0$，すなわち $f(x) \ge g(x)$。

(2)

(1) より

$$S(p) = \int_0^L f(x)\,dx - \int_0^L g(x)\,dx$$

第 1 項は $p$ によらないので、$G(p) = \displaystyle\int_0^L g(x)\,dx$ を最大にすればよい。

$$G(p) = \int_0^L\{f'(p)(x - p) + f(p)\}dx = L\left\{f'(p)\left(\frac L2 - p\right) + f(p)\right\}$$ $$G'(p) = L\left\{f''(p)\left(\frac L2 - p\right) - f'(p) + f'(p)\right\} = Lf''(p)\left(\frac L2 - p\right)$$

$f''(p) > 0$ なので、$G$ は $0 \le p \le \frac L2$ で増加，$p \ge \frac L2$ で減少。よって $S(p)$ を最小にする $p$ は

$$p = \frac L2$$

動く図解

$p$ を動かすと接線と面積 $S(p)$（赤）が変わります。右のグラフは $S(p)$ の値で、区間の真ん中 $p = \frac L2$ で最小になります。

問題の背景

下に凸なら「真ん中で接する」のが最善

計算から分かるように、$f''(p) > 0$（下に凸）でありさえすれば、$f$ が何であっても答えは $p = \frac L2$ です。実は $\int_0^L g\,dx = L\cdot g\left(\frac L2\right)$（1 次関数の平均は中点での値）なので、「接線の中点での高さ $g\left(\frac L2\right)$ を最大にする」問題と同じ。下に凸な曲線の接線が直線 $x = \frac L2$ と交わる点は、接点がちょうど $x = \frac L2$ のときに最も高くなります（凸関数の接線は曲線の下にあるから）。

chopin 先生は「(1) 直接微分して調べても OK ですが、$f(x)$ が $x \ge 0$ で下に凸なことを言えれば証明できたことになります」「(2) (1) で、$f$ と $g$ の上下関係が変わらないことを示しているので、区間分けの必要もなく素直に積分計算できます」とコメントしています。

凸関数のグラフは接線の上。$\int_a^b(1\text{次関数})dx = (b - a)\times(\text{中点での値})$。

類題紹介

放物線 $y = x^2$ 上の点 $(p,\ p^2)$ における接線と，放物線および 2 直線 $x = 0$，$x = 2$ で囲まれた部分の面積の最小値を求めよ。

（自作）

略解

放物線と接線の差は $(x - p)^2$ なので $S(p) = \displaystyle\int_0^2(x - p)^2dx = \frac{(2 - p)^3 + p^3}{3} = 2p^2 - 4p + \frac83$。$p = 1$ で最小値 $\dfrac23$。

本問の $f(x) = xe^x$ について，$p$ を $-1 \le p \le 1$ の範囲で動かす。曲線 $y = f(x)$，点 $(p,\ f(p))$ における接線，2 直線 $x = -1$，$x = 1$ で囲まれた部分の面積の最小値を求めよ。

（九大 2007　魔改造）

略解

$f''(x) = (x + 2)e^x > 0$（$x > -2$）なので $[-1,\ 1]$ でも下に凸で、本問と同じ議論から中点 $p = 0$ で最小。接線は $y = x$ なので

$$S(0) = \int_{-1}^{1}(xe^x - x)\,dx = \Big[(x - 1)e^x\Big]_{-1}^{1} - 0 = \frac2e$$
