$t$ を実数とするとき，2 次方程式 $z^2 + tz + t = 0$ について，次の問いに答えよ。

  1. (1)　この 2 次方程式が異なる 2 つの虚数解をもつような $t$ の範囲と，そのときの虚数解をすべて求めよ。
  2. (2)　(1) の虚数解のうち，その虚部が正のものを $z(t)$ で表す。$t$ が (1) で求めた範囲を動くとき，複素数平面上で点 $z(t)$ が描く図形 $C$ を求め，図示せよ。
  3. (3)　複素数平面上で，点 $z$ が (2) の図形 $C$ 上を動くとき，$w = \dfrac{iz}{z + 1}$ で表される点 $w$ が描く図形を求め，図示せよ。

（2005 九州大学 前期 理系 第3問）

解答例

(2) は $z = x + yi$ とおいて $t$ を消去すると円 $(x + 1)^2 + y^2 = 1$ の上半分。(3) は $z + 1 = \cos\theta + i\sin\theta$ とおけば $w$ が直接計算でき、別の半円になります。端点が含まれるかどうかに注意。

解答例（タップで展開）

(1)

判別式 $t^2 - 4t < 0$ より $0 < t < 4$。このとき

$$z = \frac{-t \pm \sqrt{4t - t^2}\,i}{2}$$

(2)

$z(t) = x + yi$ とすると $x = -\dfrac t2$，$y = \dfrac{\sqrt{4t - t^2}}{2} > 0$。$t = -2x$ を代入して

$$y^2 = \frac{-8x - 4x^2}{4} = -2x - x^2\quad\therefore\ (x + 1)^2 + y^2 = 1$$

$0 < t < 4$ より $-2 < x < 0$，$y > 0$。よって $C$ は点 $-1$ を中心とする半径 1 の円の $y > 0$ の部分（両端 $0$，$-2$ を除く上半円）。

(3)

$C$ 上の点は $z + 1 = \cos\theta + i\sin\theta\ (0 < \theta < \pi)$ と表せる。

$$w = \frac{i(z + 1 - 1)}{z + 1} = i\left(1 - \frac{1}{\cos\theta + i\sin\theta}\right) = i\{1 - (\cos\theta - i\sin\theta)\} = -\sin\theta + i(1 - \cos\theta)$$

$w = u + vi$ とすると $u = -\sin\theta$，$v - 1 = -\cos\theta$ なので $u^2 + (v - 1)^2 = 1$。$0 < \theta < \pi$ より $u = -\sin\theta < 0$ で、逆に $u < 0$ を満たす円周上の点はすべて現れる。よって $w$ の描く図形は点 $i$ を中心とする半径 1 の円の $u < 0$ の部分（両端 $0$，$2i$ を除く左半円）。

動く図解

$t$ を動かすと、左の $z$ 平面で 2 つの虚数解（赤が $z(t)$）が、右の $w$ 平面で対応する $w$ が動きます。

問題の背景

1 次分数変換は円を円に移す

$w = \frac{az + b}{cz + d}$ の形の変換（1 次分数変換・メビウス変換）は「円または直線」を「円または直線」に移します。ここでは $w = i\left(1 - \frac1{z + 1}\right)$ と分解すると、平行移動 → 反転 $\frac1{z+1}$ → 平行移動・回転の組合せ。$|z + 1| = 1$ の円は反転 $\frac1{z+1}$ で単位円（向き逆）に移り、それを $1$ から引いて $i$ 倍（90° 回転）したものが答えです。

chopin 先生は「(1) は教科書レベルでしょう。判別式 $< 0$ です」「(2) $z$ の実部を $x$、虚部を $y$ として $t$ を消去しましょう」「(3) (2) の結果から、$z = (\cos\theta - 1) + i\sin\theta$ と書くことができますので、最終的に $\theta$ が消えるように計算をしましょう。$w$ の実部と虚部のとりうる値の範囲には注意です」とコメントしています。

軌跡は「パラメータ消去」＋「範囲の確認」。円上の点は $\cos\theta + i\sin\theta$ で表すと計算が楽。

類題紹介

点 $z$ が円 $|z + 1| = 1$ 上の原点以外の部分を動くとき，$w = \dfrac1z$ の描く図形を求めよ。

（自作）

略解

$|z + 1|^2 = 1$ より $z\bar z + z + \bar z = 0$。$z = \frac1w$ を代入し $w\bar w$ をかけると $1 + \bar w + w = 0$，すなわち $\mathrm{Re}\,w = -\dfrac12$。直線 $\mathrm{Re}\,w = -\frac12$ 全体。

本問 (3) の変換を $w = \dfrac{z}{z + 1}$ に変えたとき，点 $z$ が $C$ 上を動くときの $w$ の描く図形を求めよ。

（九大 2005　魔改造）

略解

$w = 1 - \dfrac1{z + 1} = 1 - \cos\theta + i\sin\theta\ (0 < \theta < \pi)$。$|w - 1| = 1$ で虚部 $\sin\theta > 0$。点 $1$ を中心とする半径 1 の円の上半分（両端 $0$，$2$ を除く）。本問の答えを $-i$ 倍（$-90°$ 回転）したものになっています。
