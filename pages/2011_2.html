$a$ を正の定数とする。以下の問いに答えよ。

  1. (1)　関数 $f(x) = (x^2 + 2x + 2 - a^2)e^{-x}$ の極大値および極小値を求めよ。
  2. (2)　$x \ge 3$ のとき，不等式 $x^3e^{-x} \le 27e^{-3}$ が成り立つことを示せ。さらに，極限値 $\displaystyle\lim_{x\to\infty}x^2e^{-x}$ を求めよ。
  3. (3)　$k$ を定数とする。$y = x^2 + 2x + 2$ のグラフと $y = ke^x + a^2$ のグラフが異なる 3 点で交わるための必要十分条件を，$a$ と $k$ を用いて表せ。

（2011 九州大学 前期 理系 第2問）

解答例

(3) は連立すると $(x^2 + 2x + 2 - a^2)e^{-x} = k$，つまり $y = f(x)$ と $y = k$ の共有点の問題です。$x \to \infty$ で $f(x) \to 0$（(2) の極限）なので、$k > 0$ が必要になるのがポイント。極小値の符号で場合分けします。

解答例（タップで展開）

(1)

$$f'(x) = \{(2x + 2) - (x^2 + 2x + 2 - a^2)\}e^{-x} = (a^2 - x^2)e^{-x} = -(x + a)(x - a)e^{-x}$$

$f$ は $x < -a$ で減少，$-a < x < a$ で増加，$x > a$ で減少。

$$\text{極大値 } f(a) = 2(a + 1)e^{-a},\qquad \text{極小値 } f(-a) = 2(1 - a)e^{a}$$

(2)

$g(x) = x^3e^{-x}$ とおくと $g'(x) = x^2(3 - x)e^{-x} \le 0$（$x \ge 3$）なので $g$ は $x \ge 3$ で減少し、$g(x) \le g(3) = 27e^{-3}$。

よって $x \ge 3$ で $0 < x^2e^{-x} \le \dfrac{27e^{-3}}{x}$。右辺 $\to 0$ なので、はさみうちの原理より

$$\lim_{x\to\infty}x^2e^{-x} = 0$$

(3)

$x^2 + 2x + 2 = ke^x + a^2 \iff f(x) = k$。共有点の個数は $y = f(x)$ と $y = k$ の共有点の個数に等しい。

(2) より $x \to \infty$ で $f(x) = (x^2 e^{-x})\left(1 + \frac2x + \frac{2 - a^2}{x^2}\right) \to 0$，また $x \to -\infty$ で $f(x) \to \infty$。$x > a$ では $f(x) > 0$（$x^2 + 2x + 2 - a^2 = (x + 1)^2 + 1 - a^2 > (a + 1)^2 - a^2 > 0$）。

したがって $f$ のとる値は

  • $x < -a$：$f(-a) < f(x)$ の範囲を 1 回ずつ
  • $-a \le x \le a$：$f(-a) \le f(x) \le f(a)$ を 1 回ずつ
  • $x > a$：$0 < f(x) < f(a)$ を 1 回ずつ

3 点で交わるのは、3 つの区間すべてで解をもつとき、すなわち $f(-a) < k < f(a)$ かつ $k > 0$ のとき。

  • $0 < a \le 1$ のとき（極小値 $\ge 0$）：$2(1 - a)e^{a} < k < 2(1 + a)e^{-a}$
  • $a > 1$ のとき（極小値 $< 0$）：$0 < k < 2(1 + a)e^{-a}$

動く図解

$a$ と $k$ を動かすと、$y = f(x)$（赤）と $y = k$（緑）の共有点の個数が表示されます。$a > 1$ で $k \le 0$ にすると、右側の山すそ（$x \to \infty$ で $0$ に近づく部分）と交わらなくなる様子が分かります。

問題の背景

漸近線が見えるかどうか

$e^{-x}$ を含む関数のグラフは、$x \to \infty$ で $x$ 軸に漸近することが多く、「極大値より小さい $k$ なら必ず右側で交わる」わけではありません。$y = 0$ が漸近線なので、$k \le 0$ では右側で交わらない。これを見落とすと $a > 1$ の答えを $f(-a) < k < f(a)$ と書いてしまいます。

(2) の不等式 $x^3e^{-x} \le 27e^{-3}$ は、$\displaystyle\lim_{x\to\infty}x^2e^{-x} = 0$ をはさみうちで示すための誘導。「$x^3e^{-x}$ が有界 ⇒ $x^2e^{-x} = \frac{x^3e^{-x}}{x} \to 0$」という、1 次分だけ余裕を持たせる典型手法です。

chopin 先生は「(1) は素直に微分して増減を調べます」「(2) $x^2e^{-x}$ の極限は、先に示した不等式を使ってはさみうちの定理です」「(3) は、2 つの式を連立すると、$f(x) = k$ となり、(1) がつかえる格好になります。…極小値が 0 になるかプラスになるかマイナスになるかで場合分けが発生することになります」とコメントしています。

文字定数は分離して $f(x) = k$ に。グラフをかくときは極値だけでなく両端の極限（漸近線）も必ず確認。

類題紹介

$x$ の方程式 $x^2e^{-x} = k$ の異なる実数解の個数を，定数 $k$ の値によって分類せよ。ただし $\displaystyle\lim_{x\to\infty}x^2e^{-x} = 0$ は用いてよい。

（自作）

略解

$h(x) = x^2e^{-x}$，$h'(x) = x(2 - x)e^{-x}$。極小 $h(0) = 0$，極大 $h(2) = 4e^{-2}$，$x \to -\infty$ で $\infty$，$x \to \infty$ で $0$。

$k < 0$：0 個，$k = 0$：1 個，$0 < k < 4e^{-2}$：3 個，$k = 4e^{-2}$：2 個，$k > 4e^{-2}$：1 個。

本問 (3) で，2 つのグラフがちょうど 2 点で共有点をもつ（接する場合を含む）ための必要十分条件を，$a$ と $k$ を用いて表せ。

（九大 2011　魔改造）

略解

$M = 2(1 + a)e^{-a}$，$m = 2(1 - a)e^{a}$ とし、上の 3 区間ごとの値域で数えます。$k = M$ のときはどの $a$ でも 2 個（$x = a$ と $x < -a$ の 1 点）。それ以外では

  • $0 < a < 1$（$m > 0$）：$k = m$ のとき、$x = -a$ と $x > a$ の 1 点で 2 個。
  • $a = 1$（$m = 0$）：$k = 0$ は $x = -1$ の 1 個なので、追加なし。
  • $a > 1$（$m < 0$）：$m < k \le 0$ のとき、$x < -a$ と $-a < x < a$ に 1 個ずつで 2 個。

まとめて：$k = 2(1 + a)e^{-a}$，または $\{0 < a < 1$ かつ $k = 2(1 - a)e^a\}$，または $\{a > 1$ かつ $2(1 - a)e^a < k \le 0\}$。
