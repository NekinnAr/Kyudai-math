区間 $[a,\ b]$ が関数 $f(x)$ に関して不変であるとは，$a \le x \le b$ ならば，$a \le f(x) \le b$ が成り立つこととする。$f(x) = 4x(1 - x)$ とするとき，次の問いに答えよ。

  1. (1)　区間 $[0,\ 1]$ は関数 $f(x)$ に関して不変であることを示せ。
  2. (2)　$0 < a < b < 1$ とする。このとき，区間 $[a,\ b]$ は関数 $f(x)$ に関して不変ではないことを示せ。

（2006 九州大学 前期 理系 第5問）

※ 参照した問題画像では大問番号が「6」と表記されていますが、本サイトでは第5問として掲載しています。

解答例

不変だと仮定して矛盾を導きます。頂点 $x = \frac12$（$f = 1$）が区間に入るか、区間が $\frac12$ の左か右かで場合分け。右側では不動点 $x = \frac34$ が鍵で、そこでの傾き $f'\left(\frac34\right) = -2$（絶対値が 1 より大きい）が「区間が広がってしまう」原因です。

解答例（タップで展開）

(1)

$f(x) = 1 - (2x - 1)^2$。$0 \le x \le 1$ なら $0 \le (2x - 1)^2 \le 1$ なので $0 \le f(x) \le 1$。よって $[0,\ 1]$ は不変。

(2)

$[a,\ b]$ が不変であると仮定して矛盾を導く。$f(x) - x = x(3 - 4x)$ より、$0 < x < \frac34$ で $f(x) > x$，$\frac34 < x < 1$ で $f(x) < x$。

(i) $a \le \frac12 \le b$ のとき：$f\left(\frac12\right) = 1 > b$ となり矛盾。

(ii) $b < \frac12$ のとき：$b < \frac34$ より $f(b) > b$ となり矛盾。

(iii) $a > \frac12$ のとき：$b < \frac34$ なら $f(b) > b$，$a > \frac34$ なら $f(a) < a$ で矛盾するので、$a \le \frac34 \le b$。$a = \frac34 - u$，$b = \frac34 + v$（$0 \le u < \frac14$，$v \ge 0$，$u + v > 0$）とおくと

$$f\left(\tfrac34 + t\right) = \tfrac34 - 2t - 4t^2$$

より $f(a) = \frac34 + 2u - 4u^2$，$f(b) = \frac34 - 2v - 4v^2$。不変性から $f(a) \le b$，$f(b) \ge a$ なので

$$2u - 4u^2 \le v,\qquad 2v + 4v^2 \le u$$

第 2 式から $u \ge 2v$。$u > 0$ のとき、$u < \frac14$ より $2u - 4u^2 = 2u(1 - 2u) > u$ なので第 1 式から $v > u \ge 2v$，すなわち $v < 0$ となり矛盾。$u = 0$ のときは第 2 式から $v = 0$ となり $u + v > 0$ に矛盾。

以上より、$[a,\ b]$ は不変ではない。

動く図解

$a$，$b$ を動かすと、正方形 $[a,\ b]\times[a,\ b]$ が表示されます。グラフ（赤い部分）がこの正方形からはみ出したら「不変でない」。どう動かしても、$0 < a < b < 1$ では必ずはみ出します。

問題の背景

ロジスティック写像とカオス

$f(x) = 4x(1 - x)$ は「ロジスティック写像」$x \mapsto rx(1 - x)$ の $r = 4$ の場合で、カオス力学系の代表例です。$x_{n+1} = f(x_n)$ を繰り返すと、$[0,\ 1]$ の中を不規則に動き回ります（$x = \sin^2\theta$ とおくと $f(x) = \sin^2 2\theta$ となり、角度の 2 倍写像そのもの）。本問 (2) は「$[0,\ 1]$ より小さい閉じこもる区間が存在しない」ことを示していて、これがカオス的に動き回る理由の一端です。不動点 $\frac34$ での傾きが $-2$ なので、近くの点ははじき出されてしまいます。

chopin 先生は「定義域と値域が一致するかを考える問題です」「(1) $f(x)$ のグラフを書けば明らかでしょう」「(2) は $a$ と $b$ の間に $f(x)$ の軸が来るか否かによる場合分けが必要で、その都度 $f(a) = a$ かつ $f(b) = b$ になるか、あるいは $f(a) = b$ かつ $f(b) = a$ になるかを考えないといけません。特に後者の検討が難しいポイントです」とコメントしています。

不変区間の判定：区間上の $f$ の最大・最小が区間に収まるか。$y = x$ との上下関係（不動点）が手がかり。

類題紹介

$f(x) = x^2$ とする。$0 \le a < b$ を満たす区間 $[a,\ b]$ で，$f(x)$ に関して不変であるものをすべて求めよ。

（自作）

略解

$f$ は $[a,\ b]$ で増加なので、条件は $a^2 \ge a$ かつ $b^2 \le b$。$b \le 1$ より $a < 1$ だから $a^2 \ge a$ は $a = 0$ のみ。よって $[0,\ b]$（$0 < b \le 1$）。

$f(x) = 2x(1 - x)$ とする。$0 \le a < b \le 1$ のとき，区間 $[a,\ b]$ が $f(x)$ に関して不変となるための $a$，$b$ の条件を求めよ。

（九大 2006　魔改造）

略解

$f$ の最大値は $f\left(\frac12\right) = \frac12$，不動点は $0$ と $\frac12$（そこでの傾き $0$ で、今度は引きつける）。$b < \frac12$ なら $f(b) > b$ で不可。$a \ge \frac12$ なら $f(b) < \frac12 \le a$ で不可。$a < \frac12 \le b$ なら値域は $\left[\min(f(a), f(b)),\ \frac12\right]$ で、$f(a) \ge a$ は自動的に成り立つから、条件は

$$\frac12 \le b \le 1,\qquad a \le 2b(1 - b)$$
