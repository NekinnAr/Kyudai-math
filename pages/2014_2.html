以下の問いに答えよ。

  1. (1)　任意の自然数 $a$ に対し，$a^2$ を 3 で割った余りは 0 か 1 であることを証明せよ。
  2. (2)　自然数 $a,\ b,\ c$ が $a^2 + b^2 = 3c^2$ を満たすと仮定すると，$a,\ b,\ c$ はすべて 3 で割り切れなければならないことを証明せよ。
  3. (3)　$a^2 + b^2 = 3c^2$ を満たす自然数 $a,\ b,\ c$ は存在しないことを証明せよ。

（2014 九州大学 前期 理系 第2問）

解答例

平方数を 3 で割った余りは 0 か 1。和が 3 の倍数になるのは両方 0 のときだけ。(3) は (2) を繰り返す無限降下法（最小性による背理法）。

解答例（タップで展開）

(1)

$a = 3n,\ 3n \pm 1$（$n$ は整数）と表せる。$a^2 = 9n^2$，$9n^2 \pm 6n + 1 = 3(3n^2 \pm 2n) + 1$ より、余りは 0 か 1。

(2)

右辺は 3 の倍数なので $a^2 + b^2 \equiv 0 \pmod 3$。(1) より $a^2,\ b^2$ の余りは 0 か 1 なので、和の余りは $0 + 0 = 0$，$0 + 1 = 1$，$1 + 1 = 2$ のいずれか。0 になるのは $a^2 \equiv b^2 \equiv 0$ のときだけで、3 は素数だから $3 \mid a$，$3 \mid b$。

$a = 3a'$，$b = 3b'$ とおくと $9(a'^2 + b'^2) = 3c^2$，すなわち $c^2 = 3(a'^2 + b'^2)$。よって $3 \mid c^2$ で、$3 \mid c$。

(3)

解が存在すると仮定し、その中で $c$ が最小のものを $(a,\ b,\ c)$ とする。(2) より $a = 3a'$，$b = 3b'$，$c = 3c'$（$a',\ b',\ c'$ は自然数）と書けて、代入すると

$$9a'^2 + 9b'^2 = 27c'^2 \iff a'^2 + b'^2 = 3c'^2$$

$(a',\ b',\ c')$ も解で、$c' = \frac c3 \lt c$。これは $c$ の最小性に矛盾する。よって自然数解は存在しない。

動く図解

左は $a,\ b$ を 3 で割った余りごとの $a^2 + b^2$ の余りの表、右は $a^2 + b^2 = kc^2$ の自然数解を $c \le 50$ の範囲で探した結果です。$k$ を変えて比べてみましょう。

問題の背景

無限降下法と円上の有理点

「解があれば、もっと小さい解がつくれる」→「自然数は無限に小さくできない」→ 矛盾、という論法を無限降下法といい、フェルマーが $x^4 + y^4 = z^4$ の解なしを示すのに使ったことで有名です。

$a^2 + b^2 = 3c^2$ を $c^2$ で割ると $\left(\frac ac\right)^2 + \left(\frac bc\right)^2 = 3$。つまり本問は「円 $x^2 + y^2 = 3$ 上には有理点が 1 つもない」ことと同じです。一方 $x^2 + y^2 = 2$ には $(1,\ 1)$，$\left(\frac15,\ \frac75\right)$ などの有理点が無数にあります。一般に自然数 $k$ について、$x^2 + y^2 = k$ が有理点をもつのは「$k$ を素因数分解したとき、4 で割って 3 余る素数がすべて偶数乗で現れる」ときに限られます（$k = 3,\ 6,\ 7,\ 11$ は解なし、$k = 2,\ 5,\ 10,\ 13$ は解あり。図解で確かめられます）。

chopin 先生は「(2) 左辺を 3 で割った余りがどうなるかを調べます」「(3) この議論を繰り返すと、$a,\ b,\ c$ はすべて 3 で何回でも割り切れる自然数ということになってしまい矛盾です。このような証明方法は『無限降下法』と呼ばれています」とコメントしています。

平方数の余り：mod 3 で $\{0, 1\}$，mod 4 で $\{0, 1\}$，mod 8 で $\{0, 1, 4\}$。「解なし」の証明は余りで絞るか最小の解を考えて背理法。

類題紹介

$x^2 - 3y^2 = 2$ を満たす整数 $x,\ y$ は存在しないことを示せ。

（自作）

略解

両辺を 3 で割った余りを比べると $x^2 \equiv 2 \pmod 3$。しかし平方数の余りは 0 か 1 なので矛盾。

$a^2 + b^2 = 7c^2$ を満たす自然数 $a,\ b,\ c$ は存在しないことを証明せよ。

（九大 2014　魔改造）

略解

平方数を 7 で割った余りは $0^2,\ 1^2,\ \cdots,\ 6^2$ より $\{0,\ 1,\ 2,\ 4\}$。2 つの和が $0 \pmod 7$ になるのは $0 + 0$ だけ（$1 + 6$，$2 + 5$，$4 + 3$ は 6, 5, 3 が平方剰余でないので不可）。

よって $7 \mid a$，$7 \mid b$。$a = 7a'$，$b = 7b'$ とすると $c^2 = 7(a'^2 + b'^2)$ で $7 \mid c$。$c = 7c'$ とすると $a'^2 + b'^2 = 7c'^2$ となり、本問 (3) と同様に $c$ の最小性に矛盾。
