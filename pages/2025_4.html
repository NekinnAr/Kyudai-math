半径 $1$ の円周上に反時計回りに点 A，B，C，D を順にとり，線分 AD は直径で，$\mathrm{AC} = \mathrm{CD}$，$\mathrm{AB} = \mathrm{BC}$ が成り立つとする。

  1. (1)　$\angle\mathrm{ACB}$ を求めよ。
  2. (2)　BC を求めよ。
  3. (3)　線分 AC と線分 BD の交点を E とするとき，三角形 BCE の面積を求めよ。

（2025 九州大学 前期 理系 第4問）

解答例

「等しい弦には等しい弧（中心角）が対応する」ことから、弧 AB, BC, CD の中心角が $45^\circ,\ 45^\circ,\ 90^\circ$ と決まる。あとは円周角・余弦定理・角の二等分線の性質で計算。

解答例（タップで展開）

円の中心を O とする。

(1)

AD は直径なので $\angle\mathrm{ACD} = \dfrac{\pi}{2}$。$\mathrm{AC} = \mathrm{CD}$ より $\angle\mathrm{AOC} = \angle\mathrm{COD} = \dfrac{\pi}{2}$。さらに $\mathrm{AB} = \mathrm{BC}$ より $\angle\mathrm{AOB} = \angle\mathrm{BOC} = \dfrac{\pi}{4}$。円周角の定理から

$$\angle\mathrm{ACB} = \frac12\angle\mathrm{AOB} = \frac{\pi}{8}$$

(2)

三角形 OBC に余弦定理を用いて

$$\mathrm{BC}^2 = 1^2 + 1^2 - 2\cos\frac{\pi}{4} = 2 - \sqrt2 \qquad \therefore\ \mathrm{BC} = \sqrt{2-\sqrt2}$$

(3)

$\mathrm{AC} = \sqrt2$（直角二等辺三角形 ACD の辺）。三角形 ABC は $\mathrm{AB} = \mathrm{BC}$、$\angle\mathrm{ABC} = \pi - 2\cdot\dfrac{\pi}{8} = \dfrac{3}{4}\pi$ より

$$\triangle\mathrm{ABC} = \frac12\,\mathrm{BC}^2\sin\frac34\pi = \frac12(2-\sqrt2)\cdot\frac{\sqrt2}{2} = \frac{\sqrt2-1}{2}$$

弧 AB と弧 BC は等しいので $\angle\mathrm{ADB} = \angle\mathrm{BDC}$、すなわち DE は $\angle\mathrm{ADC}$ の二等分線。角の二等分線の性質より

$$\mathrm{AE} : \mathrm{EC} = \mathrm{DA} : \mathrm{DC} = 2 : \sqrt2$$

よって

$$\triangle\mathrm{BCE} = \frac{\mathrm{EC}}{\mathrm{AC}}\,\triangle\mathrm{ABC} = \frac{\sqrt2}{2+\sqrt2}\cdot\frac{\sqrt2-1}{2} = \frac{(\sqrt2-1)^2}{2} = \frac{3-2\sqrt2}{2}$$

動く図解

条件 $\mathrm{AB} = \mathrm{BC}$ を外して、B を弧 AC 上で動かしてみましょう（$\angle\mathrm{AOB} = \theta$）。三角形 BCE の面積がどう変わるか、本問の位置（$\theta = 45^\circ$）がどこにあるかを観察できます。

問題の背景

正八角形が隠れている

中心角が $45^\circ$ 刻みなので、A, B, C, D はすべて円に内接する正八角形の頂点です（A から数えて 0, 1, 2, 4 番目）。本問は「正八角形の対角線が作る図形」の計量問題と見ることができ、$\dfrac{\pi}{8} = 22.5^\circ$ の三角比が自然に現れます。

$$\cos\frac{\pi}{8} = \frac{\sqrt{2+\sqrt2}}{2},\qquad \sin\frac{\pi}{8} = \frac{\sqrt{2-\sqrt2}}{2},\qquad \tan\frac{\pi}{8} = \sqrt2 - 1$$

(2) の答え $\mathrm{BC} = \sqrt{2-\sqrt2}$ は、まさに $2\sin\dfrac{\pi}{8}$（弦の長さ $= 2R\sin\dfrac{\text{中心角}}{2}$）です。

答えの正体は $\dfrac12\tan^2\dfrac{\pi}{8}$

答え $\dfrac{3-2\sqrt2}{2} = \dfrac{(\sqrt2-1)^2}{2}$ は、ちょうど $\dfrac12\tan^2\dfrac{\pi}{8}$ になっています。これは偶然ではありません。三角形 BCE の角を調べると

  • $\angle\mathrm{BCE} = \angle\mathrm{BCA} = \dfrac{\pi}{8}$（(1) より）
  • $\angle\mathrm{CBE} = \angle\mathrm{CBD} = \dfrac12\angle\mathrm{COD} = \dfrac{\pi}{4}$（弧 CD の円周角）
  • $\angle\mathrm{BEC} = \pi - \dfrac{\pi}{8} - \dfrac{\pi}{4} = \dfrac{5}{8}\pi$

なので、正弦定理と面積公式から

$$\triangle\mathrm{BCE} = \frac{\mathrm{BC}^2\sin\frac{\pi}{4}\sin\frac{\pi}{8}}{2\sin\frac{5\pi}{8}} = \frac{4\sin^2\frac{\pi}{8}\cdot\frac{\sqrt2}{2}\cdot\sin\frac{\pi}{8}}{2\cos\frac{\pi}{8}} = \sqrt2\,\sin^2\frac{\pi}{8}\tan\frac{\pi}{8}$$

$\sin^2\dfrac{\pi}{8} = \dfrac{2-\sqrt2}{4} = \dfrac{\sqrt2(\sqrt2-1)}{4}$ を代入すると $\dfrac{(\sqrt2-1)^2}{2} = \dfrac12\tan^2\dfrac{\pi}{8}$ となります。

座標で一気に解くなら

O を原点、$\mathrm{A}(1,\ 0)$, $\mathrm{C}(0,\ 1)$, $\mathrm{D}(-1,\ 0)$ とおくと、直線 BD の傾きは「弧 AB の円周角」$= \dfrac{\theta}{2}$ の正接、つまり $\tan\dfrac{\theta}{2}$ です。これを使うと、$\theta$ が一般の場合も面積が計算できます（下の魔改造）。$x = \tan\dfrac{\theta}{2}$ とおくと、$\mathrm{B}\left(\dfrac{1-x^2}{1+x^2},\ \dfrac{2x}{1+x^2}\right)$ と有理式で表せるのがポイントで、これは 2025-2 の背景で紹介した「万能置換」と同じ式です。

初等幾何（円周角・二等分線）、三角比、座標 ── どの道具でも解ける問題は、複数の方法で解いて答えを照合すると力がつきます。

類題紹介

本問の図を利用して，$\cos\dfrac{\pi}{8}$ と $\tan\dfrac{\pi}{8}$ の値を求めよ。

（自作）

略解

$\angle\mathrm{ADB} = \dfrac{\pi}{8}$（弧 AB の円周角）で、$\angle\mathrm{ABD} = \dfrac{\pi}{2}$（直径の円周角）。直角三角形 ABD で $\mathrm{AB} = \sqrt{2-\sqrt2}$, $\mathrm{AD} = 2$ より $\mathrm{BD} = \sqrt{4 - (2-\sqrt2)} = \sqrt{2+\sqrt2}$。よって

$$\cos\frac{\pi}{8} = \frac{\mathrm{BD}}{\mathrm{AD}} = \frac{\sqrt{2+\sqrt2}}{2},\qquad \tan\frac{\pi}{8} = \frac{\mathrm{AB}}{\mathrm{BD}} = \sqrt{\frac{2-\sqrt2}{2+\sqrt2}} = \sqrt{(\sqrt2-1)^2} = \sqrt2-1$$

半径 $1$ の円周上に反時計回りに点 A，B，C，D を順にとり，線分 AD は直径で，$\mathrm{AC} = \mathrm{CD}$ が成り立つとする。円の中心を O，$\angle\mathrm{AOB} = \theta$ $\left(0 \lt \theta \lt \dfrac{\pi}{2}\right)$，線分 AC と線分 BD の交点を E とする。三角形 BCE の面積を $x = \tan\dfrac{\theta}{2}$ を用いて表せ。

（九大 2025　魔改造）

略解

$\mathrm{A}(1,0)$, $\mathrm{C}(0,1)$, $\mathrm{D}(-1,0)$, $\mathrm{B}\left(\dfrac{1-x^2}{1+x^2},\ \dfrac{2x}{1+x^2}\right)$ とおける。直線 AC は $X + Y = 1$、直線 BD は傾き $x$ で D を通るので $Y = x(X+1)$。連立して

$$\mathrm{E}\left(\frac{1-x}{1+x},\ \frac{2x}{1+x}\right)$$ $$\overrightarrow{\mathrm{CB}} = \frac{\bigl(1-x^2,\ -(1-x)^2\bigr)}{1+x^2},\qquad \overrightarrow{\mathrm{CE}} = \frac{(1-x)(1,\ -1)}{1+x}$$

より

$$\triangle\mathrm{BCE} = \frac12\left|\frac{-(1-x^2)+(1-x)^2}{1+x^2}\cdot\frac{1-x}{1+x}\right| = \frac{x(1-x)^2}{(1+x)(1+x^2)}$$

$x = \tan\dfrac{\pi}{8} = \sqrt2 - 1$ を代入すると、本問の答え $\dfrac{3-2\sqrt2}{2}$ に一致します。
