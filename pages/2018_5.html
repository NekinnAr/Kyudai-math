$\alpha$ を複素数とする。等式

$$\alpha(|z|^2 + 2) + i(2|\alpha|^2 + 1)\bar z = 0$$

を満たす複素数 $z$ をすべて求めよ。ただし，$i$ は虚数単位である。

（2018 九州大学 前期 理系 第5問）

解答例

両辺の絶対値をとると $|z|$ だけの方程式（2 次方程式）になり、$|z|$ が先に求まる。$|z|$ が分かれば元の式から $\bar z$、さらに $z$ が求まる。

解答例（タップで展開）

$\alpha = 0$ のとき：$i\bar z = 0$ より $z = 0$。

$\alpha \neq 0$ のとき：$A = |\alpha| \gt 0$，$r = |z|$ とおく。与式より $i(2A^2 + 1)\bar z = -\alpha(r^2 + 2)$。両辺の絶対値をとって

$$(2A^2 + 1)r = A(r^2 + 2) \iff Ar^2 - (2A^2 + 1)r + 2A = 0 \iff (Ar - 1)(r - 2A) = 0$$

よって $r = \frac1A$ または $r = 2A$。また与式より

$$\bar z = \frac{i\alpha(r^2 + 2)}{2A^2 + 1},\qquad z = -\frac{i\bar\alpha(r^2 + 2)}{2A^2 + 1}$$
  • $r = 2A$ のとき：$\dfrac{r^2 + 2}{2A^2 + 1} = \dfrac{4A^2 + 2}{2A^2 + 1} = 2$ より $z = -2i\bar\alpha$。実際 $|z| = 2A$ で整合する。
  • $r = \frac1A$ のとき：$\dfrac{r^2 + 2}{2A^2 + 1} = \dfrac{1 + 2A^2}{A^2(2A^2 + 1)} = \dfrac{1}{A^2}$ より $z = -\dfrac{i\bar\alpha}{|\alpha|^2} = -\dfrac{i}{\alpha}$。$|z| = \frac1A$ で整合する。

逆にこれらは与式をみたす（例：$z = -2i\bar\alpha$ なら $\bar z = 2i\alpha$，$|z|^2 = 4A^2$ で、$\alpha(4A^2 + 2) + i(2A^2 + 1)\cdot2i\alpha = 0$）。

$\alpha = 0$ のとき $z = 0$，$\alpha \neq 0$ のとき $z = -2i\bar\alpha,\ -\dfrac{i}{\alpha}$

（$|\alpha| = \frac{1}{\sqrt2}$ のときは 2 つが一致する。）

動く図解

$\alpha$ の絶対値と偏角を動かすと、2 つの解 $z_1 = -2i\bar\alpha$（赤）と $z_2 = -\frac i\alpha$（青）が動きます。$|z_1| = 2|\alpha|$，$|z_2| = \frac{1}{|\alpha|}$ なので、$|\alpha| = \frac{1}{\sqrt2}$ で 2 つが重なります。

問題の背景

絶対値をとって「大きさ」と「向き」を分ける

複素数の方程式に $|z|$ と $\bar z$ が混ざっているときは、両辺の絶対値をとると「大きさ」だけの方程式になります。大きさが決まれば、残りは「向き」の問題で、元の式から直接求まります。

chopin 先生は極形式 $\alpha = Ae^{i\phi},\ z = re^{i\theta}$ で書いて連立方程式に持ち込む解法を示し、「別解としては、与式で絶対値を取ることにより、極形式に直すことなく解き進める方法」「ちょっと思いつきにくいですが、処理自体はこちらの別解の方が楽」と紹介しています。上の解答はこの別解です。

$|z|$ と $z,\ \bar z$ が混在する方程式 → 絶対値をとって $|z|$ を先に決める。$\bar z$ を含む式は共役をとれば $z$ の式になる。

類題紹介

$\bar z = z^2$ を満たす複素数 $z$ をすべて求めよ。

（自作・頻出）

略解

絶対値をとって $|z| = |z|^2$ より $|z| = 0$ または $1$。$|z| = 1$ のとき $\bar z = \frac1z$ なので $\frac1z = z^2$、$z^3 = 1$。

$$z = 0,\ 1,\ \frac{-1 \pm \sqrt3 i}{2}$$

$k$ を正の定数とする。等式 $\alpha(|z|^2 + k) + i(k|\alpha|^2 + 1)\bar z = 0$ を満たす複素数 $z$ がちょうど 1 つであるような $\alpha$ の条件を求めよ。
