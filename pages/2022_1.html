座標空間内の 5 点

$$\mathrm{O}(0,\ 0,\ 0),\ \mathrm{A}(1,\ 1,\ 0),\ \mathrm{B}(2,\ 1,\ 2),\ \mathrm{P}(4,\ 0,\ -1),\ \mathrm{Q}(4,\ 0,\ 5)$$

を考える。3 点 $\mathrm{O}$，$\mathrm{A}$，$\mathrm{B}$ を通る平面を $\alpha$ とし，$\vec a = \overrightarrow{\mathrm{OA}}$，$\vec b = \overrightarrow{\mathrm{OB}}$ とおく。以下の問いに答えよ。

  1. (1)　ベクトル $\vec a,\ \vec b$ の両方に垂直であり，$x$ 成分が正であるような，大きさが $1$ のベクトル $\vec n$ を求めよ。
  2. (2)　平面 $\alpha$ に関して点 $\mathrm{P}$ と対称な点 $\mathrm{P'}$ の座標を求めよ。
  3. (3)　点 $\mathrm{R}$ が平面 $\alpha$ 上を動くとき，$|\overrightarrow{\mathrm{PR}}| + |\overrightarrow{\mathrm{RQ}}|$ が最小となるような点 $\mathrm{R}$ の座標を求めよ。

（2022 九州大学 前期 理系 第1問）

解答例

(1) 法線ベクトル → (2) 対称点 → (3) 折れ線の最短経路、という一本道の誘導。(3) は平面上の「川の問題（光の反射）」の空間版で、P と Q が平面の同じ側にあることを確認してから対称点を使う。

解答例（タップで展開）

(1)

$\vec n = (p,\ q,\ r)$ とすると $\vec a\cdot\vec n = p + q = 0$，$\vec b\cdot\vec n = 2p + q + 2r = 0$。$q = -p$，$r = -\frac p2$ より $\vec n = \frac p2(2,\ -2,\ -1)$。$|(2, -2, -1)| = 3$ で、$x$ 成分が正かつ大きさ $1$ なので

$$\vec n = \left(\frac23,\ -\frac23,\ -\frac13\right)$$

(2)

$\alpha$ は原点を通り $\vec n$ に垂直なので、方程式は $2x - 2y - z = 0$。点 $(x,\ y,\ z)$ の「$\alpha$ からの符号付き距離」は $\dfrac{2x - 2y - z}{3}$ で、P では $\dfrac{8 + 1}{3} = 3$。よって

$$\overrightarrow{\mathrm{OP'}} = \overrightarrow{\mathrm{OP}} - 2\cdot 3\,\vec n = (4,\ 0,\ -1) - (4,\ -4,\ -2) = (0,\ 4,\ 1)$$

$\mathrm{P'}(0,\ 4,\ 1)$。（PP′ の中点 $(2,\ 2,\ 0)$ が $\alpha$ 上にあり、$\overrightarrow{\mathrm{PP'}} \parallel \vec n$ であることが確認できる。）

(3)

$h(x,\ y,\ z) = 2x - 2y - z$ とすると $h(\mathrm{P}) = 9 \gt 0$，$h(\mathrm{Q}) = 8 - 5 = 3 \gt 0$ なので、P と Q は $\alpha$ に関して同じ側にある。また $h(\mathrm{P'}) = -9 \lt 0$ なので P′ と Q は反対側。

$\alpha$ 上の点 R について、$\alpha$ は線分 PP′ の垂直二等分面なので $\mathrm{PR} = \mathrm{P'R}$。よって

$$\mathrm{PR} + \mathrm{RQ} = \mathrm{P'R} + \mathrm{RQ} \ge \mathrm{P'Q}$$

等号は R が線分 P′Q と $\alpha$ の交点のとき。線分 P′Q 上の点は $(0,\ 4,\ 1) + u(4,\ -4,\ 4) = (4u,\ 4 - 4u,\ 1 + 4u)$ で、$h = 8u - 8 + 8u - 1 - 4u = 12u - 9 = 0$ より $u = \frac34$。

$$\mathrm{R}(3,\ 1,\ 4)\qquad(\text{最小値は}\ \mathrm{P'Q} = 4\sqrt3)$$

動く図解

平面 $\alpha$ 上で R を動かして、$\mathrm{PR} + \mathrm{RQ}$ を小さくしてみましょう。図はドラッグで回転できます。点線は P′ からの経路で、$\mathrm{PR} = \mathrm{P'R}$ が常に成り立っています。


問題の背景

光の反射とフェルマーの原理

P から出た光が鏡 $\alpha$ で反射して Q に届くとき、光は最短時間（最短距離）の経路を通ります（フェルマーの原理）。本問の R はまさに反射点で、PR と RQ は $\alpha$ の法線と等しい角をなします（入射角 = 反射角）。

同じ側か、反対側か

もし P と Q が $\alpha$ の反対側にあれば、線分 PQ と $\alpha$ の交点が答えで、対称点は不要です。$h(\mathrm{P})$ と $h(\mathrm{Q})$ の符号を調べるのは、答案で必ず書くべきポイントです（chopin 先生も「P, Q は α について同じ側にあるので、折れ線の長さを最小化する問題になる」と解説しています）。

平面に関する対称点は、「符号付き距離 × 2 だけ法線方向に戻る」で一発。中点が平面上にあることと、PP′ が法線と平行なことで検算できます。

類題紹介

本問の P，Q と平面 $\alpha$ について，点 R が $\alpha$ 上を動くとき，$\bigl|\,|\overrightarrow{\mathrm{PR}}| - |\overrightarrow{\mathrm{QR}}|\,\bigr|$ の最大値と，そのときの R の座標を求めよ。

（自作）

略解

三角形の成立条件（三角不等式）より $|\mathrm{PR} - \mathrm{QR}| \le \mathrm{PQ} = 6$。等号は R が直線 PQ 上で、P，Q の外側にあるとき。直線 PQ：$(4,\ 0,\ -1 + 6u)$ と $\alpha$ の交点は $8 + 1 - 6u = 0$ より $u = \frac32$、$\mathrm{R}(4,\ 0,\ 8)$（PR $= 9$，QR $= 3$）。最大値 $6$。

（和の最小は「反対側に折り返す」、差の最大は「同じ側のまま延長する」。対になっています。）

本問の P，Q について，点 R が平面 $\alpha$ と $xy$ 平面の交線上を動くとき，$|\overrightarrow{\mathrm{PR}}| + |\overrightarrow{\mathrm{RQ}}|$ の最小値と，そのときの R の座標を求めよ。

（九大 2022　魔改造）

略解

交線は $2x - 2y - z = 0,\ z = 0$ より $x = y,\ z = 0$。$\mathrm{R}(u,\ u,\ 0)$ とおくと

$$\mathrm{PR} = \sqrt{2(u - 2)^2 + 9},\qquad \mathrm{RQ} = \sqrt{2(u - 2)^2 + 33}$$

どちらも $u = 2$ で最小になるので、和の最小値は $3 + \sqrt{33}$（$\mathrm{R}(2,\ 2,\ 0)$）。

（「平面上」から「直線上」に制限すると、対称点の方法ではなく、それぞれの距離を直接最小化する方が速い、という例です。）
