$\triangle OAB$ において，辺 $OB$ の中点を $M$，辺 $AB$ を $\alpha : 1 - \alpha$ に内分する点を $P$ とする。ただし，$0 < \alpha < 1$ とする。線分 $OP$ と $AM$ の交点を $Q$ とし，$Q$ を通り，線分 $AM$ に垂直な直線が，辺 $OA$ またはその延長と交わる点を $R$ とする。$\overrightarrow{OA} = \vec{a}$，$\overrightarrow{OB} = \vec{b}$ として，次の問いに答えよ。

  1. (1)　ベクトル $\overrightarrow{OP}$ と $\overrightarrow{OQ}$ を $\vec{a}$，$\vec{b}$ および $\alpha$ を用いて表せ。
  2. (2)　$|\vec{a}| = 2$，$|\vec{b}| = 3$，$\angle AOB = \theta$ で $\cos\theta = \dfrac16$ とする。このとき，ベクトル $\overrightarrow{OR}$ を $\vec{a}$ と $\alpha$ を用いて表せ。
  3. (3)　(2) の条件のもとで，点 $R$ が辺 $OA$ の中点であるときの $\alpha$ の値を求めよ。

（2006 九州大学 前期 理系 第2問）

解答例

交点 $Q$ は「$OP$ 上」「$AM$ 上」の 2 通りに表して係数比較。$\overrightarrow{OR} = r\vec{a}$ とおき、$\overrightarrow{QR}\cdot\overrightarrow{AM} = 0$ を解きます。内積 $\vec a\cdot\vec b = 1$ が効きます。

解答例（タップで展開）

(1)

$$\overrightarrow{OP} = (1 - \alpha)\vec{a} + \alpha\vec{b}$$

$Q$ は $OP$ 上なので $\overrightarrow{OQ} = t\{(1 - \alpha)\vec{a} + \alpha\vec{b}\}$，$AM$ 上なので $\overrightarrow{OQ} = (1 - s)\vec{a} + \dfrac s2\vec{b}$。$\vec a$，$\vec b$ は 1 次独立なので

$$t(1 - \alpha) = 1 - s,\qquad t\alpha = \frac s2$$

$s = 2t\alpha$ を代入して $t(1 + \alpha) = 1$。よって

$$\overrightarrow{OQ} = \frac{(1 - \alpha)\vec{a} + \alpha\vec{b}}{1 + \alpha}$$

(2)

$\vec a\cdot\vec b = 2\cdot3\cdot\frac16 = 1$。$\overrightarrow{AM} = \frac12\vec b - \vec a$ で

$$\vec a\cdot\overrightarrow{AM} = \frac12 - 4 = -\frac72,\qquad \vec b\cdot\overrightarrow{AM} = \frac92 - 1 = \frac72$$

$\overrightarrow{OR} = r\vec a$ とおくと、$\overrightarrow{QR}\cdot\overrightarrow{AM} = 0$ より $r\,\vec a\cdot\overrightarrow{AM} = \overrightarrow{OQ}\cdot\overrightarrow{AM}$。

$$-\frac72r = \frac{(1 - \alpha)\left(-\frac72\right) + \alpha\cdot\frac72}{1 + \alpha} = \frac72\cdot\frac{2\alpha - 1}{1 + \alpha}$$ $$\therefore\ \overrightarrow{OR} = \frac{1 - 2\alpha}{1 + \alpha}\vec a$$

(3)

$\dfrac{1 - 2\alpha}{1 + \alpha} = \dfrac12$ より $2 - 4\alpha = 1 + \alpha$，$\alpha = \dfrac15$。

動く図解

(2) の条件どおりの三角形です。$\alpha$ を動かすと $P$，$Q$，$R$ が動きます。$\alpha > \frac12$ では $R$ は $O$ を越えて延長上に出ます。

問題の背景

交点ベクトルの定番＋垂直条件

(1) は「2 直線の交点は 2 通りに表して係数比較」という超定番（メネラウスの定理でも出せます）。(2) で垂直条件を内積で処理しますが、$\vec a\cdot\overrightarrow{AM}$ と $\vec b\cdot\overrightarrow{AM}$ が $\mp\frac72$ と符号違いで同じ大きさになるため、式が非常に簡単になります。実は $(\vec a + \vec b)\cdot\overrightarrow{AM} = 0$、つまり $AM$ は $\vec a + \vec b$（平行四辺形の対角線）と垂直という、数値の選び方の妙があります。

chopin 先生は「(1) は典型問題です。$Q$ については $OP$ 上にあり、かつ $AM$ 上にあるという条件から求めます」「(2) $\overrightarrow{OR}$ は $\vec a$ の定数倍です。これと $QR \perp AM$ という条件から $\overrightarrow{OR}$ を求めます」「(3) (2) ができれば瞬殺です」とコメントしています。

交点は 2 通りに表して係数比較。直線上の点は「実数倍」でおいて内積＝0。

類題紹介

本問で $\alpha = \dfrac12$ のとき，$AQ : QM$ と $OQ : QP$ を求めよ。

（自作）

略解

$t = \dfrac1{1 + \alpha} = \dfrac23$，$s = 2t\alpha = \dfrac23$。よって $OQ : QP = 2 : 1$，$AQ : QM = 2 : 1$。$P$，$M$ がともに辺の中点なので、$Q$ は $\triangle OAB$ の重心です。

本問 (2) の条件のもとで，点 $R$ が辺 $OA$ 上（両端を含む）にあるような $\alpha$ の範囲を求めよ。また，$R = O$ となるときの $\alpha$ の値を求め，そのとき $OQ \perp AM$ であることを確かめよ。

（九大 2006　魔改造）

略解

$0 \le \dfrac{1 - 2\alpha}{1 + \alpha} \le 1$。右側は $\alpha > 0$ で常に成立、左側から $\alpha \le \dfrac12$。よって $0 < \alpha \le \dfrac12$。$R = O$ は $\alpha = \dfrac12$ で、このとき $\overrightarrow{OQ} = \frac13(\vec a + \vec b)$。$(\vec a + \vec b)\cdot\overrightarrow{AM} = -\frac72 + \frac72 = 0$ なので確かに $OQ \perp AM$。
