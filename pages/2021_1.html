座標空間内の 4 点 $\mathrm{O}(0,\ 0,\ 0)$，$\mathrm{A}(1,\ 0,\ 0)$，$\mathrm{B}(0,\ 1,\ 0)$，$\mathrm{C}(0,\ 0,\ 2)$ を考える。以下の問いに答えよ。

  1. (1)　四面体 $\mathrm{OABC}$ に内接する球の中心の座標を求めよ。
  2. (2)　中心の $x$ 座標，$y$ 座標，$z$ 座標がすべて正の実数であり，$xy$ 平面，$yz$ 平面，$zx$ 平面のすべてと接する球を考える。この球が平面 $\mathrm{ABC}$ と交わるとき，その交わりとしてできる円の面積の最大値を求めよ。

（2021 九州大学 前期 理系 第1問）

解答例

3 つの座標平面に接する球の中心は $(r,\ r,\ r)$（半径 $r$）の形。あとは平面 ABC との距離で、(1) は「距離 = 半径」、(2) は三平方の定理で切り口の円の半径を出す。

解答例（タップで展開）

平面 ABC の方程式は $x + y + \dfrac z2 = 1$、すなわち $2x + 2y + z - 2 = 0$。点 $(s,\ s,\ s)$ との距離は

$$d(s) = \frac{|2s + 2s + s - 2|}{\sqrt{2^2 + 2^2 + 1^2}} = \frac{|5s - 2|}{3}$$

(1)

内接球は 3 つの座標平面に接するので、中心は $(r,\ r,\ r)$、半径 $r$（$r \gt 0$）。中心は四面体の内部にあるので $5r - 2 \lt 0$ で、平面 ABC にも接するから

$$\frac{2 - 5r}{3} = r \iff r = \frac14$$

中心は $\left(\dfrac14,\ \dfrac14,\ \dfrac14\right)$。

（別解：体積 $V = \frac13$，表面積 $S = \frac12 + 1 + 1 + \frac32 = 4$ から $r = \frac{3V}{S} = \frac14$。）

(2)

球の中心は $(s,\ s,\ s)$、半径 $s$（$s \gt 0$）。平面 ABC と交わる条件は $d(s) \lt s$ で、そのとき切り口の円の半径 $\rho$ は三平方の定理より

$$\rho^2 = s^2 - d(s)^2 = s^2 - \frac{(5s - 2)^2}{9} = \frac{-16s^2 + 20s - 4}{9} = \frac{4}{9}(-4s^2 + 5s - 1)$$

$\rho^2 \gt 0 \iff (4s - 1)(s - 1) \lt 0 \iff \frac14 \lt s \lt 1$。この範囲で

$$-4s^2 + 5s - 1 = -4\left(s - \frac58\right)^2 + \frac{9}{16}$$

は $s = \frac58$ で最大値 $\frac{9}{16}$ をとる。このとき $\rho^2 = \frac49\cdot\frac{9}{16} = \frac14$ で、円の面積の最大値は

$$\pi\rho^2 = \frac{\pi}{4}\qquad\left(s = \frac58\ \text{のとき}\right)$$

動く図解

球の中心 $(s,\ s,\ s)$ を動かすと、平面 ABC（三角形を含む平面）による切り口の円が変化します。$s = \frac14$ で接し（内接球）、$s = \frac58$ で切り口が最大になります。図はドラッグで回転できます。

問題の背景

内接球の半径 $r = \frac{3V}{S}$

四面体を内接球の中心から各面に向かって 4 つの四面体に分けると、それぞれの高さは $r$ なので $V = \frac13 rS$（$S$ は表面積）。三角形の内接円の公式 $S_\triangle = \frac12 r\ell$（$\ell$ は周の長さ）の 3 次元版です。

座標平面に接する球

3 つの座標平面すべてに接する球（中心が第 1 象限側）は、中心が直線 $x = y = z$ 上にあり、半径が中心の座標に等しいので、1 つのパラメータ $s$ で表せます。chopin 先生は「球の中心と平面との距離を考えれば、三平方の定理で円の半径を求めることができます」と解説しており、標準的な問題です。

球と平面の問題は「中心と平面の距離 $d$」がすべて。接する ⇔ $d = r$、交わる ⇔ $d \lt r$、切り口の半径は $\sqrt{r^2 - d^2}$。

類題紹介

本問の四面体 $\mathrm{OABC}$ に外接する球の中心と半径を求めよ。

（自作）

略解

中心 $(p,\ q,\ r)$ が O，A，B，C から等距離なので、$p^2 = (p - 1)^2$，$q^2 = (q - 1)^2$，$r^2 = (r - 2)^2$ より $p = q = \frac12$，$r = 1$。中心 $\left(\frac12,\ \frac12,\ 1\right)$，半径 $\sqrt{\frac14 + \frac14 + 1} = \dfrac{\sqrt6}{2}$。

（O で 3 辺が直交しているので、外接球は「OA，OB，OC を 3 辺とする直方体」の外接球と同じです。）

$c \gt 0$ とし，$\mathrm{C}(0,\ 0,\ c)$ として四面体 $\mathrm{OABC}$ を考える。内接球の半径 $r(c)$ を求め，$\displaystyle\lim_{c\to\infty}r(c)$ を求めよ。また，その値の図形的な意味を説明せよ。

（九大 2021　魔改造）

略解

平面 ABC：$x + y + \frac zc = 1$。中心 $(r,\ r,\ r)$ との距離が $r$ となる条件は

$$\frac{1 - 2r - \frac rc}{\sqrt{2 + \frac{1}{c^2}}} = r \iff r(c) = \frac{1}{2 + \frac1c + \sqrt{2 + \frac{1}{c^2}}} = \frac{c}{2c + 1 + \sqrt{2c^2 + 1}}$$

（$c = 2$ で $\frac{2}{5 + 3} = \frac14$ と本問に一致。）$c \to \infty$ で $r(c) \to \dfrac{1}{2 + \sqrt2} = \dfrac{2 - \sqrt2}{2}$。

これは直角二等辺三角形 OAB（直角をはさむ辺が $1$）の内接円の半径 $\frac{1 + 1 - \sqrt2}{2}$ に等しい。C が無限に高くなると、四面体は三角柱のように細長くなり、内接球は底面の三角形 OAB の内接円と同じ大きさになる、という意味です。
