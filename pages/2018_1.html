座標空間において，$xy$ 平面上にある双曲線 $x^2 - y^2 = 1$ のうち $x \ge 1$ を満たす部分を $C$ とする。また，$z$ 軸上の点 $\mathrm{A}(0,\ 0,\ 1)$ を考える。点 $\mathrm{P}$ が $C$ 上を動くとき，直線 $\mathrm{AP}$ と平面 $x = d$ との交点の軌跡を求めよ。ただし，$d$ は正の定数とする。

（2018 九州大学 前期 理系 第1問）

解答例

$\mathrm{P}(p,\ q,\ 0)$ とおいて交点を $p,\ q$ で表し、逆に $p,\ q$ を交点の座標で表して $p^2 - q^2 = 1$ に代入する（逆像法）。範囲の確認を忘れずに。

解答例（タップで展開）

$\mathrm{P}(p,\ q,\ 0)$（$p^2 - q^2 = 1$，$p \ge 1$）とする。直線 AP 上の点は $(0,\ 0,\ 1) + s(p,\ q,\ -1)$。$x = d$ となるのは $s = \frac dp$ のときで、交点は

$$(x,\ y,\ z) = \left(d,\ \frac{dq}{p},\ 1 - \frac dp\right)$$

$y = \frac{dq}{p}$，$z = 1 - \frac dp$ より $1 - z = \frac dp \gt 0$ で、$p = \dfrac{d}{1 - z}$，$q = \dfrac{py}{d} = \dfrac{y}{1 - z}$。これを $p^2 - q^2 = 1$ に代入して

$$\frac{d^2 - y^2}{(1 - z)^2} = 1 \iff y^2 + (z - 1)^2 = d^2$$

範囲：$p \ge 1$ より $0 \lt \frac dp \le d$、つまり $1 - d \le z \lt 1$。逆に、$y^2 + (z - 1)^2 = d^2$，$z \lt 1$ をみたす $(y,\ z)$ に対して $p = \frac{d}{1 - z},\ q = \frac{y}{1 - z}$ と定めると、$p^2 - q^2 = \frac{d^2 - y^2}{(1 - z)^2} = 1$，$p \gt 0$ なので $p \ge 1$ となり、対応する P が C 上に存在する。

よって求める軌跡は

平面 $x = d$ 上の半円 $y^2 + (z - 1)^2 = d^2$，$z \lt 1$

（中心 $(d,\ 0,\ 1)$，半径 $d$ の円の $z \lt 1$ の部分。両端の点 $(d,\ \pm d,\ 1)$ は含まない。）

動く図解

P（赤）を双曲線上で動かすと、直線 AP と平面 $x = d$ の交点（オレンジ）が半円を描きます。P が遠くへ行くほど、交点は半円の端（高さ $z = 1$）に近づきます。図はドラッグで回転できます。

問題の背景

双曲線関数によるパラメータ表示

chopin 先生は「P をどう表現するかという初手でかなり左右される」とし、双曲線を $x = \frac{e^t + e^{-t}}{2},\ y = \frac{e^t - e^{-t}}{2}$（双曲線関数 $\cosh t,\ \sinh t$）でパラメータ表示する方法を紹介しています。上の解答のように P を $(p,\ q)$ のまま扱い、逆に解いて代入する方法でも解けます。

中心射影と円錐曲線

点 A から見て、双曲線を平面 $x = d$ に映した影が円になる、というのが本問の内容です。点からの射影（中心射影）で円錐曲線は円錐曲線に移ります。双曲線は「円を斜めから見たもの」の一種で、見る位置を選ぶと円に戻せるのです。射影幾何学の入口となる話題です。

軌跡は「動く点の座標 $(X,\ Y)$ を媒介変数で表し、媒介変数を $X,\ Y$ で表して条件式に代入」。逆向きに解けるか（範囲）の確認で、軌跡の除外点が決まる。

類題紹介

$xy$ 平面上の放物線 $y = x^2$ の $x \gt 0$ の部分を点 P が動くとき，$\mathrm{A}(0,\ 0,\ 1)$ と P を通る直線と平面 $x = d\ (d \gt 0)$ との交点の軌跡を求めよ。

（自作）

略解

$\mathrm{P}(t,\ t^2,\ 0)$ とすると交点は $\left(d,\ dt,\ 1 - \frac dt\right)$。$y = dt$ より $t = \frac yd$、$z = 1 - \frac{d^2}{y}$。$t \gt 0$ を $y \gt 0$ に対応させて

平面 $x = d$ 上の曲線 $(z - 1)y = -d^2$，$y \gt 0$（双曲線の片方）

本問で，$C$ を双曲線 $x^2 - y^2 = 1$ 全体（$x \le -1$ の部分も含む）に変えたとき，直線 AP と平面 $x = d$ との交点の軌跡を求めよ。

（九大 2018　魔改造）

略解

同じ計算で $y^2 + (z - 1)^2 = d^2$ が得られる。$p \le -1$ のとき $\frac dp \in [-d,\ 0)$ で $1 \lt z \le 1 + d$。また $\frac qp$ は $-1 \lt \frac qp \lt 1$ なので $y \neq \pm d$。よって軌跡は

円 $y^2 + (z - 1)^2 = d^2$（平面 $x = d$ 上）から 2 点 $(d,\ \pm d,\ 1)$ を除いたもの

欠けた 2 点は、双曲線の漸近線 $y = \pm x$ の方向（無限遠）に対応しています。
