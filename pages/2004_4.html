座標空間内の三角柱 $0 \le x \le 1$，$0 \le y \le 1$，$x \ge y$，$0 \le z \le 1$ を考え，その $xy$ 平面内の面を $S$，$xz$ 平面内の面を $T$ とする。点 $A(a,\ b,\ 0)$ を $S$ 内に，点 $B(c,\ 0,\ d)$ を $T$ 内にとり，また $C(1,\ 1,\ 1)$ とする。ただし，点 $A$，$B$ は原点 $O$ とは異なるとする。

  1. (1)　ベクトル $\overrightarrow{OA}$ および $\overrightarrow{OC}$ に直交する単位ベクトルを求め，その単位ベクトルとベクトル $\overrightarrow{OB}$ の内積の絶対値を求めよ。
  2. (2)　四面体 $OABC$ の体積を求めよ。ただし，点 $O$，$A$，$B$，$C$ は同一平面上にないとする。
  3. (3)　点 $A$ が $S$ 内を，点 $B$ が $T$ 内を動くとする。このときの，四面体 $OABC$ の体積の最大値，および最大値を与える点 $A$，$B$ の位置をすべて求めよ。

（2004 九州大学 前期 理系 第4問）

解答例

(1) の内積の絶対値は、平面 $OAC$ から $B$ までの距離（高さ）です。体積は $\frac16\{bc + (a - b)d\}$ となり、$c,\ d \le 1$ と $a \le 1$ で上から押さえれば最大値 $\frac16$。等号条件を丁寧に拾うのがポイント。

解答例（タップで展開）

(1)

$S$ 内なので $0 \le b \le a \le 1$，$A \ne O$ より $a > 0$。求める単位ベクトルを $\vec e = (p,\ q,\ r)$ とすると

$$ap + bq = 0,\qquad p + q + r = 0,\qquad p^2 + q^2 + r^2 = 1$$

第 1，2 式より $(p,\ q,\ r) = k(b,\ -a,\ a - b)$。正規化して

$$\vec e = \pm\frac{(b,\ -a,\ a - b)}{\sqrt{2(a^2 - ab + b^2)}}$$

$\overrightarrow{OB} = (c,\ 0,\ d)$ との内積の絶対値は

$$|\vec e\cdot\overrightarrow{OB}| = \frac{|bc + (a - b)d|}{\sqrt{2(a^2 - ab + b^2)}} = \frac{bc + (a - b)d}{\sqrt{2(a^2 - ab + b^2)}}$$

（$b \ge 0$，$c \ge 0$，$a - b \ge 0$，$d \ge 0$ より絶対値は外れる。）

(2)

$\triangle OAC = \frac12\sqrt{|\overrightarrow{OA}|^2|\overrightarrow{OC}|^2 - (\overrightarrow{OA}\cdot\overrightarrow{OC})^2} = \frac12\sqrt{3(a^2 + b^2) - (a + b)^2} = \frac12\sqrt{2(a^2 - ab + b^2)}$。高さは (1) の値なので

$$V = \frac13\cdot\triangle OAC\cdot|\vec e\cdot\overrightarrow{OB}| = \frac{bc + (a - b)d}{6}$$

(3)

$0 \le c \le 1$，$0 \le d \le 1$，$b \ge 0$，$a - b \ge 0$ より

$$bc + (a - b)d \le b + (a - b) = a \le 1$$

よって $V \le \frac16$。等号は $a = 1$，$b(1 - c) = 0$，$(1 - b)(1 - d) = 0$ のとき。

  • $b = 0$：$d = 1$。$A(1,\ 0,\ 0)$，$B(c,\ 0,\ 1)$（$0 \le c \le 1$）
  • $b = 1$：$c = 1$。$A(1,\ 1,\ 0)$，$B(1,\ 0,\ d)$（$0 \le d \le 1$）
  • $0 < b < 1$：$c = d = 1$。$A(1,\ b,\ 0)$，$B(1,\ 0,\ 1)$

最大値は $\dfrac16$ で、それを与える $A$，$B$ は上の 3 通り（まとめると「$A$ は辺 $x = 1$ 上，$B = (1, 0, 1)$」に加えて、$A$ が端点 $(1,0,0)$ なら $B$ は辺 $z = 1$ 上，$A$ が端点 $(1,1,0)$ なら $B$ は辺 $x = 1$ 上）。

動く図解

灰色が三角柱、青い三角形が $S$，緑の正方形が $T$ です。$a, b, c, d$ を動かして四面体 $OABC$（赤）の体積を最大にしてみましょう（ドラッグで回転）。$b > a$ にはできないよう制限しています。

問題の背景

予選決勝法と等号条件

4 変数の最大化ですが、$V = \frac16\{bc + (a - b)d\}$ は $c$，$d$ について 1 次で係数が非負なので、まず $c = d = 1$ とするのが最善（予選）。すると $V \le \frac a6$ で、$a = 1$（決勝）。ただし「すべて求めよ」なので、係数が $0$ になって $c$ や $d$ が自由になる場合（$b = 0$ や $b = 1$）を落とさないことが大事です。体積は $\frac16|\det(\overrightarrow{OA}, \overrightarrow{OB}, \overrightarrow{OC})|$ で直接計算しても確認できます。

chopin 先生は「(1) 求める単位ベクトルを $\vec e = (p, q, r)$ とおいて $p, q, r$ を求めます」「(2) 底面を $\triangle OAC$ とすると、高さが (1) で求めた $\overrightarrow{OB}$ と $\vec e$ の内積になります」「(3) は、予選決勝法で考えていきます」とコメントしています。

法線ベクトルとの内積の絶対値＝平面からの距離。多変数の最大は 1 文字ずつ固定（予選決勝法）、「すべて」なら等号条件を漏れなく。

類題紹介

$\vec u = (1,\ 2,\ 0)$，$\vec v = (1,\ 1,\ 1)$ の両方に直交する単位ベクトルを求めよ。

（自作）

略解

$(p, q, r)$ で $p + 2q = 0$，$p + q + r = 0$ より $(p, q, r) = k(2, -1, -1)$。$\pm\dfrac{1}{\sqrt6}(2,\ -1,\ -1)$。

本問 (3) で四面体 $OABC$ の体積が最大となるとき，$\triangle OAC$ の面積の最小値と，そのときの点 $A$ を求めよ。

（九大 2004　魔改造）

略解

最大のとき $A = (1,\ b,\ 0)$（$0 \le b \le 1$ のすべてが実現可能：$B = (1, 0, 1)$ とすればよい）。$\triangle OAC = \frac12\sqrt{2(1 - b + b^2)}$ は $b = \frac12$ で最小値 $\dfrac12\sqrt{\dfrac32} = \dfrac{\sqrt6}{4}$。$A\left(1,\ \frac12,\ 0\right)$。
