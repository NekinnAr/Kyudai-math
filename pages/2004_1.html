$n = 0,\ 1,\ 2,\ \cdots$ に対して $I_n = \dfrac{(-1)^n}{n!}\displaystyle\int_0^2x^ne^xdx$ とおく。ただし，$0! = 1$ とする。

  1. (1)　$I_0$ の値を求め，$n = 1,\ 2,\ \cdots$ のとき $I_n$ と $I_{n-1}$ の関係式を求めよ。また，これらを用いて $I_3$ の値を求めよ。
  2. (2)　$0 \le x \le 2$ に対して $e^x \le e^2$ であることを利用して，次の不等式を示せ。 $$\frac1{n!}\int_0^2x^ne^xdx \le 2e^2\left(\frac23\right)^{n-1}\quad(n = 1,\ 2,\ \cdots)$$
  3. (3)　極限 $\displaystyle\lim_{n\to\infty}\sum_{k=0}^{n}\frac{(-1)^k2^k}{k!}$ を求めよ。

（2004 九州大学 前期 理系 第1問）

解答例

部分積分で $I_n - I_{n-1} = \dfrac{(-2)^ne^2}{n!}$。これを足し合わせると $\displaystyle\sum_{k=0}^n\frac{(-2)^k}{k!} = \frac{I_n + 1}{e^2}$ となり、(2) で $I_n \to 0$ を示せば答えは $e^{-2}$。

解答例（タップで展開）

(1)

$I_0 = \displaystyle\int_0^2e^xdx = e^2 - 1$。$n \ge 1$ のとき部分積分により

$$\int_0^2x^ne^xdx = \Big[x^ne^x\Big]_0^2 - n\int_0^2x^{n-1}e^xdx = 2^ne^2 - n\int_0^2x^{n-1}e^xdx$$

両辺に $\dfrac{(-1)^n}{n!}$ をかけて

$$I_n = \frac{(-2)^ne^2}{n!} + I_{n-1}$$

よって $I_3 = I_0 + e^2\left(-2 + \dfrac42 - \dfrac86\right) = e^2 - 1 - \dfrac43e^2 = -\dfrac{e^2}{3} - 1$。

(2)

$$\frac1{n!}\int_0^2x^ne^xdx \le \frac{e^2}{n!}\int_0^2x^ndx = \frac{2^{n+1}e^2}{(n+1)!}$$

したがって $\dfrac{2^{n+1}}{(n+1)!} \le 2\left(\dfrac23\right)^{n-1}$，すなわち $2\cdot3^{n-1} \le (n+1)!$ を示せばよい。$n = 1$ で $2 \le 2$。$n$ で成り立てば $(n+2)! = (n+2)(n+1)! \ge 3\cdot2\cdot3^{n-1} = 2\cdot3^n$ で $n + 1$ でも成立。帰納法により示された。

(3)

(1) の関係式を $n = 1$ から $n$ まで足して

$$I_n = I_0 + e^2\sum_{k=1}^n\frac{(-2)^k}{k!} = e^2\sum_{k=0}^n\frac{(-2)^k}{k!} - 1\quad\therefore\ \sum_{k=0}^n\frac{(-1)^k2^k}{k!} = \frac{I_n + 1}{e^2}$$

(2) より $|I_n| \le 2e^2\left(\frac23\right)^{n-1} \to 0$ なので

$$\lim_{n\to\infty}\sum_{k=0}^n\frac{(-1)^k2^k}{k!} = \frac1{e^2}$$

動く図解

部分和 $\sum_{k=0}^n\frac{(-2)^k}{k!}$ を点で表示します。上下に振動しながら $e^{-2} \approx 0.1353$（緑の線）に収束します。灰色の帯は (2) の評価から分かる誤差の範囲 $\pm 2(2/3)^{n-1}$。

問題の背景

テイラー展開を高校範囲で

大学で学ぶテイラー展開 $e^x = \sum_{k=0}^\infty\frac{x^k}{k!}$ に $x = -2$ を代入すれば (3) の答えは即 $e^{-2}$ です。本問はこれを「積分の漸化式 ＋ はさみうち」で高校範囲だけで証明させる構成で、$I_n$ はテイラー展開の剰余項（積分形）そのもの。同じ手法は $\sum\frac1{k!} = e$ や $\sum\frac{(-1)^{k-1}}k = \log2$ の証明でもおなじみです。

chopin 先生は「(1) $I_0$ は単なる計算問題、漸化式も部分積分で容易に求まります。この時点で、(3) の片鱗が見えます」「(2) $e^x \le e^2$ を使って積分を計算しますが、これだけでは目標の不等式に到達できないので、もう一段階大小関係を調べる必要があります。具体的には、階乗と指数関数の比較です」「(3) の結果は、指数関数 $e^x$ のテイラー展開を使うと容易に求まりますが、この問題はテイラー展開を使わず高校範囲で級数を計算しています」とコメントしています。

積分の漸化式を足し合わせて級数を作り、剰余（積分）を評価して $0$ に。階乗は指数関数より速く増える。

類題紹介

$\displaystyle\int_0^1xe^xdx$ および $\displaystyle\int_0^1x^2e^xdx$ を求めよ。

（自作）

略解

部分積分で $\int_0^1xe^xdx = e - (e - 1) = 1$，$\int_0^1x^2e^xdx = e - 2\cdot1 = e - 2$。

本問の積分区間を $[0,\ 2]$ から $[0,\ 1]$ に変えて同様に考えることで，$\displaystyle\lim_{n\to\infty}\sum_{k=0}^{n}\frac{(-1)^k}{k!}$ を求めよ。

（九大 2004　魔改造）

略解

$J_n = \dfrac{(-1)^n}{n!}\displaystyle\int_0^1x^ne^xdx$ とおくと、部分積分で $J_n = \dfrac{(-1)^ne}{n!} + J_{n-1}$，$J_0 = e - 1$。よって $\displaystyle\sum_{k=0}^n\frac{(-1)^k}{k!} = \frac{J_n + 1}{e}$。$|J_n| \le \dfrac{e}{n!}\int_0^1x^ndx = \dfrac{e}{(n+1)!} \to 0$ なので、極限は $\dfrac1e$。
