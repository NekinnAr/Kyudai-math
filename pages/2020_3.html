四面体 $\mathrm{OABC}$ において，辺 $\mathrm{OA}$ の中点と辺 $\mathrm{BC}$ の中点を通る直線を $\ell$，辺 $\mathrm{OB}$ の中点と辺 $\mathrm{CA}$ の中点を通る直線を $m$，辺 $\mathrm{OC}$ の中点と辺 $\mathrm{AB}$ の中点を通る直線を $n$ とする。$\ell \perp m$，$m \perp n$，$n \perp \ell$ であり，$\mathrm{AB} = \sqrt5$，$\mathrm{BC} = \sqrt3$，$\mathrm{CA} = 2$ のとき，以下の問いに答えよ。

  1. (1)　直線 $\mathrm{OB}$ と直線 $\mathrm{CA}$ のなす角 $\theta\ \left(0 \le \theta \le \dfrac{\pi}{2}\right)$ を求めよ。
  2. (2)　四面体 $\mathrm{OABC}$ の 4 つの頂点をすべて通る球の半径を求めよ。

（2020 九州大学 前期 理系 第3問）

解答例

$\vec a = \overrightarrow{\mathrm{OA}}$ などとおいて垂直条件を内積で書くと、「向かい合う辺の長さが等しい」ことが分かる（等面四面体）。すると四面体は直方体にすっぽり埋め込めて、(2) は直方体の対角線の半分になる。

解答例（タップで展開）

(1)

$\vec a = \overrightarrow{\mathrm{OA}},\ \vec b = \overrightarrow{\mathrm{OB}},\ \vec c = \overrightarrow{\mathrm{OC}}$ とする。$\ell$ の方向ベクトルは $\dfrac{\vec b + \vec c}{2} - \dfrac{\vec a}{2}$ より $\vec b + \vec c - \vec a$。同様に $m,\ n$ の方向ベクトルは $\vec c + \vec a - \vec b$，$\vec a + \vec b - \vec c$。

$$\ell \perp m \iff (\vec c + (\vec b - \vec a))\cdot(\vec c - (\vec b - \vec a)) = 0 \iff |\vec c|^2 = |\vec b - \vec a|^2 \iff \mathrm{OC} = \mathrm{AB}$$

同様に $m \perp n \iff \mathrm{OA} = \mathrm{BC}$，$n \perp \ell \iff \mathrm{OB} = \mathrm{CA}$。よって

$$|\vec a| = \sqrt3,\quad |\vec b| = 2,\quad |\vec c| = \sqrt5$$

$|\vec a - \vec b|^2 = 5$ より $3 - 2\vec a\cdot\vec b + 4 = 5$、$\vec a\cdot\vec b = 1$。$|\vec b - \vec c|^2 = 3$ より $4 - 2\vec b\cdot\vec c + 5 = 3$、$\vec b\cdot\vec c = 3$。

$$\overrightarrow{\mathrm{OB}}\cdot\overrightarrow{\mathrm{CA}} = \vec b\cdot(\vec a - \vec c) = 1 - 3 = -2$$ $$\cos\theta = \frac{|\overrightarrow{\mathrm{OB}}\cdot\overrightarrow{\mathrm{CA}}|}{\mathrm{OB}\cdot\mathrm{CA}} = \frac{2}{2 \cdot 2} = \frac12 \qquad\therefore\ \theta = \frac{\pi}{3}$$

(2)

向かい合う辺の長さが等しいので、四面体は直方体の 4 つの頂点を結んでできる（各辺が直方体の面の対角線になる）。直方体の 3 辺を $p,\ q,\ r$ とすると

$$p^2 + q^2 = 5,\quad q^2 + r^2 = 3,\quad r^2 + p^2 = 4$$

辺々加えて $p^2 + q^2 + r^2 = 6$。四面体の外接球は直方体の外接球と同じなので、半径は直方体の対角線の半分。

$$R = \frac{\sqrt{p^2 + q^2 + r^2}}{2} = \frac{\sqrt6}{2}$$

（直方体を使わない場合：外接球の中心を $\overrightarrow{\mathrm{OT}} = s\vec a + t\vec b + u\vec c$ とおき、$|\overrightarrow{\mathrm{OT}}| = |\overrightarrow{\mathrm{AT}}| = |\overrightarrow{\mathrm{BT}}| = |\overrightarrow{\mathrm{CT}}|$ から $s,\ t,\ u$ を決めても同じ結果になります。）

実際、$p = \sqrt3,\ q = \sqrt2,\ r = 1$ で $\mathrm{O}(0,0,0)$，$\mathrm{A}(0,\sqrt2,1)$，$\mathrm{B}(\sqrt3,0,1)$，$\mathrm{C}(\sqrt3,\sqrt2,0)$ とおくと、すべての条件をみたします。

動く図解

ドラッグで回転できます。四面体 OABC（赤）が直方体（灰色）にぴったり収まり、3 本の直線 $\ell,\ m,\ n$（青・緑・オレンジ）は直方体の中心を通って各面に垂直、つまり互いに垂直です。

問題の背景

等面四面体

向かい合う 3 組の辺の長さがそれぞれ等しい四面体を等面四面体といいます。4 つの面がすべて合同な三角形（本問では 3 辺が $\sqrt3,\ 2,\ \sqrt5$）になるからです。等面四面体は必ず直方体に埋め込めるので、体積・外接球・内接球などが直方体を使ってすっきり計算できます。大学入試では頻出のテーマです。

四面体の問題で「向かい合う辺が等しい」「中点を結ぶ線分が垂直」などが出たら、直方体への埋め込みを疑う。3 辺 $p,\ q,\ r$ の直方体から 4 隅を切り落とすと体積 $\dfrac{pqr}{3}$ の等面四面体が残る。

類題紹介

本問の四面体 $\mathrm{OABC}$ の体積を求めよ。

（自作）

略解

直方体（体積 $pqr = \sqrt3\cdot\sqrt2\cdot1 = \sqrt6$）から、4 隅の三角錐（それぞれ体積 $\frac16 pqr$）を除くと

$$V = pqr - 4\cdot\frac{pqr}{6} = \frac{pqr}{3} = \frac{\sqrt6}{3}$$

本問の四面体 $\mathrm{OABC}$ に内接する球の半径を求めよ。

（九大 2020　魔改造）

略解

4 つの面は 3 辺が $\sqrt3,\ 2,\ \sqrt5$ の合同な三角形。その面積 $S$ は、$\cos A = \dfrac{3 + 4 - 5}{2\cdot\sqrt3\cdot2} = \dfrac{1}{2\sqrt3}$，$\sin A = \sqrt{\dfrac{11}{12}}$ より

$$S = \frac12\cdot\sqrt3\cdot2\cdot\sqrt{\frac{11}{12}} = \frac{\sqrt{11}}{2}$$

体積 $V = \frac13 r\cdot 4S$ より

$$r = \frac{3V}{4S} = \frac{\sqrt6}{2\sqrt{11}} = \frac{\sqrt{66}}{22}$$

（chopin 先生が勘違いしかけた「内接球」バージョンです。）
