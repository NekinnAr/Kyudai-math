$\alpha$ を実数とする。数列 $\{a_n\}$ が

$$a_1 = \alpha,\qquad a_{n+1} = |a_n - 1| + a_n - 1\quad(n = 1,\ 2,\ 3,\ \cdots)$$

で定められるとき，以下の問いに答えよ。

  1. (1)　$\alpha \le 1$ のとき，数列 $\{a_n\}$ の収束，発散を調べよ。
  2. (2)　$\alpha \gt 2$ のとき，数列 $\{a_n\}$ の収束，発散を調べよ。
  3. (3)　$1 \lt \alpha \lt \dfrac32$ のとき，数列 $\{a_n\}$ の収束，発散を調べよ。
  4. (4)　$\dfrac32 \le \alpha \lt 2$ のとき，数列 $\{a_n\}$ の収束，発散を調べよ。

（2023 九州大学 前期 理系 第2問）

解答例

まず絶対値を外して漸化式の正体をつかむ。$a_n \ge 1$ なら $a_{n+1} = 2(a_n - 1)$、$a_n \lt 1$ なら $a_{n+1} = 0$。つまり一度 $1$ 未満になったら次からはずっと $0$。あとは「いつ $1$ 未満になるか」を追いかける。

解答例（タップで展開）

$f(x) = |x - 1| + x - 1$ とおくと

$$f(x) = \begin{cases} 2(x - 1) & (x \ge 1) \\ 0 & (x \lt 1) \end{cases}$$

特に、ある $k$ で $a_k \lt 1$ となれば $a_{k+1} = 0$、$0 \lt 1$ なので $a_{k+2} = 0$、… と以後すべて $0$ になる。…（☆）

(1)

$\alpha \lt 1$ なら $a_2 = 0$、$\alpha = 1$ なら $a_2 = 2(1 - 1) = 0$。いずれも $a_2 = 0 \lt 1$ なので（☆）より $a_n = 0\ (n \ge 2)$。$0$ に収束する。

(2)

$a_n \gt 2$ ならば $a_{n+1} = 2(a_n - 1) \gt 2$ なので、帰納的にすべての $n$ で $a_n \gt 2$。よって $a_{n+1} = 2a_n - 2$、すなわち $a_{n+1} - 2 = 2(a_n - 2)$ より

$$a_n = 2 + (\alpha - 2)\cdot 2^{n-1} \to \infty\qquad(\alpha - 2 \gt 0)$$

正の無限大に発散する。

(3)

$a_2 = 2(\alpha - 1)$ で、$1 \lt \alpha \lt \frac32$ より $0 \lt a_2 \lt 1$。（☆）より $a_n = 0\ (n \ge 3)$。$0$ に収束する。

(4)

$b_n = 2 - a_n$ とおく。$a_n \ge 1$（$b_n \le 1$）のとき $a_{n+1} = 2a_n - 2$ より $b_{n+1} = 2b_n$。

$b_1 = 2 - \alpha$ で $0 \lt b_1 \le \frac12$。$2^{N-1}b_1 \le 1 \lt 2^N b_1$ をみたす自然数 $N$ をとる（$b_1 \gt 0$ なので存在する）。$n = 1,\ 2,\ \dots,\ N$ では $b_n = 2^{n-1}b_1 \le 1$、つまり $a_n \ge 1$ が帰納的に保たれ、

$$b_{N+1} = 2^N b_1 \gt 1\quad\text{すなわち}\quad a_{N+1} \lt 1$$

（☆）より $a_n = 0\ (n \ge N + 2)$。$0$ に収束する。

動く図解

グラフ $y = f(x)$ と直線 $y = x$ を使ったクモの巣図（cobweb plot）です。$\alpha$ を動かすと、点が $y = f(x)$ と $y = x$ の間を行き来して数列の動きが分かります。$\alpha$ を $2$ に近づけると、$0$ に落ちるまでの回数がどんどん増えます。

問題の背景

不動点 $x = 2$ は「不安定」

$f(2) = 2$ なので、$\alpha = 2$ ならずっと $a_n = 2$ です。でも $2$ から少しでもずれると、ずれ $2 - a_n$ は毎回 2 倍に拡大され、上にずれれば $\infty$ へ、下にずれれば最後は $0$ に落ちます。このような不動点を不安定な不動点（反発的不動点）と呼びます。傾き $2$ の直線と $y = x$ の交点なので、クモの巣図が外向きに広がっていくのが分かります。

落ちるまでの回数

(4) の議論から、$2 - \dfrac{1}{2^{k-1}} \le \alpha \lt 2 - \dfrac{1}{2^k}$ のとき、$a_{k+1}$ で初めて $1$ 未満になり、$a_{k+2}$ 以降が $0$ です。chopin 先生の解説にもある通り、場合分けの境界は $2 - \frac{1}{2^k}$ という形をしています。

区分的に定義された漸化式は、「状態が変わる条件」と「一度入ったら抜けられない状態」を見つけるのがコツ。本問では「$1$ 未満 → 以後 $0$」がそれでした。

類題紹介

本問の数列で $\alpha = 2 - \dfrac{1}{1000}$ とする。$a_n = 0$ となる最小の $n$ を求めよ。

（自作）

略解

$b_n = 2 - a_n$ とすると、$b_n \le 1$ の間は $b_n = \dfrac{2^{n-1}}{1000}$。$2^9 = 512 \le 1000 \lt 1024 = 2^{10}$ より $b_{10} \le 1 \lt b_{11}$。よって $a_{10} \ge 1$、$a_{11} \lt 1$（$a_{11} = 2 - 1.024 = 0.976$）、$a_{12} = 0$。答えは $n = 12$。

数列 $\{a_n\}$ を $a_1 = \alpha$，$a_{n+1} = 2|a_n - 1|$ で定める。ただし $0 \le \alpha \le 2$ とする。$a_3 = a_1$ かつ $a_2 \neq a_1$ となる $\alpha$ をすべて求めよ。

（九大 2023　魔改造）

略解

$g(x) = 2|x - 1|$ は $[0,\ 2]$ を $[0,\ 2]$ に移す「テント写像」。$g(g(x)) = x$ を、$x$ と $g(x)$ が $1$ 以上か未満かの 4 通りに分けて解く。

  • $x \ge 1,\ g(x) \ge 1$：$4(x - 1) - 2 = x$ より $x = 2$（不動点）
  • $x \ge 1,\ g(x) \lt 1$：$2 - 4(x - 1) = x$ より $x = \frac65$（$g(\frac65) = \frac25 \lt 1$ で適）
  • $x \lt 1,\ g(x) \ge 1$：$4(1 - x) - 2 = x$ より $x = \frac25$（$g(\frac25) = \frac65$ で適）
  • $x \lt 1,\ g(x) \lt 1$：$2 - 4(1 - x) = x$ より $x = \frac23$（不動点）

不動点を除いて $\alpha = \dfrac25,\ \dfrac65$（周期 2 の軌道 $\frac25 \to \frac65 \to \frac25 \to \cdots$）。

本問の $f$ は $1$ 未満を全部 $0$ に潰してしまいますが、テント写像は $[0,\ 2]$ の中で永遠に動き回り、周期点がいくらでもあるカオスの代表例です。
