以下の問いに答えよ。

  1. (1)　$n$ を整数とするとき，$n^2$ を $8$ で割った余りは $0,\ 1,\ 4$ のいずれかであることを示せ。
  2. (2)　$2^m = n^2 + 3$ をみたす $0$ 以上の整数の組 $(m,\ n)$ をすべて求めよ。

（2025 九州大学 前期 理系 第3問）

解答例

(1) が (2) への露骨な誘導。$m \ge 3$ のとき左辺は $8$ の倍数になるので、両辺を $8$ で割った余りを比べるだけで決着する。

解答例（タップで展開）

(1)

$n$ が偶数のとき、$n = 2k$（$k$ は整数）とおくと $n^2 = 4k^2$。

  • $k$ が偶数なら $4k^2$ は $16$ の倍数なので、$8$ で割った余りは $0$。
  • $k$ が奇数なら $k^2$ は奇数なので $4k^2 = 8\cdot\dfrac{k^2-1}{2} + 4$ より余りは $4$。

$n$ が奇数のとき、$n = 2k+1$ とおくと

$$n^2 = 4k(k+1) + 1$$

であり、$k(k+1)$ は連続 2 整数の積なので偶数。よって $4k(k+1)$ は $8$ の倍数で、余りは $1$。

以上より、$n^2$ を $8$ で割った余りは $0,\ 1,\ 4$ のいずれかである。$\blacksquare$

(2)

(1) より、$n^2+3$ を $8$ で割った余りは $3,\ 4,\ 7$ のいずれかであり、特に $8$ の倍数にはならない。

一方、$m \ge 3$ のとき $2^m$ は $8$ の倍数なので不適。したがって $m = 0,\ 1,\ 2$ に限られる。

  • $m=0$：$n^2 = 1 - 3 = -2$ となり不適。
  • $m=1$：$n^2 = 2 - 3 = -1$ となり不適。
  • $m=2$：$n^2 = 4 - 3 = 1$ より $n = 1$（$n \ge 0$）。

よって $(m,\ n) = (2,\ 1)$。

動画では、(1) の誘導（$\bmod 8$）を使わない解法が 2 つ紹介されています。以下にその内容を整理しました（記述は管理人が答案の形に整えたものです）。

別解 1：偶奇と「連続 2 整数の積」（鶴崎さんの解法）

まず小さい値を代入して $(m,\ n)=(2,\ 1)$ を見つけたあと、「$2^m$ は $n^2+3$ よりずっと速く増えるので、解はほとんどなさそう」と見当をつけてから証明に入ります。

別解 1（タップで展開）

$m=0$ のとき $n^2 = -2$ で不適。よって $m \ge 1$ で、左辺 $2^m$ は偶数。$n$ が偶数だと右辺 $n^2+3$ は奇数になるので、$n$ は奇数。$n = 2k+1$（$k \ge 0$ の整数）とおくと

$$n^2 + 3 = 4k^2 + 4k + 4 = 4(k^2 + k + 1)$$

右辺は $4$ の倍数なので $m \ge 2$ で、両辺を $4$ で割ると

$$2^{m-2} = k(k+1) + 1$$

$k(k+1)$ は連続 2 整数の積なので偶数。よって右辺は奇数。奇数になる $2$ のべきは $2^0 = 1$ だけなので

$$m - 2 = 0,\qquad k(k+1) = 0$$

$k \ge 0$ より $k = 0$。よって $(m,\ n) = (2,\ 1)$。

ポイント：$k^2+k+1$ を丸ごと因数分解しようとせず、$k^2+k$ の部分だけを $k(k+1)$ とくくる。整数問題では、こうすると偶奇の情報が手に入ります。動画では「模範解答よりスマートかも」と評されていました。

別解 2：$\bmod 3$ と因数分解

動画で「誘導がなければこう解く」として紹介されている解法です。式に $3$ があるので、$3$ で割った余りを見ます。

別解 2（タップで展開）

$2 \equiv -1 \pmod 3$ より $2^m \equiv (-1)^m \pmod 3$。一方、$n^2 + 3 \equiv n^2 \pmod 3$ で、平方数を $3$ で割った余りは $0,\ 1$。$(-1)^m$ は $1$ か $-1 \equiv 2$ なので、両辺が等しくなるのは $(-1)^m \equiv 1$、つまり $m$ が偶数のとき。

$m = 2l$（$l \ge 0$）とおくと、$2^{2l} - n^2 = 3$ より

$$(2^l - n)(2^l + n) = 3$$

$2^l + n \gt 0$ なので $2^l - n \gt 0$ でもあり、$2^l - n \le 2^l + n$ だから（$3$ が素数であることから）

$$2^l - n = 1,\qquad 2^l + n = 3$$

辺々足して $2^{l+1} = 4$ より $l = 1$、引いて $n = 1$。よって $(m,\ n) = (2,\ 1)$。

ポイント：$m$ が偶数と分かれば「$2^m$ が平方数」になり、平方の差の因数分解が使えます。動画では「足して 3、引いて 1 なら、平均の 2 が $2^l$」という見方も紹介されていました。

誘導（mod 8）の解法についての補足

動画の後半では、本来の誘導である (1) の解き方にも触れています。

  • $n$ を $8$ で割った余りが $0,\ 1,\ \ldots,\ 7$ の場合を調べれば十分です。$n = 8k + x$ とおくと $n^2 = x^2 + 16kx + 64k^2$ で、$x^2$ 以外の項は $8$ の倍数だからです（合同式の性質「$a \equiv b$ なら $a^2 \equiv b^2$」）。
  • 誘導がない場合、$\bmod 2$ → $\bmod 4$ → $\bmod 8$ と試して見つけることになりそうです。$\bmod 2$ や $\bmod 4$ では決め手にならない理由は、下の「問題の背景」で詳しく扱っています。

動く図解

本問の「$3$」を好きな数 $k$ に変えて、$2^m = n^2 + k$ の解を探してみましょう。$m \le 200$ の範囲を全探索し、あわせて「$8$ で割った余り」だけで $m \ge 3$ の解を否定できるかどうかを判定します。

（試してほしい値：3, 5, 7, 15, 23）

※ 大きな数は BigInt で厳密に計算しています。

問題の背景

なぜ「8 で割った余り」なのか

$2^m$ は $m$ が大きいほど $2$ を多く因数にもつので、「$2^j$ で割った余り」を見るのは自然な発想です。では、もっと小さい $4$ ではダメなのでしょうか。

平方数を $4$ で割った余りは $0,\ 1$ なので、$n^2+3$ を $4$ で割った余りは $3,\ 0$ です。余り $0$ が残ってしまう（$n$ が奇数のとき）ので、$\bmod 4$ では $m \ge 2$ の解を否定しきれません。

奇数の平方は $\bmod 8$ で必ず $1$ になる、という一段細かい情報を使って初めて $n^2 + 3 \equiv 4 \pmod 8$ となり、$8$ の倍数でないことが言えます。つまり (1) の「$8$」は、この論法が通用する最小の $2$ のべきになっているわけです。

3 を他の数に変えると？

$2^m = n^2 + k$ について、上と同じ議論ができるのはどんな $k$ でしょうか。$n^2 \equiv 0,\ 1,\ 4 \pmod 8$ なので、$n^2 + k \equiv 0 \pmod 8$ となりうるのは

$$k \equiv 0,\ 7,\ 4 \pmod 8$$

のときに限られます。逆に言えば $k \equiv 1,\ 2,\ 3,\ 5,\ 6 \pmod 8$ なら、本問とまったく同じ方法で $m \ge 3$ の解がないことが分かります。$k \equiv 0,\ 4$ のときは $n$ が偶数になるので、両辺を $4$ で割って小さな問題に帰着できます。

問題は $k \equiv 7 \pmod 8$ のときです。このとき $\bmod 8$ どころか、$\bmod 16,\ \bmod 32,\ \ldots$ と、どんな $2^j$ で割った余りを見ても矛盾は出てきません。（$-7 \equiv 1 \pmod 8$ なので、$n^2 \equiv -7 \pmod{2^j}$ はどの $j$ でも解をもつ、という事実によります。）

ラマヌジャン–ナゲルの方程式

その代表例が $k=7$ の場合で、

$$2^m = n^2 + 7$$

はラマヌジャン–ナゲル方程式と呼ばれています。上の「動く図解」で $k=7$ を入力すると分かるように、

$$n = 1,\ 3,\ 5,\ 11,\ 181 \quad (m = 3,\ 4,\ 5,\ 7,\ 15)$$

という 5 つの解をもちます。ラマヌジャンは 1913 年にこれ以外に解がないと予想し、1948 年にナゲルが証明しました。その証明には、$\sqrt{-7}$ を含む数の世界（代数的整数論）での素因数分解が使われます。

3 つの解法は $k=7$ で全部止まる

ここまでに出てきた 3 つの解法を $2^m = n^2 + 7$ に当てはめてみると、どれも途中で止まってしまいます。

解法$k=3$ のとき$k=7$ のとき
$\bmod 8$（誘導）$n^2+3 \equiv 3,4,7$ で $0$ にならない$n$ が奇数なら $n^2+7 \equiv 0$ になり、矛盾が出ない
偶奇（別解 1）$2^{m-2} = k(k+1)+1$ は奇数$n=2k+1$ とすると $2^{m-2} = k(k+1)+2$ は偶数になり、決め手にならない
$\bmod 3$（別解 2）$m$ は偶数と分かる$n^2+7 \equiv n^2+1 \equiv 1,2$ で、$(-1)^m$ に何の制限もつかない（$\bmod 7$ で見ても $2^m \equiv 1,2,4$ はすべて平方数の余りなので同様）
本問は「$k=3$ ならどの方針でも数行で終わるが、$k=7$ にすると数論の難問になる」という、紙一重の位置に置かれた問題だと言えます。

類題紹介

$2^m = n^2 + 1$ をみたす $0$ 以上の整数の組 $(m,\ n)$ をすべて求めよ。

（自作）

略解

平方数を $4$ で割った余りは $0,\ 1$ なので $n^2+1 \equiv 1,\ 2 \pmod 4$。よって $m \ge 2$ は不適。$m=0,\ 1$ を調べて $(m,\ n) = (0,\ 0),\ (1,\ 1)$。（こちらは $\bmod 4$ で十分です。）

$2^m + 1 = n^2$ をみたす正の整数の組 $(m,\ n)$ をすべて求めよ。

（自作）

略解

余りではなく因数分解で攻める型。$(n-1)(n+1) = 2^m$ より $n-1,\ n+1$ はともに $2$ のべきで、差が $2$ なので $n-1 = 2,\ n+1 = 4$。よって $(m,\ n) = (3,\ 3)$。

$m$ を偶数とする。$2^m = n^2 + 7$ をみたす $0$ 以上の整数の組 $(m,\ n)$ をすべて求めよ。

（九大 2025　魔改造）

略解

$\bmod 8$ は通用しないので因数分解に切り替える。$m = 2l$ とおくと $(2^l - n)(2^l + n) = 7$。$2^l + n \gt 0$ より両因数は正で、$2^l - n \le 2^l + n$ だから $2^l - n = 1,\ 2^l + n = 7$。よって $2^l = 4,\ n = 3$ となり $(m,\ n) = (4,\ 3)$。

$m$ が奇数の場合も含めた完全な解決が、上で紹介したラマヌジャン–ナゲルの定理です。
