$a,\ b,\ c,\ d$ を整数とし，$i$ を虚数単位とする。整式 $f(x) = x^4 + ax^3 + bx^2 + cx + d$ が $f\!\left(\dfrac{1 + \sqrt3 i}{2}\right) = 0$ をみたすとき，以下の問いに答えよ。

  1. (1)　$c,\ d$ を $a,\ b$ を用いて表せ。
  2. (2)　$f(1)$ を $7$ で割ると $1$ 余り，$11$ で割ると $10$ 余るとする。また，$f(-1)$ を $7$ で割ると $3$ 余り，$11$ で割ると $10$ 余るとする。$a$ の絶対値と $b$ の絶対値がともに $40$ 以下であるとき，方程式 $f(x) = 0$ の解をすべて求めよ。

（2020 九州大学 前期 理系 第2問）

解答例

$\alpha = \dfrac{1 + \sqrt3 i}{2} = \cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}$ なので $\alpha^3 = -1$ で、累乗が簡単に計算できる。(2) は $f(1),\ f(-1)$ を $a,\ b$ で表し、合同式で $a,\ b$ を絞り込む。

解答例（タップで展開）

(1)

$\alpha = \dfrac{1 + \sqrt3 i}{2}$ は $\alpha^2 - \alpha + 1 = 0$ をみたす。よって $\alpha^2 = \alpha - 1$，$\alpha^3 = -1$，$\alpha^4 = -\alpha$。

$$f(\alpha) = -\alpha - a + b(\alpha - 1) + c\alpha + d = (b + c - 1)\alpha + (d - a - b) = 0$$

$b + c - 1,\ d - a - b$ は実数（整数）で $\alpha$ は虚数なので、$b + c - 1 = 0$ かつ $d - a - b = 0$。

$$c = 1 - b,\qquad d = a + b$$

(2)

(1) より $f(x) = x^4 + ax^3 + bx^2 + (1 - b)x + (a + b)$。

$$f(1) = 2a + b + 2,\qquad f(-1) = 3b$$

$b$ を決める：$3b \equiv 3 \pmod 7$ より $b \equiv 1 \pmod 7$。$3b \equiv 10 \pmod{11}$ の両辺に $4$ をかけると（$3 \cdot 4 = 12 \equiv 1$）$b \equiv 40 \equiv 7 \pmod{11}$。

$b = 7k + 1$ とおくと $7k + 1 \equiv 7 \pmod{11}$、$7k \equiv 6$、両辺に $8$ をかけて（$7 \cdot 8 = 56 \equiv 1$）$k \equiv 48 \equiv 4 \pmod{11}$。よって $b \equiv 29 \pmod{77}$。$|b| \le 40$ より $b = 29$。

$a$ を決める：$f(1) = 2a + 31$。$2a + 31 \equiv 1 \pmod 7$ より $2a \equiv -30 \equiv -2$、$a \equiv -1 \equiv 6 \pmod 7$（$2$ と $7$ は互いに素）。$2a + 31 \equiv 10 \pmod{11}$ より $2a \equiv -21 \equiv 1 \equiv 12$、$a \equiv 6 \pmod{11}$。よって $a \equiv 6 \pmod{77}$、$|a| \le 40$ より $a = 6$。

このとき $c = -28$，$d = 35$ で

$$f(x) = x^4 + 6x^3 + 29x^2 - 28x + 35 = (x^2 - x + 1)(x^2 + 7x + 35)$$

（$\alpha$ とその共役 $\bar\alpha$ が解なので、$f(x)$ は $x^2 - x + 1$ で割り切れる。）

$$x = \frac{1 \pm \sqrt3 i}{2},\quad \frac{-7 \pm \sqrt{91}\,i}{2}$$

動く図解

整数 $a,\ b$ を動かすと、(1) の関係で $c,\ d$ が決まり、$f(x) = 0$ の 4 つの解が複素数平面上に表示されます。$\frac{1 \pm \sqrt3 i}{2}$（灰色の円周上）はいつも解です。(2) の 4 つの条件をすべてみたす $(a,\ b)$ を探してみましょう。

問題の背景

$\omega$ の仲間を使った計算

$\alpha = \frac{1 + \sqrt3 i}{2}$ は $-\omega^2$（$\omega$ は 1 の虚数立方根）で、$\alpha^6 = 1$ をみたす「1 の 6 乗根」です。chopin 先生も「$\alpha = \cos 60^\circ + i\sin 60^\circ$ なので、$\alpha$ の累乗がド・モアブルの定理で簡単に計算できる」と指摘しています。次数下げ（$\alpha^2 = \alpha - 1$）でも同じことができます。

中国剰余定理

(2) は「7 で割った余り」と「11 で割った余り」から「77 で割った余り」を決める、中国剰余定理そのものです。7 と 11 が互いに素なので、$0 \sim 76$ の中に条件をみたす数がちょうど 1 つあります。絶対値 $40$ 以下という条件は、77 の幅の中で 1 つに決めるためのものです。

chopin 先生は「(2) は意外と息の長い計算が必要」「あとは $f(1),\ f(-1)$ の余りの条件を愚直に処理していくしかない」と評し、やや難レベルに分類しています。

実数係数の方程式が虚数解 $\alpha$ をもつ → $\bar\alpha$ も解 → $(x - \alpha)(x - \bar\alpha)$ で割り切れる。合同式で「$3b \equiv 10$」のような式は、$3$ の逆数（$3 \cdot 4 \equiv 1$ となる $4$）をかけて解く。

類題紹介

$\omega = \dfrac{-1 + \sqrt3 i}{2}$ とする。整数 $a,\ b,\ c$ に対して $g(x) = x^3 + ax^2 + bx + c$ が $g(\omega) = 0$ をみたすとき，$b,\ c$ を $a$ で表し，$g(x)$ を因数分解せよ。

（自作）

略解

$\omega^2 = -1 - \omega$，$\omega^3 = 1$ より $g(\omega) = (1 - a + c) + (b - a)\omega = 0$。よって $b = a$，$c = a - 1$ で

$$g(x) = x^3 + ax^2 + ax + a - 1 = (x^2 + x + 1)(x + a - 1)$$

本問 (2) で「$a$ の絶対値と $b$ の絶対値がともに $40$ 以下」という条件をはずす。方程式 $f(x) = 0$ が実数解をもつような整数の組 $(a,\ b)$ のうち，$|a| + |b|$ が最小となるものを求め，そのときの実数解を求めよ。

（九大 2020　魔改造）

略解

本問と同じ計算で $a \equiv 6,\ b \equiv 29 \pmod{77}$。$f(x) = (x^2 - x + 1)\{x^2 + (a + 1)x + (a + b)\}$ なので、実数解をもつ条件は $(a + 1)^2 - 4(a + b) \ge 0$、すなわち $(a - 1)^2 \ge 4b$。

  • $b = 29$ のとき：$(a - 1)^2 \ge 116$ が必要で、$a = 6$ は不適。$a = 83,\ -71$ が候補で $|a| + |b| \ge 100$。
  • $b = -48$ のとき：常に成り立つので $a = 6$ でよく、$|a| + |b| = 54$。
  • $|b| \ge 106$ なら $|a| + |b| \gt 54$。

よって $(a,\ b) = (6,\ -48)$。$x^2 + 7x - 42 = 0$ より実数解は $x = \dfrac{-7 \pm \sqrt{217}}{2}$。
