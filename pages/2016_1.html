座標平面上の曲線 $C_1,\ C_2$ をそれぞれ

$$C_1：y = \log x \quad (x \gt 0),\qquad C_2：y = (x - 1)(x - a)$$

とする。ただし，$a$ は実数である。$n$ を自然数とするとき，曲線 $C_1,\ C_2$ が 2 点 $\mathrm{P},\ \mathrm{Q}$ で交わり，$\mathrm{P},\ \mathrm{Q}$ の $x$ 座標はそれぞれ $1,\ n + 1$ となっている。また，曲線 $C_1$ と直線 $\mathrm{PQ}$ で囲まれた領域の面積を $S_n$，曲線 $C_2$ と直線 $\mathrm{PQ}$ で囲まれた領域の面積を $T_n$ とする。このとき，以下の問いに答えよ。

  1. (1)　$a$ を $n$ の式で表し，$a \gt 1$ を示せ。
  2. (2)　$S_n$ と $T_n$ をそれぞれ $n$ の式で表せ。
  3. (3)　極限値 $\displaystyle\lim_{n\to\infty}\frac{S_n}{n\log T_n}$ を求めよ。

（2016 九州大学 前期 理系 第1問）

解答例

$x = n + 1$ を代入して $a$ を求める。$T_n$ は放物線と弦で囲まれた部分なので $\frac16$ 公式で一発。$S_n$ は $\int\log x\,dx$ から台形を引く。

解答例（タップで展開）

(1)

$x = 1$ では両方とも $y = 0$ で、自動的に交わる。$x = n + 1$ で交わる条件は $\log(n + 1) = n(n + 1 - a)$ なので

$$a = n + 1 - \frac{\log(n + 1)}{n}$$

$a - 1 = n - \dfrac{\log(n+1)}{n} = \dfrac{n^2 - \log(n + 1)}{n}$。$x \gt 0$ で $\log(1 + x) \lt x$（$g(x) = x - \log(1 + x)$ は $g(0) = 0$，$g'(x) = \frac{x}{1+x} \gt 0$）なので $\log(n + 1) \lt n \le n^2$。よって $a \gt 1$。

(2)

$y = \log x$ は上に凸なので、$1 \le x \le n + 1$ で $C_1$ は弦 PQ の上側にある。

$$S_n = \int_1^{n+1}\log x\,dx - \frac12\cdot n\cdot\log(n + 1) = \Big[x\log x - x\Big]_1^{n+1} - \frac n2\log(n + 1)$$ $$= (n + 1)\log(n + 1) - n - \frac n2\log(n+1) = \frac{n + 2}{2}\log(n + 1) - n$$

$C_2$ は $x^2$ の係数が $1$ の放物線で、弦 PQ の下側にある。直線 PQ を $y = \ell(x)$ とすると $\ell(x) - (x-1)(x-a) = -(x - 1)(x - n - 1)$ なので

$$T_n = \int_1^{n+1}\{-(x - 1)(x - n - 1)\}dx = \frac{n^3}{6}$$

(3)

$$\frac{S_n}{n\log T_n} = \frac{\frac{n+2}{2}\log(n + 1) - n}{n(3\log n - \log 6)}$$

分母・分子を $n\log n$ で割る。$\dfrac{\log(n+1)}{\log n} = 1 + \dfrac{\log(1 + \frac1n)}{\log n} \to 1$，$\dfrac{1}{\log n} \to 0$ より

$$\text{分子}/(n\log n) = \frac{n + 2}{2n}\cdot\frac{\log(n+1)}{\log n} - \frac{1}{\log n} \to \frac12,\qquad \text{分母}/(n\log n) = 3 - \frac{\log 6}{\log n} \to 3$$ $$\lim_{n\to\infty}\frac{S_n}{n\log T_n} = \frac16$$

動く図解

$n$ を動かすと、$C_1$（赤）と弦 PQ で囲まれた部分 $S_n$、$C_2$（青）と弦で囲まれた部分 $T_n$ が表示されます。$T_n$ のほうが圧倒的に大きくなっていく様子がわかります。

問題の背景

凸・凹と弦の位置関係

上に凸な $\log x$ は弦の上に、下に凸な放物線は弦の下にあります。$T_n$ は有名な $\int_\alpha^\beta -(x-\alpha)(x-\beta)\,dx = \frac{(\beta - \alpha)^3}{6}$ で、$a$ の値にかかわらず $\frac{n^3}{6}$ になるのがポイントです。

(3) は $S_n \approx \frac n2\log n$，$\log T_n \approx 3\log n$ という主要項の比較で、答えの $\frac16$ が見通せます。

chopin 先生は「(1) $C_1$ と $C_2$ を連立した式が $x = n + 1$ を解に持つことから $a$ が求まります（$x = 1$ は必ず解に持つので考えなくてよし）」「(3) も定義に従って計算するだけ。$\log(n + 1) \div \log n$ は 1 に収束します」とコメントしています。

放物線と直線で囲まれた面積は $\frac{|a|}{6}(\beta - \alpha)^3$。極限は主要項（$n\log n$）で割って各項の収束を確かめる。$\frac{\log(n+1)}{\log n} \to 1$ は頻出。

類題紹介

曲線 $y = \log x$ と，2 点 $(1,\ 0)$，$(e,\ 1)$ を結ぶ線分で囲まれた部分の面積を求めよ。

（自作）

略解

$\displaystyle\int_1^e\log x\,dx = \Big[x\log x - x\Big]_1^e = 1$。三角形部分 $\frac12(e - 1)\cdot1$ を引いて $\dfrac{3 - e}{2}$。

本問の $C_1$ を $y = \sqrt x$ に変え，$C_1$ と $C_2：y = (x - 1)(x - a)$ が $x$ 座標 $1,\ (n + 1)^2$ の 2 点 P，Q で交わるとする。$C_1$ と直線 PQ で囲まれた面積 $S_n$，$C_2$ と直線 PQ で囲まれた面積 $T_n$ を求め，$\dfrac{S_n}{T_n}$ を $n$ で表せ。

（九大 2016　魔改造）

略解

$C_1$ は $x = y^2$（$y \ge 0$）という横向きの放物線なので、$y$ で積分すれば $\frac16$ 公式が使える。弦 PQ は $y = 1$ から $y = n + 1$ までなので $S_n = \dfrac{n^3}{6}$。

$T_n$ は $x$ 方向の幅が $(n + 1)^2 - 1 = n(n + 2)$ なので $T_n = \dfrac{n^3(n + 2)^3}{6}$。

$$\frac{S_n}{T_n} = \frac{1}{(n + 2)^3}$$

（$a = (n+1)^2 - \frac{n+1}{n(n+2)}$ だが、答えには不要。）
