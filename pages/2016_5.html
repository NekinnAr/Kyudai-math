以下の問いに答えよ。

  1. (1)　$\theta$ を $0 \le \theta \lt 2\pi$ を満たす実数，$i$ を虚数単位とし，$z$ を $z = \cos\theta + i\sin\theta$ で表される複素数とする。このとき，整数 $n$ に対して次の式を証明せよ。 $$\cos n\theta = \frac12\left(z^n + \frac{1}{z^n}\right),\qquad \sin n\theta = -\frac i2\left(z^n - \frac{1}{z^n}\right)$$
  2. (2)　次の方程式を満たす実数 $x$（$0 \le x \lt 2\pi$）を求めよ。 $$\cos x + \cos 2x - \cos 3x = 1$$
  3. (3)　次の式を証明せよ。 $$\sin^2 20^\circ + \sin^2 40^\circ + \sin^2 60^\circ + \sin^2 80^\circ = \frac94$$

（2016 九州大学 前期 理系 第5問）

解答例

(1) はド・モアブル。(2) は $\cos x$ の 3 次方程式がきれいに因数分解できる。(3) は半角の公式で $\cos 40^\circ + \cos 80^\circ + \cos 160^\circ = 0$ に帰着。

解答例（タップで展開）

(1)

ド・モアブルの定理より $z^n = \cos n\theta + i\sin n\theta$，$\dfrac1{z^n} = z^{-n} = \cos n\theta - i\sin n\theta$（$n$ は負の整数でもよい）。

$$z^n + \frac1{z^n} = 2\cos n\theta,\qquad z^n - \frac1{z^n} = 2i\sin n\theta$$

よって $\cos n\theta = \frac12\left(z^n + \frac1{z^n}\right)$，$\sin n\theta = \frac{1}{2i}\left(z^n - \frac1{z^n}\right) = -\frac i2\left(z^n - \frac1{z^n}\right)$。

(2)

$c = \cos x$ とおくと $\cos 2x = 2c^2 - 1$，$\cos 3x = 4c^3 - 3c$ なので

$$c + 2c^2 - 1 - 4c^3 + 3c = 1 \iff 2c^3 - c^2 - 2c + 1 = 0 \iff (c^2 - 1)(2c - 1) = 0$$

$\cos x = 1,\ -1,\ \frac12$ より

$$x = 0,\ \frac\pi3,\ \pi,\ \frac{5\pi}{3}$$

(3)

$\sin^2 60^\circ = \frac34$。残りは半角の公式 $\sin^2\alpha = \frac{1 - \cos 2\alpha}{2}$ より

$$\sin^2 20^\circ + \sin^2 40^\circ + \sin^2 80^\circ = \frac32 - \frac12(\cos 40^\circ + \cos 80^\circ + \cos 160^\circ)$$

和積の公式で $\cos 40^\circ + \cos 80^\circ = 2\cos 60^\circ\cos 20^\circ = \cos 20^\circ$，また $\cos 160^\circ = -\cos 20^\circ$。よって括弧内は $0$。

$$\text{左辺} = \frac32 + \frac34 = \frac94$$

(1) を使う別解。$z = \cos 40^\circ + i\sin 40^\circ$ とすると $z^9 = 1$，$z \ne 1$ なので $1 + z + z^2 + \cdots + z^8 = 0$。(1) より（$\cos 280^\circ = \cos 80^\circ$ などに注意して）

$$\cos 40^\circ + \cos 80^\circ + \cos 160^\circ = \frac12(z + z^8 + z^2 + z^7 + z^4 + z^5) = \frac12\{(-1) - (z^3 + z^6)\}$$

$z^3 = \cos 120^\circ + i\sin 120^\circ = \omega$ は $\omega^2 + \omega + 1 = 0$ をみたすので $z^3 + z^6 = -1$。よって括弧内は $0$。

動く図解

グラフは $y = \cos x + \cos 2x - \cos 3x$ です。直線 $y = 1$ との交点が (2) の解。下のボタンで (3) の 3 つの角 $40^\circ,\ 80^\circ,\ 160^\circ$ を単位円上に表示し、$x$ 座標の和が 0 になる様子を見られます。

問題の背景

20° と 9 次の 1 の冪根

$\cos 20^\circ$ は $\cos 3\theta = \frac12$ の解なので $4c^3 - 3c = \frac12$ という 3 次方程式をみたし、これは有理数の範囲で因数分解できません（作図不可能 → 角の 3 等分問題）。それでも $\cos 40^\circ + \cos 80^\circ + \cos 160^\circ = 0$ のような対称式はきれいな値になります。$40^\circ,\ 160^\circ,\ 280^\circ$ は 120° ずつずれた 3 方向なので、ベクトルの和が 0 になる、と見ることもできます（$\cos 280^\circ = \cos 80^\circ$）。

chopin 先生は「誘導形式かと思いきや、小問集合に近い」「(2) は倍角の公式を使うと $\cos x$ の 3 次関数となります。幸い $\cos x$ は角度が求まる値になります」「(3) $\theta = 20^\circ$ とすると $\cos\theta - \cos2\theta - \cos4\theta$ となり、$\cos 3\theta = \frac12$ から次数下げ」とコメントしています。

$\sin^2,\ \cos^2$ の和は半角の公式で 1 次の $\cos$ の和へ。120° ずつずれた 3 つの角の $\cos$ の和は 0（正三角形の頂点ベクトルの和）。

類題紹介

$\cos 20^\circ\cos 40^\circ\cos 80^\circ = \dfrac18$ を証明せよ。

（自作）

略解

左辺に $\sin 20^\circ$ をかけて 2 倍角の公式を 3 回使うと $\sin 20^\circ\cos 20^\circ\cos 40^\circ\cos 80^\circ = \frac18\sin 160^\circ = \frac18\sin 20^\circ$。両辺を $\sin 20^\circ \ne 0$ で割る。

$\sin^4 20^\circ + \sin^4 40^\circ + \sin^4 80^\circ$ の値を求めよ。

（九大 2016　魔改造）

略解

$\sin^4\alpha = \left(\frac{1 - \cos 2\alpha}{2}\right)^2 = \frac{3 - 4\cos 2\alpha + \cos 4\alpha}{8}$。

$\alpha = 20^\circ,\ 40^\circ,\ 80^\circ$ で和をとると、$\cos 2\alpha$ の和は $\cos 40^\circ + \cos 80^\circ + \cos 160^\circ = 0$、$\cos 4\alpha$ の和は $\cos 80^\circ + \cos 160^\circ + \cos 320^\circ = \cos 80^\circ + \cos 160^\circ + \cos 40^\circ = 0$。

$$\sin^4 20^\circ + \sin^4 40^\circ + \sin^4 80^\circ = \frac98$$
