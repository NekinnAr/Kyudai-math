円 $x^2 + (y - 1)^2 = 4$ で囲まれた図形を $x$ 軸のまわりに 1 回転してできる立体の体積を求めよ。

（2012 九州大学 前期 理系 第1問）

解答例

円が $x$ 軸をまたいでいるのがポイントです。$x$ 軸より下の部分を $x$ 軸に関して折り返して上側に重ねると、回転体は「上半分にできた図形」を回したものになります。断面がドーナツ型になる範囲と円板になる範囲を分けて計算します。

解答例（タップで展開）

$s = \sqrt{4 - x^2}$（$-2 \le x \le 2$）とおくと、直線 $x = (\text{一定})$ による図形の切り口は $1 - s \le y \le 1 + s$ の線分です。

回転体の切り口は、$x$ 軸からの距離の最大値・最小値で決まります。

  • 距離の最大値はつねに $1 + s$。
  • $1 - s \le 0$，すなわち $|x| \le \sqrt3$ のとき、線分は $x$ 軸と交わるので距離の最小値は $0$（切り口は円板）。
  • $1 - s > 0$，すなわち $\sqrt3 < |x| \le 2$ のとき、距離の最小値は $1 - s$（切り口はドーナツ型）。

よって、対称性も使って

$$V = \pi\int_{-2}^{2}(1 + s)^2\,dx - 2\pi\int_{\sqrt3}^{2}(1 - s)^2\,dx$$

ここで $(1 \pm s)^2 = 5 - x^2 \pm 2\sqrt{4 - x^2}$。$\displaystyle\int_{-2}^{2}\sqrt{4 - x^2}\,dx = 2\pi$（半円の面積），$\displaystyle\int_{\sqrt3}^{2}\sqrt{4 - x^2}\,dx$ は中心角 $\frac{\pi}{6}$ の扇形から三角形を引いた弓形の面積で $\dfrac{\pi}{3} - \dfrac{\sqrt3}{2}$。

$$\int_{-2}^{2}(1 + s)^2\,dx = \left(20 - \frac{16}{3}\right) + 4\pi = \frac{44}{3} + 4\pi$$ $$\int_{\sqrt3}^{2}(1 - s)^2\,dx = 5(2 - \sqrt3) - \frac{8 - 3\sqrt3}{3} - 2\left(\frac{\pi}{3} - \frac{\sqrt3}{2}\right) = \frac{22}{3} - 3\sqrt3 - \frac{2\pi}{3}$$

したがって

$$V = \pi\left\{\frac{44}{3} + 4\pi - \frac{44}{3} + 6\sqrt3 + \frac{4\pi}{3}\right\} = \frac{16}{3}\pi^2 + 6\sqrt3\,\pi$$

（$\approx 85.29$）

動く図解

赤が元の円板、灰色の破線が $x$ 軸で折り返した円です。$x$ を動かすと、その位置での回転体の切り口（外半径・内半径）が表示されます。$|x| \le \sqrt3 \approx 1.732$ では内半径が $0$ になります。

問題の背景

軸をまたぐ図形の回転体は「折り返して重ねる」

回転軸をまたぐ図形を回転させるとき、軸の下側の部分は「軸で折り返して上側に重ねた図形」を回しても同じ立体になります。重なった部分を 2 回数えてはいけないので、折り返した図形と元の図形の和集合を回すと考えるのが安全です。

本問では、$|x| \le \sqrt3$ の範囲は和集合が $x$ 軸まで届いているので円板、$\sqrt3 < |x| \le 2$ では元の円の下側の弧が穴の縁になります。境目の $x = \pm\sqrt3$ は、円が $x$ 軸と交わる点です。

chopin 先生は「円を回転してできる立体の体積を求める問題です」「グラフに円を書いてあげれば、非常に容易く体積を出せます」とコメントしています。

回転軸をまたぐ図形は、軸の反対側を折り返して重ね、軸から最も遠い点・最も近い点で切り口を決める。$\int\sqrt{a^2 - x^2}\,dx$ は扇形と三角形で計算。

類題紹介

円 $x^2 + (y - 2)^2 = 1$ で囲まれた図形を $x$ 軸のまわりに 1 回転してできる立体（トーラス）の体積を求めよ。

（自作）

略解

$s = \sqrt{1 - x^2}$ とおくと切り口は外半径 $2 + s$，内半径 $2 - s$ のドーナツ型。

$$V = \pi\int_{-1}^{1}\{(2 + s)^2 - (2 - s)^2\}dx = 8\pi\int_{-1}^{1}\sqrt{1 - x^2}\,dx = 8\pi\cdot\frac{\pi}{2} = 4\pi^2$$

（パップス・ギュルダンの定理：面積 $\pi$ × 重心の描く円周 $2\pi\cdot2$ とも一致。）

円 $x^2 + (y - 1)^2 = 4$ で囲まれた図形を，直線 $y = -1$ のまわりに 1 回転してできる立体の体積を求めよ。

（九大 2012　魔改造）

略解

直線 $y = -1$ は円の最下点 $(0,\ -1)$ で円に接するので、図形は回転軸をまたぎません。点 $(x,\ y)$ の軸からの距離は $y + 1$ なので、$s = \sqrt{4 - x^2}$ として切り口は外半径 $2 + s$，内半径 $2 - s$。

$$V = \pi\int_{-2}^{2}\{(2 + s)^2 - (2 - s)^2\}dx = 8\pi\int_{-2}^{2}\sqrt{4 - x^2}\,dx = 8\pi\cdot2\pi = 16\pi^2$$

（面積 $4\pi$ × 中心の描く円周 $2\pi\cdot2$ でも同じ。軸に接していても穴の半径が $0$ になる点が 1 点あるだけです。）
