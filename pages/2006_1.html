次の問いに答えよ。ただし，$\displaystyle\lim_{x\to\infty}\frac{\log x}{x} = 0$ であること，また，$e$ は自然対数の底で，$e < 3$ であることを用いてよい。

  1. (1)　自然数 $n$ に対して，方程式 $\dfrac{\log x}{x} = \dfrac{1}{3n}$ は $x > 0$ の範囲にちょうど 2 つの実数解をもつことを示せ。
  2. (2)　(1) の実数解を $\alpha_n$，$\beta_n$（$\alpha_n < \beta_n$）とするとき，$1 < \alpha_n < e^{\frac1n}$，$ne < \beta_n$ が成り立つことを示せ。また，$\displaystyle\lim_{n\to\infty}\alpha_n$ を求めよ。

（2006 九州大学 前期 理系 第1問）

解答例

$f(x) = \frac{\log x}{x}$ は $x = e$ で極大値 $\frac1e$。$\frac1{3n} \le \frac13 < \frac1e$ なので 2 交点。(2) は $f$ の単調性を使い、$f(e^{1/n})$，$f(ne)$ と $\frac1{3n}$ の大小を比べるだけです。

解答例（タップで展開）

(1)

$f(x) = \dfrac{\log x}{x}$ とおくと $f'(x) = \dfrac{1 - \log x}{x^2}$。$f$ は $0 < x \le e$ で増加，$x \ge e$ で減少し、極大値 $f(e) = \dfrac1e$。また

$$\lim_{x\to+0}f(x) = -\infty,\qquad \lim_{x\to\infty}f(x) = 0,\qquad x > 1 \text{ で } f(x) > 0$$

$e < 3$ より $0 < \dfrac1{3n} \le \dfrac13 < \dfrac1e$。よって $y = \frac1{3n}$ は $0 < x < e$ と $x > e$ でそれぞれちょうど 1 回ずつ $y = f(x)$ と交わり（中間値の定理と単調性）、実数解はちょうど 2 つ。

(2)

(1) より $\alpha_n < e < \beta_n$。$f$ は $(0,\ e]$ で増加で、

$$f(1) = 0 < \frac1{3n},\qquad f\left(e^{\frac1n}\right) = \frac{1/n}{e^{1/n}} = \frac{1}{ne^{1/n}} > \frac1{3n}\quad(e^{\frac1n} \le e < 3)$$

$1 < e^{\frac1n} \le e$ なので $1 < \alpha_n < e^{\frac1n}$。

また $f$ は $[e,\ \infty)$ で減少で、$ne \ge e$ かつ

$$f(ne) = \frac{1 + \log n}{ne}$$

ここで $3(1 + \log n) \ge 3 > e$ なので $\dfrac{1 + \log n}{ne} > \dfrac{1}{3n}$，すなわち $f(ne) > \dfrac1{3n} = f(\beta_n)$。

よって $ne < \beta_n$。

最後に $e^{\frac1n} \to 1$ なので、はさみうちの原理より

$$\lim_{n\to\infty}\alpha_n = 1$$

動く図解

$n$ を大きくすると直線 $y = \frac1{3n}$ が下がり、$\alpha_n$ は 1 に、$\beta_n$ は右へどんどん遠ざかります。

問題の背景

$\frac{\log x}{x}$ のグラフは入試の常連

$\frac{\log x}{x}$ は「$x^y = y^x$」「$e^\pi$ と $\pi^e$ の比較」などでもおなじみの関数です。極大値 $\frac1e$ と、$x \to \infty$ で $0$ に近づくことさえ押さえれば、解の個数はグラフで一目瞭然。(2) は解を具体的な値ではさむ「評価」の練習で、はさむ値 $e^{\frac1n}$，$ne$ は $f$ に代入すると計算がきれいになるように選ばれています。

chopin 先生は「(1) $f(x) = \frac{\log x}{x}$ の増減を調べて、$\frac1{3n}$ が極大値より小さいことを示しましょう」「(2) $f(x)$ のグラフを書けば、$\alpha_n$ と $\beta_n$ の配置がわかります。あとは、$f(e^{\frac1n})$ と $f(ne)$ の値と $\frac1{3n}$ との大小関係を調べれば OK です」とコメントしています。

方程式の解の評価：単調な区間で、候補の値を $f$ に代入して大小比較。

類題紹介

方程式 $\dfrac{\log x}{x} = k$ が異なる 2 つの正の実数解をもつような定数 $k$ の範囲を求めよ。

（自作）

略解

本問 (1) のグラフより、$y = k$ が 2 回交わるのは $0 < k < \dfrac1e$。

本問の $\alpha_n$ について，$\displaystyle\lim_{n\to\infty}n(\alpha_n - 1)$ を求めよ。

（九大 2006　魔改造）

略解

$\dfrac{\log\alpha_n}{\alpha_n} = \dfrac1{3n}$ より $n\log\alpha_n = \dfrac{\alpha_n}3 \to \dfrac13$。$\alpha_n \to 1$ なので $\dfrac{\alpha_n - 1}{\log\alpha_n} \to 1$（$\lim_{t\to1}\frac{\log t}{t - 1} = 1$）。よって $n(\alpha_n - 1) = n\log\alpha_n\cdot\dfrac{\alpha_n - 1}{\log\alpha_n} \to \dfrac13$。
