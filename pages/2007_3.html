$a$，$b$ を正の数とし，空間内の 3 点 $A(a,\ -a,\ b)$，$B(-a,\ a,\ b)$，$C(a,\ a,\ -b)$ を考える。$A$，$B$，$C$ を通る平面を $\alpha$，原点 $O$ を中心とし $A$，$B$，$C$ を通る球面を $S$ とする。このとき，次の問いに答えよ。

  1. (1)　線分 $AB$ の中点を $D$ とするとき，$\overrightarrow{DC} \perp \overrightarrow{AB}$ および $\overrightarrow{DO} \perp \overrightarrow{AB}$ であることを示せ。また $\triangle ABC$ の面積を求めよ。
  2. (2)　ベクトル $\overrightarrow{DC}$ と $\overrightarrow{DO}$ のなす角を $\theta$ とするとき，$\sin\theta$ を求めよ。また，平面 $\alpha$ に垂直で原点 $O$ を通る直線と平面 $\alpha$ との交点を $H$ とするとき，線分 $OH$ の長さを求めよ。
  3. (3)　点 $P$ が球面 $S$ 上を動くとき，四面体 $ABCP$ の体積の最大値を求めよ。ただし，$P$ は平面 $\alpha$ 上にないものとする。

（2007 九州大学 前期 理系 第3問）

解答例

$AB$ が $DC$ と $DO$ の両方に垂直なので、$AB$ は平面 $ODC$ に垂直。すると平面 $ODC$ は平面 $\alpha$ に垂直で、$O$ から $\alpha$ への垂線の足 $H$ は直線 $DC$ 上にあります。$OH = OD\sin\theta$ がすぐ出ます。

解答例（タップで展開）

(1)

$D(0,\ 0,\ b)$，$\overrightarrow{AB} = (-2a,\ 2a,\ 0)$，$\overrightarrow{DC} = (a,\ a,\ -2b)$，$\overrightarrow{DO} = (0,\ 0,\ -b)$。

$$\overrightarrow{DC}\cdot\overrightarrow{AB} = -2a^2 + 2a^2 + 0 = 0,\qquad \overrightarrow{DO}\cdot\overrightarrow{AB} = 0$$

よって $\overrightarrow{DC} \perp \overrightarrow{AB}$，$\overrightarrow{DO} \perp \overrightarrow{AB}$。$|\overrightarrow{AB}| = 2\sqrt2a$，$|\overrightarrow{DC}| = \sqrt{2a^2 + 4b^2}$ で、$DC$ は $\triangle ABC$ の高さなので

$$\triangle ABC = \frac12\cdot 2\sqrt2a\cdot\sqrt{2a^2 + 4b^2} = 2a\sqrt{a^2 + 2b^2}$$

(2)

$$\cos\theta = \frac{\overrightarrow{DC}\cdot\overrightarrow{DO}}{|\overrightarrow{DC}||\overrightarrow{DO}|} = \frac{2b^2}{\sqrt{2a^2 + 4b^2}\cdot b} = \frac{\sqrt2\,b}{\sqrt{a^2 + 2b^2}}$$ $$\sin\theta = \sqrt{1 - \frac{2b^2}{a^2 + 2b^2}} = \frac{a}{\sqrt{a^2 + 2b^2}}$$

(1) より $AB$ は平面 $ODC$ 上の交わる 2 直線 $DC$，$DO$ に垂直なので、$AB \perp$ 平面 $ODC$。$\alpha$ は $AB$ を含むので平面 $ODC \perp \alpha$ であり、$O$ から $\alpha$ へ下ろした垂線は平面 $ODC$ 内にあって、$H$ は直線 $DC$ 上。直角三角形 $ODH$ で

$$OH = OD\sin\theta = \frac{ab}{\sqrt{a^2 + 2b^2}}$$

(3)

球面 $S$ の半径は $OA = \sqrt{2a^2 + b^2}$。$P$ と平面 $\alpha$ の距離は、$P$ が直線 $OH$ 上で $O$ に関して $H$ と反対側にあるとき最大で、その値は $OH + \sqrt{2a^2 + b^2}$。よって最大値は

$$\frac13\cdot 2a\sqrt{a^2 + 2b^2}\left(\frac{ab}{\sqrt{a^2 + 2b^2}} + \sqrt{2a^2 + b^2}\right) = \frac{2a}{3}\left(ab + \sqrt{(a^2 + 2b^2)(2a^2 + b^2)}\right)$$

動く図解

$a$，$b$ を変えてみましょう（図はドラッグで回転）。赤い三角形が $\triangle ABC$，緑の点が $H$，オレンジの点が体積を最大にする $P$ です。$H$ は必ず直線 $DC$ 上にあります。

問題の背景

「垂直な 2 直線」から「垂直な平面」へ

(1) の 2 つの垂直は、(2) の「$H$ は直線 $DC$ 上」を導くための布石です。座標で $\alpha$ の方程式を立てて点と平面の距離公式を使っても解けますが（$\alpha$：$bx + by + az = ab$ となり、距離は $\frac{ab}{\sqrt{a^2 + 2b^2}}$。これはこれで検算に便利）、図形的に見れば $OH = OD\sin\theta$ の一行で済みます。(3) は「球面上の点から平面までの最大距離 $=$ 中心からの距離 $+$ 半径」という典型。

chopin 先生は「(2) $\angle ODH = \theta$ なので $OH = OD\sin\theta$ となります」「(3) $P$ と平面 $\alpha$ の距離の最大値は、$OH$ と球の半径の和であることに注意しましょう」とコメントしています。

ある直線が平面内の交わる 2 直線に垂直 → その平面に垂直。球面上の点と平面の距離の最大 $=$ 中心からの距離 $+$ 半径。

類題紹介

本問で $a = b = 1$ のとき，四面体 $ABCP$ の体積の最大値を求めよ。

（自作）

略解

$\triangle ABC = 2\sqrt3$，$OH = \dfrac1{\sqrt3}$，半径 $\sqrt3$。最大値 $\dfrac13\cdot2\sqrt3\left(\dfrac1{\sqrt3} + \sqrt3\right) = \dfrac83$。

本問の設定で，正の数 $a$，$b$ が $a + b = 1$ を満たしながら動くとき，四面体 $OABC$ の体積の最大値を求めよ。

（九大 2007　魔改造）

略解

$V = \dfrac13\cdot\triangle ABC\cdot OH = \dfrac13\cdot 2a\sqrt{a^2 + 2b^2}\cdot\dfrac{ab}{\sqrt{a^2 + 2b^2}} = \dfrac23a^2b$（行列式 $\frac16|\det(\vec{A},\vec{B},\vec{C})| = \frac16\cdot4a^2b$ でも確認できる）。$b = 1 - a$ を代入し $\dfrac23a^2(1 - a)$ を微分すると $a = \dfrac23$ で最大値 $\dfrac{8}{81}$。
