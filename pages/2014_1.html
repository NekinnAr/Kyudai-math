関数 $f(x) = x - \sin x$ $\left(0 \le x \le \dfrac{\pi}{2}\right)$ を考える。曲線 $y = f(x)$ の接線で傾きが $\dfrac12$ となるものを $l$ とする。

  1. (1)　$l$ の方程式と接点の座標 $(a,\ b)$ を求めよ。
  2. (2)　$a$ は (1) で求めたものとする。曲線 $y = f(x)$，直線 $x = a$，および $x$ 軸で囲まれた領域を，$x$ 軸のまわりに 1 回転してできる回転体の体積 $V$ を求めよ。

（2014 九州大学 前期 理系 第1問）

解答例

(1) は $f'(x) = \frac12$ を解くだけ。(2) は $(x - \sin x)^2$ を展開して、$x^2$，$x\sin x$（部分積分），$\sin^2x$（半角）を別々に積分する。

解答例（タップで展開）

(1)

$f'(x) = 1 - \cos x = \frac12$ より $\cos x = \frac12$，$0 \le x \le \frac\pi2$ で $x = \frac\pi3$。

$$a = \frac\pi3,\quad b = \frac\pi3 - \frac{\sqrt3}{2},\qquad l：y = \frac12x + \frac\pi6 - \frac{\sqrt3}{2}$$

(2)

$0 \le x \le \frac\pi3$ で $f(x) \ge 0$（$f(0) = 0$，$f' \ge 0$）なので

$$V = \pi\int_0^{\frac\pi3}(x - \sin x)^2dx = \pi\int_0^{\frac\pi3}\left(x^2 - 2x\sin x + \sin^2x\right)dx$$
  • $\displaystyle\int_0^{\frac\pi3}x^2dx = \frac{\pi^3}{81}$
  • $\displaystyle\int_0^{\frac\pi3}x\sin x\,dx = \Big[-x\cos x + \sin x\Big]_0^{\frac\pi3} = -\frac\pi6 + \frac{\sqrt3}{2}$
  • $\displaystyle\int_0^{\frac\pi3}\sin^2x\,dx = \left[\frac x2 - \frac{\sin 2x}{4}\right]_0^{\frac\pi3} = \frac\pi6 - \frac{\sqrt3}{8}$
$$V = \pi\left\{\frac{\pi^3}{81} - 2\left(-\frac\pi6 + \frac{\sqrt3}{2}\right) + \frac\pi6 - \frac{\sqrt3}{8}\right\} = \pi\left(\frac{\pi^3}{81} + \frac\pi2 - \frac{9\sqrt3}{8}\right)$$

（$V \approx 0.0158$。）

動く図解

点の位置を動かすと、その点での接線の傾き $1 - \cos x$ が表示されます。傾きが $\frac12$ になる点が (1) の接点。赤い部分を $x$ 軸のまわりに回転したものが (2) の回転体です（薄い部分は回転した像の断面）。

問題の背景

サイクロイドとのつながり

$x = \theta - \sin\theta$ は、サイクロイド $(\theta - \sin\theta,\ 1 - \cos\theta)$ の $x$ 座標と同じ式です。$f(x) = x - \sin x$ は原点付近で $\frac{x^3}{6}$ のようにふるまう（3 次の接触）ので、グラフは原点で $x$ 軸に非常に強く接しています。そのため体積は約 $0.016$ ととても小さくなります。

chopin 先生は「(1) は教科書レベルの問題」「(2) もテンプレ通りの体積計算の問題です。計算ミスに注意して解きましょう」とコメントしています。

回転体の体積 $\pi\int y^2dx$ は、2 乗を展開して部分積分（$x\sin x$）と半角の公式（$\sin^2x$）に分ける。

類題紹介
