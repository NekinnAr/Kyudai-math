一辺の長さが 1 の正方形 $\mathrm{OABC}$ を底面とし，点 $\mathrm{P}$ を頂点とする四角錐 $\mathrm{POABC}$ がある。ただし，点 $\mathrm{P}$ は内積に関する条件 $\overrightarrow{\mathrm{OA}}\cdot\overrightarrow{\mathrm{OP}} = \dfrac14$，および $\overrightarrow{\mathrm{OC}}\cdot\overrightarrow{\mathrm{OP}} = \dfrac12$ をみたす。辺 $\mathrm{AP}$ を $2 : 1$ に内分する点を $\mathrm{M}$ とし，辺 $\mathrm{CP}$ の中点を $\mathrm{N}$ とする。さらに，点 $\mathrm{P}$ と直線 $\mathrm{BC}$ 上の点 $\mathrm{Q}$ を通る直線 $\mathrm{PQ}$ は，平面 $\mathrm{OMN}$ に垂直であるとする。このとき，長さの比 $\mathrm{BQ} : \mathrm{QC}$，および線分 $\mathrm{OP}$ の長さを求めよ。

（2013 九州大学 前期 理系 第2問）

解答例

座標を入れるのが速い。$\mathrm{O}$ を原点、$\mathrm{A}(1, 0, 0)$，$\mathrm{C}(0, 1, 0)$ とすると、内積の条件から $\mathrm{P}\left(\frac14,\ \frac12,\ h\right)$。「平面 OMN に垂直」$\iff$「$\overrightarrow{\mathrm{OM}},\ \overrightarrow{\mathrm{ON}}$ の両方に垂直」。

解答例（タップで展開）

$\mathrm{O}(0,0,0)$，$\mathrm{A}(1,0,0)$，$\mathrm{B}(1,1,0)$，$\mathrm{C}(0,1,0)$ とし、$\mathrm{P}(p_1,\ p_2,\ h)$（$h \gt 0$）とおく。$\overrightarrow{\mathrm{OA}}\cdot\overrightarrow{\mathrm{OP}} = p_1 = \frac14$，$\overrightarrow{\mathrm{OC}}\cdot\overrightarrow{\mathrm{OP}} = p_2 = \frac12$。

$$\mathrm{M} = \frac{\mathrm{A} + 2\mathrm{P}}{3} = \left(\frac12,\ \frac13,\ \frac{2h}{3}\right),\qquad \mathrm{N} = \frac{\mathrm{C} + \mathrm{P}}{2} = \left(\frac18,\ \frac34,\ \frac h2\right)$$

Q は直線 BC 上なので $\mathrm{Q}(s,\ 1,\ 0)$ とおける。$\overrightarrow{\mathrm{PQ}} = \left(s - \frac14,\ \frac12,\ -h\right)$。

PQ が平面 OMN に垂直 $\iff \overrightarrow{\mathrm{PQ}}\cdot\overrightarrow{\mathrm{OM}} = 0$ かつ $\overrightarrow{\mathrm{PQ}}\cdot\overrightarrow{\mathrm{ON}} = 0$。$u = s - \frac14$ とおくと

$$\frac u2 + \frac16 - \frac{2h^2}{3} = 0,\qquad \frac u8 + \frac38 - \frac{h^2}{2} = 0$$

それぞれ 3 倍・4 倍して $\frac{3u}{2} + \frac12 = 2h^2$，$\frac u2 + \frac32 = 2h^2$。辺々引いて $u - 1 = 0$，$u = 1$。よって $s = \frac54$，$2h^2 = 2$，$h = 1$。

$\mathrm{Q}\left(\frac54,\ 1,\ 0\right)$ は辺 CB を B の側に延長した点で、$\mathrm{BQ} = \frac14$，$\mathrm{QC} = \frac54$。

$$\mathrm{BQ} : \mathrm{QC} = 1 : 5,\qquad \mathrm{OP} = \sqrt{\frac1{16} + \frac14 + 1} = \frac{\sqrt{21}}{4}$$

動く図解

四角錐と平面 OMN（青）、直線 PQ（赤）を表示します。Q は辺 BC の外側（B の先）にあります。ドラッグで回転して、PQ が平面 OMN に垂直になっている様子を確かめましょう。高さ $h$ を変えると垂直でなくなります。

問題の背景

座標か、ベクトルか

chopin 先生は「与えられている内積が $\overrightarrow{\mathrm{OA}},\ \overrightarrow{\mathrm{OC}},\ \overrightarrow{\mathrm{OP}}$ となっているので、この 3 本のベクトルを基準にしてすべての点を表現する方向で考えていきましょう」「最後に求まる $\mathrm{BQ} : \mathrm{QC}$ については、Q が外分点となるので少しややこしいです。図に落として考えると分かりやすい」とコメントしています。

底面が正方形なので座標を入れると、内積の条件がそのまま P の $x,\ y$ 座標になり、計算が一気に楽になります。ベクトルで解く場合も、$\vec a\cdot\vec c = 0$，$|\vec a| = |\vec c| = 1$ を使うので本質は同じです。

直線が平面に垂直 $\iff$ 平面上の 1 次独立な 2 ベクトルと垂直。底面が正方形・長方形なら座標を入れるのが最速。外分点になる場合は図で位置を確認。

類題紹介

3 点 $\mathrm{O}(0,0,0)$，$\mathrm{M}\left(\frac12,\ \frac13,\ \frac23\right)$，$\mathrm{N}\left(\frac18,\ \frac34,\ \frac12\right)$ を通る平面に垂直なベクトルを 1 つ求めよ。

（自作）

略解

$\vec n = (a,\ b,\ c)$ が $\overrightarrow{\mathrm{OM}},\ \overrightarrow{\mathrm{ON}}$ と垂直：$3a + 2b + 4c = 0$，$a + 6b + 4c = 0$。引いて $2a - 4b = 0$，$a = 2b$，$c = -2b$。$\vec n = (2,\ 1,\ -2)$。

（本問の $\overrightarrow{\mathrm{PQ}} = \left(1,\ \frac12,\ -1\right)$ はこれに平行。）

本問で，M を「辺 AP の中点」に変えたとき，$\mathrm{BQ} : \mathrm{QC}$ と線分 OP の長さを求めよ。

（九大 2013　魔改造）

略解

$\mathrm{M}\left(\frac58,\ \frac14,\ \frac h2\right)$。$u = s - \frac14$ として $\frac{5u}{8} + \frac18 - \frac{h^2}{2} = 0$，$\frac u8 + \frac38 - \frac{h^2}{2} = 0$。引いて $\frac u2 - \frac14 = 0$，$u = \frac12$，$s = \frac34$，$h^2 = \frac78$。

Q は辺 BC 上（内分点）で $\mathrm{BQ} : \mathrm{QC} = \frac14 : \frac34 = 1 : 3$。$\mathrm{OP} = \sqrt{\frac1{16} + \frac14 + \frac78} = \dfrac{\sqrt{19}}{4}$。
