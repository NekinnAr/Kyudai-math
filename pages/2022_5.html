$xy$ 平面上の曲線 $C$ を，媒介変数 $t$ を用いて次のように定める。

$$x = 5\cos t + \cos 5t,\qquad y = 5\sin t - \sin 5t\qquad(-\pi \le t \lt \pi)$$

以下の問いに答えよ。

  1. (1)　区間 $0 \lt t \lt \dfrac{\pi}{6}$ において，$\dfrac{dx}{dt} \lt 0$，$\dfrac{dy}{dx} \lt 0$ であることを示せ。
  2. (2)　曲線 $C$ の $0 \le t \le \dfrac{\pi}{6}$ の部分，$x$ 軸，直線 $y = \dfrac{1}{\sqrt3}x$ で囲まれた図形の面積を求めよ。
  3. (3)　曲線 $C$ は $x$ 軸に関して対称であることを示せ。また，$C$ 上の点を原点を中心として反時計回りに $\dfrac{\pi}{3}$ だけ回転させた点は $C$ 上にあることを示せ。
  4. (4)　曲線 $C$ の概形を図示せよ。

（2022 九州大学 前期 理系 第5問）

解答例

和積公式で $\frac{dx}{dt},\ \frac{dy}{dt}$ を積の形にすれば符号が分かる。(3) の対称性により、$0 \le t \le \frac{\pi}{6}$ の部分を折り返し・回転させるだけで全体が描ける。正体は、半径 $6$ の円の内側を半径 $1$ の円が転がるときの軌跡（ハイポサイクロイド）。

解答例（タップで展開）

(1)

和積公式より

$$\frac{dx}{dt} = -5\sin t - 5\sin 5t = -10\sin 3t\cos 2t,\qquad \frac{dy}{dt} = 5\cos t - 5\cos 5t = 10\sin 3t\sin 2t$$

$0 \lt t \lt \frac{\pi}{6}$ では $0 \lt 3t \lt \frac{\pi}{2}$，$0 \lt 2t \lt \frac{\pi}{3}$ なので $\sin 3t,\ \cos 2t,\ \sin 2t \gt 0$。よって $\dfrac{dx}{dt} \lt 0$ で、

$$\frac{dy}{dx} = \frac{dy/dt}{dx/dt} = -\frac{\sin 2t}{\cos 2t} = -\tan 2t \lt 0$$

(2)

$t = 0$ で $(6,\ 0)$、$t = \frac{\pi}{6}$ で $x = \frac{5\sqrt3}{2} - \frac{\sqrt3}{2} = 2\sqrt3$，$y = \frac52 - \frac12 = 2$ で、点 $(2\sqrt3,\ 2)$ は直線 $y = \frac{1}{\sqrt3}x$ 上にある。(1) より、この部分で $x$ は $6$ から $2\sqrt3$ まで単調に減少し、$y \ge 0$。

図形は、三角形（O，$(2\sqrt3,\ 0)$，$(2\sqrt3,\ 2)$）と、$2\sqrt3 \le x \le 6$ で曲線の下側の部分に分けられる。三角形の面積は $\frac12\cdot2\sqrt3\cdot2 = 2\sqrt3$。曲線の下側は

$$\int_{2\sqrt3}^{6}y\,dx = \int_{\frac{\pi}{6}}^{0}y\frac{dx}{dt}\,dt = \int_0^{\frac{\pi}{6}}(5\sin t - \sin 5t)(5\sin t + 5\sin 5t)\,dt = \int_0^{\frac{\pi}{6}}\left(25\sin^2 t + 20\sin t\sin 5t - 5\sin^2 5t\right)dt$$

それぞれ計算すると

$$\int_0^{\frac{\pi}{6}}\sin^2 t\,dt = \frac{\pi}{12} - \frac{\sqrt3}{8},\quad \int_0^{\frac{\pi}{6}}\sin t\sin 5t\,dt = \int_0^{\frac{\pi}{6}}\frac{\cos 4t - \cos 6t}{2}\,dt = \frac{\sqrt3}{16},\quad \int_0^{\frac{\pi}{6}}\sin^2 5t\,dt = \frac{\pi}{12} + \frac{\sqrt3}{40}$$

より $\displaystyle\int_{2\sqrt3}^6 y\,dx = \frac{25\pi}{12} - \frac{25\sqrt3}{8} + \frac{5\sqrt3}{4} - \frac{5\pi}{12} - \frac{\sqrt3}{8} = \frac{5}{3}\pi - 2\sqrt3$。よって求める面積は

$$2\sqrt3 + \left(\frac53\pi - 2\sqrt3\right) = \frac53\pi$$

(3)

$t$ を $-t$ にすると $x$ は変わらず $y$ は $-y$ になる。$t$ と $-t$ はともに範囲内（$t = -\pi$ は周期性より $t = \pi$ と同じ点）なので、$C$ は $x$ 軸に関して対称。

点 $(x(t),\ y(t))$ を $\frac{\pi}{3}$ 回転した点を $(X,\ Y)$ とすると、加法定理より

$$\begin{aligned} X &= x\cos\tfrac{\pi}{3} - y\sin\tfrac{\pi}{3} = 5\cos\left(t + \tfrac{\pi}{3}\right) + \cos\left(5t - \tfrac{\pi}{3}\right) \\ Y &= x\sin\tfrac{\pi}{3} + y\cos\tfrac{\pi}{3} = 5\sin\left(t + \tfrac{\pi}{3}\right) - \sin\left(5t - \tfrac{\pi}{3}\right) \end{aligned}$$

$5t - \frac{\pi}{3} = 5\left(t + \frac{\pi}{3}\right) - 2\pi$ なので、$(X,\ Y) = \left(x\left(t + \frac{\pi}{3}\right),\ y\left(t + \frac{\pi}{3}\right)\right)$ で、これは $C$ 上の点（周期 $2\pi$）。

(4)

(1)(2) より、$0 \le t \le \frac{\pi}{6}$ の部分は $(6,\ 0)$ から $(2\sqrt3,\ 2)$ へ、$x$ が減少し $y$ が増加する曲線。$t = 0$ で $\frac{dx}{dt} = \frac{dy}{dt} = 0$ となり、$(6,\ 0)$ は尖った点（カスプ）。これを $x$ 軸で折り返し、$\frac{\pi}{3}$ ずつ回転させると、原点を中心とし、半径 $6$ の円周上の 6 点 $6\left(\cos\frac{k\pi}{3},\ \sin\frac{k\pi}{3}\right)$ を尖点とする星形の曲線になる（図解参照）。原点に最も近い点は半径 $4$ の円上にある。

動く図解

半径 $6$ の円の内側を、半径 $1$ の円が滑らずに転がります。小円上の 1 点が描く軌跡が曲線 $C$ です。$t$ を動かすか、再生ボタンを押してください。

問題の背景

複素数で見るハイポサイクロイド

$z = x + yi$ とおくと

$$z = 5e^{it} + e^{-5it}\qquad\left(e^{i\theta} = \cos\theta + i\sin\theta\right)$$

となります。$5e^{it}$ は半径 $5$ の円を回る点（小円の中心）、$e^{-5it}$ はそこから見て逆向きに 5 倍速で回る点で、これが「半径 1 の円が半径 6 の円の内側を転がる」動きです。(3) の $\frac{\pi}{3}$ 回転は $z\left(t + \frac{\pi}{3}\right) = e^{\frac{\pi}{3}i}z(t)$ と一瞬で示せます（$e^{-5\cdot\frac{\pi}{3}i} = e^{\frac{\pi}{3}i}$）。

面積の公式

(2) の面積は、閉曲線の面積公式 $\frac12\int(x\,dy - y\,dx)$ を使うとさらに楽です。$x\frac{dy}{dt} - y\frac{dx}{dt} = 20 - 20\cos 6t$ となり（原点を通る線分上では $x\,dy - y\,dx = 0$）、

$$\frac12\int_0^{\frac{\pi}{6}}(20 - 20\cos 6t)\,dt = \frac53\pi$$

一般に、尖点が $k$ 個のハイポサイクロイド（大円の半径 $kr$、小円の半径 $r$）が囲む面積は $(k - 1)(k - 2)\pi r^2$ で、$k = 6,\ r = 1$ なら $20\pi$。本問の図形はその $\frac{1}{12}$ です。

媒介変数表示の曲線は、対称性（偶奇・回転）を見抜くと、調べる範囲を大幅に減らせる。本問なら全体の $\frac{1}{12}$ だけ調べれば十分でした。

類題紹介

曲線 $x = 2\cos t + \cos 2t,\ y = 2\sin t - \sin 2t\ (0 \le t \le 2\pi)$ で囲まれた図形の面積を求めよ。

（自作）

略解

尖点 3 個のハイポサイクロイド（デルトイド）。$x\frac{dy}{dt} - y\frac{dx}{dt}$ を計算すると $2 - 2\cos 3t$ となるので

$$S = \frac12\int_0^{2\pi}(2 - 2\cos 3t)\,dt = 2\pi$$

（公式 $(k-1)(k-2)\pi r^2$ で $k = 3,\ r = 1$。）

本問の曲線 $C$ について，$C$ 全体で囲まれる図形の面積 $S$ と，$C$ の長さ $L$ を求めよ。

（九大 2022　魔改造）

略解

(2)(3) より $S = 12\times\frac53\pi = 20\pi$。長さは

$$\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2 = 100\sin^2 3t\,(\cos^2 2t + \sin^2 2t) = 100\sin^2 3t$$

より $L = \displaystyle\int_{-\pi}^{\pi}10|\sin 3t|\,dt = 10\times 6\int_0^{\frac{\pi}{3}}\sin 3t\,dt = 10\times6\times\frac23 = 40$。

一般に、尖点 $k$ 個のハイポサイクロイドの長さは $8(k - 1)r$ です。
