1 個のさいころを 3 回投げる試行において，1 回目に出る目を $a$，2 回目に出る目を $b$，3 回目に出る目を $c$ とする。なお，さいころは 1 から 6 までの目が等確率で出るものとする。

  1. (1)　2 次方程式 $ax^2 + bx + c = 0$ が異なる 2 つの実数解をもつために $a$，$c$ が満たすべき条件を考える。積 $ac$ のとりうる値の範囲を求めよ。また，$ac$ のとりうる各値に対して，そのような $a$，$c$ の組の個数を求めよ。
  2. (2)　2 次方程式 $ax^2 + bx + c = 0$ が異なる 2 つの有理数を解にもつ確率を求めよ。ただし，自然数 $n$ が平方数でないとき，$\sqrt{n}$ は無理数であることを用いてよい。

（2007 九州大学 前期 理系 第4問）

解答例

判別式 $D = b^2 - 4ac > 0$ と $b \le 6$ から $ac \le 8$。有理数解 ⇔ $\sqrt D$ が有理数 ⇔ $D$ が平方数。$b^2 - D = 4ac$ を $(b - k)(b + k) = 4ac$ と因数分解すると、各 $ac$ について調べる $b$ がすぐ絞れます。

解答例（タップで展開）

(1)

異なる 2 実数解をもつ条件は $b^2 - 4ac > 0$。$b \le 6$ なので、そのような $b$ が存在するためには $4ac < 36$，すなわち $ac \le 8$ が必要で、逆に $ac \le 8$ なら $b = 6$ で $36 > 32 \ge 4ac$ となり十分。$ac$ はさいころの目の積なので $7$ にはならない。よって $ac$ のとりうる値は

$$ac = 1,\ 2,\ 3,\ 4,\ 5,\ 6,\ 8$$

それぞれの $(a,\ c)$ の組の個数は

$ac$1234568
組数1223242

（例：$ac = 4$ は $(1,4),(2,2),(4,1)$，$ac = 6$ は $(1,6),(2,3),(3,2),(6,1)$，$ac = 8$ は $(2,4),(4,2)$。）

(2)

係数は整数なので、解 $\dfrac{-b \pm \sqrt{D}}{2a}$ が異なる有理数 ⇔ $D = b^2 - 4ac$ が正の平方数 $k^2$（$k \ge 1$）。このとき $(b - k)(b + k) = 4ac$ で、$b - k$ と $b + k$ は偶奇が一致するので両方偶数、かつ $0 < b - k < b + k \le 2b - 1 \le 11$。各 $ac$ について：

  • $ac = 1$：$4 = 2\cdot2$ は $k = 0$ になり不適。
  • $ac = 2$：$8 = 2\cdot4$ → $b = 3$。
  • $ac = 3$：$12 = 2\cdot6$ → $b = 4$。
  • $ac = 4$：$16 = 2\cdot8$ → $b = 5$（$4\cdot4$ は $k = 0$ で不適）。
  • $ac = 5$：$20 = 2\cdot10$ → $b = 6$。
  • $ac = 6$：$24 = 4\cdot6$ → $b = 5$（$2\cdot12$ は $b = 7$ で不適）。
  • $ac = 8$：$32 = 4\cdot8$ → $b = 6$（$2\cdot16$ は $b = 9$ で不適）。

いずれも $b$ は 1 通りなので、(1) の組数を足して $2 + 2 + 3 + 2 + 4 + 2 = 15$ 通り。求める確率は

$$\frac{15}{6^3} = \frac{5}{72}$$

動く図解

$b$ を選ぶと、$6\times6$ のマス（縦 $a$，横 $c$）が色分けされます。薄い色＝異なる 2 実数解，濃い色＝異なる 2 有理数解。

問題の背景

判別式と平方数

(1) で $ac \le 8$ と組数を整理しておくと、(2) は「$b^2 - 4ac$ が平方数になる $b$」を $ac$ ごとに探すだけになります。全 216 通りを書き出すのは大変ですが、$ac$ で分類すれば 7 ケース。積の差の形 $(b - k)(b + k)$ にすると候補が一瞬で絞れます。

chopin 先生は「(1) 判別式を考えればよいでしょう」「(2) 判別式がポイントになります。(1) の後半部分が利用できます」とコメントしています。

整数係数 2 次方程式の解が有理数 ⇔ 判別式が平方数。$b^2 - k^2 = (b - k)(b + k)$ は偶奇がそろう。

略解

(2) の 15 通りのうち解が整数になるものを調べる（解と係数の関係から解は負，$a$ は $b$，$c$ の公約数が必要）。$(a,b,c) = (1,3,2),(1,4,3),(1,5,4),(1,5,6),(1,6,5),(2,6,4)$ の 6 通りで，確率は $\dfrac{6}{216} = \dfrac1{36}$。
