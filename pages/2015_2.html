以下の問いに答えよ。

  1. (1)　関数 $y = \dfrac{1}{x(\log x)^2}$ は $x \gt 1$ において単調に減少することを示せ。
  2. (2)　不定積分 $\displaystyle\int\frac{1}{x(\log x)^2}\,dx$ を求めよ。
  3. (3)　$n$ を 3 以上の整数とするとき，不等式 $$\sum_{k=3}^{n}\frac{1}{k(\log k)^2} \lt \frac{1}{\log 2}$$ が成り立つことを示せ。

（2015 九州大学 前期 理系 第2問）

解答例

和を積分で上から押さえる定番問題。減少関数なら「幅 1 の長方形 $<$ その区間の積分」。$\frac1x$ が $\log x$ の導関数なので $t = \log x$ と置換。

解答例（タップで展開）

(1)

$g(x) = x(\log x)^2$ とおくと $g'(x) = (\log x)^2 + 2\log x = \log x(\log x + 2) \gt 0$（$x \gt 1$）。$g(x) \gt 0$ は増加するので、$y = \frac{1}{g(x)}$ は単調に減少する。

(2)

$t = \log x$ とおくと $dt = \frac{dx}{x}$。

$$\int\frac{dx}{x(\log x)^2} = \int\frac{dt}{t^2} = -\frac1t + C = -\frac{1}{\log x} + C$$

(3)

$f(x) = \frac{1}{x(\log x)^2}$ は $x \gt 1$ で減少するので、$k \ge 3$ に対し $k - 1 \le x \le k$ で $f(x) \ge f(k)$（等号は $x = k$ のみ）。

$$\frac{1}{k(\log k)^2} = \int_{k-1}^{k}f(k)\,dx \lt \int_{k-1}^{k}f(x)\,dx$$

$k = 3,\ \cdots,\ n$ で足すと

$$\sum_{k=3}^{n}\frac{1}{k(\log k)^2} \lt \int_2^n f(x)\,dx = \left[-\frac{1}{\log x}\right]_2^n = \frac{1}{\log 2} - \frac{1}{\log n} \lt \frac{1}{\log 2}$$

動く図解

赤い長方形（幅 1，高さ $f(k)$）の面積の和が左辺です。どの長方形も曲線の下に収まるので、和は $\int_2^n f(x)\,dx$ より小さくなります。

問題の背景

ベルトラン級数

$\sum\frac{1}{k(\log k)^p}$ はベルトラン級数と呼ばれ、$p \gt 1$ なら収束、$p \le 1$ なら発散します。$\sum\frac1k$（発散）と $\sum\frac{1}{k^{1+\varepsilon}}$（収束）のちょうど境目を調べる級数で、本問は $p = 2$ の場合に「和は $\frac{1}{\log 2}$ を超えない」ことを示させています。

chopin 先生は「(2) は $\frac1x$ が $\log x$ の微分だと気づければ、置換積分でうまくいきます」「(3) は $\sum\frac1k$ を評価するときによく使う、グラフの面積と短冊の面積の大小比較。このグラフの形状を (1) で、面積を (2) で計算していたというわけです」とコメントしています。

減少関数 $f$ なら $f(k) \lt \int_{k-1}^{k}f(x)\,dx \lt f(k - 1)$。和の評価は短冊と積分の比較。$\int\frac{f'}{f^2}dx = -\frac1f$。

類題紹介

自然数 $n$ に対して $\displaystyle\sum_{k=1}^{n}\frac{1}{k^2} \lt 2$ を示せ。

（自作）

略解

$k \ge 2$ で $\frac1{k^2} \lt \int_{k-1}^{k}\frac{dx}{x^2}$。足して $\sum_{k=2}^{n}\frac1{k^2} \lt \int_1^n\frac{dx}{x^2} = 1 - \frac1n \lt 1$。$k = 1$ の項 1 を加えて $\lt 2$。

$\displaystyle\sum_{k=2}^{n}\frac{1}{k\log k} \gt \log(\log(n + 1)) - \log(\log 2)$ を示し，$\displaystyle\lim_{n\to\infty}\sum_{k=2}^{n}\frac{1}{k\log k}$ を求めよ。

（九大 2015　魔改造）

略解

$f(x) = \frac{1}{x\log x}$ は $x \gt 1$ で減少するので、$\frac{1}{k\log k} \gt \int_k^{k+1}f(x)\,dx$（今度は右側の区間と比べる）。$\int\frac{dx}{x\log x} = \log(\log x) + C$ より

$$\sum_{k=2}^{n}\frac{1}{k\log k} \gt \Big[\log(\log x)\Big]_2^{n+1} = \log(\log(n + 1)) - \log(\log 2)$$

右辺 $\to \infty$ なので、極限は $\infty$（発散）。$(\log k)^2$ を $\log k$ にするだけで収束から発散に変わる。
