2 つの定数 $a \gt 0$ および $b \gt 0$ に対し，座標空間内の 4 点を

$$\mathrm{A}(a,\ 0,\ 0),\quad \mathrm{B}(0,\ b,\ 0),\quad \mathrm{C}(0,\ 0,\ 1),\quad \mathrm{D}(a,\ b,\ 1)$$

と定める。以下の問いに答えよ。

  1. (1)　点 $\mathrm{A}$ から線分 $\mathrm{CD}$ におろした垂線と $\mathrm{CD}$ の交点を $\mathrm{G}$ とする。$\mathrm{G}$ の座標を $a,\ b$ を用いて表せ。
  2. (2)　さらに，点 $\mathrm{B}$ から線分 $\mathrm{CD}$ におろした垂線と $\mathrm{CD}$ の交点を $\mathrm{H}$ とする。$\overrightarrow{\mathrm{AG}}$ と $\overrightarrow{\mathrm{BH}}$ がなす角を $\theta$ とするとき，$\cos\theta$ を $a,\ b$ を用いて表せ。

（2017 九州大学 前期 理系 第2問）

解答例

垂線の足は「直線上の点をパラメータ $t$ で表し、$\overrightarrow{\mathrm{AG}}\cdot\overrightarrow{\mathrm{CD}} = 0$」で求める典型問題。$s = a^2 + b^2$ とおくと計算がすっきりする。

解答例（タップで展開）

(1)

$\overrightarrow{\mathrm{CD}} = (a,\ b,\ 0)$。線分 CD 上の点を $(ta,\ tb,\ 1)$（$0 \le t \le 1$）とおく。$\overrightarrow{\mathrm{AG}} = (ta - a,\ tb,\ 1)$ で、$\overrightarrow{\mathrm{AG}}\cdot\overrightarrow{\mathrm{CD}} = 0$ より

$$(t - 1)a^2 + tb^2 = 0 \iff t = \frac{a^2}{a^2 + b^2}$$

（$0 \lt t \lt 1$ で線分上。）$s = a^2 + b^2$ とおくと

$$\mathrm{G}\left(\frac{a^3}{s},\ \frac{a^2b}{s},\ 1\right) = \left(\frac{a^3}{a^2 + b^2},\ \frac{a^2b}{a^2 + b^2},\ 1\right)$$

(2)

同様に $\overrightarrow{\mathrm{BH}} = (ta,\ tb - b,\ 1)$，$ta^2 + (t - 1)b^2 = 0$ より $t = \frac{b^2}{s}$、$\mathrm{H}\left(\frac{ab^2}{s},\ \frac{b^3}{s},\ 1\right)$。

$$\overrightarrow{\mathrm{AG}} = \left(-\frac{ab^2}{s},\ \frac{a^2b}{s},\ 1\right),\qquad \overrightarrow{\mathrm{BH}} = \left(\frac{ab^2}{s},\ -\frac{a^2b}{s},\ 1\right)$$

$\frac{a^2b^4 + a^4b^2}{s^2} = \frac{a^2b^2(a^2 + b^2)}{s^2} = \frac{a^2b^2}{s}$ に注意すると

$$\overrightarrow{\mathrm{AG}}\cdot\overrightarrow{\mathrm{BH}} = 1 - \frac{a^2b^2}{s},\qquad |\overrightarrow{\mathrm{AG}}|^2 = |\overrightarrow{\mathrm{BH}}|^2 = 1 + \frac{a^2b^2}{s}$$ $$\cos\theta = \frac{1 - \frac{a^2b^2}{s}}{1 + \frac{a^2b^2}{s}} = \frac{a^2 + b^2 - a^2b^2}{a^2 + b^2 + a^2b^2}$$

動く図解

$a,\ b$ を動かすと、A，B から線分 CD への垂線（赤・青）が動きます。$\overrightarrow{\mathrm{AG}}$ と $\overrightarrow{\mathrm{BH}}$ のなす角 $\theta$ を観察しましょう。図はドラッグで回転できます。

問題の背景

直方体の中の対角線

4 点 A，B，C，D は、3 辺が $a,\ b,\ 1$ の直方体の頂点です（原点 O を 1 つの頂点とする直方体で、A，B，C は O に隣り合う頂点、D は O と対角の位置にある頂点）。CD は上面の対角線で、A，B から CD への垂線を考えています。

$\overrightarrow{\mathrm{AG}}$ と $\overrightarrow{\mathrm{BH}}$ は $z$ 成分が等しく、$xy$ 成分がちょうど逆向き（$-1$ 倍）になっています。これは G，H が CD の中点に関して対称な位置にあり、A と B も（$xy$ 平面への射影で）CD の中点に関して対称だからです。

chopin 先生は「(1) は典型問題でしょう。G を C，D で表し、$\overrightarrow{\mathrm{AG}}$ と $\overrightarrow{\mathrm{CD}}$ の内積 $= 0$ を使います」とコメントしています。

直線への垂線の足：直線上の点を $\vec p + t\vec d$ とおき、$(\vec p + t\vec d - \vec a)\cdot\vec d = 0$ から $t$ を求める。共通部分を文字でおく（$s = a^2 + b^2$）と計算ミスが減る。

類題紹介

点 $\mathrm{A}(1,\ 0,\ 0)$ から直線 $\ell:\ (x,\ y,\ z) = (0,\ 0,\ 1) + t(1,\ 1,\ 0)$ におろした垂線の足 $\mathrm{G}$ と，A と $\ell$ の距離を求めよ。

（自作）

略解

$(t - 1,\ t,\ 1)\cdot(1,\ 1,\ 0) = 2t - 1 = 0$ より $t = \frac12$、$\mathrm{G}\left(\frac12,\ \frac12,\ 1\right)$。距離は $\left|\left(-\frac12,\ \frac12,\ 1\right)\right| = \dfrac{\sqrt6}{2}$。（本問で $a = b = 1$ の場合。）

本問で $\overrightarrow{\mathrm{AG}} \perp \overrightarrow{\mathrm{BH}}$ となるための $a,\ b$ の条件を求めよ。また，$a = b$ のときの $a$ の値を求めよ。

（九大 2017　魔改造）

略解

$\cos\theta = 0 \iff a^2 + b^2 = a^2b^2 \iff \dfrac{1}{a^2} + \dfrac{1}{b^2} = 1$。$a = b$ なら $\frac{2}{a^2} = 1$ より $a = \sqrt2$。

（$\frac{1}{a^2} + \frac{1}{b^2} \gt 1$ なら鋭角、$\lt 1$ なら鈍角。）
