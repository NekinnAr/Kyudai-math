座標平面上の楕円

$$\frac{(x + 2)^2}{16} + \frac{(y - 1)^2}{4} = 1 \quad\cdots\cdots ①$$

を考える。以下の問いに答えよ。

  1. (1)　楕円①と直線 $y = x + a$ が交点をもつときの $a$ の値の範囲を求めよ。
  2. (2)　$|x| + |y| = 1$ を満たす点 $(x,\ y)$ 全体がなす図形の概形をかけ。
  3. (3)　点 $(x,\ y)$ が楕円①上を動くとき，$|x| + |y|$ の最大値，最小値とそれを与える $(x,\ y)$ をそれぞれ求めよ。

（2014 九州大学 前期 理系 第3問）

解答例

$|x| + |y| = k$ は 4 頂点 $(\pm k,\ 0)$，$(0,\ \pm k)$ の正方形。これを大きくしていき、楕円と初めて触れるときが最小、最後に離れるときが最大。最大は辺が接するとき（(1) を使う）、最小は頂点がぶつかるとき。

解答例（タップで展開）

(1)

$u = x + 2$ とおくと $y = u + a - 2$ で、①は $u^2 + 4(u + a - 3)^2 = 16$，すなわち

$$5u^2 + 8(a - 3)u + 4(a - 3)^2 - 16 = 0$$

実数解をもつ条件は $\frac D4 = 16(a - 3)^2 - 5\{4(a - 3)^2 - 16\} = 80 - 4(a - 3)^2 \ge 0$。

$$3 - 2\sqrt5 \le a \le 3 + 2\sqrt5$$

(2)

4 点 $(1,\ 0)$，$(0,\ 1)$，$(-1,\ 0)$，$(0,\ -1)$ を頂点とする正方形（の周）。（図解参照）

(3)

最大値。①上の点を $x = -2 + 4\cos\theta$，$y = 1 + 2\sin\theta$ と表す。$|x| + |y|$ は $x + y,\ x - y,\ -x + y,\ -x - y$ の最大のものに等しく、合成により

  • $-x + y = 3 - 4\cos\theta + 2\sin\theta \le 3 + 2\sqrt5$
  • $-x - y = 1 - 4\cos\theta - 2\sin\theta \le 1 + 2\sqrt5$
  • $x + y \le -1 + 2\sqrt5$，$x - y \le -3 + 2\sqrt5$

よって最大値は $3 + 2\sqrt5$。これは (1) で $a = 3 + 2\sqrt5$（直線 $y = x + a$ が楕円に接する）のときで、接点は重解 $u = -\frac{4(a - 3)}{5} = -\frac{8\sqrt5}{5}$ より

$$(x,\ y) = \left(-2 - \frac{8\sqrt5}{5},\ 1 + \frac{2\sqrt5}{5}\right)$$

（$x \lt 0 \lt y$ なのでこの点で $|x| + |y| = -x + y = 3 + 2\sqrt5$。）

最小値。原点は①の内部（$\frac4{16} + \frac14 \lt 1$）。正方形 $D_k：|x| + |y| \le k$ は 4 頂点の凸包で、楕円の内部も凸なので、$D_k$ が①の周および内部に含まれる $\iff$ 4 頂点が含まれる。各頂点の条件は

  • $(k,\ 0)$：$(k + 2)^2 \le 12 \iff k \le 2\sqrt3 - 2$
  • $(-k,\ 0)$：$k \le 2 + 2\sqrt3$
  • $(0,\ k)$：$(k - 1)^2 \le 3 \iff k \le 1 + \sqrt3$
  • $(0,\ -k)$：$(k + 1)^2 \le 3 \iff k \le \sqrt3 - 1$

$k_0 = \sqrt3 - 1$ とおくと、$D_{k_0}$ は①の内部（周を含む）にある。①上の点で $|x| + |y| \lt k_0$ となるものがあれば、その点は $D_{k_0}$ の内部、したがって楕円の内部にあり、①上にあることに矛盾。よって①上で $|x| + |y| \ge \sqrt3 - 1$ で、等号は $(0,\ 1 - \sqrt3)$ で成り立つ。

最大値 $3 + 2\sqrt5$ $\left(\left(-2 - \frac{8\sqrt5}{5},\ 1 + \frac{2\sqrt5}{5}\right)\right)$，最小値 $\sqrt3 - 1$ $\left((0,\ 1 - \sqrt3)\right)$。

動く図解

$k$ を動かすと正方形 $|x| + |y| = k$ が拡大・縮小します。楕円と共有点をもつ $k$ の範囲が $\sqrt3 - 1 \le k \le 3 + 2\sqrt5$ です。

問題の背景

マンハッタン距離

$|x| + |y|$ は原点からのマンハッタン距離（$L^1$ ノルム）で、「距離 $k$ の点全体」が正方形になります。普通の距離（円）の代わりに正方形を広げていく、という発想で解けます。

chopin 先生は「(1) は (3) のヒントになっています」「正方形のサイズを 0 から徐々に大きくしていくと、最小値は正方形の頂点が楕円と初めてぶつかるとき、最大値は正方形の辺が楕円から離れる直前」とコメントしています。

$|x| + |y| = k$ は正方形、$\max(|x|,\ |y|) = k$ は軸に平行な正方形。「凸図形が凸図形に含まれる $\iff$ 頂点が含まれる」は最小値の議論で強力。

類題紹介

点 $(x,\ y)$ が円 $x^2 + y^2 = 1$ 上を動くとき，$|x| + |y|$ の最大値と最小値を求めよ。

（自作）

略解

$x = \cos\theta$，$y = \sin\theta$ とすると対称性から $0 \le \theta \le \frac\pi2$ で考えてよく、$\cos\theta + \sin\theta = \sqrt2\sin\left(\theta + \frac\pi4\right)$。最大値 $\sqrt2$（$\theta = \frac\pi4$），最小値 $1$（$\theta = 0,\ \frac\pi2$）。

点 $(x,\ y)$ が楕円①上を動くとき，$\max(|x|,\ |y|)$ の最小値を求めよ。

（九大 2014　魔改造）

略解

$\max(|x|,\ |y|) \le k$ は 4 頂点 $(\pm k,\ \pm k)$ の正方形。本問の最小値と同じ論法で、4 頂点が楕円の内部（周を含む）に入る最大の $k$ が答え。

  • $(k,\ -k)$：$(k + 2)^2 + 4(k + 1)^2 \le 16 \iff 5k^2 + 12k - 8 \le 0 \iff k \le \frac{-6 + 2\sqrt{19}}{5}\ (\approx 0.544)$
  • $(-k,\ -k)$：$5k^2 + 4k - 8 \le 0 \iff k \le \frac{-2 + 2\sqrt{11}}{5}\ (\approx 0.927)$
  • $(k,\ k)$，$(-k,\ k)$ はさらにゆるい条件

最小値は $\dfrac{2\sqrt{19} - 6}{5}$（頂点 $(k,\ -k)$ が楕円にぶつかるとき）。
