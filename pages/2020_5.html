座標空間において，中心 $(0,\ 2,\ 0)$，半径 $1$ で $xy$ 平面内にある円を $D$ とする。$D$ を底面とし，$z \ge 0$ の部分にある高さ $3$ の直円柱（内部を含む）を $E$ とする。点 $(0,\ 2,\ 2)$ と $x$ 軸を含む平面で $E$ を 2 つの立体に分け，$D$ を含む方を $T$ とする。以下の問いに答えよ。

  1. (1)　$-1 \le t \le 1$ とする。平面 $x = t$ で $T$ を切ったときの断面積 $S(t)$ を求めよ。また，$T$ の体積を求めよ。
  2. (2)　$T$ を $x$ 軸のまわりに 1 回転させてできる立体の体積を求めよ。

（2020 九州大学 前期 理系 第5問）

解答例

切る平面は $z = y$。円柱も平面も $x$ 方向に「金太郎飴」なので、$x = t$ で切った断面は台形になる。(2) はその台形を $x$ 軸（断面上では原点）のまわりに回すので、断面はドーナツ型（円環）。原点から最も近い点と最も遠い点を探す。

解答例（タップで展開）

(1)

点 $(0,\ 2,\ 2)$ と $x$ 軸を含む平面は $z = y$。$D$ 側（$z = 0$ を含む側）は $z \le y$。

平面 $x = t$ で $E$ を切ると、$w = \sqrt{1 - t^2}$ として $2 - w \le y \le 2 + w$，$0 \le z \le 3$ の長方形。このうち $z \le y$ の部分が $T$ の断面。$y \le 3$ なので $z \le y$ の方が $z \le 3$ より厳しく、断面は

$$2 - w \le y \le 2 + w,\qquad 0 \le z \le y$$

の台形。

$$S(t) = \int_{2-w}^{2+w} y\,dy = \frac{(2 + w)^2 - (2 - w)^2}{2} = 4w = 4\sqrt{1 - t^2}$$ $$V_T = \int_{-1}^{1} 4\sqrt{1 - t^2}\,dt = 4\cdot\frac{\pi}{2} = 2\pi$$

（$\int_{-1}^1\sqrt{1 - t^2}\,dt$ は半径 1 の半円の面積。）

(2)

平面 $x = t$ 上で、$x$ 軸は点 $(y,\ z) = (0,\ 0)$。台形の 4 頂点は $(2 - w,\ 0)$，$(2 + w,\ 0)$，$(2 + w,\ 2 + w)$，$(2 - w,\ 2 - w)$。

  • 原点に最も近い点：台形は $y \ge 2 - w,\ z \ge 0$ の範囲にあるので、$(2 - w,\ 0)$ で距離 $2 - w$。
  • 原点から最も遠い点：凸図形なので頂点のどれか。$(2 + w,\ 2 + w)$ で距離 $\sqrt2(2 + w)$。

台形は連結なので、回転させると円環 $2 - w \le (\text{距離}) \le \sqrt2(2 + w)$ ができる。その面積は

$$\pi\{2(2 + w)^2 - (2 - w)^2\} = \pi(4 + 12w + w^2) = \pi(5 - t^2 + 12\sqrt{1 - t^2})$$ $$V = \pi\int_{-1}^{1}(5 - t^2 + 12\sqrt{1 - t^2})\,dt = \pi\left(10 - \frac23 + 6\pi\right) = \frac{28}{3}\pi + 6\pi^2$$

動く図解

$t$ を動かすと、左の立体 $T$ を平面 $x = t$ で切った断面（赤い台形）が動きます。右は断面を正面から見た図で、台形を原点のまわりに回すと青い円環になります。左の図はドラッグで回転できます。

問題の背景

回転体は「断面を回す」

立体を軸のまわりに回転させた体積は、軸に垂直な平面で切った断面を回転させるのが鉄則です。回転後の断面は「軸から最も近い点」と「最も遠い点」で決まる円環（ドーナツ）になります（断面が軸を中心とする円周と途切れずに交わる場合）。立体全体を回したイメージを描こうとすると混乱するので、断面だけを考えます。

chopin 先生は「やはりいつもの『断面積を出す→積分』」「(1) の設問が丁寧すぎる気がします。東大京大ならノーヒントで $T$ の体積を出させます」とコメントし、「第 1 問の次に簡単なので、ぜひ押さえたい問題」と評しています。

回転体の体積：軸に垂直に切る → 断面上で軸は 1 点 → その点からの最小距離 $r_1$・最大距離 $r_2$ を求めて $\pi(r_2^2 - r_1^2)$ を積分。

類題紹介

本問の立体 $T$ の体積を，平面 $y = s\ (1 \le s \le 3)$ で切った断面積を積分することで求めよ。

（自作）

略解

$y = s$ での断面は $|x| \le \sqrt{1 - (s - 2)^2}$，$0 \le z \le s$ の長方形で、面積 $2s\sqrt{1 - (s - 2)^2}$。$s = 2 + u$ とおくと

$$\int_{-1}^{1}2(2 + u)\sqrt{1 - u^2}\,du = 4\int_{-1}^1\sqrt{1 - u^2}\,du + 2\int_{-1}^1 u\sqrt{1 - u^2}\,du = 2\pi + 0 = 2\pi$$

（2 つ目は奇関数の積分で $0$。）

本問の立体 $T$ を $y$ 軸のまわりに 1 回転させてできる立体の体積を求めよ。

（九大 2020　魔改造）

略解

$y = s$ での断面は長方形 $|x| \le w_s$，$0 \le z \le s$（$w_s = \sqrt{1 - (s - 2)^2}$）。この平面上で $y$ 軸は点 $(x,\ z) = (0,\ 0)$ で、長方形はこの点を含む（辺上）ので最小距離は $0$、最大距離は頂点 $(\pm w_s,\ s)$ までの $\sqrt{w_s^2 + s^2}$。回転させた断面は円板で、面積は

$$\pi(w_s^2 + s^2) = \pi\{1 - (s - 2)^2 + s^2\} = \pi(4s - 3)$$ $$V = \pi\int_1^3(4s - 3)\,ds = \pi\Big[2s^2 - 3s\Big]_1^3 = 10\pi$$
