1 から 4 までの数字を 1 つずつ書いた 4 枚のカードが箱に入っている。箱の中から 1 枚カードを取り出してもとに戻す試行を $n$ 回続けて行う。$k$ 回目に取り出したカードの数字を $X_k$ とし，積 $X_1X_2\cdots X_n$ を 4 で割った余りが $0,\ 1,\ 2,\ 3$ である確率をそれぞれ $p_n,\ q_n,\ r_n,\ s_n$ とする。$p_n,\ q_n,\ r_n,\ s_n$ を求めよ。

（2018 九州大学 前期 理系 第3問）

解答例

余りがどう移り変わるかを表にして確率漸化式を立てる。余り $0$ は一度なったら抜け出せない。$q_n,\ s_n$ → $r_n$ → $p_n$ の順に求まる（$p_n$ は $1 - q_n - r_n - s_n$ が早い）。

各カードは確率 $\frac14$ なので

$$q_{n+1} = \frac14q_n + \frac14s_n,\qquad s_{n+1} = \frac14q_n + \frac14s_n,\qquad r_{n+1} = \frac14q_n + \frac12r_n + \frac14s_n$$

$q_1 = r_1 = s_1 = \frac14$。

$q_n,\ s_n$：$q_{n+1} = s_{n+1}$ と $q_1 = s_1$ より、すべての $n$ で $q_n = s_n$。すると $q_{n+1} = \frac12q_n$ で

$$q_n = s_n = \frac14\left(\frac12\right)^{n-1} = \frac{1}{2^{n+1}}$$

$r_n$：$r_{n+1} = \frac12r_n + \frac12q_n = \frac12r_n + \frac{1}{2^{n+2}}$。両辺に $2^{n+1}$ をかけると

$$2^{n+1}r_{n+1} = 2^nr_n + \frac12$$

$2^1r_1 = \frac12$ より $2^nr_n = \frac n2$、$r_n = \dfrac{n}{2^{n+1}}$。

$p_n$：$p_n = 1 - q_n - r_n - s_n = 1 - \dfrac{n + 2}{2^{n+1}}$。

$$p_n = 1 - \frac{n + 2}{2^{n+1}},\quad q_n = \frac{1}{2^{n+1}},\quad r_n = \frac{n}{2^{n+1}},\quad s_n = \frac{1}{2^{n+1}}$$

動く図解

$n$ を変えると $p_n,\ q_n,\ r_n,\ s_n$ の棒グラフが変わります。「カードを引く」で実際に 1 枚ずつ引いて、余りの移り変わりを追ってみましょう。いつか 2 か 4 を引くと、余りは 0 に吸い込まれていきます。

問題の背景

マルコフ連鎖と吸収状態

「今の状態だけで次の状態の確率が決まる」確率過程をマルコフ連鎖といいます。本問の「余り 0」のように、一度入ると出られない状態を吸収状態と呼びます。$n \to \infty$ で $p_n \to 1$ となり、最終的には必ず吸収されます。

chopin 先生は「設定的に、どっかでは 2，4，6（本問では 2，4）が混入するので、回数を稼げば、積はいずれ 4 の倍数になる」「$p$ は $1 - (q + r + s)$ で簡単に出せます（$p_n$ を計算した後に気がつきました笑）」とコメントしています。

対称性で漸化式を減らす

$q_n$ と $s_n$ の漸化式がまったく同じ形をしていることに気づくと、連立漸化式を解く手間が省けます。余り 1 と余り 3 は「$-1$ 倍」の関係にあり、確率的に区別がつかないのです。

確率漸化式は状態の遷移表を書いてから立てる。全確率の和が 1 であることや、状態の対称性を使って計算を減らす。$a_{n+1} = \frac12a_n + c\left(\frac12\right)^n$ 型は両辺に $2^{n+1}$ をかける。

類題紹介

1 から 3 までの数字を書いた 3 枚のカードから 1 枚引いて戻す試行を $n$ 回行う。引いた数字の積を 3 で割った余りが $0,\ 1,\ 2$ である確率をそれぞれ求めよ。

（自作）

略解

余り 1，2 の確率を $a_n,\ b_n$ とすると、1 を引けばそのまま、2 を引けば 1 ↔ 2 が入れ替わり、3 を引けば 0。$a_{n+1} = b_{n+1} = \frac13(a_n + b_n)$，$a_1 = b_1 = \frac13$ より $a_n = b_n$ で、$a_n + b_n = \left(\frac23\right)^n$。

$$\text{余り 0}:\ 1 - \left(\frac23\right)^n,\qquad \text{余り 1, 2}:\ \frac12\left(\frac23\right)^n$$

本問と同じ試行で，積 $X_1X_2\cdots X_n$ が $8$ の倍数である確率を求めよ。

（九大 2018　魔改造）

略解

積に含まれる素因数 2 の個数を考える。カード 2 で $+1$、カード 4 で $+2$、カード 1，3 で $+0$。8 の倍数でないのは 2 の個数が $0,\ 1,\ 2$ のとき。

  • 0 個：すべて 1 か 3 で $\frac{1}{2^n}$
  • 1 個：2 を 1 回、残り奇数で $n\cdot\frac14\cdot\frac{1}{2^{n-1}} = \frac{n}{2^{n+1}}$
  • 2 個：2 を 2 回（${}_n\mathrm{C}_2\cdot\frac{1}{16}\cdot\frac{1}{2^{n-2}} = \frac{n(n-1)}{2^{n+3}}$）または 4 を 1 回（$\frac{n}{2^{n+1}}$）
$$1 - \frac{8 + 4n + n(n - 1) + 4n}{2^{n+3}} = 1 - \frac{n^2 + 7n + 8}{2^{n+3}}$$

（$n = 2$ で $\frac{3}{16}$：$(2, 4),\ (4, 2),\ (4, 4)$ の 3 通り。）
