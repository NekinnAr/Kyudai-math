座標空間内の 3 点 $\mathrm{A}(1,\ 1,\ -5)$，$\mathrm{B}(-1,\ -1,\ 7)$，$\mathrm{C}(1,\ -1,\ 3)$ を通る平面を $\alpha$ とする。点 $\mathrm{P}(a,\ b,\ t)$ を通り $\alpha$ に垂直な直線と $xy$ 平面との交点を $\mathrm{Q}$ とする。

  1. (1)　点 $\mathrm{Q}$ の座標を求めよ。
  2. (2)　$t$ がすべての実数値をとって変化するときの $\mathrm{OQ}$ の最小値が $1$ 以下となるような $a,\ b$ の条件を求めよ。ただし，$\mathrm{O}$ は原点である。

（2025 九州大学 前期 理系 第1問）

解答例

平面 $\alpha$ の法線ベクトル $\vec n$ さえ求まれば、P を通り $\alpha$ に垂直な直線は $\overrightarrow{\mathrm{OP}} + s\vec n$ と書ける。(2) は $t$ の 2 次関数の最小値。

解答例（タップで展開）

(1)

$$\overrightarrow{\mathrm{CA}} = (0,\ 2,\ -8) = 2(0,\ 1,\ -4),\qquad \overrightarrow{\mathrm{CB}} = (-2,\ 0,\ 4) = -2(1,\ 0,\ -2)$$

$\vec n = (p,\ q,\ r)$ がこの 2 つに垂直とすると $q - 4r = 0,\ p - 2r = 0$。$r = 1$ として $\vec n = (2,\ 4,\ 1)$ は $\alpha$ の法線ベクトルである。

P を通り $\alpha$ に垂直な直線上の点は、実数 $s$ を用いて

$$(a + 2s,\ b + 4s,\ t + s)$$

と表せる。$z$ 座標が $0$ となるのは $s = -t$ のときなので

$$\mathrm{Q}(a - 2t,\ b - 4t,\ 0)$$

(2)

$$\begin{aligned} \mathrm{OQ}^2 &= (a-2t)^2 + (b-4t)^2 = 20t^2 - 4(a+2b)t + a^2 + b^2 \\ &= 20\left(t - \frac{a+2b}{10}\right)^2 + a^2 + b^2 - \frac{(a+2b)^2}{5} \\ &= 20\left(t - \frac{a+2b}{10}\right)^2 + \frac{(2a-b)^2}{5} \end{aligned}$$

よって $\mathrm{OQ}$ の最小値は $\dfrac{|2a-b|}{\sqrt5}$（$t = \dfrac{a+2b}{10}$ のとき）。これが $1$ 以下となる条件は

$$|2a - b| \le \sqrt5 \quad\text{すなわち}\quad -\sqrt5 \le 2a - b \le \sqrt5$$

動く図解

$t$ を動かすと、Q は $xy$ 平面上の直線を描きます。OQ の最小値は「原点からその直線までの距離」です。下の図の上でクリック（タップ）すると点 $(a,\ b)$ を動かせます。

■ 薄い帯：条件 |2a−b| ≤ √5 をみたす (a, b) の範囲
● 黒点：(a, b)　● 赤点：Q
― 赤線：t を動かしたときの Q の軌跡
― 青線：原点からの垂線（最小値）

問題の背景

Q は「斜めの光でできる影」

P から $\vec n = (2,\ 4,\ 1)$ の方向に進んで $xy$ 平面にぶつかった点が Q なので、Q は$\vec n$ の方向から平行光線を当てたときの、P の影だと見ることができます。このような写像を平行投影といいます。

P$(a,\ b,\ t)$ は $t$ を動かすと $z$ 軸に平行な直線上を動くので、その影 Q も直線を描きます。実際、

$$\mathrm{Q} = (a,\ b,\ 0) + t(-2,\ -4,\ 0)$$

は「点 $(a,\ b)$ を通り方向 $(1,\ 2)$ の直線」です。

(2) は「点と直線の距離」

点 $(a,\ b)$ を通り方向 $(1,\ 2)$ の直線の方程式は $2(x - a) - (y - b) = 0$、すなわち $2x - y - (2a - b) = 0$。原点との距離は、点と直線の距離の公式から

$$\frac{|2a - b|}{\sqrt{2^2 + 1^2}} = \frac{|2a-b|}{\sqrt5}$$

となり、平方完成の結果と一致します。つまり (2) の答え $-\sqrt5 \le 2a - b \le \sqrt5$ は、直線 $y = 2x$ を中心とする幅 2 の帯です。直線 $y = 2x$ は、法線ベクトル $\vec n$ を $xy$ 平面に落とした向き $(2,\ 4) \parallel (1,\ 2)$ と平行になっています。

計算で解いたあとに「この式は図形的に何を意味するのか」を考えると、検算にもなり、問題の構造も見えてきます。

平面の方程式を使う方法

平面 $\alpha$ の方程式は $2x + 4y + z = 1$ です（A, B, C を代入して確かめられます）。$ax+by+cz=d$ の形の平面の法線ベクトルは $(a,\ b,\ c)$ なので、方程式が分かれば法線ベクトルは「係数を読むだけ」です。新課程では平面の方程式は発展的な扱いですが、知っていると検算に便利です。

類題紹介

本問の平面 $\alpha$ について，原点 O から $\alpha$ に下ろした垂線の足 H の座標と，O と $\alpha$ の距離を求めよ。

（自作）

略解

H $= s(2,\ 4,\ 1)$ とおいて $\alpha: 2x+4y+z=1$ に代入すると $21s = 1$。よって $\mathrm{H}\left(\dfrac{2}{21},\ \dfrac{4}{21},\ \dfrac{1}{21}\right)$、距離は $|\overrightarrow{\mathrm{OH}}| = \dfrac{\sqrt{21}}{21} = \dfrac{1}{\sqrt{21}}$。

本問と同じ平面 $\alpha$ を考える。点 P が球面 $x^2 + y^2 + (z-3)^2 = 1$ 上を動くとき，P を通り $\alpha$ に垂直な直線と $xy$ 平面との交点 Q が動く範囲の面積を求めよ。

（九大 2025　魔改造）

略解

Q の動く範囲は、球を $\vec n$ 方向の平行光線で照らしたときの $xy$ 平面上の影で、楕円になります。$\vec n$ に垂直な平面への球の影は半径 $1$ の円（面積 $\pi$）で、それを $xy$ 平面に斜めに落とすと面積は $\dfrac{1}{\cos\theta}$ 倍になります（$\theta$ は $\vec n$ と $z$ 軸のなす角）。

$$\cos\theta = \frac{\vec n\cdot(0,0,1)}{|\vec n|} = \frac{1}{\sqrt{21}} \quad\text{より}\quad \text{面積} = \pi\sqrt{21}$$

式で確かめるなら、Q$(X,\ Y,\ 0)$ に対して P $= (X + 2s,\ Y + 4s,\ s)$ が球面上にあるような実数 $s$ が存在する条件（$s$ の 2 次方程式の判別式 $\ge 0$）を求めると、楕円の内部が得られます。
