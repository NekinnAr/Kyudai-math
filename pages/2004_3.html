座標平面上を動く点 $P(x(t),\ y(t))$ の時刻 $t$ における座標が

$$\begin{cases} x(t) = \cos\left(t + \dfrac\pi4\right) \\ y(t) = \cos(2t) \end{cases}\quad(0 \le t < 2\pi)$$

で与えられているとし，この点の軌跡を $C$ とする。

  1. (1)　$P$ が原点を通るときの速度ベクトルを求めよ。
  2. (2)　$C$ が $x$ 軸，$y$ 軸に関して対称であることを示せ。
  3. (3)　$C$ の概形を描け。
  4. (4)　$C$ が囲む図形の面積を求めよ。

（2004 九州大学 前期 理系 第3問）

解答例

$s = t + \frac\pi4$ とおくと $x = \cos s$，$y = \cos\left(2s - \frac\pi2\right) = \sin 2s = 2\sin s\cos s$。$t$ を消去すると $y^2 = 4x^2(1 - x^2)$ で、8 の字型（リサジュー曲線）になります。

解答例（タップで展開）

(1)

$x = 0$ となるのは $t + \frac\pi4 = \frac\pi2,\ \frac{3\pi}2$，すなわち $t = \frac\pi4,\ \frac{5\pi}4$ で、どちらも $y = \cos2t = 0$。速度は $(x', y') = \left(-\sin\left(t + \frac\pi4\right),\ -2\sin2t\right)$ なので

$$t = \tfrac\pi4:\ (-1,\ -2),\qquad t = \tfrac{5\pi}4:\ (1,\ -2)$$

(2)

$s = t + \frac\pi4$ とおくと、$s$ は長さ $2\pi$ の区間を動き、$x = \cos s$，$y = \cos\left(2s - \frac\pi2\right) = \sin2s$。周期性より $C = \{(\cos s,\ \sin2s) \mid s \text{ は実数}\}$。

  • $s \to -s$：$(\cos s,\ -\sin2s)$ も $C$ 上 → $x$ 軸対称。
  • $s \to \pi + s$：$(-\cos s,\ \sin2s)$ も $C$ 上 → $y$ 軸対称。

(3)

$y = 2\sin s\cos s = \pm2x\sqrt{1 - x^2}$ より $C$ は $y^2 = 4x^2(1 - x^2)$（$-1 \le x \le 1$）。第 1 象限の部分 $y = 2x\sqrt{1 - x^2}$ は $\frac{dy}{dx} = \frac{2(1 - 2x^2)}{\sqrt{1 - x^2}}$ より $x = \frac1{\sqrt2}$ で最大値 $1$，$x = 1$ で $y = 0$（接線は鉛直）。これを (2) の対称性で折り返すと、原点で交差する 8 の字型（下の図解）。原点での接線の傾きは $\pm2$。

(4)

対称性より第 1 象限の 4 倍。

$$S = 4\int_0^1 2x\sqrt{1 - x^2}\,dx = 4\left[-\frac23(1 - x^2)^{\frac32}\right]_0^1 = \frac83$$

動く図解

$t$ を動かすと点 $P$ と速度ベクトル（赤い矢印）が動きます。$t = \frac\pi4 \approx 0.785$，$\frac{5\pi}4 \approx 3.927$ で原点を通ります。

問題の背景

リサジュー曲線

$x = \cos(at + \delta)$，$y = \cos bt$ の形の曲線はリサジュー曲線と呼ばれ、オシロスコープで 2 つの振動を合成すると現れます。周波数比 $1 : 2$，位相差 $\frac\pi4$ の本問は、典型的な「8 の字」。位相差を変えると放物線のような形（$\delta = 0$ のとき $y = 2x^2 - 1$）にもつぶれます。媒介変数のままでは見通しが悪いので、$t$ を消去して $x$，$y$ の関係式にするのが鍵です。

chopin 先生は「(1) $x$，$y$ を $t$ で微分したものが速度になります」「(2) パラメータ表示されたままでは考えにくいので、$t$ を消去して $x$，$y$ だけの式にしてあげると見通しが良くなります」「(3) $x$，$y$ の増減を調べればよいでしょう」「(4) 対称性から、$\frac14$ した面積を計算すればよいです」とコメントしています。

媒介変数は消去して関係式に。対称性を示せば面積は一部分の何倍かで済む。

類題紹介

曲線 $y^2 = x^2(1 - x^2)$ が囲む図形の面積を求めよ。

（自作）

略解

$x$ 軸，$y$ 軸対称なので $4\displaystyle\int_0^1x\sqrt{1 - x^2}\,dx = 4\cdot\frac13 = \frac43$。（本問の曲線を縦に $\frac12$ 倍したもの。）

本問の曲線 $C$ が囲む図形を $x$ 軸のまわりに 1 回転してできる立体の体積を求めよ。

（九大 2004　魔改造）

略解

$x$ 軸対称なので、$0 \le y \le 2|x|\sqrt{1 - x^2}$ の部分を回せばよい。

$$V = \pi\int_{-1}^{1}4x^2(1 - x^2)\,dx = 8\pi\left(\frac13 - \frac15\right) = \frac{16\pi}{15}$$
