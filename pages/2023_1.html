以下の問いに答えよ。

  1. (1)　4 次方程式 $x^4 - 2x^3 + 3x^2 - 2x + 1 = 0$ を解け。
  2. (2)　複素数平面上の $\triangle\mathrm{ABC}$ の頂点を表す複素数をそれぞれ $\alpha,\ \beta,\ \gamma$ とする。 $$(\alpha - \beta)^4 + (\beta - \gamma)^4 + (\gamma - \alpha)^4 = 0$$ が成り立つとき，$\triangle\mathrm{ABC}$ はどのような三角形になるか答えよ。

（2023 九州大学 前期 理系 第1問）

解答例

(1) は係数が左右対称な相反方程式。(2) は一見 (1) と無関係な小問に見えるが、$\delta = \dfrac{\alpha - \beta}{\gamma - \beta}$ とおいて式全体を $(\gamma - \beta)^4$ で割ると、(1) の方程式そのものが現れる。

解答例（タップで展開）

(1)

$x = 0$ は解でないので、両辺を $x^2$ で割ると

$$x^2 + \frac{1}{x^2} - 2\left(x + \frac1x\right) + 3 = 0$$

$t = x + \dfrac1x$ とおくと $x^2 + \dfrac{1}{x^2} = t^2 - 2$ より $t^2 - 2t + 1 = 0$、すなわち $t = 1$。$x + \dfrac1x = 1$ より $x^2 - x + 1 = 0$。

$$x = \frac{1 \pm \sqrt3\,i}{2}\qquad\left(\text{実は}\ x^4 - 2x^3 + 3x^2 - 2x + 1 = (x^2 - x + 1)^2\right)$$

(2)

A，B，C は三角形の頂点なので相異なり、$\gamma - \beta \neq 0$。$\delta = \dfrac{\alpha - \beta}{\gamma - \beta}$ とおくと

$$\alpha - \beta = \delta(\gamma - \beta),\qquad \gamma - \alpha = (\gamma - \beta) - (\alpha - \beta) = (1 - \delta)(\gamma - \beta)$$

与式を $(\gamma - \beta)^4\ (\neq 0)$ で割ると

$$\delta^4 + 1 + (1 - \delta)^4 = 0 \iff 2\delta^4 - 4\delta^3 + 6\delta^2 - 4\delta + 2 = 0 \iff \delta^4 - 2\delta^3 + 3\delta^2 - 2\delta + 1 = 0$$

これは (1) の方程式なので

$$\delta = \frac{1 \pm \sqrt3\,i}{2} = \cos\left(\pm\frac{\pi}{3}\right) + i\sin\left(\pm\frac{\pi}{3}\right)$$

$\delta = \dfrac{\alpha - \beta}{\gamma - \beta}$ は「$\overrightarrow{\mathrm{BC}}$ を何倍・何度回転すると $\overrightarrow{\mathrm{BA}}$ になるか」を表す。$|\delta| = 1$ より $\mathrm{BA} = \mathrm{BC}$、$\arg\delta = \pm\dfrac{\pi}{3}$ より $\angle\mathrm{ABC} = \dfrac{\pi}{3}$。2 辺が等しくその間の角が $60^\circ$ なので

$$\triangle\mathrm{ABC}\ \text{は正三角形}$$

別解（対称式で）：$u = \alpha - \beta,\ v = \beta - \gamma,\ w = \gamma - \alpha$ とおくと $u + v + w = 0$ で、このとき $u^4 + v^4 + w^4 = \dfrac12(u^2 + v^2 + w^2)^2$ が成り立ちます。よって条件は $u^2 + v^2 + w^2 = 0$、すなわち $\alpha^2 + \beta^2 + \gamma^2 = \alpha\beta + \beta\gamma + \gamma\alpha$ と同値で、これは正三角形の有名な条件です。

動く図解

A，B，C をドラッグして動かしてみましょう。右の図は $\delta = \dfrac{\alpha - \beta}{\gamma - \beta}$ の位置で、(1) の解（赤い点）と重なるとき、与式の値が $0$ になり正三角形になります。

問題の背景

小問集合…ではなかった

九大では珍しい小問集合に見えますが、(1) は (2) の伏線でした。chopin 先生も、読者から $\delta$ を使う別解を教わって「小問集合だと思い込んでいたら (2) の伏線になっていたとは驚きました」と追記しています。「一見関係なさそうな前問を、どう使うか」を考えるのは入試問題を解くうえで大切な視点です。

相反方程式

係数が $1,\ -2,\ 3,\ -2,\ 1$ と左右対称な方程式は相反方程式と呼ばれ、$x$ が解なら $\dfrac1x$ も解です。$x^2$ で割って $t = x + \dfrac1x$ とおくと次数が半分になります。

複素数で見る三角形の形

$\dfrac{\alpha - \beta}{\gamma - \beta}$ は「角 B のところの 2 辺の比と角度」を一度に表す量で、三角形の形（相似の類）を決めます。正三角形なら $\cos\frac{\pi}{3} \pm i\sin\frac{\pi}{3}$、直角二等辺三角形なら $\pm i$ です。

複素数平面の図形問題は、「比 $\frac{\alpha - \beta}{\gamma - \beta}$」を 1 文字でおくと、式の対称性が図形の性質にそのまま翻訳できます。

類題紹介

4 次方程式 $x^4 + x^3 + x^2 + x + 1 = 0$ を解け。また，その結果を用いて $\cos\dfrac{2\pi}{5}$ の値を求めよ。

（自作）

略解

$x^2$ で割って $t = x + \frac1x$ とおくと $t^2 + t - 1 = 0$、$t = \dfrac{-1 \pm \sqrt5}{2}$。各 $t$ について $x^2 - tx + 1 = 0$ を解くと

$$x = \frac{-1 + \sqrt5 \pm \sqrt{10 + 2\sqrt5}\,i}{4},\quad \frac{-1 - \sqrt5 \pm \sqrt{10 - 2\sqrt5}\,i}{4}$$

一方、$x^5 - 1 = (x - 1)(x^4 + x^3 + x^2 + x + 1)$ より解は $\cos\frac{2k\pi}{5} + i\sin\frac{2k\pi}{5}$（$k = 1, 2, 3, 4$）。$x + \frac1x = 2\cos\frac{2k\pi}{5}$ なので、正の方の $t$ と比べて $\cos\dfrac{2\pi}{5} = \dfrac{-1 + \sqrt5}{4}$。

複素数 $\alpha,\ \beta,\ \gamma$ が $(\alpha - \beta)^3 + (\beta - \gamma)^3 + (\gamma - \alpha)^3 = 0$ をみたすとき，3 点 $\mathrm{A}(\alpha)$，$\mathrm{B}(\beta)$，$\mathrm{C}(\gamma)$ は三角形をなさないことを示せ。

（九大 2023　魔改造）

略解

$u = \alpha - \beta,\ v = \beta - \gamma,\ w = \gamma - \alpha$ とおくと $u + v + w = 0$。恒等式

$$u^3 + v^3 + w^3 - 3uvw = (u + v + w)(u^2 + v^2 + w^2 - uv - vw - wu)$$

より $u^3 + v^3 + w^3 = 3uvw$。条件から $uvw = 0$ となり、A，B，C のうち 2 点が一致する。よって三角形をなさない。

（4 乗なら正三角形、3 乗なら三角形にすらならない。指数を 1 つ変えるだけで結論が激変します。）
