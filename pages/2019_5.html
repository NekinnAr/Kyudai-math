$a,\ b$ を複素数，$c$ を純虚数でない複素数とし，$i$ を虚数単位とする。複素数平面において，点 $z$ が虚軸全体を動くとき

$$w = \frac{az + b}{cz + 1}$$

で定まる点 $w$ の軌跡を $C$ とする。次の 3 条件が満たされているとする。

  • (ア)　$z = i$ のときに $w = i$ となり，$z = -i$ のときに $w = -i$ となる。
  • (イ)　$C$ は単位円の周に含まれる。
  • (ウ)　点 $-1$ は $C$ に属さない。

このとき $a,\ b,\ c$ の値を求めよ。さらに $C$ を求め，複素数平面上に図示せよ。

（2019 九州大学 前期 理系 第5問）

解答例

(ア) で $a,\ b$ を $c$ で表し、(イ) で $|c| = 1$ を導く（$z = ti$ とおいて恒等式にする）。最後に (ウ)：$w = -1$ となる $z$ を逆算すると、$c \neq -1$ ならそれが虚軸上に来てしまう。

解答例（タップで展開）

$a,\ b,\ c$ の決定

(ア)：$z = i$ で $w = i$ より $ai + b = i(ci + 1) = -c + i$。$z = -i$ で $w = -i$ より $-ai + b = -i(-ci + 1) = -c - i$。辺々引いて $2ai = 2i$、$a = 1$。辺々足して $2b = -2c$、$b = -c$。

$$w = \frac{z - c}{cz + 1}$$

(イ)：$z = ti$（$t$ は実数）とおき、$c = p + qi$（$p,\ q$ は実数、$p \neq 0$）とする。（$cz + 1 = 0$ となる $t$ は C に含まれないので除く。）すべての $t$ で $|w| = 1$、すなわち $|ti - c| = |cti + 1|$。

$$|ti - c|^2 = p^2 + (t - q)^2,\qquad |cti + 1|^2 = |(1 - qt) + pti|^2 = (1 - qt)^2 + p^2t^2$$

差をとって整理すると $(1 - p^2 - q^2)t^2 + (p^2 + q^2 - 1) = 0$。これが（有限個を除く）すべての実数 $t$ で成り立つので $p^2 + q^2 = 1$、つまり $|c| = 1$。

(ウ)：$w = -1$ とすると $z - c = -cz - 1$ より $(1 + c)z = c - 1$。

もし $c \neq -1$ なら $z = \dfrac{c - 1}{c + 1}$。$|c| = 1$ より $\bar c = \frac1c$ で

$$\overline{\left(\frac{c - 1}{c + 1}\right)} = \frac{\frac1c - 1}{\frac1c + 1} = \frac{1 - c}{1 + c} = -\frac{c - 1}{c + 1}$$

なので $z$ は純虚数または $0$、つまり虚軸上にある。このとき $cz + 1 = \frac{c^2 + 1}{c + 1} \neq 0$（$c$ は純虚数でないので $c \neq \pm i$）で、$w = -1$ が C に属してしまい (ウ) に反する。よって $c = -1$（純虚数でなく、$|c| = 1$ もみたす）。

$$a = 1,\quad b = 1,\quad c = -1$$

C の決定

$w = \dfrac{1 + z}{1 - z}$，$z = ti$ より

$$w = \frac{1 + ti}{1 - ti} = \frac{(1 + ti)^2}{1 + t^2} = \frac{1 - t^2}{1 + t^2} + \frac{2t}{1 + t^2}i$$

$t = \tan\frac\theta2$（$-\pi \lt \theta \lt \pi$）とおくと $w = \cos\theta + i\sin\theta$。$t$ が実数全体を動くとき $\theta$ は $-\pi \lt \theta \lt \pi$ 全体を動くので

C は単位円から点 $-1$ を除いたもの

動く図解

$|c| = 1$ の範囲で $c$ の偏角を動かすと、$w = \frac{z - c}{cz + 1}$ による虚軸の像（赤）が変わります。像はいつも単位円ですが、欠ける 1 点（○）の位置が $c$ によって変わります。欠ける点が $-1$ になるのは $c = -1$ のときだけです。

問題の背景

1 次分数変換（メビウス変換）

$w = \frac{az + b}{cz + d}$（$ad - bc \neq 0$）の形の変換を1 次分数変換（メビウス変換）といいます。「円または直線」を「円または直線」に移すという著しい性質があり、本問はその具体例です。直線（虚軸）は無限遠点を通る「円」とみなせ、その無限遠点の行き先 $\frac ac$ が像の円から欠ける点になります。本問では $\frac ac = \frac1c$ なので、$-1$ が欠けるには $c = -1$。

「c は純虚数でない」の意味

$c = \pm i$ だと $ad - bc = 1 + c^2 = 0$ となり、$w$ が定数（$\mp i$）になってしまいます。問題文の「純虚数でない」は、このような退化を防ぐための条件です。

chopin 先生は「(ウ) について考えるところがこの問題の難しい部分」「結局、C は円から $z = -1$ を除いただけの図形となります。なんか拍子抜けですね」とコメントしています。

$|c| = 1 \iff \bar c = \dfrac1c$。これを使うと「$\frac{c - 1}{c + 1}$ は純虚数」のような計算が一瞬でできる。直線の 1 次分数変換の像から欠ける点は「$z \to \infty$ のときの $w$ の極限」。

類題紹介

点 $z$ が単位円周上の $z \neq 1$ をみたす部分を動くとき，$w = \dfrac{1 + z}{1 - z}$ の軌跡を求めよ。

（自作）

略解

$\bar z = \frac1z$ より $\bar w = \dfrac{1 + \frac1z}{1 - \frac1z} = \dfrac{z + 1}{z - 1} = -w$。よって $w$ は純虚数または $0$。逆に $w = ti$ に対して $z = \frac{w - 1}{w + 1}$ は $|z| = 1$，$z \neq 1$ をみたす。軌跡は虚軸全体（本問の変換の逆）。

本問の条件 (ウ) を「点 $1$ は $C$ に属さない」に変えたとき，$a,\ b,\ c$ の値と $C$ を求めよ。

（九大 2019　魔改造）

略解

(ア)(イ) までは同じで $a = 1,\ b = -c,\ |c| = 1$。$w = 1$ とすると $z - c = cz + 1$、$(1 - c)z = 1 + c$。$c \neq 1$ なら $z = \frac{1 + c}{1 - c}$ は（同様の計算で）虚軸上にあり不適。よって $c = 1$、$a = 1,\ b = -1$。

$w = \dfrac{z - 1}{z + 1} = \dfrac{ti - 1}{ti + 1}$ で、$t \to \pm\infty$ のとき $w \to 1$。C は単位円から点 $1$ を除いたもの。
