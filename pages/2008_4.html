$a > 0$ に対して，$f(x) = a + \log x\ (x > 0)$，$g(x) = \sqrt{x - 1}\ (x \ge 1)$ とおく。2 曲線 $y = f(x)$，$y = g(x)$ が，ある点 $P$ を共有し，その点で共通の接線 $l$ を持つとする。このとき，次の問いに答えよ。

  1. (1)　$a$ の値，点 $P$ の座標，および接線 $l$ の方程式を求めよ。
  2. (2)　2 曲線は点 $P$ 以外の共有点を持たないことを示せ。
  3. (3)　2 曲線と $x$ 軸で囲まれた部分の面積を求めよ。

（2008 九州大学 前期 理系 第4問）

解答例

「接する」⇔「$f(p) = g(p)$ かつ $f'(p) = g'(p)$」。(2) は差 $h = f - g$ の単調性、(3) は $y$ 軸方向に積分すると逆関数が簡単なので楽です。

解答例（タップで展開）

(1)

$P$ の $x$ 座標を $p\ (> 1)$ とする（$x = 1$ では $g$ は微分できない）。$f'(x) = \dfrac1x$，$g'(x) = \dfrac{1}{2\sqrt{x - 1}}$ より

$$\frac1p = \frac{1}{2\sqrt{p - 1}} \iff p = 2\sqrt{p - 1} \iff p^2 - 4p + 4 = 0 \iff p = 2$$

$f(2) = g(2)$ より $a + \log2 = 1$，$a = 1 - \log2$（$> 0$ をみたす）。

$$a = 1 - \log2,\qquad P(2,\ 1),\qquad l:\ y = \frac12x$$

(2)

$h(x) = f(x) - g(x) = 1 - \log2 + \log x - \sqrt{x - 1}\ (x \ge 1)$ とおく。$x > 1$ で

$$h'(x) = \frac1x - \frac{1}{2\sqrt{x - 1}} = \frac{2\sqrt{x - 1} - x}{2x\sqrt{x - 1}} = -\frac{(\sqrt{x - 1} - 1)^2}{2x\sqrt{x - 1}} \le 0$$

（$x = (\sqrt{x - 1})^2 + 1$ を使った。）等号は $x = 2$ のみなので $h$ は狭義単調減少で、$h(x) = 0$ の解は $x = 2$ だけ。よって共有点は $P$ のみ。

(3)

$h$ は減少で $h(2) = 0$ なので $1 \le x \le 2$ で $f \ge g$。$f(x) = 0 \iff x = \frac2e$，$g(x) = 0 \iff x = 1$。図形は $0 \le y \le 1$ の範囲で、左端が $y = f(x)$，右端が $y = g(x)$。それぞれ $x$ について解くと $x = 2e^{y - 1}$，$x = y^2 + 1$ なので

$$S = \int_0^1\left\{(y^2 + 1) - 2e^{y - 1}\right\}dy = \frac43 - 2\left(1 - \frac1e\right) = \frac2e - \frac23$$

動く図解

$a$ を動かすと $y = f(x)$ が上下に平行移動します。どの $a > 0$ でも共有点はちょうど 1 つ（$h$ が単調減少だから）ですが、その点で接するのは $a = 1 - \log2 \approx 0.307$ のときだけです。

問題の背景

接する ⇔ 差が重解をもつ

2 曲線が接することは、差 $h(x) = f(x) - g(x)$ が $h(p) = h'(p) = 0$ をみたすこと、つまり $x = p$ が「重解」になることです。本問の $h'$ が $-(\sqrt{x - 1} - 1)^2$ という完全平方を含むのは、まさにこの重解の痕跡です。

(3) では $x$ で積分すると、$x$ の区間が $\left[\frac2e,\ 1\right]$ と $[1,\ 2]$ に分かれて面倒ですが、$y$ で積分すれば 1 本の式で済みます。$\log$ と $\sqrt{}$ の逆関数が $e^y$ と $y^2$ で簡単なのもポイント。

chopin 先生は「(1) P の $x$ 座標を $p$ とすると、$f(p) = g(p)$ と $f'(p) = g'(p)$ が同時に成り立ちます」「(2) $h(x) = f(x) - g(x) = 0$ の解が 1 個しかないことを証明することになります」「(3) 定石通りの面積計算です」とコメントしています。

2 曲線が接する ⇔ $f(p) = g(p)$，$f'(p) = g'(p)$。面積は $x$ と $y$ のどちらで積分すると楽かを考える。

2 曲線 $y = \log x$ と $y = kx^2$（$k > 0$）が接するような $k$ の値と，接点の座標を求めよ。

（自作）

略解

接点の $x$ 座標を $p$ とすると $\log p = kp^2$，$\frac1p = 2kp$。後者から $kp^2 = \frac12$，よって $\log p = \frac12$，$p = \sqrt e$，$k = \dfrac{1}{2e}$。接点 $\left(\sqrt e,\ \frac12\right)$。
