座標空間内で，原点 O を中心とする半径 $3$ の球を $S$ とする。また，点 $\mathrm{P}(1,\ 0,\ \sqrt3)$ を考え，$T_1$ と $T_2$ を直線 OP と直交する相異なる 2 つの平面とする。$T_1$ と $S$ の共通部分を $C_1$，$T_2$ と $S$ の共通部分を $C_2$ とし，次の 2 つの条件をみたすとする。

  • $C_1$ と $C_2$ はどちらも半径 $1$ の円である。
  • $C_1$ の中心の $z$ 座標は正で，$C_2$ の中心の $z$ 座標は負である。

以下の問いに答えよ。

  1. (1)　円 $C_1$，$C_2$ の中心の座標を求めよ。
  2. (2)　円 $C_1$，$C_2$ を底面とする円柱の側面を平面 $z = 0$ で切る。その切り口の曲線の方程式を求めよ。また，その曲線を図示せよ。

（2026 九州大学 前期 理系 第1問）

解答例

円柱の側面は「中心軸（直線 OP）からの距離が $1$ の点の集合」。点と直線の距離を、正射影ベクトルを使って式にすれば一発で方程式が出る。

解答例（タップで展開）

(1)

球の中心 O から平面 $T_1$ までの距離を $d$ とすると、三平方の定理より $d^2 + 1^2 = 3^2$、$d = 2\sqrt2$。$C_1,\ C_2$ の中心は直線 OP 上にあり、O からの距離は $2\sqrt2$。$|\overrightarrow{\mathrm{OP}}| = 2$ なので、直線 OP 方向の単位ベクトルは $\vec u = \dfrac12(1,\ 0,\ \sqrt3)$ で、中心は

$$\pm 2\sqrt2\,\vec u = \pm(\sqrt2,\ 0,\ \sqrt6)$$

$z$ 座標の符号から、$C_1$ の中心は $(\sqrt2,\ 0,\ \sqrt6)$、$C_2$ の中心は $(-\sqrt2,\ 0,\ -\sqrt6)$。

(2)

円柱の中心軸は直線 OP（2 つの中心を結ぶ直線）。点 $\mathrm{X}(x,\ y,\ z)$ が円柱の側面（を延長した面）上にある条件は、直線 OP との距離が $1$ であること、すなわち

$$|\overrightarrow{\mathrm{OX}}|^2 - (\overrightarrow{\mathrm{OX}}\cdot\vec u)^2 = 1$$

（$\overrightarrow{\mathrm{OX}}\cdot\vec u$ は $\overrightarrow{\mathrm{OX}}$ の直線 OP への正射影の長さ）。$z = 0$ のとき $\overrightarrow{\mathrm{OX}}\cdot\vec u = \dfrac{x}{2}$ なので

$$x^2 + y^2 - \frac{x^2}{4} = 1 \qquad\therefore\quad \frac34 x^2 + y^2 = 1$$

このとき軸方向の座標 $\dfrac{x}{2}$ は $|x| \le \dfrac{2}{\sqrt3}$ より $\left|\dfrac{x}{2}\right| \le \dfrac{1}{\sqrt3} \lt 2\sqrt2$ なので、この曲線全体が実際に 2 つの底面の間の側面上にある。

よって切り口は楕円 $\dfrac{x^2}{\left(\frac{2}{\sqrt3}\right)^2} + y^2 = 1$ で、$xy$ 平面上で $x$ 軸との交点 $\left(\pm\dfrac{2}{\sqrt3},\ 0\right)$、$y$ 軸との交点 $(0,\ \pm1)$ を通る、$x$ 軸方向に長い楕円である（図は下の「動く図解」を参照）。

動く図解

ドラッグで視点を回転できます。軸の傾き $\varphi$（直線 OP と $z$ 軸のなす角）を変えると、切り口の楕円がどう変わるかを観察してみましょう。本問は $\varphi = 30^\circ$ です。

左：赤＝切り口の楕円，青＝C₁・C₂，灰＝円柱の母線，薄い円＝球 S　／　右：xy 平面上の切り口（点は焦点）

問題の背景

円柱を斜めに切ると楕円になる

軸が $z$ 軸と角 $\varphi$ をなす半径 $1$ の円柱を平面 $z = 0$ で切ると、同じ計算で

$$x^2\cos^2\varphi + y^2 = 1$$

が得られます。軸に垂直な方向（$y$ 方向）の半径は $1$ のまま、斜めに切った方向（$x$ 方向）だけが $\dfrac{1}{\cos\varphi}$ 倍に引き伸ばされた楕円です。本問は $\cos^2 30^\circ = \dfrac34$ のケースです。斜めに切ったきゅうりやソーセージの断面が楕円になるのと同じ現象ですね。

ダンドランの球 ── 焦点はどこにある？

楕円 $\dfrac34x^2 + y^2 = 1$ の焦点は、$a^2 = \dfrac43,\ b^2 = 1$ より $c = \sqrt{a^2 - b^2} = \dfrac{1}{\sqrt3}$ で、$\left(\pm\dfrac{1}{\sqrt3},\ 0\right)$ です。実はこの焦点は、空間図形として美しく説明できます。

円柱の内側に、半径 $1$ の球を平面 $z = 0$ の上下から 1 つずつ、円柱にぴったり内接し、かつ平面 $z = 0$ に接するように入れます（ダンドランの球）。球の中心は軸上で $z = \pm1$ の点、すなわち $\left(\pm\dfrac{1}{\sqrt3},\ 0,\ \pm1\right)$ で、平面 $z = 0$ との接点は $\left(\pm\dfrac{1}{\sqrt3},\ 0,\ 0\right)$ ── ちょうど楕円の焦点です。

切り口上の点 X から 2 つの接点までの距離は、それぞれ X から各球への接線の長さに等しく、それは X を通る母線に沿って 2 つの球と円柱の接触円まで測った長さと同じです。その和は「2 つの接触円の間隔」で一定になるので、切り口は 2 つの接点を焦点とする楕円になる ── というのがダンドラン（1822 年）の証明です。

離心率 $e = \dfrac{c}{a} = \dfrac{1/\sqrt3}{2/\sqrt3} = \dfrac12$ は $\sin30^\circ$ に一致します。一般に、円柱を軸と角 $\varphi$ をなす向きに切った楕円の離心率は $\sin\varphi$ です。

球 S の役割

球 $S$ は「軸上のどこに底面があるか」を決めるためだけに使われていて、(2) の切り口の方程式には一切影響しません（底面の間隔が十分長ければ、切り口は同じ楕円）。条件が多い問題では、「どの条件が本質で、どれが設定のための飾りか」を見抜くことも大切です。

類題紹介

本問の楕円上の任意の点 X について，2 点 $\mathrm{F}_1\left(\dfrac{1}{\sqrt3},\ 0,\ 0\right)$，$\mathrm{F}_2\left(-\dfrac{1}{\sqrt3},\ 0,\ 0\right)$ からの距離の和 $\mathrm{XF}_1 + \mathrm{XF}_2$ が一定であることを，楕円の方程式を用いて示し，その値を求めよ。

（自作）

略解

$\mathrm{X}(x,\ y,\ 0)$ で $y^2 = 1 - \dfrac34x^2$ を代入すると

$$\mathrm{XF}_1^2 = \left(x - \frac{1}{\sqrt3}\right)^2 + 1 - \frac34x^2 = \frac{x^2}{4} - \frac{2x}{\sqrt3} + \frac43 = \left(\frac{2}{\sqrt3} - \frac{x}{2}\right)^2$$

$|x| \le \dfrac{2}{\sqrt3}$ より $\mathrm{XF}_1 = \dfrac{2}{\sqrt3} - \dfrac{x}{2}$。同様に $\mathrm{XF}_2 = \dfrac{2}{\sqrt3} + \dfrac{x}{2}$。和は $\dfrac{4}{\sqrt3}$（長軸の長さ）で一定。

本問の円柱（円 $C_1$，$C_2$ を底面とする円柱）の側面を平面 $z = k$ で切った切り口が，楕円全体（底面にかからない閉曲線）となるような実数 $k$ の範囲を求めよ。

（九大 2026　魔改造）

略解

円 $C_1$ は中心の $z$ 座標が $\sqrt6$、半径 $1$ で、軸と $z$ 軸のなす角が $30^\circ$ なので、$C_1$ 上の点の $z$ 座標は $\sqrt6 - \sin30^\circ$ から $\sqrt6 + \sin30^\circ$ まで、すなわち $\sqrt6 - \dfrac12 \le z \le \sqrt6 + \dfrac12$ の範囲にあります。平面 $z = k$ が $C_1$ と交わらず、その下側にあればよいので $k \le \sqrt6 - \dfrac12$。$C_2$ についても同様にして

$$-\sqrt6 + \frac12 \le k \le \sqrt6 - \frac12$$
