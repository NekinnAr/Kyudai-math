実数 $a$ と自然数 $n$ に対して，$x$ の方程式

$$a(x^2 + |x + 1| + n - 1) = \sqrt{n}\,(x + 1)$$

を考える。以下の問いに答えよ。

  1. (1)　この方程式が実数解を持つような $a$ の範囲を，$n$ を用いて表せ。
  2. (2)　この方程式が，すべての自然数 $n$ に対して実数解を持つような $a$ の範囲を求めよ。

（2012 九州大学 前期 理系 第3問）

解答例

$a$ を分離して「$y = f(x)$ と $y = a$ の共有点」の問題にします。$u = x + 1$ と置き換えると絶対値が $|u|$ になり、$u \ge 0$ と $u < 0$ の場合分けで、それぞれ相加・相乗平均が使える形になります。

解答例（タップで展開）

(1)

$x^2 \ge 0$，$|x + 1| \ge 0$ で、両方が同時に $0$ になることはないので $x^2 + |x + 1| + n - 1 > 0$。よって方程式は

$$a = f(x) = \frac{\sqrt n\,(x + 1)}{x^2 + |x + 1| + n - 1}$$

と同値で、求める範囲は $f(x)$ の値域です。$u = x + 1$ とおくと $x^2 = u^2 - 2u + 1$ より

$$f = \frac{\sqrt n\,u}{u^2 - 2u + |u| + n}$$

$u > 0$ のとき：$f = \dfrac{\sqrt n\,u}{u^2 - u + n} = \dfrac{\sqrt n}{u + \frac{n}{u} - 1}$。相加・相乗平均より $u + \dfrac nu \ge 2\sqrt n$（等号は $u = \sqrt n$）なので $0 < f \le \dfrac{\sqrt n}{2\sqrt n - 1}$。また $u \to +0$ で $f \to 0$。

$u = 0$ のとき：$f = 0$。

$u < 0$ のとき：$f = \dfrac{\sqrt n\,u}{u^2 - 3u + n} = \dfrac{\sqrt n}{u + \frac nu - 3}$。$u < 0$ では $u + \dfrac nu \le -2\sqrt n$（等号は $u = -\sqrt n$）なので分母 $\le -2\sqrt n - 3 < 0$，よって $-\dfrac{\sqrt n}{2\sqrt n + 3} \le f < 0$。

$f$ は連続なので、値域は最小値から最大値までのすべての値です。

$$-\frac{\sqrt n}{2\sqrt n + 3} \le a \le \frac{\sqrt n}{2\sqrt n - 1}$$

(2)

(1) の範囲を $L_n \le a \le U_n$ とおくと

$$U_n = \frac{1}{2 - \frac{1}{\sqrt n}},\qquad L_n = -\frac{1}{2 + \frac{3}{\sqrt n}}$$

$U_n$ は $n$ について単調減少で $U_n > \dfrac12$，$U_n \to \dfrac12$。よって「すべての $n$ で $a \le U_n$」$\iff a \le \dfrac12$。

$L_n$ も $n$ について単調減少（$2 + \frac{3}{\sqrt n}$ が減少するので $\frac{1}{2 + 3/\sqrt n}$ は増加）なので最大値は $L_1 = -\dfrac15$。よって「すべての $n$ で $a \ge L_n$」$\iff a \ge -\dfrac15$。

$$-\frac15 \le a \le \frac12$$

動く図解

$n$ を変えると $y = f(x)$ のグラフが変わります。$y = a$（緑）と共有点を持つかどうかで、実数解の有無が分かります。右側には $n = 1, 2, \ldots$ と増やしたときの範囲の共通部分を表示します。

問題の背景

文字定数は分離する

「方程式が実数解を持つ $a$ の範囲」は、$a = f(x)$ と変形できれば $f(x)$ の値域を求める問題になります。本問は分母が正であることを確認してから割る、というひと手間が必要です。

さらに、$\dfrac{u}{u^2 + bu + n}$ 型は分子・分母を $u$ で割ると $\dfrac{1}{u + \frac nu + b}$ となり、微分しなくても相加・相乗平均で最大・最小が出せます。$u = x + 1$ の置き換えで絶対値の中身が単純になるのも効いています。

(2) は「すべての $n$ について」なので範囲の共通部分。上端は $\frac12$ に近づくが届かない、下端は $n = 1$ のときが一番きつい、という非対称な結果になります。

chopin 先生は「絶対値の処理が煩雑な難問」「$f(x) = \sqrt n(x + 1)/(x^2 + |x + 1| + n - 1)$ とおいて、$y = f(x)$ と $y = a$ の交点の個数を考える方法です。視覚的にわかりやすく解くことができます」「(2) は、(1) で求めた $a$ の範囲について、$n$ を動かしたときの共通部分を調べればよい。その際、$a$ の最小値と最大値がどのように変化するかを調べておく必要があります」とコメントしています。

定数分離 → 値域。$\dfrac{u}{u^2 + bu + c}$ は $u$ で割って相加・相乗平均。「すべての $n$」は共通部分、「ある $n$」は和集合。

類題紹介

$x$ の方程式 $a(x^2 + 1) = x$ が実数解を持つような実数 $a$ の範囲を求めよ。

（自作）

略解

$a = \dfrac{x}{x^2 + 1}$ の値域を求める。$x > 0$ で $\dfrac{1}{x + 1/x} \le \dfrac12$（$x = 1$），$x < 0$ で $\ge -\dfrac12$（$x = -1$），$x = 0$ で $0$。連続なので $-\dfrac12 \le a \le \dfrac12$。

本問の方程式が，少なくとも 1 つの自然数 $n$ に対して実数解を持つような $a$ の範囲を求めよ。

（九大 2012　魔改造）

略解

今度は (1) の範囲の和集合。$U_n$ は減少なので最大は $U_1 = 1$。$L_n$ は減少して $-\frac12$ に近づくが、$L_n > -\frac12$ なので $-\frac12$ には届かない。

$$-\frac12 < a \le 1$$
