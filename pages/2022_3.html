自然数 $m,\ n$ が

$$n^4 = 1 + 210m^2\qquad\cdots\cdots ①$$

をみたすとき，以下の問いに答えよ。

  1. (1)　$\dfrac{n^2 + 1}{2}$，$\dfrac{n^2 - 1}{2}$ は互いに素な整数であることを示せ。
  2. (2)　$n^2 - 1$ は $168$ の倍数であることを示せ。
  3. (3)　① をみたす自然数の組 $(m,\ n)$ を 1 つ求めよ。

（2022 九州大学 前期 理系 第3問）

解答例

$n^4 - 1 = (n^2 + 1)(n^2 - 1) = 210m^2$ と因数分解。$210 = 2\cdot3\cdot5\cdot7$ の素因数が 2 つの因数にどう分配されるかを、互いに素であることと平方数の余りで決めていく。(3) は (2) で絞った形から「当たり」を探す。

解答例（タップで展開）

(1)

① より $n^4 = 1 + 210m^2$ は奇数なので $n$ は奇数。$n = 2k - 1$（$k$ は自然数）とおくと $n^2 = 4k^2 - 4k + 1$ で

$$\frac{n^2 + 1}{2} = 2k^2 - 2k + 1,\qquad \frac{n^2 - 1}{2} = 2k^2 - 2k$$

はともに整数で、差が $1$。公約数 $g$ は差 $1$ を割り切るので $g = 1$、互いに素である。

(2)

$X = \dfrac{n^2 + 1}{2}$，$Y = \dfrac{n^2 - 1}{2}$ とおくと、① より $4XY = 210m^2$、すなわち $2XY = 105m^2$。

  • 8 の倍数：$n^2 - 1 = (n - 1)(n + 1)$ は連続する 2 つの偶数の積なので、一方は 4 の倍数で、$8$ の倍数。
  • 3 の倍数：$n^2 \equiv 0,\ 1 \pmod 3$ より $n^2 + 1 \equiv 1,\ 2 \pmod 3$ なので $3 \nmid n^2 + 1$、よって $3 \nmid X$。$3 \mid 2XY$ より $3 \mid Y$。
  • 7 の倍数：$n^2 \equiv 0,\ 1,\ 2,\ 4 \pmod 7$ より $n^2 + 1 \equiv 1,\ 2,\ 3,\ 5 \pmod 7$ なので $7 \nmid X$。$7 \mid 2XY$ より $7 \mid Y$。

$3,\ 7$ は $Y$ を割り切るので $n^2 - 1 = 2Y$ も割り切る。$8,\ 3,\ 7$ は互いに素なので、$n^2 - 1$ は $8\cdot3\cdot7 = 168$ の倍数。

(3)

(2) より $n^2 - 1 = 168k$（$k$ は自然数）とおくと $n^2 + 1 = 168k + 2$ で、① は

$$168k(168k + 2) = 210m^2 \iff 8k(84k + 1) = 5m^2$$

$k$ と $84k + 1$ は互いに素。たとえば $8k = 5\times(\text{平方数})$、$84k + 1 = (\text{平方数})$ となる $k$ を探す。$k = 10$ とすると $8k = 80 = 5\cdot4^2$、$84k + 1 = 841 = 29^2$ となり成功。$5m^2 = 5\cdot4^2\cdot29^2$ より $m = 116$、$n^2 = 1681$ より $n = 41$。

$$(m,\ n) = (116,\ 41)$$

（検算：$41^4 = 2825761$，$1 + 210\cdot116^2 = 1 + 210\cdot13456 = 2825761$。）

動く図解

奇数 $n$ を動かして、$X = \frac{n^2+1}{2}$，$Y = \frac{n^2-1}{2}$ や $n^2 - 1$ が 168 の倍数か、$\frac{n^4 - 1}{210}$ が平方数かを確かめましょう。(2) の条件（168 の倍数）をみたす $n$ はたくさんありますが、① をみたすのは…？

問題の背景

ペル方程式

$N = n^2$ とおくと、① は $N^2 - 210m^2 = 1$ というペル方程式 $x^2 - Dy^2 = 1$ の形です。ペル方程式の解は、最小の解（基本解）$(x_1,\ y_1)$ から

$$x_k + y_k\sqrt D = (x_1 + y_1\sqrt D)^k$$

で全部得られることが知られています。$D = 210$ の基本解は $(29,\ 2)$（$29^2 - 210\cdot2^2 = 841 - 840 = 1$）で、$k = 2$ とすると

$$(29 + 2\sqrt{210})^2 = 1681 + 116\sqrt{210}$$

となり、$x_2 = 1681 = 41^2$ がちょうど平方数！ これが答え $(m,\ n) = (116,\ 41)$ の正体です。解答の $k = 10$ のときの「$841 = 29^2$」は、基本解の $29$ が顔を出していたわけです。

chopin 先生も「(2) の解法でかなり手間取った」「運よく露骨に見えている $k = 5$ でうまくいきます」と書いており（文字のおき方が違うため値は異なります）、試験場では「探す」発想が必要な問題でした。

「$A\cdot B = $ 定数 × 平方数」で $A,\ B$ が互いに素なら、素因数をどちらに振り分けるかを考える。振り分けを決めるのが「平方数の余り」です。

類題紹介

自然数 $a,\ b$ が $a^2 - Db^2 = 1$ をみたすとき（$D$ は自然数），$(2a^2 - 1)^2 - D(2ab)^2 = 1$ が成り立つことを示せ。

（自作）

略解
$$(2a^2 - 1)^2 - 4Da^2b^2 = 4a^4 - 4a^2 + 1 - 4a^2(a^2 - 1) = 1$$

（$Db^2 = a^2 - 1$ を代入。）$(a + b\sqrt D)^2 = (a^2 + Db^2) + 2ab\sqrt D = (2a^2 - 1) + 2ab\sqrt D$ に対応しています。$a = 29,\ b = 2,\ D = 210$ とすれば本問の答えが出ます。

$n^4 = 1 + 6m^2$ をみたす自然数の組 $(m,\ n)$ を 1 つ求めよ。

（九大 2022　魔改造）

略解

$x^2 - 6y^2 = 1$ の基本解は $(5,\ 2)$（$25 - 24 = 1$）。類題（自作）より $(2\cdot25 - 1,\ 2\cdot5\cdot2) = (49,\ 20)$ も解で、$49 = 7^2$ は平方数！ よって $n = 7,\ m = 20$。

検算：$7^4 = 2401 = 1 + 6\cdot400$。$(m,\ n) = (20,\ 7)$。
