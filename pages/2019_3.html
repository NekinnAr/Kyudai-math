1 個のサイコロを 3 回投げて出た目を順に $a,\ b,\ c$ とする。2 次方程式

$$ax^2 + bx + c = 0$$

の 2 つの解 $z_1,\ z_2$ を表す複素数平面上の点をそれぞれ $\mathrm{P_1}(z_1)$，$\mathrm{P_2}(z_2)$ とする。また，複素数平面上の原点を $\mathrm{O}$ とする。以下の問いに答えよ。

  1. (1)　$\mathrm{P_1}$ と $\mathrm{P_2}$ が一致する確率を求めよ。
  2. (2)　$\mathrm{P_1}$ と $\mathrm{P_2}$ がともに単位円の周上にある確率を求めよ。
  3. (3)　$\mathrm{P_1}$ と $\mathrm{O}$ を通る直線を $\ell_1$ とし，$\mathrm{P_2}$ と $\mathrm{O}$ を通る直線を $\ell_2$ とする。$\ell_1$ と $\ell_2$ のなす鋭角が $60^\circ$ である確率を求めよ。

（2019 九州大学 前期 理系 第3問）

解答例

係数が正なので、実数解はどちらも負。虚数解なら互いに共役で、実軸に関して対称。(2) は「実数解（$-1$ の重解）」と「虚数解で $|z_1|^2 = z_1z_2 = \frac ca = 1$」に分ける。(3) は直線が実軸と $30^\circ$ をなす場合と $60^\circ$ をなす場合の両方があることに注意。

解答例（タップで展開）

目の出方は $6^3 = 216$ 通りで同様に確からしい。判別式を $D = b^2 - 4ac$ とする。

(1)

$\mathrm{P_1} = \mathrm{P_2} \iff D = 0 \iff b^2 = 4ac$。$b$ は偶数で

  • $b = 2$：$ac = 1$ → $(a, c) = (1, 1)$
  • $b = 4$：$ac = 4$ → $(1, 4),\ (2, 2),\ (4, 1)$
  • $b = 6$：$ac = 9$ → $(3, 3)$

計 $5$ 通りで、確率は $\dfrac{5}{216}$。

(2)

$D \ge 0$ のとき：$z_1 + z_2 = -\frac ba \lt 0$，$z_1z_2 = \frac ca \gt 0$ より 2 解はともに負。単位円周上の負の実数は $-1$ だけなので $z_1 = z_2 = -1$、すなわち $a(x + 1)^2 = ax^2 + 2ax + a$。$(a, b, c) = (1, 2, 1),\ (2, 4, 2),\ (3, 6, 3)$ の $3$ 通り。

$D \lt 0$ のとき：$z_2 = \overline{z_1}$ なので $|z_1| = |z_2|$ で、$|z_1|^2 = z_1\overline{z_1} = z_1z_2 = \frac ca$。条件は $c = a$ かつ $b^2 \lt 4a^2$（$b \lt 2a$）。

  • $a = c = 1$：$b = 1$（1 通り）　$a = c = 2$：$b = 1,2,3$（3 通り）　$a = c = 3$：$b = 1 \sim 5$（5 通り）
  • $a = c = 4,\ 5,\ 6$：$b = 1 \sim 6$（各 6 通り）

計 $1 + 3 + 5 + 18 = 27$ 通り。合わせて $30$ 通りで、確率は $\dfrac{30}{216} = \dfrac{5}{36}$。

(3)

$D \ge 0$ なら 2 解は負の実数で $\ell_1 = \ell_2$（実軸）となり不適。よって $D \lt 0$ で、$z_1,\ z_2$ は共役、$\ell_1,\ \ell_2$ は実軸に関して対称。実部 $-\frac{b}{2a}$ は負。$\ell_1$ と実軸のなす鋭角を $\varphi$ とすると、$\ell_1,\ \ell_2$ のなす角は $2\varphi$ なので、なす鋭角が $60^\circ$ になるのは $\varphi = 30^\circ$ または $\varphi = 60^\circ$（$2\varphi = 120^\circ$）のとき。$r = |z_1| = \sqrt{\frac ca}$ とする。

  • $\varphi = 60^\circ$：$z_1 = r\left(-\frac12 \pm \frac{\sqrt3}{2}i\right)$。実部より $\frac{b}{2a} = \frac r2$、$r = \frac ba$。$r^2 = \frac ca$ より $b^2 = ac$（このとき $D = -3ac \lt 0$ は自動的に成立）。
    $(a, b, c) = (1,1,1),\ (1,2,4),\ (2,2,2),\ (4,2,1),\ (3,3,3),\ (4,4,4),\ (5,5,5),\ (6,6,6)$ の $8$ 通り。
  • $\varphi = 30^\circ$：$z_1 = r\left(-\frac{\sqrt3}{2} \pm \frac12 i\right)$。$\frac{b}{2a} = \frac{\sqrt3}{2}r$ より $r^2 = \frac{b^2}{3a^2} = \frac ca$、$b^2 = 3ac$（$D = -ac \lt 0$）。$b$ は $3$ の倍数で
    $b = 3$：$ac = 3$ → $(1, 3),\ (3, 1)$。$b = 6$：$ac = 12$ → $(2, 6),\ (3, 4),\ (4, 3),\ (6, 2)$。計 $6$ 通り。

合わせて $14$ 通りで、確率は $\dfrac{14}{216} = \dfrac{7}{108}$。

問題の背景

係数の符号から解の位置が分かる

係数がすべて正の 2 次方程式の解は、実数なら負、虚数なら実部が負（左半平面）です。この「位置の情報」を使うと、(2) で $+1$ を考える必要がなくなり、(3) でも偏角の候補が絞れます。

見落としがちなケース

chopin 先生は (3) について「直線と実軸が $\pm30^\circ$ で交わるケースは思いつきやすいですが、直線と虚軸が $\pm30^\circ$ で交わるケースもありうる、というのを意外と見落としがちなので要注意」と注意しています。「なす鋭角」なので、2 直線のなす角が $120^\circ$ の場合も含まれるのです。

実数係数の 2 次方程式が虚数解をもつとき：$z_2 = \overline{z_1}$，$|z_1|^2 = z_1z_2 = \dfrac ca$，$\mathrm{Re}\,z_1 = -\dfrac{b}{2a}$。偏角の条件は「実部と絶対値の比」に直して係数の関係式にする。

類題紹介

1 個のサイコロを 3 回投げて出た目を順に $a,\ b,\ c$ とする。2 次方程式 $ax^2 + bx + c = 0$ が実数解をもつ確率を求めよ。

（自作・頻出）

略解

$b^2 \ge 4ac$ となる $(a, c)$ の個数を $b$ ごとに数える：$b = 1$：0，$b = 2$：$ac \le 1$ で 1，$b = 3$：$ac \le 2$ で 3，$b = 4$：$ac \le 4$ で 8，$b = 5$：$ac \le 6$ で 14，$b = 6$：$ac \le 9$ で 17。計 $43$ 通りで、確率は $\dfrac{43}{216}$。

本問の設定で，3 点 $\mathrm{O}$，$\mathrm{P_1}$，$\mathrm{P_2}$ が正三角形の 3 頂点となる確率を求めよ。

（九大 2019　魔改造）

略解

$\mathrm{P_1} \neq \mathrm{P_2}$ で、しかも O を含む三角形なので虚数解。$z_1,\ z_2$ は共役なので $\mathrm{OP_1} = \mathrm{OP_2}$ で、正三角形 $\iff \angle\mathrm{P_1OP_2} = 60^\circ$。実部が負なので偏角は $\pm150^\circ$、つまり (3) の $\varphi = 30^\circ$ の場合で $b^2 = 3ac$。$6$ 通りで、確率は $\dfrac{6}{216} = \dfrac{1}{36}$。

（$\varphi = 60^\circ$ の場合は $\angle\mathrm{P_1OP_2} = 120^\circ$ の二等辺三角形になります。）
