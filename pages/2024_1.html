$a$ を実数とし，座標空間内の 3 点 $\mathrm{P}(-1,\ 1,\ -1)$，$\mathrm{Q}(1,\ 1,\ 1)$，$\mathrm{R}(a,\ a^2,\ a^3)$ を考える。以下の問いに答えよ。

  1. (1)　$a \neq -1$，$a \neq 1$ のとき，3 点 $\mathrm{P}$，$\mathrm{Q}$，$\mathrm{R}$ は一直線上にないことを示せ。
  2. (2)　$a$ が $-1 \lt a \lt 1$ の範囲を動くとき，三角形 $\mathrm{PQR}$ の面積の最大値を求めよ。

（2024 九州大学 前期 理系 第1問）

解答例

空間の三角形の面積は $\dfrac12\sqrt{|\vec u|^2|\vec v|^2 - (\vec u\cdot\vec v)^2}$ で計算できる。ここでは R から直線 PQ までの距離を求める方法で解く（どちらでも計算量は同程度）。ルートの中は $a$ の 6 次式だが、$a^2$ の 3 次式として扱える。

解答例（タップで展開）

(1)

$\overrightarrow{\mathrm{PQ}} = (2,\ 0,\ 2)$ より、直線 PQ 上の点は実数 $s$ を用いて $(s,\ 1,\ s)$ と表せる。R がこの直線上にあるとすると

$$a = s,\quad a^2 = 1,\quad a^3 = s$$

第 2 式より $a = \pm1$ となり、$a \neq \pm1$ に反する。よって P，Q，R は一直線上にない。

(2)

直線 PQ 上の点 $\mathrm{H}(s,\ 1,\ s)$ について

$$\mathrm{RH}^2 = (s - a)^2 + (1 - a^2)^2 + (s - a^3)^2 = 2\left(s - \frac{a + a^3}{2}\right)^2 + \frac{(a^3 - a)^2}{2} + (1 - a^2)^2$$

なので、R と直線 PQ の距離 $d$ は（$s = \frac{a+a^3}{2}$ のとき）

$$d^2 = \frac{a^2(1-a^2)^2}{2} + (1-a^2)^2 = \frac{(1-a^2)^2(a^2+2)}{2}$$

$\mathrm{PQ} = 2\sqrt2$ だから、三角形 PQR の面積を $S$ とすると

$$S = \frac12\cdot 2\sqrt2\cdot d = (1-a^2)\sqrt{a^2+2}\qquad(-1 \lt a \lt 1)$$

$b = a^2$ とおくと $0 \le b \lt 1$ で、$S^2 = (1-b)^2(b+2) = g(b)$ とおくと

$$g'(b) = -2(1-b)(b+2) + (1-b)^2 = -3(1-b)(b+1) \lt 0\quad(0 \le b \lt 1)$$

よって $g(b)$ は減少関数で、最大となるのは $b = 0$、すなわち $a = 0$ のとき。$g(0) = 2$ より

$$S\ \text{の最大値は}\ \sqrt2\qquad(a = 0\ \text{のとき})$$

外積を知っていれば：$\overrightarrow{\mathrm{PQ}}\times\overrightarrow{\mathrm{PR}} = 2(a^2-1)(-1,\ -a,\ 1)$ となり、$S = \frac12\cdot 2|1-a^2|\sqrt{a^2+2}$ が一瞬で出ます。答案では上のように高校範囲の方法で書くのが無難です。

動く図解

R は曲線 $(t,\ t^2,\ t^3)$ の上を動きます。実は P，Q もこの曲線上の点（$t = -1,\ 1$）です。左の図はドラッグで回転できます。

赤＝曲線 (t, t², t³)，青＝三角形 PQR，右＝面積 S(a) のグラフ

問題の背景

曲線 $(t,\ t^2,\ t^3)$：ねじれ 3 次曲線

点 $(t,\ t^2,\ t^3)$ が描く曲線はねじれ 3 次曲線（twisted cubic）と呼ばれます。P，Q，R はすべてこの曲線上の点なので、(1) は「この曲線上のどの 3 点も一直線上にない」ことの一部を示していることになります。

実はもっと強く、この曲線上のどの 4 点も同一平面上にないことが知られています。平面 $px + qy + rz = k$ と曲線の交点は、3 次方程式 $rt^3 + qt^2 + pt - k = 0$ の解に対応し、これは高々 3 個しかないからです（下の類題 1）。

2 次元の放物線 $(t,\ t^2)$ 上の 3 点は一直線上にない。3 次元のねじれ 3 次曲線 $(t,\ t^2,\ t^3)$ 上の 4 点は同一平面上にない。次数と次元がそろった美しい対応です。

(2) の置き換え

面積の 2 乗が $a^2$ だけの式になるのは、図形が $y$ 軸まわりの対称性（$a \to -a$ で R は $(x,\ z) \to (-x,\ -z)$ に移り、P と Q が入れ替わる）を持つからです。偶関数を見たら $a^2 = b$ とおく、は定石です。

類題紹介

曲線 $C:\ (t,\ t^2,\ t^3)$（$t$ は実数）上の相異なる 4 点は，同一平面上にないことを示せ。

（自作）

略解

4 点 $(t_i,\ t_i^2,\ t_i^3)$（$i = 1,2,3,4$、相異なる）が平面 $px + qy + rz = k$（$(p,q,r) \neq (0,0,0)$）上にあるとすると、$t_1,\ \dots,\ t_4$ は方程式 $rt^3 + qt^2 + pt - k = 0$ の相異なる 4 つの解。$r,\ q,\ p$ のいずれかは $0$ でないので、左辺は 1 次以上 3 次以下の多項式であり、相異なる解は高々 3 個。矛盾。

本問の P，Q と，曲線 $(t,\ t^2,\ t^3)$ 上の 2 点 $\mathrm{R}(a,\ a^2,\ a^3)$，$\mathrm{S}(b,\ b^2,\ b^3)$（$-1 \lt a \lt b \lt 1$）を頂点とする四面体 $\mathrm{PQRS}$ の体積の最大値を求めよ。

（九大 2024　魔改造）

略解

$\overrightarrow{\mathrm{PQ}},\ \overrightarrow{\mathrm{PR}},\ \overrightarrow{\mathrm{PS}}$ で張る四面体の体積を計算すると（底面 PQR の法線 $(-1,\ -a,\ 1)$ 方向への S の高さを使うなど）

$$V = \frac13(1-a^2)(1-b^2)(b-a)$$

（一般に、パラメータ $t_1, \dots, t_4$ の 4 点の四面体の体積は $\frac16\prod_{i\lt j}|t_i - t_j|$。）

$a = c - d,\ b = c + d$（$d \gt 0$）とおくと $(1-a^2)(1-b^2) = (1 - c^2 - d^2)^2 - 4c^2d^2$。$d$ を固定して $u = c^2$ の関数と見ると、$u$ で微分すると $-2(1 + 2d - d^2 - u)$。$|c| + d \lt 1$ より $u \lt (1-d)^2 = 1 - 2d + d^2 \le 1 + 2d - d^2$（$0 \lt d \lt 1$）なので、これは負。よって $c = 0$ で最大になり、

$$V \le \frac13(1-d^2)^2\cdot 2d$$

右辺は $d = \frac{1}{\sqrt5}$ で最大となる。最大値は

$$V = \frac{2}{3}\cdot\frac{1}{\sqrt5}\cdot\frac{16}{25} = \frac{32\sqrt5}{375}\qquad\left(a = -\frac{1}{\sqrt5},\ b = \frac{1}{\sqrt5}\right)$$
