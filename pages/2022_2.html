$n$ を $3$ 以上の自然数，$\alpha,\ \beta$ を相異なる実数とするとき，以下の問いに答えよ。

  1. (1)　次をみたす実数 $A,\ B,\ C$ と整式 $Q(x)$ が存在することを示せ。 $$x^n = (x - \alpha)(x - \beta)^2 Q(x) + A(x - \alpha)(x - \beta) + B(x - \alpha) + C$$
  2. (2)　(1) の $A,\ B,\ C$ を $n,\ \alpha,\ \beta$ で表せ。
  3. (3)　(2) の $A$ について，$n$ と $\alpha$ を固定して，$\beta$ を $\alpha$ に近づけたときの極限 $\displaystyle\lim_{\beta\to\alpha}A$ を求めよ。

（2022 九州大学 前期 理系 第2問）

解答例

(1) は「3 次式で割った余りは 2 次以下」。(2) は $x = \alpha,\ \beta$ を代入し、さらに $(x - \beta)^2$ の因数を活かすために微分してから $x = \beta$ を代入する。(3) は $\frac00$ 型の極限で、$\beta^k - \alpha^k$ を因数分解して処理する。

解答例（タップで展開）

(1)

$x^n$ を 3 次式 $(x - \alpha)(x - \beta)^2$ で割った商を $Q(x)$、余りを $R(x)$ とすると、$R(x)$ は 2 次以下の実数係数の整式。$R(x)$ の $x^2$ の係数を $A$ とすると $R(x) - A(x - \alpha)(x - \beta)$ は 1 次以下なので、$B(x - \alpha) + C$ の形に書ける（$B$ は $x$ の係数、$C$ は $x = \alpha$ での値）。よって題意の $A,\ B,\ C,\ Q(x)$ が存在する。

(2)

$x = \alpha$ を代入して $C = \alpha^n$。$x = \beta$ を代入して $\beta^n = B(\beta - \alpha) + \alpha^n$ より

$$B = \frac{\beta^n - \alpha^n}{\beta - \alpha}$$

両辺を $x$ で微分すると、$(x - \beta)^2$ を含む項の微分は $(x - \beta)$ を因数にもつので

$$nx^{n-1} = (x - \beta)\{\cdots\} + A(2x - \alpha - \beta) + B$$

$x = \beta$ を代入して $n\beta^{n-1} = A(\beta - \alpha) + B$。よって

$$A = \frac{n\beta^{n-1} - B}{\beta - \alpha} = \frac{n\beta^{n-1}(\beta - \alpha) - (\beta^n - \alpha^n)}{(\beta - \alpha)^2},\qquad B = \frac{\beta^n - \alpha^n}{\beta - \alpha},\qquad C = \alpha^n$$

(3)

$B = \displaystyle\sum_{k=0}^{n-1}\alpha^k\beta^{n-1-k}$ なので、$n\beta^{n-1} = \displaystyle\sum_{k=0}^{n-1}\beta^{n-1}$ と書くと

$$A = \frac{1}{\beta - \alpha}\sum_{k=0}^{n-1}\left(\beta^{n-1} - \alpha^k\beta^{n-1-k}\right) = \sum_{k=1}^{n-1}\beta^{n-1-k}\cdot\frac{\beta^k - \alpha^k}{\beta - \alpha}$$

ここで $\dfrac{\beta^k - \alpha^k}{\beta - \alpha} = \displaystyle\sum_{j=0}^{k-1}\alpha^j\beta^{k-1-j} \to k\alpha^{k-1}$（$\beta \to \alpha$）なので

$$\lim_{\beta\to\alpha}A = \sum_{k=1}^{n-1}\alpha^{n-1-k}\cdot k\alpha^{k-1} = \alpha^{n-2}\sum_{k=1}^{n-1}k = \frac{n(n-1)}{2}\alpha^{n-2}$$

動く図解

余り $R(x) = A(x - \alpha)(x - \beta) + B(x - \alpha) + C$ は、「$x = \alpha$ で $y = x^n$ を通り、$x = \beta$ で $y = x^n$ に接する」放物線です。$\beta$ を $\alpha$ に近づけると、$x = \alpha$ で $y = x^n$ に 2 次の精度で寄り添う放物線（テイラー展開の 2 次近似）に近づきます。

　

問題の背景

重解と微分

「$(x - \beta)^2$ で割り切れる ⇔ $x = \beta$ を代入しても、微分してから代入しても $0$」は、重解の判定法として重要です。これにより、余りの放物線は $x = \beta$ で元の曲線に接することになります。

テイラー展開とロピタルの定理

(3) の極限は $\frac{n(n-1)}{2}\alpha^{n-2} = \frac{f''(\alpha)}{2}$（$f(x) = x^n$）です。$\beta = \alpha$ のときの余り（$x^n$ を $(x - \alpha)^3$ で割った余り）は

$$f(\alpha) + f'(\alpha)(x - \alpha) + \frac{f''(\alpha)}{2}(x - \alpha)^2$$

で、これはテイラー展開の 2 次までの部分そのものです。chopin 先生は「大学入試でロピタルの定理が禁じ手なのが悔やまれる」と書いていますが、(3) は 2 回ロピタルを使えば一瞬の極限です。答案では上のように因数分解で処理しましょう。

$\dfrac{\beta^k - \alpha^k}{\beta - \alpha} = \beta^{k-1} + \beta^{k-2}\alpha + \cdots + \alpha^{k-1}$ は極限計算の万能道具。$\beta \to \alpha$ で $k\alpha^{k-1}$（$x^k$ の微分係数）になります。

類題紹介

$n$ を $3$ 以上の自然数とする。$x^n$ を $(x - 1)^3$ で割った余りを求めよ。

（自作）

略解

二項定理より $x^n = \{1 + (x - 1)\}^n = \displaystyle\sum_{k=0}^{n}{}_n\mathrm{C}_k(x - 1)^k$。$k \ge 3$ の項は $(x - 1)^3$ で割り切れるので、余りは

$$1 + n(x - 1) + \frac{n(n-1)}{2}(x - 1)^2$$

（本問 (3) で $\alpha = 1$ とした値 $\frac{n(n-1)}{2}$ が $(x - 1)^2$ の係数に現れています。）

$\alpha,\ \beta,\ \gamma$ を相異なる実数とする。$x^n$ を $(x - \alpha)(x - \beta)(x - \gamma)$ で割った余りを $A(x - \alpha)(x - \beta) + B(x - \alpha) + C$ と表すとき，$A$ を $n,\ \alpha,\ \beta,\ \gamma$ で表せ。

（九大 2022　魔改造）

略解

$x = \alpha,\ \beta,\ \gamma$ を順に代入すると $C = \alpha^n$，$B = \dfrac{\beta^n - \alpha^n}{\beta - \alpha}$，$\gamma^n = A(\gamma - \alpha)(\gamma - \beta) + B(\gamma - \alpha) + \alpha^n$。整理すると

$$A = \frac{\alpha^n}{(\alpha - \beta)(\alpha - \gamma)} + \frac{\beta^n}{(\beta - \alpha)(\beta - \gamma)} + \frac{\gamma^n}{(\gamma - \alpha)(\gamma - \beta)}$$

これはラグランジュ補間（3 点を通る放物線）の $x^2$ の係数で、$\alpha,\ \beta,\ \gamma$ について対称です。$\gamma \to \beta$ とすると本問の $A$ に、さらに $\beta \to \alpha$ とすると $\frac{n(n-1)}{2}\alpha^{n-2}$ になります。
