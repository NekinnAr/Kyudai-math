自然数 $n$ と実数 $a_0,\ a_1,\ a_2,\ \cdots\cdots,\ a_n\ (a_n \neq 0)$ に対して，2 つの整式

$$f(x) = \sum_{k=0}^{n}a_kx^k = a_nx^n + a_{n-1}x^{n-1} + \cdots\cdots + a_1x + a_0$$ $$f'(x) = \sum_{k=1}^{n}ka_kx^{k-1} = na_nx^{n-1} + (n-1)a_{n-1}x^{n-2} + \cdots\cdots + a_1$$

を考える。$\alpha,\ \beta$ を異なる複素数とする。複素数平面上の 2 点 $\alpha,\ \beta$ を結ぶ線分上にある点 $\gamma$ で，

$$\frac{f(\beta) - f(\alpha)}{\beta - \alpha} = f'(\gamma)$$

をみたすものが存在するとき，

　　$\alpha,\ \beta,\ f(x)$ は平均値の性質をもつ

ということにする。以下の問いに答えよ。ただし，$i$ は虚数単位とする。

  1. (1)　$n = 2$ のとき，どのような $\alpha,\ \beta,\ f(x)$ も平均値の性質をもつことを示せ。
  2. (2)　$\alpha = 1 - i$，$\beta = 1 + i$，$f(x) = x^3 + ax^2 + bx + c$ が平均値の性質をもつための，実数 $a,\ b,\ c$ に関する必要十分条件を求めよ。
  3. (3)　$\alpha = \dfrac{1 - i}{\sqrt2}$，$\beta = \dfrac{1 + i}{\sqrt2}$，$f(x) = x^7$ は，平均値の性質をもたないことを示せ。

（2021 九州大学 前期 理系 第4問）

解答例

定義は長いが、やることは「線分上の点 $\gamma$ を $1$ 変数で表し、方程式 $f'(\gamma) = (\text{平均変化率})$ が解をもつか調べる」だけ。(2)(3) は線分が虚軸に平行なので $\gamma = (\text{定数}) + si$ と表せる。

解答例（タップで展開）

(1)

$f(x) = a_2x^2 + a_1x + a_0\ (a_2 \neq 0)$ とすると

$$\frac{f(\beta) - f(\alpha)}{\beta - \alpha} = \frac{a_2(\beta^2 - \alpha^2) + a_1(\beta - \alpha)}{\beta - \alpha} = a_2(\alpha + \beta) + a_1$$

一方 $f'(\gamma) = 2a_2\gamma + a_1$ なので、$\gamma = \dfrac{\alpha + \beta}{2}$（線分 $\alpha\beta$ の中点）とすれば等式が成り立つ。よって、どのような $\alpha,\ \beta,\ f(x)$ も平均値の性質をもつ。

(2)

$\alpha + \beta = 2$，$\alpha\beta = 2$ より $\alpha^2 + \alpha\beta + \beta^2 = (\alpha + \beta)^2 - \alpha\beta = 2$。よって

$$\frac{f(\beta) - f(\alpha)}{\beta - \alpha} = (\alpha^2 + \alpha\beta + \beta^2) + a(\alpha + \beta) + b = 2 + 2a + b$$

線分上の点は $\gamma = 1 + si\ (-1 \le s \le 1)$ と表せる。$f'(\gamma) = 3\gamma^2 + 2a\gamma + b$ で、$\gamma^2 = 1 - s^2 + 2si$ より条件は

$$3(1 - s^2) + 2a + (6 + 2a)s\,i = 2 + 2a$$

$s,\ a$ は実数なので、実部と虚部を比べて

$$3s^2 = 1 \quad\text{かつ}\quad (6 + 2a)s = 0$$

$s^2 = \frac13$ より $s \neq 0$ なので $a = -3$。逆に $a = -3$ なら $s = \pm\frac{1}{\sqrt3}$（$-1 \le s \le 1$ をみたす）で成り立つ。求める条件は

$$a = -3\quad(b,\ c \text{ は任意の実数})$$

(3)

$\alpha = e^{-\frac{\pi}{4}i}$，$\beta = e^{\frac{\pi}{4}i}$ なので $\beta^7 = e^{\frac{7\pi}{4}i} = \alpha$，$\alpha^7 = e^{-\frac{7\pi}{4}i} = \beta$。よって

$$\frac{f(\beta) - f(\alpha)}{\beta - \alpha} = \frac{\alpha - \beta}{\beta - \alpha} = -1$$

条件は $7\gamma^6 = -1$。線分上の点は $\gamma = \dfrac{1}{\sqrt2} + si\ \left(|s| \le \dfrac{1}{\sqrt2}\right)$ で、これは $\gamma = r(\cos\varphi + i\sin\varphi)$，$-\dfrac{\pi}{4} \le \varphi \le \dfrac{\pi}{4}$，$r\cos\varphi = \dfrac{1}{\sqrt2}$ と表せる。

$\gamma^6 = r^6(\cos 6\varphi + i\sin 6\varphi)$ が負の実数になるには $6\varphi = \pi + 2k\pi$。$-\dfrac{3\pi}{2} \le 6\varphi \le \dfrac{3\pi}{2}$ より $6\varphi = \pm\pi$、つまり $\varphi = \pm\dfrac{\pi}{6}$。このとき

$$r = \frac{1}{\sqrt2\cos\frac{\pi}{6}} = \sqrt{\frac23},\qquad |\gamma|^6 = \left(\frac23\right)^3 = \frac{8}{27}$$

一方 $7\gamma^6 = -1$ には $|\gamma|^6 = \dfrac17$ が必要で、$\dfrac{8}{27} \neq \dfrac17$（$56 \neq 27$）。よって条件をみたす $\gamma$ は存在せず、平均値の性質をもたない。

動く図解

左は線分 $\alpha\beta$ と点 $\gamma$、右は $\gamma$ が線分上を動くときの $f'(\gamma)$ の軌跡（青）と平均変化率 $M = \dfrac{f(\beta) - f(\alpha)}{\beta - \alpha}$（赤の ×）です。青い曲線が × を通れば平均値の性質をもちます。

問題の背景

平均値の定理は複素数では成り立たない

実数の関数については、平均値の定理「$\dfrac{f(b) - f(a)}{b - a} = f'(c)$ となる $c$ が $a$ と $b$ の間にある」が成り立ちます。本問は、これを複素数に拡張しようとすると一般には成り立たないこと（(3)）、でも 2 次式なら成り立つこと（(1)）を体験させる問題です。

大学の複素解析では、代わりに次のような結果が知られています。

  • Grace–Heawood の定理：$n$ 次多項式 $f$ が $f(z_1) = f(z_2)$ をみたすなら、$f'$ は $z_1,\ z_2$ の中点を中心とする半径 $\dfrac{|z_1 - z_2|}{2}\cot\dfrac{\pi}{n}$ の円板内に零点をもつ。

$g(z) = f(z) - Mz$（$M$ は平均変化率）に適用すると $g(\alpha) = g(\beta)$ なので、$f'(\gamma) = M$ をみたす $\gamma$ は「線分上」とは限らないが「線分 $\alpha\beta$ の中点を中心とするある円板の中」には必ずある、ということになります。$n = 2$ なら $\cot\frac{\pi}{2} = 0$ で中点そのもの、という (1) とも合っています。

見た目ほど難しくない

chopin 先生は「『平均値の性質』という造語が出てきて身構えるが、見た目ほどは難しくない」と評しています。長い定義文に圧倒されず、線分上の点を実数パラメータ 1 つで表すという基本に戻れるかがポイントです。

線分 $\alpha\beta$ 上の点は $\gamma = (1 - t)\alpha + t\beta\ (0 \le t \le 1)$。本問のように線分が軸に平行なら $\gamma = (\text{定数}) + si$ でさらに簡単になる。複素数の等式は「実部・虚部」または「絶対値・偏角」に分けて比べる。

類題紹介

$\alpha = 1$，$\beta = i$，$f(x) = x^3$ は平均値の性質をもたないことを示せ。

（自作）

略解

平均変化率は $\alpha^2 + \alpha\beta + \beta^2 = 1 + i - 1 = i$。$3\gamma^2 = i$ より $\gamma^2 = \dfrac{i}{3}$、$\gamma = \pm\dfrac{1 + i}{\sqrt6}$。線分 $\alpha\beta$ 上の点は「実部 + 虚部 $= 1$，ともに $0$ 以上」をみたすが、$\pm\dfrac{1 + i}{\sqrt6}$ の実部 + 虚部は $\pm\dfrac{2}{\sqrt6} \neq 1$。よって平均値の性質をもたない。

$\alpha = 1 - i$，$\beta = 1 + i$，$f(x) = x^4 + ax^3$（$a$ は実数）が平均値の性質をもつような $a$ をすべて求めよ。
