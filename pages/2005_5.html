実数 $t$ が $t \ge 0$ の範囲を動くとき，$xy$ 平面上で点 $P(t^2,\ e^{-t})$ が描く曲線を $C$ とする。$a$ を正の実数とし，曲線 $C$ と $x$ 軸，$y$ 軸，および直線 $x = a^2$ で囲まれる部分の面積を $S(a)$ とする。このとき次の問いに答えよ。

  1. (1)　面積 $S(a)$ を求めよ。
  2. (2)　$a > 0$ の範囲で関数 $S(a)$ の増減，凹凸を調べ，そのグラフの概形を描け。ただし，$\displaystyle\lim_{a\to\infty}ae^{-a} = 0$ であることを用いてよい。
  3. (3)　$S(a) = 1.35$ となる $a$ が $2 < a < 3$ の範囲に存在することを示せ。ただし，必要なら $2.5 < e < 3$ であることを用いてよい。

（2005 九州大学 前期 理系 第5問）

解答例

媒介変数表示の面積は置換積分 $\int y\,dx = \int y\frac{dx}{dt}dt$。$S(a) = 2\int_0^a te^{-t}dt$ となり部分積分で終わり。(3) は中間値の定理で、$S(2)$，$S(3)$ と $1.35$ の大小を $2.5 < e < 3$ だけで判定します。

解答例（タップで展開）

(1)

$x = t^2$ は $t \ge 0$ で増加し、$x: 0 \to a^2$ に $t: 0 \to a$ が対応。$y = e^{-t} > 0$，$dx = 2t\,dt$ より

$$S(a) = \int_0^{a^2}y\,dx = \int_0^a e^{-t}\cdot2t\,dt = 2\Big[-(t + 1)e^{-t}\Big]_0^a = 2 - 2(a + 1)e^{-a}$$

(2)

$$S'(a) = 2ae^{-a} > 0,\qquad S''(a) = 2(1 - a)e^{-a}$$

$S(a)$ は単調増加。$0 < a < 1$ で下に凸，$a > 1$ で上に凸，変曲点は $\left(1,\ 2 - \frac4e\right)$。また $\lim_{a\to+0}S(a) = 0$，$\lim_{a\to\infty}S(a) = 2 - 2\lim(ae^{-a} + e^{-a}) = 2$ で、直線 $S = 2$ が漸近線（下の図解参照）。

(3)

$S(2) = 2 - \dfrac6{e^2}$，$S(3) = 2 - \dfrac8{e^3}$。

  • $e < 3$ より $e^2 < 9$，$\dfrac6{e^2} > \dfrac69 = \dfrac23 > 0.65$。よって $S(2) < 2 - 0.65 = 1.35$。
  • $e > 2.5$ より $e^3 > 15.625 > 8 \div 0.65\ (\approx 12.3)$，すなわち $\dfrac8{e^3} < 0.65$。よって $S(3) > 1.35$。

$S(a)$ は連続なので、中間値の定理より $S(a) = 1.35$ となる $a$ が $2 < a < 3$ に存在する（(2) より単調なのでただ 1 つ）。

動く図解

左が曲線 $C$ と面積 $S(a)$（$x$ 軸方向に $a^2$ まで），右が $S(a)$ のグラフです。$S = 1.35$ の線（オレンジ）と交わる $a$ は約 $2.33$。

問題の背景

$C$ の正体は $y = e^{-\sqrt x}$

$t = \sqrt x$ と消去すると $C$ は $y = e^{-\sqrt x}$。$\int e^{-\sqrt x}dx$ を直接計算するより、媒介変数のまま置換積分する方が楽です。$S(a) \to 2$ は $\int_0^\infty e^{-\sqrt x}dx = 2\int_0^\infty te^{-t}dt = 2\cdot1! = 2$（ガンマ関数 $\Gamma(2) = 1$）に対応します。(3) は電卓なしで $e$ の評価だけを使う、九大らしい「数値評価」の小問です。

chopin 先生は「(1), (2) ともに教科書レベルの処理です」「(3) $S(a)$ は単調増加なので、$S(2) < 1.35 < S(3)$ を証明します。幸い、与えられているネイピア数の評価式が $2.5 < e < 3$ と手計算しやすい値になっているので、電卓なしで何とかなります」とコメントしています。

媒介変数の面積は $\int y\frac{dx}{dt}dt$。「解の存在」は中間値の定理、端点の値は与えられた評価で。
