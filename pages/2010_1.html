三角形 $ABC$ の 3 辺の長さを $a = BC$，$b = CA$，$c = AB$ とする。実数 $t \ge 0$ を与えたとき，$A$ を始点とし $B$ を通る半直線上に $AP = tc$ となるように点 $P$ をとる。次の問いに答えよ。

  1. (1)　$CP^2$ を $a,\ b,\ c,\ t$ を用いて表せ。
  2. (2)　点 $P$ が $CP = a$ を満たすとき，$t$ を求めよ。
  3. (3)　(2) の条件を満たす点 $P$ が辺 $AB$ 上にちょうど 2 つあるとき，$\angle A$ と $\angle B$ に関する条件を求めよ。

（2010 九州大学 前期 理系 第1問）

解答例

$\triangle APC$ で余弦定理、$\cos A$ は $\triangle ABC$ の余弦定理で $a,\ b,\ c$ に直します。(2) の 2 次方程式は $P = B$（$t = 1$）が明らかに解なので因数分解できます。

解答例（タップで展開）

(1)

$\triangle APC$ で余弦定理（$t = 0$ のときも成立）：$CP^2 = b^2 + t^2c^2 - 2btc\cos A$。$\cos A = \dfrac{b^2 + c^2 - a^2}{2bc}$ を代入して

$$CP^2 = c^2t^2 - (b^2 + c^2 - a^2)t + b^2$$

(2)

$CP^2 = a^2$ より $c^2t^2 - (b^2 + c^2 - a^2)t + b^2 - a^2 = 0$。$t = 1$ が解なので

$$(t - 1)\{c^2t - (b^2 - a^2)\} = 0 \quad\therefore\ t = 1,\ \frac{b^2 - a^2}{c^2}$$

$t \ge 0$ なので

  • $b < a$ のとき：$t = 1$
  • $b \ge a$ のとき：$t = 1,\ \dfrac{b^2 - a^2}{c^2}$

(3)

$P$ が辺 $AB$ 上 $\iff 0 \le t \le 1$。$t = 1$（$P = B$）は常に条件をみたすので、もう 1 つの解 $t = \dfrac{b^2 - a^2}{c^2}$ が $0 \le t < 1$ をみたせばよい：

$$0 \le b^2 - a^2 < c^2 \iff a \le b \ \text{かつ}\ b^2 < c^2 + a^2$$

三角形では大きい辺に大きい角が対するので $a \le b \iff \angle A \le \angle B$。また余弦定理より $b^2 < c^2 + a^2 \iff \cos B > 0 \iff \angle B < 90^\circ$。

$$\angle A \le \angle B < 90^\circ$$

動く図解

$AB = 1$ に固定し、$\angle A,\ \angle B$ を動かします。$C$ を中心とする半径 $a = BC$ の円（青）と半直線 $AB$ の交点が $CP = a$ の点で、1 つは必ず $B$。もう 1 つ（赤）が辺 $AB$ 上に来るのは $\angle A \le \angle B < 90^\circ$ のときです。

問題の背景

二等辺三角形が隠れている

$CP = CB = a$ となる $P\ (\ne B)$ は、$C$ から直線 $AB$ に下ろした垂線の足 $H$ に関して $B$ と対称な点です（$\triangle CPB$ が二等辺三角形）。だから $P$ が辺 $AB$ 上にあるには、$H$ が辺 $AB$ 上（$\angle B < 90^\circ$）で、しかも $P$ が $A$ を越えない（$HB \le HA$，すなわち $\angle A \le \angle B$）ことが必要十分です。計算の結果と図形的な意味がぴったり一致します。

chopin 先生は「(1) は、余弦定理を 2 回使えばよいでしょう」「(2) $b$ と $a$ の大小関係によって場合分けが発生します」「(3) (2) で求めた $t$ が $0 \le t < 1$ となる条件を求めればよいです。すると、辺の大小関係と、三平方の定理もどきの不等式が出てくるので、角度の大小関係に直せます」とコメントしています。

辺の大小 ⇔ 対角の大小。$b^2 < c^2 + a^2 \iff \angle B$ が鋭角。明らかな解（ここでは $P = B$）があれば因数分解。

類題紹介

$a = 4,\ b = 5,\ c = 6$ の三角形 $ABC$ において，辺 $AB$ 上の点 $P\ (\ne B)$ で $CP = 4$ となるものの $AP$ の長さを求めよ。

（自作）

略解

本問 (2) より $t = \dfrac{b^2 - a^2}{c^2} = \dfrac{25 - 16}{36} = \dfrac14$，$AP = tc = \dfrac32$。（$a \le b$，$b^2 = 25 < 52 = a^2 + c^2$ なので確かに辺上。）

本問の (2) の条件を満たす点 $P$ が，半直線 $AB$ 上（$t \ge 0$）にちょうど 2 つあるための $\angle A,\ \angle B$ の条件を求めよ。また，そのうち $B$ でない方の点が辺 $AB$ の $B$ 側の延長上にあるのはどのようなときか。

（九大 2010　魔改造）

略解

$t_2 = \dfrac{b^2 - a^2}{c^2} \ge 0$ かつ $t_2 \ne 1$：$a \le b$ かつ $b^2 \ne a^2 + c^2$，すなわち $\angle A \le \angle B$ かつ $\angle B \ne 90^\circ$。

$t_2 > 1 \iff b^2 > a^2 + c^2 \iff \angle B > 90^\circ$（このとき自動的に $\angle A < \angle B$）。垂線の足 $H$ が $B$ の外側に出るので、$B$ の対称点も外側に出ます。
