以下の問いに答えよ。

  1. (1)　自然数 $n,\ k$ が $2 \le k \le n - 2$ をみたすとき，${}_n\mathrm{C}_k \gt n$ であることを示せ。
  2. (2)　$p$ を素数とする。$k \le n$ をみたす自然数の組 $(n,\ k)$ で ${}_n\mathrm{C}_k = p$ となるものをすべて求めよ。

（2021 九州大学 前期 理系 第5問）

解答例

(1) は二項係数が「真ん中に向かって増える」ことを使う。(2) は $k$ を $1,\ n - 1,\ n$ と $2 \le k \le n - 2$ に分け、後者は (1) と「素数 $p \gt n$ は $n!$ を割り切らない」ことで矛盾を導く。

解答例（タップで展開）

(1)

$2 \le k \le n - 2$ より $n \ge 4$。$0 \le j \le n - 1$ に対して

$$\frac{{}_n\mathrm{C}_{j+1}}{{}_n\mathrm{C}_j} = \frac{n - j}{j + 1}$$

これは $j \lt \frac{n-1}{2}$ のとき $1$ より大きく、$j \gt \frac{n-1}{2}$ のとき $1$ より小さい。よって ${}_n\mathrm{C}_j$ は $j \le \frac{n}{2}$ の範囲で増加（広義）、$j \ge \frac{n}{2}$ の範囲で減少（広義）する。したがって $2 \le k \le n - 2$ のとき

$${}_n\mathrm{C}_k \ge {}_n\mathrm{C}_2 = {}_n\mathrm{C}_{n-2} = \frac{n(n-1)}{2}$$

$n \ge 4$ より $\dfrac{n(n-1)}{2} - n = \dfrac{n(n-3)}{2} \gt 0$。よって ${}_n\mathrm{C}_k \gt n$。

(2)

  • $k = n$ のとき：${}_n\mathrm{C}_n = 1 \neq p$。不適。
  • $k = 1$ または $k = n - 1$ のとき：${}_n\mathrm{C}_k = n$ なので $n = p$。$(n,\ k) = (p,\ 1),\ (p,\ p - 1)$。
  • $2 \le k \le n - 2$ のとき：${}_n\mathrm{C}_k = p$ と仮定すると、(1) より $p \gt n$。一方 $$n! = p \cdot k!\,(n - k)!$$ の右辺は $p$ で割り切れるので、左辺 $n! = 1 \cdot 2 \cdots n$ も $p$ で割り切れる。$p$ は素数なので $1,\ 2,\ \cdots,\ n$ のどれかが $p$ の倍数となり $p \le n$。これは $p \gt n$ に矛盾。

以上より（$k \le n$ と $k \ge 1$ に注意して）

$$(n,\ k) = (p,\ 1),\ (p,\ p - 1)$$

（$p = 2$ のときは 2 つが一致して $(2,\ 1)$ のみ。）

動く図解

パスカルの三角形で、値が $m$ に等しい場所を赤で示します。$m$ が素数なら、赤は左右の端の隣（$k = 1,\ n - 1$）にしか現れません。合成数（$6,\ 10,\ 15,\ 120$ など）と比べてみましょう。「$m$ で割り切れる数を塗る」にすると、$m$ が素数のとき $p$ 行目が端以外すべて塗られます（類題 1）。

問題の背景

素数と二項係数

$p$ が素数のとき、$1 \le k \le p - 1$ に対して ${}_p\mathrm{C}_k$ は $p$ の倍数です（類題 1）。これはフェルマーの小定理 $a^p \equiv a \pmod p$ の二項定理による証明の鍵になる性質で、入試頻出です。本問 (2) の「$p \le n$ でないと $n!$ は $p$ で割り切れない」という議論も、同じ「素数の性質」の裏返しです。

パスカルの三角形にある数は何回現れるか

本問は「素数はパスカルの三角形の端以外に 2 回しか現れない」と言っています。一般に 2 以上の数 $m$ が何回現れるかはシングマスター予想という未解決問題に関係していて、例えば $3003$ は 8 回現れます（${}_{3003}\mathrm{C}_1,\ {}_{78}\mathrm{C}_2,\ {}_{15}\mathrm{C}_5,\ {}_{14}\mathrm{C}_6$ とその対称）。上の図解で $m = 3003$ を入れてみてください。

全体の講評

chopin 先生の評価は「1 < 2 < 5 < 3 < 4」の順で、本問は易しめ。「バラエティに富んでいるが、全体としてそこまで難しくない」セットです。(1) の結果を (2) でどう使うかが見えれば完答できます。

「素数 $p$ が積 $ab$ を割り切るなら、$a$ か $b$ を割り切る」。これを $n! = 1 \cdot 2 \cdots n$ に使うと「$p \mid n! \iff p \le n$」。整数問題の基本道具です。

類題紹介

$p$ を素数とする。$1 \le k \le p - 1$ のとき，${}_p\mathrm{C}_k$ は $p$ の倍数であることを示せ。

（自作・頻出）

略解

$k \cdot {}_p\mathrm{C}_k = p \cdot {}_{p-1}\mathrm{C}_{k-1}$ より、右辺は $p$ の倍数なので $p \mid k \cdot {}_p\mathrm{C}_k$。$1 \le k \le p - 1$ より $k$ は $p$ と互いに素なので $p \mid {}_p\mathrm{C}_k$。

$p$ を素数とする。$k \le n$ をみたす自然数の組 $(n,\ k)$ で ${}_n\mathrm{C}_k = 2p$ となるものをすべて求めよ。

（九大 2021　魔改造）

略解

$k = n$ は不適、$k = 1,\ n - 1$ なら $n = 2p$。以下 $2 \le k \le n - 2$（$n \ge 4$）とする。(1) より $2p \ge {}_n\mathrm{C}_2 = \dfrac{n(n-1)}{2}$。

  • $p = 2$ のとき：${}_n\mathrm{C}_k = 4$ だが ${}_n\mathrm{C}_2 \ge 6$ で不適。
  • $p$ が奇素数のとき：$n! = 2p \cdot k!\,(n - k)!$ は $p$ の倍数なので $p \le n$。すると $\dfrac{n(n-1)}{2} \le 2p \le 2n$ より $n \le 5$。$n = 4,\ 5$ を調べると ${}_4\mathrm{C}_2 = 6 = 2 \cdot 3$，${}_5\mathrm{C}_2 = {}_5\mathrm{C}_3 = 10 = 2 \cdot 5$。
$$(n,\ k) = (2p,\ 1),\ (2p,\ 2p - 1),\ \text{および } p = 3 \text{ のとき } (4,\ 2),\ p = 5 \text{ のとき } (5,\ 2),\ (5,\ 3)$$
