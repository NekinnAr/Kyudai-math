空間内の 4 点 $O(0,\ 0,\ 0)$，$A(0,\ 2,\ 3)$，$B(1,\ 0,\ 3)$，$C(1,\ 2,\ 0)$ を考える。このとき，以下の問いに答えよ。

  1. (1)　4 点 $O,\ A,\ B,\ C$ を通る球面の中心 $D$ の座標を求めよ。
  2. (2)　3 点 $A,\ B,\ C$ を通る平面に点 $D$ から垂線を引き，交点を $F$ とする。線分 $DF$ の長さを求めよ。
  3. (3)　四面体 $ABCD$ の体積を求めよ。

（2011 九州大学 前期 理系 第4問）

解答例

原点を通る球面は $x^2 + y^2 + z^2 + px + qy + rz = 0$ とおけます。平面 $ABC$ の方程式を求めれば、(2) は点と平面の距離の公式、(3) は「底面 $\triangle ABC$ × 高さ $DF$」です。

解答例（タップで展開）

(1)

球面を $x^2 + y^2 + z^2 + px + qy + rz = 0$（$O$ を通る）とおく。$A,\ B,\ C$ を代入して

$$13 + 2q + 3r = 0,\qquad 10 + p + 3r = 0,\qquad 5 + p + 2q = 0$$

第 2 式 − 第 3 式より $5 + 3r - 2q = 0$。第 1 式と足して $18 + 6r = 0$，$r = -3$，$q = -2$，$p = -1$。

$$x^2 + y^2 + z^2 - x - 2y - 3z = 0 \iff \left(x - \tfrac12\right)^2 + (y - 1)^2 + \left(z - \tfrac32\right)^2 = \frac{14}{4}$$ $$D\left(\frac12,\ 1,\ \frac32\right)\qquad（\text{半径 } \tfrac{\sqrt{14}}{2}）$$

(2)

$\overrightarrow{AB} = (1,\ -2,\ 0)$，$\overrightarrow{AC} = (1,\ 0,\ -3)$ の両方に垂直なベクトルとして $\vec n = (6,\ 3,\ 2)$（$6 - 6 + 0 = 0$，$6 + 0 - 6 = 0$ で確認）。平面 $ABC$ は $A$ を通るので

$$6x + 3y + 2z = 12$$ $$DF = \frac{|6\cdot\frac12 + 3\cdot1 + 2\cdot\frac32 - 12|}{\sqrt{36 + 9 + 4}} = \frac{|9 - 12|}{7} = \frac37$$

(3)

$|\overrightarrow{AB}|^2 = 5$，$|\overrightarrow{AC}|^2 = 10$，$\overrightarrow{AB}\cdot\overrightarrow{AC} = 1$ より

$$\triangle ABC = \frac12\sqrt{5\cdot10 - 1^2} = \frac72$$ $$V = \frac13\cdot\frac72\cdot\frac37 = \frac12$$

動く図解

ドラッグで回転できます。四面体 $OABC$（灰），外接球の中心 $D$，平面 $ABC$ への垂線の足 $F$（赤）。$F$ は $\triangle ABC$ の外心になっています。

問題の背景

外接球の中心から面への垂線の足は外心

$D$ は $A,\ B,\ C$ から等距離なので、$DF \perp$ 平面 $ABC$ のとき三平方の定理から $FA = FB = FC$。つまり $F$ は $\triangle ABC$ の外心で、$\triangle ABC$ の外接円の半径を $\rho$ とすると $\rho^2 + DF^2 = (\text{球の半径})^2$ が成り立ちます。本問では $\rho^2 = \frac{14}{4} - \frac{9}{49} = \frac{325}{98}$。

また、四面体の体積は 3 つの辺ベクトルの成分から $\frac16|\det|$ で一気に計算することもできます（検算用に便利）。$\overrightarrow{DA},\ \overrightarrow{DB},\ \overrightarrow{DC}$ でやると確かに $\frac12$ になります。

chopin 先生は「(1) 球面の式を立てて、4 つの式からなる連立方程式を解くことになります。時間はかかりますが、ミスなく解きたいところです」「(2) A, B, C を通る平面の式を出すのが最も確実な方法でしょう」「(3) (2) で高さが求まったので、あとは底面 △ABC の面積が分かってしまえばお終いです」とコメントしています。

原点を通る球面は定数項なしでおく。点と平面の距離 $\dfrac{|ax_0 + by_0 + cz_0 - d|}{\sqrt{a^2 + b^2 + c^2}}$。三角形の面積は $\frac12\sqrt{|\vec a|^2|\vec b|^2 - (\vec a\cdot\vec b)^2}$。

類題紹介

本問の 4 点について，四面体 $OABC$ の体積と，点 $O$ と平面 $ABC$ の距離を求めよ。

（自作）

略解

$O$ と平面 $6x + 3y + 2z = 12$ の距離は $\dfrac{12}{7}$。体積は $\dfrac13\cdot\dfrac72\cdot\dfrac{12}{7} = 2$。（行列式でも $\frac16\left|\det\begin{pmatrix} 0 & 2 & 3 \\ 1 & 0 & 3 \\ 1 & 2 & 0 \end{pmatrix}\right| = \frac{12}{6} = 2$。）

本問の球面上を点 $P$ が動くとき，四面体 $ABCP$ の体積の最大値を求めよ。

（九大 2011　魔改造）

略解

底面 $\triangle ABC = \frac72$ は一定なので、$P$ と平面 $ABC$ の距離を最大にすればよい。$D$ は平面から $\frac37$ の距離にあり、球の半径は $\frac{\sqrt{14}}{2}$ なので、平面から最も遠い球面上の点までの距離は $\frac37 + \frac{\sqrt{14}}{2}$（直線 $FD$ を $D$ の先へ延ばした点）。

$$V_{\max} = \frac13\cdot\frac72\left(\frac37 + \frac{\sqrt{14}}{2}\right) = \frac12 + \frac{7\sqrt{14}}{12}$$
