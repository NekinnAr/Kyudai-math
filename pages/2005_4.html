実数 $x$ に対して，$[x]$ は $x$ を超えない最大の整数を表す。例えば，$\left[\dfrac32\right] = 1$，$[2] = 2$ である。このとき，$0 < \theta < \pi$ として次の問いに答えよ。ただし，必要なら $\sin\alpha = \dfrac{1}{2\sqrt2}$ となる角 $\alpha\ \left(0 < \alpha < \dfrac\pi2\right)$ を用いてよい。

  1. (1)　不等式 $\log_2\left[\dfrac52 + \cos\theta\right] \le 1$ を満たす $\theta$ の範囲を求めよ。
  2. (2)　不等式 $\left[\dfrac32 + \log_2\sin\theta\right] \ge 1$ を満たす $\theta$ の範囲を求めよ。
  3. (3)　不等式 $\log_2\left[\dfrac52 + \cos\theta\right] \le \left[\dfrac32 + \log_2\sin\theta\right]$ を満たす $\theta$ の範囲を求めよ。

（2005 九州大学 前期 理系 第4問）

解答例

ガウス記号の中身の範囲を先に調べると、とりうる整数値が数個に絞れます。$\left[\frac52 + \cos\theta\right] \in \{1, 2, 3\}$，$\left[\frac32 + \log_2\sin\theta\right] \le 1$。あとは値ごとの場合分けです。

解答例（タップで展開）

(1)

$-1 < \cos\theta < 1$ より $\frac32 < \frac52 + \cos\theta < \frac72$ なので、$N = \left[\frac52 + \cos\theta\right]$ は $1,\ 2,\ 3$ のいずれか。$\log_2N \le 1 \iff N \le 2 \iff \frac52 + \cos\theta < 3 \iff \cos\theta < \frac12$。

$$\frac\pi3 < \theta < \pi$$

(2)

$[X] \ge 1 \iff X \ge 1$ なので $\frac32 + \log_2\sin\theta \ge 1$，$\log_2\sin\theta \ge -\frac12$，$\sin\theta \ge \frac1{\sqrt2}$。

$$\frac\pi4 \le \theta \le \frac{3\pi}4$$

(3)

左辺 $L = \log_2N$ は

  • $0 < \theta \le \frac\pi3$（$\cos\theta \ge \frac12$）：$N = 3$，$L = \log_23 > 1$
  • $\frac\pi3 < \theta \le \frac{2\pi}3$（$-\frac12 \le \cos\theta < \frac12$）：$N = 2$，$L = 1$
  • $\frac{2\pi}3 < \theta < \pi$（$\cos\theta < -\frac12$）：$N = 1$，$L = 0$

右辺 $R = \left[\frac32 + \log_2\sin\theta\right]$ は $\sin\theta \le 1$ より $R \le 1$。また

  • $R = 1 \iff \sin\theta \ge \frac1{\sqrt2}$（(2)）
  • $R \ge 0 \iff \frac32 + \log_2\sin\theta \ge 0 \iff \sin\theta \ge 2^{-\frac32} = \frac1{2\sqrt2} \iff \alpha \le \theta \le \pi - \alpha$

場合ごとに：

  • $0 < \theta \le \frac\pi3$：$L > 1 \ge R$ で不適。
  • $\frac\pi3 < \theta \le \frac{2\pi}3$：$R \ge 1$ が必要で、(2) よりこの区間はすべて $\frac\pi4 \le \theta \le \frac{3\pi}4$ に含まれるので、すべて適する。
  • $\frac{2\pi}3 < \theta < \pi$：$R \ge 0$ が必要で $\theta \le \pi - \alpha$。ここで $\sin\alpha = \frac1{2\sqrt2} < \frac{\sqrt3}2 = \sin\frac\pi3$ より $\alpha < \frac\pi3$，すなわち $\pi - \alpha > \frac{2\pi}3$。よって $\frac{2\pi}3 < \theta \le \pi - \alpha$。
$$\frac\pi3 < \theta \le \pi - \alpha$$

動く図解

黒が (3) の左辺，青が右辺の階段関数です（横軸は $\theta$）。黒が青以下になる区間（緑）が答えです。

問題の背景

ガウス記号は「値の候補を絞る」

ガウス記号 $[x]$ を含む方程式・不等式では、$[x]$ が整数であることと、中身の範囲から整数の候補を有限個に絞るのが基本戦略です。本問は三角関数と対数が組み合わさっていて見た目は複雑ですが、左辺は 3 段、右辺も実質 3 段（$1$，$0$，$-1$ 以下）の階段なので、図にすれば一目瞭然。$\alpha$ は $\sin\alpha = \frac1{2\sqrt2} \approx 0.354$ で、約 $20.7°$ です。

chopin 先生は「ガウス記号のついた部分は整数であり、その中身の値には範囲があるので、自ずとガウス記号の整数の取りうる値に限りが出てきます」「(1)〜(3) とも、それを念頭に解いていきます。(3) ではいくつか場合があるので、個別に調べます」とコメントしています。

$[X] = n \iff n \le X < n + 1$。中身の範囲 → 整数の候補 → 場合分け。

類題紹介

$0 < \theta < \pi$ のとき，$[2 + \sin\theta] = 2$ を満たす $\theta$ の範囲を求めよ。

（自作）

略解

$0 < \sin\theta \le 1$ より $2 < 2 + \sin\theta \le 3$。値が 3 になるのは $\sin\theta = 1$ のときだけなので、$\theta \ne \dfrac\pi2$（$0 < \theta < \frac\pi2,\ \frac\pi2 < \theta < \pi$）。

$0 < \theta < \pi$ のとき，$[2\cos\theta] + [2\sin\theta] = 1$ を満たす $\theta$ の範囲を求めよ。

（九大 2005　魔改造）

略解

$[2\cos\theta]$ は $\theta$ が $0,\ \frac\pi3,\ \frac\pi2,\ \frac{2\pi}3$ を境に $1,\ 0,\ -1,\ -2$ と変わり（境目の値に注意）、$[2\sin\theta]$ は $\frac\pi6,\ \frac\pi2,\ \frac{5\pi}6$ を境に $0,\ 1,\ 2,\ 1,\ 0$ と変わる。区間ごとに和を調べると、和が 1 になるのは

$$0 < \theta < \frac\pi6,\qquad \frac\pi3 < \theta < \frac\pi2$$

（$\theta = \frac\pi3$ では $1 + 1 = 2$，$\theta = \frac\pi2$ では $0 + 2 = 2$。）
