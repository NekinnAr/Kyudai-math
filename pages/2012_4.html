$p$ と $q$ はともに整数であるとする。2 次方程式 $x^2 + px + q = 0$ が実数解 $\alpha,\ \beta$ を持ち，条件 $(|\alpha| - 1)(|\beta| - 1) \ne 0$ をみたしているとする。このとき，数列 $\{a_n\}$ を

$$a_n = (\alpha^n - 1)(\beta^n - 1)\quad (n = 1,\ 2,\ \ldots)$$

によって定義する。以下の問いに答えよ。

  1. (1)　$a_1,\ a_2,\ a_3$ は整数であることを示せ。
  2. (2)　$(|\alpha| - 1)(|\beta| - 1) > 0$ のとき，極限値 $\displaystyle\lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|$ は整数であることを示せ。
  3. (3)　$\displaystyle\lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right| = \frac{1 + \sqrt5}{2}$ となるとき，$p$ と $q$ の値をすべて求めよ。ただし，$\sqrt5$ が無理数であることは証明なしに用いてよい。

（2012 九州大学 前期 理系 第4問）

解答例

展開すると $a_n = (\alpha\beta)^n - (\alpha^n + \beta^n) + 1$。解と係数の関係 $\alpha + \beta = -p$，$\alpha\beta = q$ で整数の式になります。極限は、絶対値が $1$ より大きい解だけが「生き残る」ことに注目します。

解答例（タップで展開）

(1)

$a_n = q^n - (\alpha^n + \beta^n) + 1$。$\alpha + \beta = -p$，$\alpha\beta = q$ より

$$\alpha^2 + \beta^2 = p^2 - 2q,\qquad \alpha^3 + \beta^3 = (\alpha + \beta)^3 - 3\alpha\beta(\alpha + \beta) = -p^3 + 3pq$$ $$a_1 = p + q + 1,\quad a_2 = q^2 - p^2 + 2q + 1,\quad a_3 = q^3 + p^3 - 3pq + 1$$

いずれも整数の和・差・積なので整数。

(2)

条件より $|\alpha| \ne 1$，$|\beta| \ne 1$ なので $\alpha^n \ne 1$，$\beta^n \ne 1$，よって $a_n \ne 0$。

$$\frac{a_{n+1}}{a_n} = \frac{\alpha^{n+1} - 1}{\alpha^n - 1}\cdot\frac{\beta^{n+1} - 1}{\beta^n - 1}$$

ここで $|\gamma| < 1$ なら $\gamma^n \to 0$ より $\dfrac{\gamma^{n+1} - 1}{\gamma^n - 1} \to 1$，$|\gamma| > 1$ なら $\dfrac{\gamma^{n+1} - 1}{\gamma^n - 1} = \dfrac{\gamma - \gamma^{-n}}{1 - \gamma^{-n}} \to \gamma$。

$(|\alpha| - 1)(|\beta| - 1) > 0$ のとき

  • $|\alpha| < 1$ かつ $|\beta| < 1$：極限値は $1\cdot1 = 1$。
  • $|\alpha| > 1$ かつ $|\beta| > 1$：極限値は $|\alpha\beta| = |q|$。

いずれも整数である。

(3)

$\dfrac{1 + \sqrt5}{2}$ は整数でないので、(2) より $(|\alpha| - 1)(|\beta| - 1) < 0$。$|\alpha| < 1 < |\beta|$ としてよく、このとき上の議論から極限値は $|\beta|$。よって $\beta = \pm\dfrac{1 + \sqrt5}{2}$。

$\beta = \dfrac{1 + \sqrt5}{2}$ のとき：$\beta^2 = \dfrac{3 + \sqrt5}{2}$ を $\beta^2 + p\beta + q = 0$ に代入して 2 倍すると

$$(3 + p + 2q) + (1 + p)\sqrt5 = 0$$

$p,\ q$ は整数，$\sqrt5$ は無理数なので $1 + p = 0$，$3 + p + 2q = 0$，すなわち $p = -1$，$q = -1$。このとき $\alpha = \dfrac{1 - \sqrt5}{2}$ で $|\alpha| \approx 0.618 < 1$ となり条件をみたす。

$\beta = -\dfrac{1 + \sqrt5}{2}$ のとき：同様に $(3 - p + 2q) + (1 - p)\sqrt5 = 0$ より $p = 1$，$q = -1$。$\alpha = \dfrac{-1 + \sqrt5}{2}$ で条件をみたす。

$$(p,\ q) = (-1,\ -1),\ (1,\ -1)$$

動く図解

整数 $p,\ q$ を選ぶと、解 $\alpha,\ \beta$ と $a_n$，比 $\left|a_{n+1}/a_n\right|$ の様子が表示されます。$(p,\ q) = (\pm1,\ -1)$ で黄金比 $1.618\ldots$ に収束します。

問題の背景

「大きい方の解」が数列を支配する

$\alpha^n$ と $\beta^n$ の和や積で作られる数列は、$n$ が大きくなると絶対値の大きい方の解の $n$ 乗が主役になり、比 $a_{n+1}/a_n$ はその解に近づきます。フィボナッチ数列の隣り合う項の比が黄金比に近づくのと同じ現象です。

(3) の後半は「係数が整数（有理数）の 2 次方程式が無理数解 $\dfrac{1 + \sqrt5}{2}$ を持てば、もう 1 つの解は共役な $\dfrac{1 - \sqrt5}{2}$」という事実そのもの。$\sqrt5$ が無理数であることを使って「有理部分・無理部分がそれぞれ $0$」とします。

ちなみに $\dfrac{1 + \sqrt5}{2}$ のように「1 より大きく、共役が絶対値 1 未満」の代数的整数はピゾ数と呼ばれ、その $n$ 乗は整数にどんどん近づきます（$\alpha^n + \beta^n$ が整数で $\alpha^n \to 0$ だから）。

chopin 先生は「(1) 解と係数の関係を使って $\alpha + \beta$ と $\alpha\beta$ を求めて、個別に計算します」「(2) $|\alpha| < 1$ かつ $|\beta| < 1$ のケースと、$|\alpha| > 1$ かつ $|\beta| > 1$ のケースに分かれる」「(3) $(1 + \sqrt5)/2$ は整数でないので、$(|\alpha| - 1)(|\beta| - 1) < 0$ でないといけません」「$\alpha + \beta$ と $\alpha\beta$ がともに整数になることから、…$|\alpha| = |(1 - \sqrt5)/2|$ となることがすぐにわかります」とコメントしています。

$\alpha^n$ 型の極限は「$|\gamma| < 1$ なら $\gamma^n \to 0$、$|\gamma| > 1$ なら $\gamma^n$ で割る」。整数係数の方程式の無理数解は共役とペア。

類題紹介

$x^2 - x - 1 = 0$ の 2 解を $\alpha,\ \beta$ とし，$L_n = \alpha^n + \beta^n$ とおく。$L_{n+2} = L_{n+1} + L_n$ を示し，$L_5$ を求めよ。

（自作）

略解

$\alpha^2 = \alpha + 1$ の両辺に $\alpha^n$ を掛けて $\alpha^{n+2} = \alpha^{n+1} + \alpha^n$。$\beta$ も同様で、足すと $L_{n+2} = L_{n+1} + L_n$。$L_1 = 1$，$L_2 = (\alpha + \beta)^2 - 2\alpha\beta = 3$ から $L_3 = 4$，$L_4 = 7$，$L_5 = 11$（リュカ数）。

本問の設定で，$\displaystyle\lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right| = 1 + \sqrt2$ となるとき，$p$ と $q$ の値をすべて求めよ。

（九大 2012　魔改造）

略解

$1 + \sqrt2$ は整数でないので本問と同様に $|\alpha| < 1 < |\beta|$，$\beta = \pm(1 + \sqrt2)$。

$\beta = 1 + \sqrt2$：$\beta^2 = 3 + 2\sqrt2$ より $(3 + p + q) + (2 + p)\sqrt2 = 0$，$p = -2$，$q = -1$。

$\beta = -(1 + \sqrt2)$：$(3 - p + q) + (2 - p)\sqrt2 = 0$，$p = 2$，$q = -1$。

どちらも $|\alpha| = \sqrt2 - 1 < 1$ で条件をみたす。$(p,\ q) = (-2,\ -1),\ (2,\ -1)$。
