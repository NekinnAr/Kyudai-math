定数 $a \gt 0$ に対し，曲線 $y = a\tan x$ の $0 \le x \lt \dfrac{\pi}{2}$ の部分を $C_1$，曲線 $y = \sin 2x$ の $0 \le x \lt \dfrac{\pi}{2}$ の部分を $C_2$ とする。以下の問いに答えよ。

  1. (1)　$C_1$ と $C_2$ が原点以外に交点をもつための $a$ の条件を求めよ。
  2. (2)　$a$ が (1) の条件を満たすとき，原点以外の $C_1$ と $C_2$ の交点を $\mathrm{P}$ とし，$\mathrm{P}$ の $x$ 座標を $p$ とする。$\mathrm{P}$ における $C_1$ と $C_2$ のそれぞれの接線が直交するとき，$a$ および $\cos 2p$ の値を求めよ。
  3. (3)　$a$ が (2) で求めた値のとき，$C_1$ と $C_2$ で囲まれた図形の面積を求めよ。

（2017 九州大学 前期 理系 第1問）

解答例

$a\tan x = \sin 2x$ を $\sin x(2\cos^2x - a) = 0$ と因数分解。交点では $\cos^2p = \frac a2$ なので、$C_1$ の傾き $\frac{a}{\cos^2p}$ が定数 $2$ になるのがポイント。

解答例（タップで展開）

(1)

$a\tan x = \sin 2x \iff \dfrac{a\sin x}{\cos x} = 2\sin x\cos x \iff \dfrac{\sin x}{\cos x}(a - 2\cos^2x) = 0$。

$0 \lt x \lt \frac\pi2$ では $\sin x \neq 0$ なので、原点以外の交点は $\cos^2x = \frac a2$ の解。$0 \lt x \lt \frac\pi2$ で $\cos^2x$ は $0 \lt \cos^2x \lt 1$ の値を 1 回ずつとるので、条件は $0 \lt \frac a2 \lt 1$。

$$0 \lt a \lt 2$$

(2)

$\cos^2p = \frac a2$。$C_1$ の接線の傾きは $\dfrac{a}{\cos^2p} = 2$、$C_2$ の接線の傾きは $2\cos 2p$。直交条件より

$$2\cdot2\cos 2p = -1 \quad\therefore\ \cos 2p = -\frac14$$

$\cos 2p = 2\cos^2p - 1 = a - 1$ より $a = \dfrac34$（$0 \lt a \lt 2$ をみたす）。

(3)

$0 \lt x \lt p$ では $\sin 2x \gt \frac34\tan x$（$\frac{\sin x}{\cos x}(2\cos^2x - \frac34) \gt 0$）なので

$$S = \int_0^p\left(\sin 2x - \frac34\tan x\right)dx = \left[-\frac12\cos 2x + \frac34\log(\cos x)\right]_0^p = \frac18 + \frac12 + \frac34\log(\cos p)$$

$\cos^2p = \frac38$ より $\log(\cos p) = \frac12\log\frac38$。

$$S = \frac58 + \frac38\log\frac38$$

動く図解

$a$ を動かすと、交点 P と、そこでの 2 本の接線が動きます。$C_1$ の接線の傾き（青）は $a$ によらずいつも $2$ です。2 本の接線が直交する $a = \frac34$ を探してみましょう。

問題の背景

交点での傾きは条件式で簡単になる

交点 P では $\cos^2p = \frac a2$ という関係があるので、傾き $\frac{a}{\cos^2p}$ は $a$ によらず $2$ になります。「交点の座標を具体的に求めずに、交点で成り立つ関係式を使う」のは、2 曲線の問題での定番テクニックです。

chopin 先生は「(1) $a\tan x = \sin 2x$ を因数分解すると…」「(2) 接線の傾きの積が $-1$ になることを使って計算」「(3) $C_1,\ C_2$ を図に書いて積分を実行」と、典型問題の組み合わせとして解説しています。

$\int\tan x\,dx = -\log|\cos x| + C$（$\frac{f'}{f}$ 型）。交点の $x$ 座標が具体的に求まらなくても、$\cos^2p = \frac38$ のような関係から値が出せる。

類題紹介

曲線 $y = e^x$ と $y = ae^{-x}$（$a \gt 0$）の交点における 2 本の接線が直交するような $a$ を求めよ。

（自作）

略解

交点では $e^{2x} = a$。傾きは $e^x$ と $-ae^{-x} = -e^x$（交点で $ae^{-x} = e^x$）。積 $-e^{2x} = -a = -1$ より $a = 1$。

本問 (2) で，「接線が直交する」を「2 本の接線のなす角が $\dfrac{\pi}{4}$ である」に変えたとき，$a$ の値を求めよ。

（九大 2017　魔改造）

略解

傾きは $m_1 = 2$，$m_2 = 2\cos 2p = 2(a - 1)$。なす角が $\frac\pi4$ $\iff \left|\dfrac{m_1 - m_2}{1 + m_1m_2}\right| = 1 \iff |4 - 2a| = |4a - 3|$。$0 \lt a \lt 2$ で解くと $4 - 2a = 4a - 3$ より $a = \dfrac76$（もう一方 $4 - 2a = -(4a - 3)$ は $a = -\frac12$ で不適）。

確認：$m_2 = \frac13$ で $\dfrac{2 - \frac13}{1 + \frac23} = 1$。
