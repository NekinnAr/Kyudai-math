赤玉 2 個，青玉 1 個，白玉 1 個が入った袋が置かれた円形のテーブルの周りに A，B，C の 3 人がこの順番で時計回りに着席している。3 人のうち，ひとりが袋から玉を 1 個取り出し，色を確認したら袋にもどす操作を考える。1 回目は A が玉を取り出し，次のルール (a)，(b)，(c) に従って勝者が決まるまで操作を繰り返す。

  • (a)　赤玉を取り出したら，取り出した人を勝者とする。
  • (b)　青玉を取り出したら，次の回も同じ人が玉を取り出す。
  • (c)　白玉を取り出したら，取り出した人の左隣りの人が次の回に玉を取り出す。

A，B，C の 3 人が $n$ 回目に玉を取り出す確率をそれぞれ $a_n,\ b_n,\ c_n$（$n = 1,\ 2,\ \cdots$）とする。ただし，$a_1 = 1$，$b_1 = c_1 = 0$ である。以下の問いに答えよ。

  1. (1)　A が 4 回目に勝つ確率と 7 回目に勝つ確率をそれぞれ求めよ。
  2. (2)　$d_n = a_n + b_n + c_n$（$n = 1,\ 2,\ \cdots$）とおくとき，$d_n$ を求めよ。
  3. (3)　自然数 $n \ge 3$ に対し，$a_{n+1}$ を $a_{n-2}$ と $n$ を用いて表せ。

（問題の図では，玉を取り出す順番が A → B → C → A → … となる向きに矢印が描かれている。）

（2017 九州大学 前期 理系 第4問）

解答例

「$n$ 回目に誰が取り出すか」の 3 状態の推移を漸化式にする。3 式を足すと $d_n$ の漸化式、3 回まとめて適用すると $a_{n+1}$ と $a_{n-2}$ の関係が出る。

解答例（タップで展開）

赤・青・白を取り出す確率は $\frac12,\ \frac14,\ \frac14$。玉を取り出す順は A → B → C → A なので、$n + 1$ 回目に A が取り出すのは「$n$ 回目に A が青」または「$n$ 回目に C が白」のとき。

$$a_{n+1} = \frac14a_n + \frac14c_n,\quad b_{n+1} = \frac14b_n + \frac14a_n,\quad c_{n+1} = \frac14c_n + \frac14b_n$$

(2)

3 式を足して $d_{n+1} = \frac12d_n$，$d_1 = 1$ より

$$d_n = \left(\frac12\right)^{n-1}$$

(1)

漸化式から順に計算する。

$n$1234567
$a_n$$1$$\frac14$$\frac1{16}$$\frac1{32}$$\frac5{256}$$\frac{11}{1024}$$\frac{11}{2048}$
$b_n$$0$$\frac14$$\frac18$$\frac3{64}$$\frac{5}{256}$$\frac{5}{512}$
$c_n$$0$$0$$\frac1{16}$$\frac3{64}$$\frac{3}{128}$$\frac{11}{1024}$

A が $n$ 回目に勝つ確率は $\frac12a_n$ なので

$$4\ \text{回目}：\frac12\cdot\frac1{32} = \frac1{64},\qquad 7\ \text{回目}：\frac12\cdot\frac{11}{2048} = \frac{11}{4096}$$

(3)

$a_{n+1} = \frac14(a_n + c_n)$ に、$a_n = \frac14(a_{n-1} + c_{n-1})$，$c_n = \frac14(c_{n-1} + b_{n-1})$ を代入すると

$$a_{n+1} = \frac1{16}(a_{n-1} + b_{n-1} + 2c_{n-1})$$

さらに $n - 1$ 回目を $n - 2$ 回目で表すと

$$a_{n-1} + b_{n-1} + 2c_{n-1} = \frac14\{(a + c) + (b + a) + 2(c + b)\}_{n-2} = \frac14(2a_{n-2} + 3b_{n-2} + 3c_{n-2})$$

$b_{n-2} + c_{n-2} = d_{n-2} - a_{n-2}$ を使って

$$a_{n+1} = \frac1{64}\{3d_{n-2} - a_{n-2}\} = -\frac1{64}a_{n-2} + \frac{3}{64}\left(\frac12\right)^{n-3}$$

（例：$n = 3$ で $a_4 = -\frac1{64} + \frac3{64} = \frac1{32}$ ✔）

動く図解

$n$ を動かすと $a_n,\ b_n,\ c_n$ と $d_n$（まだ勝者が決まっていない確率）が表示されます。「1 ゲーム」ボタンで実際に玉を引くシミュレーションもできます。

問題の背景

3 状態の推移と「3 回まとめる」

推移の行列は $\frac14(E + P)$（$P$ は A → B → C → A と回す巡回置換）です。$P^3 = E$ なので、3 回分 $\frac1{64}(E + P)^3 = \frac1{64}(2E + 3P + 3P^2)$ をまとめると $P$ と $P^2$ の係数がそろい、$b + c = d - a$ でまとめられる、というのが (3) の仕組みです。

chopin 先生は「(1)(2) はまとめて解いたほうが良い」「誰の番になるかの状態推移を考えて、$a_n,\ b_n,\ c_n$ を使って漸化式を立てる」「(3) 漸化式から $b_n,\ c_n$ を消去しましょう」とコメントしています。

状態推移の確率漸化式は全部足すと簡単になることが多い。周期的な構造（3 人で一周）があるときは、周期分まとめて適用すると対称性が使える。

類題紹介

A と B が A から交互にサイコロを 1 回ずつ振り，先に 6 の目を出した方を勝ちとする。A が勝つ確率を求めよ。

（自作）

略解

A が勝つ確率を $p$ とすると、A が 1 回目に勝つか、2 人とも外して最初に戻るかなので $p = \frac16 + \left(\frac56\right)^2p$。$p = \dfrac{6}{11}$。

本問のゲームで，最終的に A，B，C がそれぞれ勝者となる確率を求めよ。

（九大 2017　魔改造）

略解

A の番のとき A が最終的に勝つ確率を $f_0$，B の番のとき $f_1$，C の番のとき $f_2$ とする。

$$f_0 = \frac12 + \frac14f_0 + \frac14f_1,\quad f_1 = \frac14f_1 + \frac14f_2,\quad f_2 = \frac14f_2 + \frac14f_0$$

$f_2 = \frac13f_0$，$f_1 = \frac13f_2 = \frac19f_0$ より $\frac34f_0 = \frac12 + \frac1{36}f_0$、$f_0 = \dfrac9{13}$。

B は「自分の番の 1 つ前の人（A）が取り出す」状況なので $f_2$ と同じ形で $\frac3{13}$、C は $\frac1{13}$。

答：A $\dfrac9{13}$，B $\dfrac3{13}$，C $\dfrac1{13}$（合計 1 ✔）
