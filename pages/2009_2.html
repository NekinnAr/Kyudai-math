$k$ は 2 以上の自然数とする。「1」と書かれたカードが 1 枚，「2」と書かれたカードが 2 枚，…，「$k$」と書かれたカードが $k$ 枚ある。そのうちの偶数が書かれたカードの枚数を $M$，奇数が書かれたカードの枚数を $N$ で表す。この $(M + N)$ 枚のカードをよくきって 1 枚を取り出し，そこに書かれた数を記録してもとに戻すという操作を $n$ 回繰り返す。記録された $n$ 個の数の和が偶数となる確率を $p_n$ とする。次の問いに答えよ。

  1. (1)　$p_1$ と $p_2$ を $M,\ N$ で表せ。
  2. (2)　$p_{n+1}$ を $p_n,\ M,\ N$ で表せ。
  3. (3)　$\dfrac{M - N}{M + N}$ を $k$ で表せ。
  4. (4)　$p_n$ を $n$ と $k$ で表せ。

（2009 九州大学 前期 理系 第2問）

解答例

偶数を引く確率 $\frac{M}{M+N}$，奇数を引く確率 $\frac{N}{M+N}$。和の偶奇は「偶数を引けば変わらず、奇数を引けば反転」なので、2 状態の漸化式になります。

解答例（タップで展開）

(1)

1 回なら偶数を引けばよい。2 回なら 2 回の偶奇が一致すればよい。

$$p_1 = \frac{M}{M + N},\qquad p_2 = \frac{M^2 + N^2}{(M + N)^2}$$

(2)

$n$ 回目までの和が偶数で偶数を引くか、奇数で奇数を引くか。

$$p_{n+1} = \frac{M}{M + N}p_n + \frac{N}{M + N}(1 - p_n)$$

(3)

$M + N = 1 + 2 + \cdots + k = \dfrac{k(k + 1)}{2}$。$M - N = -1 + 2 - 3 + 4 - \cdots + (-1)^kk$ は、2 項ずつ組にすると各組が $1$ なので

  • $k$ が偶数：$M - N = \dfrac k2$，$\dfrac{M - N}{M + N} = \dfrac{1}{k + 1}$
  • $k$ が奇数：$M - N = \dfrac{k - 1}{2} - k = -\dfrac{k + 1}{2}$，$\dfrac{M - N}{M + N} = -\dfrac1k$

(4)

$r = \dfrac{M - N}{M + N}$ とおくと (2) は $p_{n+1} = rp_n + \dfrac{N}{M + N}$。$\dfrac12 = \dfrac r2 + \dfrac{N}{M + N}$ なので

$$p_{n+1} - \frac12 = r\left(p_n - \frac12\right),\qquad p_1 - \frac12 = \frac{M - N}{2(M + N)} = \frac r2$$ $$\therefore\ p_n = \frac12 + \frac12r^n$$ $$p_n = \begin{cases} \dfrac12\left\{1 + \left(\dfrac{1}{k + 1}\right)^n\right\} & (k\ \text{が偶数}) \\[10pt] \dfrac12\left\{1 + \left(-\dfrac1k\right)^n\right\} & (k\ \text{が奇数}) \end{cases}$$

動く図解

$k$ を選ぶと $M,\ N$ と $p_n$（$n = 1 \sim 10$）が表示されます。$k$ が奇数だと $r < 0$ なので、$p_n$ は $\frac12$ の上下を交互に振動しながら近づきます。

問題の背景

偶奇の確率は「$\frac12 + \frac12(\text{偏り})^n$」

1 回で偶数が出る確率を $q$ とすると、$n$ 回の和が偶数になる確率は $\dfrac{1 + (2q - 1)^n}{2}$。これは $\{q + (1 - q)\}^n$ と $\{q - (1 - q)\}^n$ を足して 2 で割ると、二項展開で奇数を偶数回引く項だけが残ることからも導けます（偶数番目の項の和を取り出すテクニック）。

偏り $2q - 1 = r$ は $|r| < 1$ なので、$n$ が大きくなると $p_n \to \frac12$。どんなに偏ったカードでも、回数を重ねれば和の偶奇は五分五分に近づきます。

chopin 先生は「(1) $n = 1$ のときはずばり偶数を引く確率、$n = 2$ の時は 2 回の偶奇が一致する確率となります」「(2) 奇数⇒奇数、または偶数⇒偶数と引けばよいので、これで漸化式が立ちます」「(3) $M + N$ はカードの総数なので $\frac12k(k + 1)$ で確定しますが、$k$ の偶奇によって $M$ と $N$ の枚数の式が変化します」とコメントしています。

2 状態の確率漸化式 $p_{n+1} = rp_n + c$ は、極限値（不動点）$\alpha$ を引いて等比数列に。偶奇の問題の不動点はたいてい $\frac12$。

類題紹介

「2」と書かれたカード 1 枚と「1」と書かれたカード 2 枚から，1 枚引いて記録し戻す操作を $n$ 回行う。記録した数の和が偶数となる確率を求めよ。

（自作）

略解

偶数を引く確率 $q = \frac13$，$r = 2q - 1 = -\frac13$。$p_n = \dfrac12\left\{1 + \left(-\dfrac13\right)^n\right\}$。

本問で $k = 3$ とする（カードは「1」が 1 枚，「2」が 2 枚，「3」が 3 枚）。記録された $n$ 個の数の和が 3 の倍数となる確率 $q_n$ を求めよ。

（九大 2009　魔改造）

略解

3 で割った余りが 0，1，2 のカードを引く確率は $\frac12,\ \frac16,\ \frac13$。$\omega = \cos\frac{2\pi}{3} + i\sin\frac{2\pi}{3}$ を使うと、和の余りが 0 の確率は

$$q_n = \frac13\left\{1 + \varphi(\omega)^n + \varphi(\omega^2)^n\right\},\qquad \varphi(z) = \frac12 + \frac16z + \frac13z^2$$

（$1 + \omega^m + \omega^{2m}$ は $m$ が 3 の倍数のとき 3，それ以外 0 になることを利用）。$\varphi(\omega) = \frac14 - \frac{\sqrt3}{12}i = \frac{1}{2\sqrt3}\left(\cos\frac\pi6 - i\sin\frac\pi6\right)$，$\varphi(\omega^2)$ はその共役なので

$$q_n = \frac13 + \frac23\left(\frac{1}{2\sqrt3}\right)^n\cos\frac{n\pi}{6}$$

（$q_1 = \frac12$，$q_2 = \frac{13}{36}$，$q_3 = \frac13$ と直接計算に一致。）
