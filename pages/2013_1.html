$a \gt 1$ とし，2 つの曲線

$$y = \sqrt x\quad(x \ge 0),\qquad y = \frac{a^3}{x}\quad(x \gt 0)$$

を順に $C_1,\ C_2$ とする。また，$C_1$ と $C_2$ の交点 $\mathrm{P}$ における $C_1$ の接線を $l_1$ とする。以下の問いに答えよ。

  1. (1)　曲線 $C_1$ と $y$ 軸および直線 $l_1$ で囲まれた部分の面積を $a$ を用いて表せ。
  2. (2)　点 $\mathrm{P}$ における $C_2$ の接線と直線 $l_1$ のなす角を $\theta(a)$ とする $\left(0 \lt \theta(a) \lt \dfrac\pi2\right)$。このとき，$\displaystyle\lim_{a\to\infty}a\sin\theta(a)$ を求めよ。

（2013 九州大学 前期 理系 第1問）

解答例

交点は $\mathrm{P}(a^2,\ a)$。(1) は接線が上にあるので「接線 − 曲線」を積分。(2) は 2 直線の傾きから $\tan$ の加法定理で $\tan\theta$ を求め、$\sin\theta \approx \tan\theta$ の感覚で極限をとる。

解答例（タップで展開）

$\sqrt x = \frac{a^3}{x} \iff x^{\frac32} = a^3 \iff x = a^2$。$\mathrm{P}(a^2,\ a)$。

(1)

$(\sqrt x)' = \frac{1}{2\sqrt x}$ より $l_1$ の傾きは $\frac1{2a}$，$l_1：y = \frac{x}{2a} + \frac a2$。$C_1$ は上に凸なので $l_1$ は $C_1$ の上側にある。

$$\int_0^{a^2}\left(\frac{x}{2a} + \frac a2 - \sqrt x\right)dx = \frac{a^3}{4} + \frac{a^3}{2} - \frac23a^3 = \frac{a^3}{12}$$

(2)

$C_2$ の接線の傾きは $-\frac{a^3}{x^2}\Big|_{x=a^2} = -\frac1a$。$l_1$ の傾き $m_1 = \frac1{2a}$，$C_2$ の接線の傾き $m_2 = -\frac1a$ より

$$\tan\theta(a) = \left|\frac{m_1 - m_2}{1 + m_1m_2}\right| = \frac{\frac{3}{2a}}{1 - \frac{1}{2a^2}} = \frac{3a}{2a^2 - 1}$$

（$a \gt 1$ で分母正。）$\sin\theta = \dfrac{\tan\theta}{\sqrt{1 + \tan^2\theta}}$ より

$$a\sin\theta(a) = \frac{a\tan\theta}{\sqrt{1 + \tan^2\theta}} = \frac{\frac{3a^2}{2a^2 - 1}}{\sqrt{1 + \frac{9a^2}{(2a^2 - 1)^2}}} \longrightarrow \frac{3/2}{1} = \frac32\quad(a \to \infty)$$

動く図解

$a$ を動かすと交点 P と 2 本の接線が動きます。$a$ が大きくなると 2 本の接線はほぼ水平になり、なす角 $\theta$ は 0 に近づきますが、$a\sin\theta$ は $\frac32$ に近づきます。（縦横の縮尺は同じで、$a$ に合わせて全体を縮小表示。）

問題の背景

なす角の極限と $\sin\theta \sim \tan\theta \sim \theta$

$\theta \to 0$ のとき $\sin\theta,\ \tan\theta,\ \theta$ はどれも同じ速さで 0 に近づきます。$\tan\theta \approx \frac{3}{2a}$ なので $a\sin\theta \to \frac32$。傾きの差 $m_1 - m_2 = \frac{3}{2a}$ がそのまま答えの $\frac32$ を決めています。

(1) は $C_1$ を $x = y^2$ と見て $y$ で積分すると、$\displaystyle\int_0^{\frac a2}y^2dy + \int_{\frac a2}^{a}(y - a)^2dy = \frac{a^3}{24} + \frac{a^3}{24}$ と、同じ面積の 2 つの部分に分かれることがわかります（接線は $y$ 軸と $y = \frac a2$ で交わる）。

chopin 先生は「(1) $L_1$ の式を求めてグラフに描くことで、面積を計算できます」「(2) $L_1$ と $L_2$（P での $C_2$ の接線）の傾きから、tan の加法定理を使って $\tan\theta$ が計算できます」とコメントしています。

2 直線のなす角は $\tan\theta = \left|\frac{m_1 - m_2}{1 + m_1m_2}\right|$。極限は $\sin\theta = \frac{\tan\theta}{\sqrt{1 + \tan^2\theta}}$ で $\tan$ に直す。

類題紹介

曲線 $y = \log x$ 上の点 $(e,\ 1)$ における接線と，曲線 $y = \log x$ および $x$ 軸で囲まれた部分の面積を求めよ。

（自作）

略解

接線は $y = \frac xe$（原点を通る）。接線と $x$ 軸と $x = e$ でできる三角形 $\frac e2$ から $\int_1^e\log x\,dx = 1$ を引いて $\dfrac e2 - 1$。

本問の $C_2$ を $y = \dfrac{a^{2n+1}}{x^n}$（$n$ は自然数）に変える。$C_1$ と $C_2$ の交点 P における $C_2$ の接線と $l_1$ のなす角を $\theta_n(a)$ とするとき，$\displaystyle\lim_{a\to\infty}a\sin\theta_n(a)$ を求めよ。

（九大 2013　魔改造）

略解

$\sqrt x = \frac{a^{2n+1}}{x^n} \iff x^{n + \frac12} = a^{2n+1}$ より交点は同じ $\mathrm{P}(a^2,\ a)$。$C_2$ の傾きは $-\frac{na^{2n+1}}{x^{n+1}}\Big|_{x=a^2} = -\frac na$。

$$\tan\theta_n = \frac{\frac1{2a} + \frac na}{1 - \frac{n}{2a^2}} = \frac{(2n + 1)a}{2a^2 - n}$$

（$a$ が十分大きいとき。）$a\sin\theta_n \to \dfrac{2n + 1}{2}$。$n = 1$ が本問の $\frac32$。
