点 $z$ が複素数平面上の線分

$$z = t + ti \qquad \left(\frac{-1+\sqrt3}{2} \le t \le \frac{1+\sqrt3}{2}\right)$$

の上を動くとき，

$$z^2 - wz + 1 = 0$$

をみたす複素数 $w$ を表す点が描く軌跡を $C$ とする。ただし，$i$ は虚数単位である。以下の問いに答えよ。

  1. (1)　軌跡 $C$ を複素数平面上に図示せよ。
  2. (2)　$t = \dfrac{1+\sqrt3}{2}$ のときに複素数 $w$ を表す点を $\mathrm{P}_1$ とし，$t = \dfrac{-1+\sqrt3}{2}$ のときに複素数 $w$ を表す点を $\mathrm{P}_2$ とする。このとき，軌跡 $C$，線分 $\mathrm{OP}_1$，線分 $\mathrm{OP}_2$ で囲まれる領域を虚軸の周りに 1 回転させてできる立体の体積を求めよ。ただし，O は複素数平面の原点である。

（2026 九州大学 前期 理系 第2問）

解答例

$z \ne 0$ なので $w = z + \dfrac1z$。実部・虚部を $t$ で表して $t$ を消去すると双曲線が現れる。(2) は虚軸（$y$ 軸）方向に輪切りにして積分。

解答例（タップで展開）

(1)

$z = t(1+i)$ で $t \gt 0$ より $z \ne 0$。$z^2 - wz + 1 = 0$ より

$$w = z + \frac1z = t(1+i) + \frac{1}{t(1+i)} = t(1+i) + \frac{1-i}{2t} = \left(t + \frac{1}{2t}\right) + \left(t - \frac{1}{2t}\right)i$$

$w = x + yi$（$x,\ y$ は実数）とおくと

$$x = t + \frac{1}{2t},\qquad y = t - \frac{1}{2t}$$

よって $x^2 - y^2 = (x+y)(x-y) = 2t\cdot\dfrac1t = 2$。また $x + y = 2t$ より、$t$ の範囲は

$$\sqrt3 - 1 \le x + y \le \sqrt3 + 1$$

に対応する。さらに $x \gt 0$ であり、$\dfrac{dy}{dt} = 1 + \dfrac{1}{2t^2} \gt 0$ より $y$ は $t$ について単調増加。端点は

  • $t = \dfrac{1+\sqrt3}{2}$ のとき $\dfrac{1}{2t} = \dfrac{\sqrt3-1}{2}$ より $w = \sqrt3 + i$
  • $t = \dfrac{-1+\sqrt3}{2}$ のとき $\dfrac{1}{2t} = \dfrac{\sqrt3+1}{2}$ より $w = \sqrt3 - i$

したがって $C$ は双曲線 $x^2 - y^2 = 2$ の $x \gt 0$ の部分のうち、点 $\sqrt3 - i$ から頂点 $\sqrt2$ を通って点 $\sqrt3 + i$ までの弧（$-1 \le y \le 1$ の部分）である。漸近線は $y = \pm x$（図は下の「動く図解」の右図）。

(2)

$\mathrm{P}_1 = \sqrt3 + i$, $\mathrm{P}_2 = \sqrt3 - i$。線分 $\mathrm{OP}_1$, $\mathrm{OP}_2$ はそれぞれ $x = \sqrt3\,y\ (0 \le y \le 1)$, $x = -\sqrt3\,y\ (-1 \le y \le 0)$。領域は、$-1 \le y \le 1$ の各 $y$ で

$$\sqrt3\,|y| \le x \le \sqrt{y^2 + 2}$$

の部分（$3y^2 \le y^2 + 2 \iff y^2 \le 1$ で確かに大小関係が成り立つ）。これを虚軸（$y$ 軸）の周りに回転すると、高さ $y$ での断面は内半径 $\sqrt3|y|$、外半径 $\sqrt{y^2+2}$ の円環なので

$$V = \int_{-1}^{1}\pi\left\{(y^2 + 2) - 3y^2\right\}dy = 2\pi\int_{0}^{1}(2 - 2y^2)\,dy = 2\pi\left(2 - \frac23\right) = \frac{8}{3}\pi$$

動く図解

$w = z + \dfrac1z$ は、$z$ 平面（左）の図形を $w$ 平面（右）に写す変換です。$t$ を動かすと、左の線分上の点 $z$ に対応して、右の双曲線上を点 $w$ が動きます。薄い線は、原点を通る直線（偏角一定）と原点中心の円（絶対値一定）が、それぞれ何に写るかを表しています。

問題の背景

ジューコフスキー変換

$w = z + \dfrac1z$ はジューコフスキー変換と呼ばれる有名な変換です。ロシアの航空力学者ジューコフスキーが、円を飛行機の翼の断面のような形に写すことに用いたことで知られています。

$z = re^{i\theta}$ とおくと

$$w = \left(r + \frac1r\right)\cos\theta + i\left(r - \frac1r\right)\sin\theta$$

となるので、

  • 円 $|z| = r$（$r \ne 1$）は、楕円 $\dfrac{x^2}{(r+\frac1r)^2} + \dfrac{y^2}{(r-\frac1r)^2} = 1$ に写る。
  • 原点を通る直線（偏角 $\theta$ 一定）は、双曲線 $\dfrac{x^2}{\cos^2\theta} - \dfrac{y^2}{\sin^2\theta} = 4$ に写る。

本問は $\theta = \dfrac{\pi}{4}$ の場合で、$2x^2 - 2y^2 = 4$、すなわち $x^2 - y^2 = 2$ が得られます。

驚くべきことに、これらの楕円と双曲線はすべて焦点 $\pm2$ を共有しています（$(r+\frac1r)^2 - (r-\frac1r)^2 = 4$、$\cos^2\theta + \sin^2\theta = 1$ より $c^2 = 4$）。このような曲線の族を共焦点 2 次曲線といいます。$z$ 平面で直線と円が直交しているのに対応して、$w$ 平面の楕円と双曲線も直交します（ジューコフスキー変換は角度を保つ「等角写像」の代表例です）。

体積 $\dfrac83\pi$ は「単位球 2 個分」

(2) の断面積は $\pi(2 - 2y^2) = 2\cdot\pi(1 - y^2)$ でした。$\pi(1-y^2)$ は半径 $1$ の球を高さ $y$ で切った断面積です。つまりこの立体は、どの高さで切っても単位球の断面のちょうど 2 倍の面積をもち、カヴァリエリの原理から体積は単位球 2 個分 $2\cdot\dfrac43\pi = \dfrac83\pi$ となります。

双曲線の回転体から円錐をくり抜いた立体が、球と同じ断面積の構造をもつ ── 「$x^2 - y^2 = 2$ と $x^2 = 3y^2$ の差が $2 - 2y^2$」という計算の裏に、こんな見方が隠れています。

類題紹介

点 $z$ が複素数平面上の円 $|z| = 2$ 上を動くとき，$w = z + \dfrac1z$ を表す点が描く軌跡を求めよ。また，その曲線の焦点を求めよ。

（自作）

略解

$z = 2(\cos\theta + i\sin\theta)$ とおくと $w = \dfrac52\cos\theta + \dfrac32 i\sin\theta$。よって楕円 $\dfrac{x^2}{\frac{25}{4}} + \dfrac{y^2}{\frac94} = 1$。$c^2 = \dfrac{25}{4} - \dfrac94 = 4$ より焦点は $\pm2$。本問の双曲線と焦点が一致します。

点 $z$ が半直線 $z = t + ti\ (t \gt 0)$ 全体を動くとき，$w = z + \dfrac1z$ を表す点が描く軌跡 $C'$ を求めよ。また，$C'$ 上の点と点 $-2$ の距離から，点 $2$ との距離を引いた値は一定であることを示せ。

（九大 2026　魔改造）

略解

本問と同様に $x^2 - y^2 = 2$。$x = t + \dfrac{1}{2t} \ge \sqrt2$（相加・相乗平均）で、$y = t - \dfrac{1}{2t}$ は $t \gt 0$ で全実数値をとるので、$C'$ は双曲線 $x^2 - y^2 = 2$ の $x \gt 0$ の部分全体。

$C'$ 上の点 $(x,\ y)$ について $y^2 = x^2 - 2$ を使うと

$$(x \mp 2)^2 + y^2 = 2x^2 \mp 4x + 2 = (\sqrt2\,x \mp \sqrt2)^2$$

$x \ge \sqrt2$ より、点 $2$ との距離は $\sqrt2x - \sqrt2$、点 $-2$ との距離は $\sqrt2x + \sqrt2$。差は $2\sqrt2$ で一定。
