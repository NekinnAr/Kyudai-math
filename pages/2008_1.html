$f(x) = \dfrac{e^x}{e^x + 1}$ とおく。ただし，$e$ は自然対数の底とする。このとき，次の問いに答えよ。

  1. (1)　$y = f(x)$ の増減，凹凸，漸近線を調べ，グラフをかけ。
  2. (2)　$f(x)$ の逆関数 $f^{-1}(x)$ を求めよ。
  3. (3)　$\displaystyle\lim_{n\to\infty}n\left\{f^{-1}\left(\frac{1}{n + 2}\right) - f^{-1}\left(\frac{1}{n + 1}\right)\right\}$ を求めよ。

（2008 九州大学 前期 理系 第1問）

解答例

$f$ はシグモイド（ロジスティック）関数と呼ばれる S 字型の関数です。逆関数は $\log\dfrac{x}{1 - x}$。(3) は代入すると $\log$ の差がきれいに $\log\frac{n}{n + 1}$ になり、$e$ の定義に帰着します。

解答例（タップで展開）

(1)

$$f'(x) = \frac{e^x(e^x + 1) - e^x\cdot e^x}{(e^x + 1)^2} = \frac{e^x}{(e^x + 1)^2} > 0$$ $$f''(x) = \frac{e^x(e^x + 1)^2 - e^x\cdot2(e^x + 1)e^x}{(e^x + 1)^4} = \frac{e^x(1 - e^x)}{(e^x + 1)^3}$$

よって $f$ はつねに増加。$x < 0$ で下に凸，$x > 0$ で上に凸で、変曲点は $\left(0,\ \frac12\right)$。

$x \to -\infty$ で $e^x \to 0$ より $f(x) \to 0$；$x \to \infty$ で $f(x) = \dfrac{1}{1 + e^{-x}} \to 1$。漸近線は $y = 0$ と $y = 1$。グラフは $(0,\ \frac12)$ を中心に点対称な S 字型（下の図）。

(2)

$f$ の値域は $0 < y < 1$。$y = \dfrac{e^x}{e^x + 1}$ を $x$ について解くと $e^x = \dfrac{y}{1 - y}$，$x = \log\dfrac{y}{1 - y}$。

$$f^{-1}(x) = \log\frac{x}{1 - x}\quad(0 < x < 1)$$

(3)

$$f^{-1}\left(\frac{1}{n + 2}\right) = \log\frac{1/(n + 2)}{(n + 1)/(n + 2)} = -\log(n + 1),\qquad f^{-1}\left(\frac{1}{n + 1}\right) = -\log n$$

よって

$$n\{\cdots\} = n\log\frac{n}{n + 1} = -\log\left(1 + \frac1n\right)^n \to -\log e = -1$$

動く図解

$y = f(x)$（赤）と逆関数 $y = f^{-1}(x)$（青）は直線 $y = x$ に関して対称です。$n$ を動かすと (3) の値が $-1$ に近づく様子が分かります。

問題の背景

シグモイド関数とロジット関数

$f(x) = \dfrac{1}{1 + e^{-x}}$ はシグモイド関数と呼ばれ、人口増加のモデル（ロジスティック曲線）や、機械学習（ニューラルネットワークの活性化関数、ロジスティック回帰）で大活躍する関数です。その逆関数 $\log\dfrac{x}{1 - x}$ はロジット関数と呼ばれ、確率 $x$ を「オッズの対数」に変換します。

$f'(x) = f(x)\{1 - f(x)\}$ が成り立つのも重要な性質で、微分方程式 $y' = y(1 - y)$ の解になっています。

chopin 先生は「(1) は教科書レベルの問題です。$f'(x)$ と $f''(x)$ を計算しましょう」「(2) $y = f(x)$ を $x =$ の形に変形してあげましょう」「(3) ネイピア数 $e$ の定義式を最後に使うことになります」とコメントしています。

$\displaystyle\lim_{n\to\infty}\left(1 + \frac1n\right)^n = e$。逆関数は「$x$ について解いて文字を入れかえる」、定義域（元の関数の値域）も忘れずに。

類題紹介

本問の $f(x)$ について，$f(x) + f(-x) = 1$ を示し，$\displaystyle\int_{-1}^{1}f(x)\,dx$ を求めよ。

（自作）

略解

$f(-x) = \dfrac{e^{-x}}{e^{-x} + 1} = \dfrac{1}{1 + e^x}$ より $f(x) + f(-x) = 1$。$\displaystyle\int_{-1}^{1}f(x)\,dx = \int_0^1\{f(x) + f(-x)\}dx = 1$。（グラフが $(0,\ \frac12)$ に関して点対称であることの式表現。）

$\displaystyle\lim_{n\to\infty}n^2\left\{f^{-1}\left(\frac{1}{n + 1}\right) - f^{-1}\left(\frac{1}{n + 2}\right) - \frac1n\right\}$ を求めよ。ただし，$x > 0$ で $x - \dfrac{x^2}{2} < \log(1 + x) < x - \dfrac{x^2}{2} + \dfrac{x^3}{3}$ が成り立つことは用いてよい。

（九大 2008　魔改造）

略解

本問より中括弧の前 2 項の差は $\log\left(1 + \frac1n\right)$。与えられた不等式で $x = \frac1n$ とすると

$$-\frac12 < n^2\left\{\log\left(1 + \frac1n\right) - \frac1n\right\} < -\frac12 + \frac{1}{3n}$$

はさみうちの原理より、極限値は $-\dfrac12$。（本問の $-1$ は「1 次の近似」、こちらは「2 次の近似」を見ています。）
