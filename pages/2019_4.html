座標平面上の 3 点 $\mathrm{O}(0,\ 0)$，$\mathrm{A}(2,\ 0)$，$\mathrm{B}(1,\ \sqrt3)$ を考える。点 $\mathrm{P_1}$ は線分 $\mathrm{AB}$ 上にあり，$\mathrm{A}$，$\mathrm{B}$ とは異なる点とする。

線分 $\mathrm{AB}$ 上の点 $\mathrm{P_2},\ \mathrm{P_3},\ \cdots\cdots$ を以下のように順に定める。点 $\mathrm{P}_n$ が定まったとき，点 $\mathrm{P}_n$ から線分 $\mathrm{OB}$ に下ろした垂線と $\mathrm{OB}$ との交点を $\mathrm{Q}_n$ とし，点 $\mathrm{Q}_n$ から線分 $\mathrm{OA}$ に下ろした垂線と $\mathrm{OA}$ との交点を $\mathrm{R}_n$ とし，点 $\mathrm{R}_n$ から線分 $\mathrm{AB}$ に下ろした垂線と $\mathrm{AB}$ との交点を $\mathrm{P}_{n+1}$ とする。

$n \to \infty$ のとき，$\mathrm{P}_n$ が限りなく近づく点の座標を求めよ。

（2019 九州大学 前期 理系 第4問）

解答例

座標でも解けるが、三角形 OAB が 1 辺 $2$ の正三角形であることを使い、頂点からの距離で追いかけると簡単。垂線を下ろすたびに「$\cos60^\circ = \frac12$ 倍」になる。

解答例（タップで展開）

$\mathrm{OA} = \mathrm{AB} = \mathrm{BO} = 2$ より、三角形 OAB は 1 辺 $2$ の正三角形で、内角はすべて $60^\circ$。$s_n = \mathrm{BP}_n$ とおく（$0 \lt s_1 \lt 2$）。

  • $\mathrm{P}_n$ から OB に垂線：$\angle\mathrm{B} = 60^\circ$ より $\mathrm{BQ}_n = \frac{s_n}{2}$。よって $\mathrm{OQ}_n = 2 - \frac{s_n}{2}$。
  • $\mathrm{Q}_n$ から OA に垂線：$\angle\mathrm{O} = 60^\circ$ より $\mathrm{OR}_n = \frac12\mathrm{OQ}_n = 1 - \frac{s_n}{4}$。よって $\mathrm{AR}_n = 1 + \frac{s_n}{4}$。
  • $\mathrm{R}_n$ から AB に垂線：$\angle\mathrm{A} = 60^\circ$ より $\mathrm{AP}_{n+1} = \frac12\mathrm{AR}_n = \frac12 + \frac{s_n}{8}$。

（いずれも垂線の足は線分の内部にある。）よって

$$s_{n+1} = 2 - \mathrm{AP}_{n+1} = \frac32 - \frac{s_n}{8}$$

$\alpha = \frac32 - \frac\alpha8$ をみたす $\alpha = \frac43$ を用いると

$$s_{n+1} - \frac43 = -\frac18\left(s_n - \frac43\right) \quad\therefore\ s_n - \frac43 = \left(-\frac18\right)^{n-1}\left(s_1 - \frac43\right) \to 0$$

よって $\mathrm{BP}_n \to \frac43$。$\mathrm{P}_n$ が近づく点は、B から A の方向へ $\frac43$（AB の $\frac23$）進んだ点で

$$(1,\ \sqrt3) + \frac23(1,\ -\sqrt3) = \left(\frac53,\ \frac{\sqrt3}{3}\right)$$

動く図解

$\mathrm{P_1}$ の位置を動かすと、P → Q → R → P → … と垂線をたどる折れ線が描かれます。どこから始めても、すぐに同じ点（緑）に吸い寄せられることが分かります。

問題の背景

縮小写像と不動点

「P から P' を作る操作」は 1 次関数 $s \mapsto \frac32 - \frac s8$ で、距離を $\frac18$ 倍に縮めます。このような縮小写像を繰り返すと、どこから始めてもただ 1 つの不動点に収束します（バナッハの不動点定理）。

極限の点 $\mathrm{P}$ と、そこから作られる $\mathrm{Q},\ \mathrm{R}$ を結ぶと、三角形 PQR は各辺が OAB の辺と垂直な三角形、つまり正三角形になっています（類題 1）。

chopin 先生は「少々手間はかかりますが、$\mathrm{P}(x_n,\ y_n)$ とおいて、$x_n,\ y_n$ の漸化式を立てて一般項を求めに行きましょう」とコメントしています。座標の代わりに距離 1 つで追うと、漸化式が 1 本で済みます。

点の列の極限は、1 変数（距離・比・パラメータ）で位置を表して漸化式 $s_{n+1} = ps_n + q$ を作る。$|p| \lt 1$ なら不動点に収束。

類題紹介

本問で $\mathrm{P_1}$ を極限の点 $\left(\frac53,\ \frac{\sqrt3}{3}\right)$ にとる。三角形 $\mathrm{P_1Q_1R_1}$ は正三角形であることを示し，その面積が三角形 OAB の面積の何倍か求めよ。

（自作）

略解

$s_1 = \frac43$ より $\mathrm{BQ_1} = \frac23$、$\mathrm{Q_1} = \left(\frac23,\ \frac{2\sqrt3}{3}\right)$、$\mathrm{OR_1} = \frac23$、$\mathrm{R_1} = \left(\frac23,\ 0\right)$。

$$\mathrm{P_1Q_1}^2 = 1 + \frac13,\quad \mathrm{Q_1R_1}^2 = \frac43,\quad \mathrm{R_1P_1}^2 = 1 + \frac13$$

3 辺とも $\frac{2}{\sqrt3}$ で正三角形。面積比は $\left(\frac{2/\sqrt3}{2}\right)^2 = \dfrac13$ 倍。

$\mathrm{O}(0,\ 0)$，$\mathrm{A}(2,\ 0)$，$\mathrm{B}(1,\ 2)$ として本問と同じ操作を行うとき，$\mathrm{P}_n$ が限りなく近づく点の座標を求めよ。

（九大 2019　魔改造）

略解

$\mathrm{P}_n = (2 - u_n,\ 2u_n)$（$0 \lt u_n \lt 1$）とおく。OB 方向の単位ベクトル $\frac{1}{\sqrt5}(1,\ 2)$ への正射影より $\mathrm{Q}_n = \frac{2 + 3u_n}{5}(1,\ 2)$、$\mathrm{R}_n = \left(\frac{2 + 3u_n}{5},\ 0\right)$。$\cos A = \frac{1}{\sqrt5}$，$\mathrm{AB} = \sqrt5$ より

$$u_{n+1} = \frac{\mathrm{AR}_n\cos A}{\mathrm{AB}} = \frac{\mathrm{AR}_n}{5} = \frac{8 - 3u_n}{25}$$

不動点は $u = \frac27$、$u_n - \frac27 = \left(-\frac{3}{25}\right)^{n-1}\left(u_1 - \frac27\right) \to 0$。極限の点は $\left(\dfrac{12}{7},\ \dfrac47\right)$。

（縮小率 $\frac{3}{25}$ は $\cos O\cos A\cos B = \frac{1}{\sqrt5}\cdot\frac{1}{\sqrt5}\cdot\frac35$。本問では $\left(\frac12\right)^3 = \frac18$ でした。）
