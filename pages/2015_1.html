$C_1,\ C_2$ をそれぞれ次式で与えられる放物線の一部分とする。

$$C_1：y = -x^2 + 2x,\quad 0 \le x \le 2,\qquad C_2：y = -x^2 - 2x,\quad -2 \le x \le 0$$

また，$a$ を実数とし，直線 $y = a(x + 4)$ を $l$ とする。

  1. (1)　直線 $l$ と $C_1$ が異なる 2 つの共有点をもつための $a$ の値の範囲を求めよ。

以下，$a$ が (1) の条件を満たすとする。このとき，$l$ と $C_1$ で囲まれた領域の面積を $S_1$，$x$ 軸と $C_2$ で囲まれた領域で $l$ の下側にある部分の面積を $S_2$ とする。

  1. (2)　$S_1$ を $a$ を用いて表せ。
  2. (3)　$S_1 = S_2$ を満たす実数 $a$ が $0 \lt a \lt \dfrac15$ の範囲に存在することを示せ。

（2015 九州大学 前期 理系 第1問）

解答例

(1) は 2 次方程式の解の配置。(2) は $\frac16$ 公式で $S_1 = \frac16(\beta - \alpha)^3$。(3) は $S_2$ を「山全体 $\frac43$ − $l$ より上の部分」として求め、中間値の定理で示す。

解答例（タップで展開）

(1)

$-x^2 + 2x = a(x + 4) \iff f(x) = x^2 + (a - 2)x + 4a = 0$ が $0 \le x \le 2$ に異なる 2 解をもつ条件は

  • 判別式：$(a - 2)^2 - 16a = a^2 - 20a + 4 \gt 0$
  • 軸：$0 \lt \frac{2 - a}{2} \lt 2 \iff -2 \lt a \lt 2$
  • $f(0) = 4a \ge 0$，$f(2) = 6a \ge 0$

$a^2 - 20a + 4 \gt 0 \iff a \lt 10 - 4\sqrt6$ または $a \gt 10 + 4\sqrt6$。まとめて

$$0 \le a \lt 10 - 4\sqrt6\quad(= 0.202\cdots)$$

(2)

$f(x) = 0$ の 2 解を $\alpha \lt \beta$ とすると、$\alpha \le x \le \beta$ で $C_1$ が $l$ の上にあり

$$S_1 = \int_\alpha^\beta\{-f(x)\}dx = \frac{(\beta - \alpha)^3}{6} = \frac{(a^2 - 20a + 4)^{\frac32}}{6}$$

(3)

$S_2$ を求める。$-x^2 - 2x = a(x + 4) \iff x^2 + (a + 2)x + 4a = 0$ の判別式は $a^2 - 12a + 4$ で、$0 \le a \lt 10 - 4\sqrt6$ では正。2 解 $\gamma \lt \delta$ は $g(x) = x^2 + (a+2)x + 4a$ について $g(-2) = 2a \ge 0$，$g(0) = 4a \ge 0$，軸 $-\frac{a+2}{2} \in (-2,\ 0)$ より $-2 \le \gamma \lt \delta \le 0$。

$\gamma \lt x \lt \delta$ では $C_2$ が $l$ より上、それ以外では $C_2$ が $l$ より下。よって $C_2$ と $x$ 軸で囲まれた山（面積 $\frac{2^3}{6} = \frac43$）から、$l$ より上の部分を除いたものが $S_2$：

$$S_2 = \frac43 - \frac{(\delta - \gamma)^3}{6} = \frac43 - \frac{(a^2 - 12a + 4)^{\frac32}}{6}$$

中間値の定理。$h(a) = S_1 - S_2 = \dfrac{(a^2 - 20a + 4)^{\frac32} + (a^2 - 12a + 4)^{\frac32}}{6} - \dfrac43$ は $0 \le a \le \frac15$ で連続（$\frac15 \lt 10 - 4\sqrt6$ を $4\sqrt6 \lt 9.8 \iff 96 \lt 96.04$ で確認）。

  • $h(0) = \frac{8 + 8}{6} - \frac43 = \frac43 \gt 0$
  • $h\left(\frac15\right)$：$a^2 - 20a + 4 = \frac1{25}$，$a^2 - 12a + 4 = \frac{41}{25}$ より $h\left(\frac15\right) = \dfrac{1 + 41\sqrt{41}}{750} - \dfrac43$。$\sqrt{41} \lt 7$ より $1 + 41\sqrt{41} \lt 288 \lt 1000$ なので $h\left(\frac15\right) \lt 0$。

よって $h(a) = 0$，すなわち $S_1 = S_2$ となる $a$ が $0 \lt a \lt \frac15$ に存在する。

動く図解

$a$ を動かすと直線 $l$ が点 $(-4,\ 0)$ を中心に回転します。$S_1$（赤）と $S_2$（青）が等しくなる $a$ を探してみましょう（$a \approx 0.094$）。

問題の背景

解けない方程式の解の存在

$S_1 = S_2$ は $\frac32$ 乗を含む方程式で、きれいには解けません。そこで「解の値」ではなく「解の存在」を問うのが (3) です。端点での符号の違いと連続性だけで存在が言えるのが中間値の定理の強みです。

chopin 先生は「(1) $l$ が $C_1$ の接線になっているときが $a$ の限界値」「(3) $S_1 = S_2$ はかなり複雑な方程式となり、解はキレイに求まりません。よって、$y = S_1$ のグラフと $y = S_2$ の交点が $0$ と $\frac15$ の間にあることを示しに行きます」とコメントしています。

「〜を満たす $a$ が存在することを示せ」→ 差の関数をつくって中間値の定理。$\sqrt{41} \lt 7$ のような粗い評価で十分なことが多い。

類題紹介

$0 \lt a \lt 2$ とする。放物線 $y = -x^2 + 2x$ と直線 $y = ax$ で囲まれた部分の面積を求めよ。

（自作）

略解

$-x^2 + 2x - ax = -x(x - (2 - a))$ より交点は $x = 0,\ 2 - a$。面積は $\dfrac{(2 - a)^3}{6}$。

本問で，$S_1 = S_2$ を満たす $a$ は (1) の範囲にただ 1 つ存在し，それは $0 \lt a \lt \dfrac1{10}$ の範囲にあることを示せ。

（九大 2015　魔改造）

略解

ただ 1 つ。$0 \le a \lt 10 - 4\sqrt6$ で $a^2 - 20a + 4$，$a^2 - 12a + 4$ はともに正で減少（軸 $a = 10,\ 6$ より左）。よって $S_1$ は減少、$S_2$ は増加し、$h = S_1 - S_2$ は狭義単調減少。解は高々 1 つで、(3) より存在する。

$\frac1{10}$ 未満。$a = \frac1{10}$ で $a^2 - 20a + 4 = \frac{201}{100}$，$a^2 - 12a + 4 = \frac{281}{100}$。

$$h\left(\tfrac1{10}\right) = \frac{201\sqrt{201} + 281\sqrt{281}}{6000} - \frac43,\qquad 201\sqrt{201} + 281\sqrt{281} \lt 201\cdot15 + 281\cdot17 = 7792 \lt 8000$$

より $h\left(\frac1{10}\right) \lt 0$。単調減少なので解は $0 \lt a \lt \frac1{10}$ にある（実際は $a \approx 0.0939$）。
