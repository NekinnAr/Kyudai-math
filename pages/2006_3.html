2 つの数列 $\{a_n\}$，$\{b_n\}$ は，$a_1 = b_1 = 1$ および，関係式

$$a_{n+1} = 2a_nb_n,\qquad b_{n+1} = 2{a_n}^2 + {b_n}^2$$

をみたすものとする。

  1. (1)　$n \ge 3$ のとき，$a_n$ は 3 で割り切れるが，$b_n$ は 3 で割り切れないことを示せ。
  2. (2)　$n \ge 2$ のとき，$a_n$ と $b_n$ は互いに素であることを示せ。

（2006 九州大学 前期 理系 第3問）

解答例

(1) は 3 で割った余りの帰納法。平方数を 3 で割った余りは 0 か 1。(2) は帰納法＋背理法で、$a_{n+1}$，$b_{n+1}$ が素数 $g$ を公約数にもつと仮定して矛盾を導きます。$b_n$ が常に奇数であることも使います。

解答例（タップで展開）

(1)

$a_2 = 2$，$b_2 = 3$，$a_3 = 12$，$b_3 = 17$。$n = 3$ では $a_3 = 12$ は 3 の倍数，$b_3 = 17$ は 3 の倍数でない。

$n = k\ (\ge 3)$ で成り立つとすると、$a_{k+1} = 2a_kb_k$ は 3 の倍数。また $b_k$ は 3 の倍数でないので ${b_k}^2 \equiv 1 \pmod 3$，$a_k \equiv 0$ より

$$b_{k+1} = 2{a_k}^2 + {b_k}^2 \equiv 0 + 1 = 1 \pmod 3$$

で 3 の倍数でない。帰納法により $n \ge 3$ で成り立つ。

(2)

まず $b_1 = 1$ は奇数で、$b_{n+1} = 2{a_n}^2 + {b_n}^2 \equiv {b_n}^2 \pmod 2$ なので $b_n$ はすべて奇数。

$n = 2$：$a_2 = 2$，$b_2 = 3$ は互いに素。$n = k\ (\ge 2)$ で $a_k$，$b_k$ が互いに素とし、$a_{k+1}$，$b_{k+1}$ が共通の素因数 $g$ をもつと仮定する。

  • $b_{k+1}$ は奇数なので $g \ne 2$。
  • $g \mid a_{k+1} = 2a_kb_k$，$g \ne 2$ より $g \mid a_k$ または $g \mid b_k$。
  • $g \mid a_k$ のとき：$g \mid b_{k+1} - 2{a_k}^2 = {b_k}^2$ より $g \mid b_k$。$a_k$，$b_k$ が互いに素なことに矛盾。
  • $g \mid b_k$ のとき：$g \mid b_{k+1} - {b_k}^2 = 2{a_k}^2$，$g \ne 2$ より $g \mid a_k$。同じく矛盾。

よって $a_{k+1}$，$b_{k+1}$ は互いに素。帰納法により $n \ge 2$ で成り立つ。

動く図解

BigInt で $a_n$，$b_n$ を正確に計算します。桁数が毎回ほぼ 2 倍になるので、$n = 10$ で数百桁。3 で割った余りと最大公約数、そして不思議な量 $b_n^2 - 2a_n^2$ も表示します。

問題の背景

正体は $(1 + \sqrt2)^{2^{n-1}}$

漸化式をよく見ると

$$b_{n+1} + \sqrt2\,a_{n+1} = {b_n}^2 + 2{a_n}^2 + 2\sqrt2\,a_nb_n = (b_n + \sqrt2\,a_n)^2$$

となっていて、$b_n + \sqrt2\,a_n = (1 + \sqrt2)^{2^{n-1}}$ です。同様に $b_n - \sqrt2\,a_n = (1 - \sqrt2)^{2^{n-1}}$ なので、かけ合わせると $n \ge 2$ で

$${b_n}^2 - 2{a_n}^2 = (-1)^{2^{n-1}} = 1$$

これはペル方程式 $x^2 - 2y^2 = 1$ の解で、$b_n/a_n$ は $\sqrt2$ の非常に良い近似（ニュートン法と同じ 2 乗収束）になっています。この式があれば $a_n$ と $b_n$ の公約数は 1 を割り切るので、(2) は一瞬で示せます。

chopin 先生は「(1) 平方数を 3 で割った余りが 0 か 1 になることに注目して考えます」「(2) 数学的帰納法と背理法のセットで考えます。$a_k$ と $b_k$ が互いに素だと仮定すると、もし $a_{k+1}$ と $b_{k+1}$ に公約数 $g$ があった時に矛盾する、という流れです。公約数 $g$ は、素数としても一般性を失わず、素数とした方が見通しが良くなります」とコメントしています。

「互いに素」の帰納法：共通の素因数 $g$ を仮定して矛盾。$x^2 - 2y^2 = 1$ の形が見えれば一発。

類題紹介

本問の数列について，$n \ge 2$ のとき ${b_n}^2 - 2{a_n}^2 = 1$ であることを示せ。

（自作）

略解

${b_{n+1}}^2 - 2{a_{n+1}}^2 = (2{a_n}^2 + {b_n}^2)^2 - 8{a_n}^2{b_n}^2 = ({b_n}^2 - 2{a_n}^2)^2$。$n = 2$ で $9 - 8 = 1$ なので、以後ずっと 1。

本問の数列について，$\displaystyle\lim_{n\to\infty}\frac{b_n}{a_n}$ を求めよ。

（九大 2006　魔改造）

略解

上の類題より $\left(\dfrac{b_n}{a_n}\right)^2 = 2 + \dfrac1{{a_n}^2}$（$n \ge 2$）。$a_n$ は正の整数で $a_{n+1} = 2a_nb_n \ge 2a_n$ より $a_n \to \infty$。$\dfrac{b_n}{a_n} > 0$ なので極限は $\sqrt2$。
