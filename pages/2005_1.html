直線 $l : y = x + a$ が曲線 $C : y = 2\sin x\ (-\pi \le x \le \pi)$ に接しているとき，次の問いに答えよ。ただし，$a \ge 0$ とする。

  1. (1)　$a$ の値を求めよ。
  2. (2)　曲線 $C$ と直線 $l$ で囲まれた図形の $y \ge 0$ の範囲にある部分を，$x$ 軸のまわりに回転する。この回転体の体積を求めよ。

（2005 九州大学 前期 理系 第1問）

解答例

接点の $x$ 座標を $t$ として「傾きが等しい」「点を共有」。(2) は「直線の下（円錐）」から「$\sin$ カーブの下」をくり抜く形。直線と $x$ 軸の交点から接点までが円錐になり、高さ・半径とも $\sqrt3$ という美しい数値です。

解答例（タップで展開）

(1)

接点の $x$ 座標を $t$ とすると $2\cos t = 1$，$t + a = 2\sin t$。$-\pi \le t \le \pi$ より $t = \pm\frac\pi3$。

  • $t = \frac\pi3$：$a = \sqrt3 - \frac\pi3$（$\sqrt3 > 1.7 > \frac\pi3$ なので $a > 0$）
  • $t = -\frac\pi3$：$a = -\sqrt3 + \frac\pi3 < 0$ で不適
$$a = \sqrt3 - \frac\pi3$$

(2)

$h(x) = 2\sin x - x - a$ は $h'(x) = 2\cos x - 1$ より $x = \frac\pi3$ で極大値 $0$ をとるので、接点以外では直線が曲線より上にある。直線は $x = -a$ で $x$ 軸と交わり、$-a < 0$。

$y \ge 0$ の部分は、$-a \le x \le 0$ では $0 \le y \le x + a$（曲線は $y \le 0$），$0 \le x \le \frac\pi3$ では $2\sin x \le y \le x + a$。よって

$$V = \pi\int_{-a}^{\pi/3}(x + a)^2dx - \pi\int_0^{\pi/3}4\sin^2x\,dx$$

第 1 項は底面の半径 $\frac\pi3 + a = \sqrt3$，高さ $\frac\pi3 + a = \sqrt3$ の円錐なので $\frac13\pi(\sqrt3)^2\cdot\sqrt3 = \sqrt3\pi$。

$$\pi\int_0^{\pi/3}4\sin^2x\,dx = 2\pi\int_0^{\pi/3}(1 - \cos2x)dx = 2\pi\left(\frac\pi3 - \frac{\sqrt3}{4}\right) = \frac{2\pi^2}{3} - \frac{\sqrt3}{2}\pi$$ $$V = \sqrt3\pi - \frac{2\pi^2}3 + \frac{\sqrt3}2\pi = \frac{3\sqrt3}{2}\pi - \frac{2}{3}\pi^2$$

動く図解

赤い部分が回転させる図形です。$x$ を動かすと、その位置での回転体の断面（外半径＝直線，内半径＝曲線）が表示されます。

問題の背景

円錐の体積で計算をショートカット

直線を $x$ 軸のまわりに回すと円錐。積分 $\pi\int(x + a)^2dx$ を真面目に計算してもいいですが、「半径 $\sqrt3$，高さ $\sqrt3$ の円錐」と見抜けば一瞬です。$\frac\pi3 + a = \sqrt3$ となるのは、接点の $y$ 座標 $2\sin\frac\pi3 = \sqrt3$ と傾き 1 から当然。もう一つの注意点は「$y \ge 0$ の部分」で、$-a \le x \le 0$ では $\sin$ カーブが $x$ 軸の下にあるので、くり抜くのは $0 \le x \le \frac\pi3$ の部分だけです。

chopin 先生は「(1) 接点の $x$ 座標を $t$ とすると、$f(x) = x + a$ と $g(x) = 2\sin x$ について、$f(t) = g(t)$ と $f'(t) = g'(t)$ が同時に成立します」「(2) グラフに描いて、素直に積分計算です。円錐の体積の知識を使えると積分の計算量が減らせます」とコメントしています。

接線条件は「値」と「傾き」の一致。直線の回転は円錐の公式で。

類題紹介

曲線 $y = 2\sin x\ (0 \le x \le \pi)$ と $x$ 軸で囲まれた部分を，$x$ 軸のまわりに 1 回転してできる立体の体積を求めよ。

（自作）

略解

$\pi\displaystyle\int_0^\pi4\sin^2x\,dx = 2\pi\int_0^\pi(1 - \cos2x)dx = 2\pi^2$。

原点を通る直線 $y = kx$ が曲線 $y = 2\sin x\ (0 \le x \le \pi)$ と $x = \dfrac\pi2$ で交わるとする。直線と曲線で囲まれた部分（$0 \le x \le \frac\pi2$）を，$x$ 軸のまわりに 1 回転してできる立体の体積を求めよ。

（九大 2005　魔改造）

略解

$k = \dfrac4\pi$。$0 \le x \le \frac\pi2$ で曲線が直線より上（$\sin$ は上に凸）なので

$$V = \pi\int_0^{\pi/2}4\sin^2x\,dx - \frac13\pi\cdot2^2\cdot\frac\pi2 = \pi^2 - \frac{2\pi^2}{3} = \frac{\pi^2}{3}$$
