関数

$$f(x) = \int_x^{x+1}\log(4t^2 + 1)\,dt$$

に関して，以下の問いに答えよ。

  1. (1)　$f(x)$ が極値をとるときの $x$ の値を求めよ。また，そのときの極値を求めよ。
  2. (2)　極限 $\displaystyle\lim_{x\to\infty} x\{f(x) - f(x-1)\}$ を求めよ。

（2026 九州大学 前期 理系 第5問）

解答例

(1) は積分を計算せずに微分（微分積分学の基本定理）。極値の計算だけ部分積分と $\tan$ 置換が必要。(2) は $f(x) - f(x-1)$ を平均値の定理で $f'(c)$ に置き換えるのが鍵。

解答例（タップで展開）

$g(t) = \log(4t^2+1)$ とおく。

(1)

$$f'(x) = g(x+1) - g(x) = \log\frac{4x^2 + 8x + 5}{4x^2 + 1} = \log\left(1 + \frac{8x+4}{4x^2+1}\right)$$

よって $f'(x)$ の符号は $8x + 4$ の符号と一致し、$x \lt -\dfrac12$ で負、$x \gt -\dfrac12$ で正。$f(x)$ は $x = -\dfrac12$ で極小値をとり、これ以外に極値はない。

$g$ は偶関数なので

$$f\left(-\frac12\right) = \int_{-\frac12}^{\frac12} g(t)\,dt = 2\int_0^{\frac12}\log(4t^2+1)\,dt$$

部分積分して

$$\int_0^{\frac12}\log(4t^2+1)\,dt = \Bigl[t\log(4t^2+1)\Bigr]_0^{\frac12} - \int_0^{\frac12}\frac{8t^2}{4t^2+1}\,dt = \frac12\log2 - \int_0^{\frac12}\left(2 - \frac{2}{4t^2+1}\right)dt$$

ここで $2t = \tan\theta$ と置換すると $dt = \dfrac{d\theta}{2\cos^2\theta}$、$t: 0 \to \dfrac12$ のとき $\theta: 0 \to \dfrac{\pi}{4}$ で

$$\int_0^{\frac12}\frac{dt}{4t^2+1} = \int_0^{\frac{\pi}{4}}\cos^2\theta\cdot\frac{d\theta}{2\cos^2\theta} = \frac{\pi}{8}$$

よって $\displaystyle\int_0^{\frac12}\log(4t^2+1)\,dt = \frac12\log 2 - 1 + \frac{\pi}{4}$ となり、

$$\text{極小値}\quad f\left(-\frac12\right) = \log 2 - 2 + \frac{\pi}{2}\qquad\left(x = -\frac12\ \text{のとき}\right)$$

(2)

$f(x)$ は微分可能なので、平均値の定理より

$$f(x) - f(x-1) = f'(c),\qquad x - 1 \lt c \lt x$$

をみたす $c$ が存在する。$h = \dfrac{8c+4}{4c^2+1}$ とおくと、$x \to \infty$ のとき $c \to \infty$、$h \to 0$ で

$$x\{f(x) - f(x-1)\} = x\log(1 + h) = xh\cdot\frac{\log(1+h)}{h}$$

$1 - \dfrac1x \lt \dfrac{c}{x} \lt 1$ より $\dfrac{c}{x} \to 1$ なので

$$xh = \frac{8\cdot\frac{c}{x} + \frac{4}{x}}{4\left(\frac{c}{x}\right)^2 + \frac{1}{x^2}} \to \frac{8}{4} = 2,\qquad \frac{\log(1+h)}{h} \to 1$$

（後者は $\displaystyle\lim_{h\to0}\frac{\log(1+h)}{h} = 1$）。したがって

$$\lim_{x\to\infty} x\{f(x) - f(x-1)\} = 2$$

動く図解

$f(x)$ は、グラフ $y = \log(4t^2+1)$ の下で、幅 $1$ の「窓」$[x,\ x+1]$ に入る部分の面積です。窓を左右に動かして、面積が最小になる位置を確かめましょう。右のグラフは (2) の $x\{f(x) - f(x-1)\}$ が $2$ に近づく様子です。

問題の背景

(1)：窓の位置と面積

$f'(x) = g(x+1) - g(x) = 0$ は「窓の両端でグラフの高さが等しい」という条件です。$g$ は偶関数で $|t|$ について増加するので、窓が原点に対して左右対称な位置、つまり $[-\frac12,\ \frac12]$ のときに面積が最小になります。図解で、窓の両端の高さがそろう瞬間が最小値だと確かめられます。

(2)：「差分」は「微分」の離散版

$g$ の原始関数を $G$ とすると $f(x) = G(x+1) - G(x)$ なので

$$f(x) - f(x-1) = G(x+1) - 2G(x) + G(x-1)$$

これは $G$ の2 階差分で、刻みが十分小さければ 2 階微分 $G''(x) = g'(x)$ に近い量です。実際、刻み $1$ でも $x$ が大きければ $g$ はゆるやかに変化するので

$$x\{f(x) - f(x-1)\} \approx x\,g'(x) = \frac{8x^2}{4x^2+1} \to 2$$

となり、答えの $2$ が見通せます。さらに言えば、$x$ が大きいとき $g(x) = \log(4x^2+1) \approx 2\log x + \log 4$ なので、$x\,g'(x) \to 2$ の「$2$」は$\log x^2$ の指数 $2$そのものです。

平均値の定理は「差 $\to$ 微分」の橋渡し。$f(x) - f(x-1)$ のような差の極限は、まず平均値の定理を疑うのが定石です。

類題紹介

本問の $f(x)$ について，極限 $\displaystyle\lim_{x\to\infty}\{f(x) - 2\log x\}$ を求めよ。

（自作）

略解

$\log(4t^2+1) = \log 4 + 2\log t + \log\left(1 + \dfrac{1}{4t^2}\right)$ と分ける（$t \gt 0$）。

  • $0 \lt \log\left(1 + \dfrac{1}{4t^2}\right) \lt \dfrac{1}{4t^2} \le \dfrac{1}{4x^2}$ より、この部分の積分は $0$ に収束。
  • $\log x \le \displaystyle\int_x^{x+1}\log t\,dt \le \log(x+1)$ より $0 \le 2\displaystyle\int_x^{x+1}\log t\,dt - 2\log x \le 2\log\left(1 + \frac1x\right) \to 0$。

よって極限は $\log 4 = 2\log 2$。

$a$ を正の定数とし，$f_a(x) = \displaystyle\int_x^{x+a}\log(4t^2+1)\,dt$ とする。$f_a(x)$ が最小となる $x$ の値と，極限 $\displaystyle\lim_{x\to\infty}x\{f_a(x) - f_a(x-a)\}$ を求めよ。

（九大 2026　魔改造）

略解

$f_a'(x) = \log\dfrac{4(x+a)^2+1}{4x^2+1}$ の符号は $(x+a)^2 - x^2 = a(2x + a)$ の符号と一致するので、最小となるのは $x = -\dfrac{a}{2}$（窓が原点対称のとき）。

平均値の定理より $f_a(x) - f_a(x-a) = a f_a'(c)$（$x - a \lt c \lt x$）。$f_a'(c) = \log\left(1 + \dfrac{8ac + 4a^2}{4c^2+1}\right)$ で、本問と同様に $\dfrac{c}{x} \to 1$ から

$$x\cdot a f_a'(c) \to a\cdot\frac{8a}{4} = 2a^2$$

刻み $a$ の 2 階差分は「刻みの 2 乗 × 2 階微分」程度の大きさになる、ということが $a^2$ に表れています。
