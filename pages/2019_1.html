$n$ を自然数とする。$x,\ y$ がすべての実数を動くとき，定積分

$$\int_0^1\left(\sin(2n\pi t) - xt - y\right)^2dt$$

の最小値を $I_n$ とおく。極限 $\displaystyle\lim_{n\to\infty}I_n$ を求めよ。

（2019 九州大学 前期 理系 第1問）

解答例

積分を実行すると $x,\ y$ の 2 次式になるので、平方完成で最小値が求まる。必要な積分は $\int_0^1\sin^2(2n\pi t)\,dt$ と $\int_0^1 t\sin(2n\pi t)\,dt$（部分積分）。

解答例（タップで展開）

$k = 2n\pi$ とおく。$\cos k = 1$，$\sin k = 0$ に注意して

$$\int_0^1\sin^2 kt\,dt = \int_0^1\frac{1 - \cos 2kt}{2}\,dt = \frac12,\qquad \int_0^1\sin kt\,dt = \left[-\frac{\cos kt}{k}\right]_0^1 = 0$$ $$\int_0^1 t\sin kt\,dt = \left[-\frac{t\cos kt}{k}\right]_0^1 + \frac1k\int_0^1\cos kt\,dt = -\frac1k = -\frac{1}{2n\pi}$$

よって、積分を $F(x,\ y)$ とすると

$$\begin{aligned} F &= \int_0^1\sin^2 kt\,dt - 2x\int_0^1 t\sin kt\,dt - 2y\int_0^1\sin kt\,dt + x^2\int_0^1 t^2dt + 2xy\int_0^1 t\,dt + y^2 \\ &= \frac12 + \frac{x}{n\pi} + \frac{x^2}{3} + xy + y^2 \end{aligned}$$

$y$ について平方完成すると

$$F = \left(y + \frac x2\right)^2 + \frac{x^2}{12} + \frac{x}{n\pi} + \frac12 = \left(y + \frac x2\right)^2 + \frac{1}{12}\left(x + \frac{6}{n\pi}\right)^2 + \frac12 - \frac{3}{n^2\pi^2}$$

$x = -\dfrac{6}{n\pi}$，$y = \dfrac{3}{n\pi}$ のとき最小で

$$I_n = \frac12 - \frac{3}{n^2\pi^2},\qquad \lim_{n\to\infty}I_n = \frac12$$

動く図解

積分の値は、曲線 $y = \sin(2n\pi t)$（赤）と直線 $y = xt + y$（青）の「ずれの 2 乗」の合計です。$x,\ y$ を動かして積分を小さくしてみましょう。$n$ が大きいと sin が細かく振動し、どんな直線でも近似できなくなっていきます（最小値 → $\frac12$）。

問題の背景

最小 2 乗法と直交射影

$\int_0^1(f(t) - g(t))^2\,dt$ を「関数どうしの距離の 2 乗」と見ると、本問は「関数 $\sin(2n\pi t)$ に最も近い 1 次関数を探す」問題、つまり最小 2 乗近似です。最適な 1 次関数は、$\sin(2n\pi t)$ を「1 次関数全体という平面」に直交射影したものになります。

このとき「ピタゴラスの定理」が成り立ち、

$$\underbrace{\int_0^1\sin^2(2n\pi t)\,dt}_{=\frac12} = \underbrace{\int_0^1(\text{射影})^2\,dt}_{=\frac{3}{n^2\pi^2}} + I_n$$

となっています。$n \to \infty$ で sin が激しく振動すると、1 次関数との「重なり」がなくなって射影が $0$ に近づき、$I_n \to \frac12$ となるわけです。この考え方はフーリエ級数につながります。

chopin 先生は「素直に積分計算実行して最小値を求めればよい」「計算ミスだけには注意しましょう」とコメントしています。

2 変数 2 次式の最小値は、一方の文字について平方完成 → 残りの文字について平方完成。等号成立の $(x,\ y)$ も必ず確認。

類題紹介

$x,\ y$ がすべての実数を動くとき，$\displaystyle\int_0^1(t^2 - xt - y)^2\,dt$ の最小値と，そのときの $x,\ y$ を求めよ。

（自作）

略解
$$\int_0^1(t^2 - xt - y)^2dt = \frac15 - \frac x2 - \frac{2y}{3} + \frac{x^2}{3} + xy + y^2 = \left(y + \frac x2 - \frac13\right)^2 + \frac{1}{12}(x - 1)^2 + \frac{1}{180}$$

$x = 1,\ y = -\frac16$ で最小値 $\dfrac{1}{180}$。（$t^2 - t + \frac16$ は 1 次関数すべてと「直交」しています。）

$n$ を自然数とする。$x,\ y,\ z$ がすべての実数を動くとき，$\displaystyle\int_0^1\left(\sin(2n\pi t) - xt^2 - yt - z\right)^2dt$ の最小値 $J_n$ を求めよ。

（九大 2019　魔改造）

略解

$\int_0^1 t^2\sin kt\,dt = -\frac1k$（部分積分を 2 回）など、必要な積分を計算して $x,\ y,\ z$ で偏微分 $= 0$ の連立方程式を解くと $x = 0$，$y = -\frac{6}{n\pi}$，$z = \frac{3}{n\pi}$。つまり 2 次の項は役に立たず

$$J_n = \frac12 - \frac{3}{n^2\pi^2} = I_n$$

背景：$6t^2 - 6t + 1$（ルジャンドル多項式）と $\sin(2n\pi t)$ の積の積分が $6\cdot(-\frac1k) - 6\cdot(-\frac1k) + 0 = 0$ なので、2 次の成分の射影が $0$ になるのです。
