$\triangle OAB$ において，辺 $AB$ 上に点 $Q$ をとり，直線 $OQ$ 上に点 $P$ をとる。ただし，点 $P$ は点 $Q$ に関して点 $O$ と反対側にあるとする。3 つの三角形 $\triangle OAP$，$\triangle OBP$，$\triangle ABP$ の面積をそれぞれ $a,\ b,\ c$ とする。このとき，次の問いに答えよ。

  1. (1)　$\overrightarrow{OQ}$ を $\overrightarrow{OA},\ \overrightarrow{OB}$ および $a,\ b$ を用いて表せ。
  2. (2)　$\overrightarrow{OP}$ を $\overrightarrow{OA},\ \overrightarrow{OB}$ および $a,\ b,\ c$ を用いて表せ。
  3. (3)　3 辺 $OA,\ OB,\ AB$ の長さはそれぞれ 3，5，6 であるとする。点 $P$ を中心とし，3 直線 $OA,\ OB,\ AB$ に接する円が存在するとき，$\overrightarrow{OP}$ を $\overrightarrow{OA}$ と $\overrightarrow{OB}$ を用いて表せ。

（2008 九州大学 前期 理系 第3問）

解答例

面積比 ＝ 線分比。$\triangle OAP$ と $\triangle OBP$ は底辺 $OP$ を共有するので、面積比は $A,\ B$ から直線 $OP$ までの距離の比 $= AQ : QB$。(3) の $P$ は傍心で、3 つの面積がすべて半径 $r$ で表せます。

解答例（タップで展開）

(1)

$\triangle OAP$，$\triangle OBP$ は底辺 $OP$ が共通で、高さの比は $A,\ B$ から直線 $OQ$ までの距離の比、すなわち $AQ : QB$。よって $AQ : QB = a : b$。

$$\overrightarrow{OQ} = \frac{b\overrightarrow{OA} + a\overrightarrow{OB}}{a + b}$$

(2)

四角形 $OAPB$ の面積は $a + b = \triangle OAB + \triangle ABP$ なので $\triangle OAB = a + b - c$。$\triangle OAB$ と $\triangle PAB$ は底辺 $AB$ を共有し、高さの比は $OQ : QP$ なので $OQ : QP = (a + b - c) : c$，$OP = \dfrac{a + b}{a + b - c}OQ$。

$$\overrightarrow{OP} = \frac{b\overrightarrow{OA} + a\overrightarrow{OB}}{a + b - c}$$

(3)

円の半径を $r$ とすると、$P$ から 3 直線までの距離はすべて $r$ なので

$$a = \frac12\cdot OA\cdot r = \frac32r,\qquad b = \frac12\cdot OB\cdot r = \frac52r,\qquad c = \frac12\cdot AB\cdot r = 3r$$

$a + b - c = r$ なので、(2) より

$$\overrightarrow{OP} = \frac{\frac52r\,\overrightarrow{OA} + \frac32r\,\overrightarrow{OB}}{r} = \frac52\overrightarrow{OA} + \frac32\overrightarrow{OB}$$

動く図解

$OA = 3$，$OB = 5$，$AB = 6$ の三角形で、$Q$ の位置と $P$ の遠さを動かすと、面積 $a,\ b,\ c$ と (2) の式の値が比べられます。「傍心」ボタンで (3) の $P$ と傍接円を表示します。

問題の背景

傍心 ─ 五心のなかで最もマイナー？

1 つの内角の二等分線と、残り 2 つの外角の二等分線は 1 点で交わり、その点を傍心、傍心を中心に 3 辺（の延長）に接する円を傍接円と呼びます。1 つの三角形に傍心は 3 つあります。本問の $P$ は $O$ の内角の二等分線上にある傍心です。

内心 $I$ が $\overrightarrow{OI} = \dfrac{(OB)\overrightarrow{OA} + (OA)\overrightarrow{OB}}{OA + OB + AB}$ と表せるのと同じ形で、傍心は分母の $AB$ の符号を変えた $\dfrac{(OB)\overrightarrow{OA} + (OA)\overrightarrow{OB}}{OA + OB - AB}$ になります。本問では $\dfrac{5\overrightarrow{OA} + 3\overrightarrow{OB}}{2}$。

chopin 先生は「三角形の傍接円を考える問題です。傍心は中々珍しい題材ですね」「この円の半径を $r$ とおいてよく見てみると、$\triangle OAP,\ \triangle OBP,\ \triangle ABP$ の面積の値が、$r$ で全て表現できてしまうことが分かります」「これにより、(2) の $a,\ b,\ c$ の比が分かってしまうので、$P$ の表現が求まってしまうわけです」とコメントしています。

面積比 ⇔ 線分比（底辺共通なら高さの比）。円の中心から接線までの距離 ＝ 半径 を使うと、三角形の面積が半径の 1 次式になる。

類題紹介

$OA = 3$，$OB = 5$，$AB = 6$ の $\triangle OAB$ の内心を $I$ とする。$\overrightarrow{OI}$ を $\overrightarrow{OA},\ \overrightarrow{OB}$ で表せ。

（自作）

略解

内接円の半径を $\rho$ とすると $\triangle OAI = \frac32\rho$，$\triangle OBI = \frac52\rho$，$\triangle ABI = 3\rho$。$OI$ の延長と $AB$ の交点を $Q$ とすると $AQ : QB = 3 : 5$，$OI : IQ = (\frac32 + \frac52) : 3 = 4 : 3$。

$$\overrightarrow{OI} = \frac47\cdot\frac{5\overrightarrow{OA} + 3\overrightarrow{OB}}{8} = \frac{5\overrightarrow{OA} + 3\overrightarrow{OB}}{14}$$

本問 (3) の円の半径 $r$ を求めよ。

（九大 2008　魔改造）

略解

(3) の計算から $\triangle OAB = a + b - c = r$。ヘロンの公式で $s = \frac{3 + 5 + 6}{2} = 7$，$\triangle OAB = \sqrt{7\cdot4\cdot2\cdot1} = 2\sqrt{14}$。よって $r = 2\sqrt{14}$。

（一般に傍接円の半径は $\dfrac{S}{s - (\text{対辺})}$。内接円の半径 $\dfrac{S}{s} = \dfrac{2\sqrt{14}}{7}$ と比べるとかなり大きい。）
