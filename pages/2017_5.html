2 つの複素数 $\alpha = 10000 + 10000i$ と $w = \dfrac{\sqrt3}{4} + \dfrac14i$ を用いて，複素数平面上の点 $\mathrm{P}_n(z_n)$ を $z_n = \alpha w^n$（$n = 1,\ 2,\ \cdots$）により定める。ただし，$i$ は虚数単位を表す。2 と 3 の常用対数を $\log_{10}2 = 0.301$，$\log_{10}3 = 0.477$ として，以下の問いに答えよ。

  1. (1)　$z_n$ の絶対値 $|z_n|$ と偏角 $\arg z_n$ を求めよ。
  2. (2)　$|z_n| \le 1$ が成り立つ最小の自然数 $n$ を求めよ。
  3. (3)　下図のように，複素数平面上の $\triangle\mathrm{ABC}$ は線分 $\mathrm{AB}$ を斜辺とし，点 $\mathrm{C}\left(\dfrac{i}{\sqrt2}\right)$ を一つの頂点とする直角二等辺三角形である。なお $\mathrm{A},\ \mathrm{B}$ を表す複素数の虚部は負であり，原点 O と 2 点 A，B の距離はともに 1 である。点 $\mathrm{P}_n$ が $\triangle\mathrm{ABC}$ の内部に含まれる最小の自然数 $n$ を求めよ。

（図の π/6 は ∠OAC，∠OBC。辺 AC，BC は x 軸と π/4 の角をなす。）

（2017 九州大学 前期 理系 第5問）

解答例

$w = \frac12\left(\cos\frac\pi6 + i\sin\frac\pi6\right)$ なので、$z_n$ は「回転しながら半分ずつ縮む」点列。偏角は 12 通りしかないので、各方向で三角形の内部に入るための半径の上限を調べる。

解答例（タップで展開）

(1)

$\alpha = 10000\sqrt2\left(\cos\frac\pi4 + i\sin\frac\pi4\right)$，$w = \frac12\left(\cos\frac\pi6 + i\sin\frac\pi6\right)$ より

$$|z_n| = \frac{10000\sqrt2}{2^n} = 10^4\cdot2^{\frac12 - n},\qquad \arg z_n = \frac\pi4 + \frac{n\pi}{6}$$

(2)

$|z_n| \le 1 \iff 2^{n - \frac12} \ge 10^4 \iff \left(n - \frac12\right)\cdot0.301 \ge 4 \iff n \ge \frac12 + \frac{4}{0.301} = 13.78\cdots$。最小の $n$ は $\mathbf{14}$。

(3)

三角形の位置。$\angle\mathrm{CAB} = \frac\pi4$，$\angle\mathrm{OAC} = \frac\pi6$ より $\angle\mathrm{OAB} = \frac{\pi}{12}$。よって

$$\mathrm{A} = \left(-\cos\tfrac{\pi}{12},\ -\sin\tfrac{\pi}{12}\right),\quad \mathrm{B} = \left(\cos\tfrac{\pi}{12},\ -\sin\tfrac{\pi}{12}\right)$$

（実際 $\cos\frac\pi{12} - \sin\frac\pi{12} = \frac{1}{\sqrt2}$ で、C から傾き $\pm1$ の直線上にある。）三角形の頂点はすべて単位円の周上または内部にあるので、三角形の内部の点は $|z| \lt 1$ をみたす。

必要条件。(2) より $|z_n| \lt 1$ となるのは $n \ge 14$（$n = 13$ 以下では $|z_n| \gt 1$）。

$n = 14$。$\arg z_{14} = \frac\pi4 + \frac{7\pi}{3} \equiv \frac{7\pi}{12}$。この方向の半直線は辺 AC（直線 $y = x + \frac{1}{\sqrt2}$）と原点から距離 $r = \dfrac{1/\sqrt2}{\sin\frac{7\pi}{12} - \cos\frac{7\pi}{12}} = \dfrac{1}{2\sin\frac\pi3} = \dfrac{1}{\sqrt3}$ の点で交わる。

$\log_{10}|z_{14}|^2 = 8 - 27\cdot0.301 = -0.127 \gt -0.477 = \log_{10}\frac13$ なので $|z_{14}| \gt \frac1{\sqrt3}$。$\mathrm{P}_{14}$ は三角形の外。

$n = 15$。$\arg z_{15} = \frac\pi4 + \frac{5\pi}{2} \equiv \frac{3\pi}{4}$。これは辺 AC に垂直な方向で、O から直線 AC までの距離は $\frac{1/\sqrt2}{\sqrt2} = \frac12$。

$|z_{15}| \lt \frac12 \iff 10^4\cdot2^{-\frac{29}{2}} \lt 2^{-1} \iff 10^4 \lt 2^{\frac{27}{2}}$。$\frac{27}{2}\cdot0.301 = 4.0635 \gt 4$ なので成立。$\arg z_{15} = \frac{3\pi}{4}$ 方向の点は $y \gt 0 \gt -\sin\frac\pi{12}$ で辺 AB より上にあるから、$\mathrm{P}_{15}$ は三角形の内部。

よって求める最小の $n$ は $\mathbf{15}$。

動く図解

$n$ を動かすと $\mathrm{P}_n$ が回転しながら原点に近づきます。破線の円は、その方向で三角形の内部に入るための半径の上限です。$n = 14$ では惜しくも外、$n = 15$ で初めて内部に入ります。

問題の背景

回転しながら縮む点列

$z_{n+1} = wz_n$ は「$30^\circ$ 回転して $\frac12$ 倍」する操作なので、$\mathrm{P}_n$ は原点に向かう等角らせん上に並びます。12 回で一周するので、方向は 12 通りしかありません。

chopin 先生は「(1)(2) はあまり大したことありませんが、(3) が非常に重たい問題です。本番では捨てて OK」「12 方向それぞれに対して、絶対値がどれだけあると三角形の中に入るかを検討しないといけない」とコメントしています。

ただし「三角形は単位円に含まれる」ことに気づけば、(2) から $n \ge 14$ に絞れて、調べるのは $n = 14,\ 15$ の 2 方向だけで済みます。(2) が (3) の強力な誘導になっているわけです。

点列 $\alpha w^n$ は極形式で「絶対値 $r^n$・偏角 $n\theta$」に分解する。図形に含まれる条件は、図形を円で外から押さえて候補を絞ると調べる範囲が小さくなる。

類題紹介

$z_n = (1 + i)^n$ とする。$|z_n| \ge 1000$ となる最小の自然数 $n$ と，そのときの $z_n$ を求めよ。ただし $\log_{10}2 = 0.301$ とする。

（自作）

略解

$|z_n| = 2^{\frac n2} \ge 10^3 \iff n \ge \frac{6}{0.301} = 19.9\cdots$ より $n = 20$。$z_{20} = (\sqrt2)^{20}(\cos 5\pi + i\sin 5\pi) = -1024$。

本問の点列で，$\mathrm{P}_n$ が「単位円の内部，かつ第 1 象限（座標軸上を除く）」にある最小の自然数 $n$ を求めよ。

（九大 2017　魔改造）

略解

単位円の内部 $\iff n \ge 14$。$\arg z_n = \frac\pi4 + \frac{n\pi}6$ が $\left(0,\ \frac\pi2\right)$（mod $2\pi$）に入るのは $n \equiv 11,\ 0,\ 1 \pmod{12}$（偏角 $15^\circ,\ 45^\circ,\ 75^\circ$）。$n \ge 14$ で最小は $n = \mathbf{23}$。
