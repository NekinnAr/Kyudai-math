$0$ でない 2 つの整式 $f(x),\ g(x)$ が以下の恒等式を満たすとする。

$$f(x^2) = (x^2 + 2)g(x) + 7$$ $$g(x^3) = x^4f(x) - 3x^2g(x) - 6x^2 - 2$$

以下の問いに答えよ。

  1. (1)　$f(x)$ の次数と $g(x)$ の次数はともに $2$ 以下であることを示せ。
  2. (2)　$f(x)$ と $g(x)$ を求めよ。

（2019 九州大学 前期 理系 第2問）

解答例

$f,\ g$ の次数を $m,\ n$ として両辺の次数を比べる。1 つ目の式から $2m = n + 2$。2 つ目の式は右辺の $x^4f(x)$ と $3x^2g(x)$ のどちらの次数が大きいかで場合分けが必要。(2) は特別な $x$ の値を代入して必要条件を出し、最後に十分性を確認する。

解答例（タップで展開）

(1)

$f(x),\ g(x)$ の次数をそれぞれ $m,\ n$（$m,\ n \ge 0$）とする。

1 つ目の式：右辺 $(x^2 + 2)g(x) + 7$ の次数は $n + 2\ (\ge 2)$ なので、左辺 $f(x^2)$ の次数 $2m$ と比べて $2m = n + 2$。特に $m \ge 1$ で、$n = 2m - 2$。

2 つ目の式：左辺の次数は $3n = 6m - 6$。右辺の $x^4f(x)$ の次数は $m + 4$，$3x^2g(x)$ の次数は $n + 2 = 2m$。

  • $m + 4 \gt 2m$（$m \le 3$）のとき：右辺の次数は $m + 4\ (\ge 5)$ なので $6m - 6 = m + 4$、$m = 2$。
  • $m + 4 \lt 2m$（$m \ge 5$）のとき：右辺の次数は $2m$ なので $6m - 6 = 2m$、$m = \frac32$ で不適。
  • $m = 4$ のとき：右辺の次数は $8$ 以下（最高次が打ち消し合う可能性がある）だが、左辺の次数は $3n = 18$ で矛盾。

よって $m = 2$，$n = 2$ で、ともに $2$ 以下。

(2)

1 つ目の式に $x = 0$ を代入：$f(0) = 2g(0) + 7$。
2 つ目の式に $x = 0$：$g(0) = -2$。よって $f(0) = 3$。
2 つ目の式に $x = 1$：$g(1) = f(1) - 3g(1) - 8$ より $f(1) = 4g(1) + 8$。
1 つ目の式に $x = 1$：$f(1) = 3g(1) + 7$。2 式から $g(1) = -1$，$f(1) = 4$。
2 つ目の式に $x = -1$：$g(-1) = f(-1) - 3g(-1) - 8$ より $f(-1) = 4g(-1) + 8$。
1 つ目の式に $x = -1$：$f(1) = 3g(-1) + 7$ より $g(-1) = -1$，$f(-1) = 4$。

$f,\ g$ は 2 次以下なので、3 点での値から決まる（ラグランジュ補間）。$f(0) = 3,\ f(\pm1) = 4$ より $f(x) = x^2 + 3$。$g(0) = -2,\ g(\pm1) = -1$ より $g(x) = x^2 - 2$。

十分性の確認：

$$f(x^2) = x^4 + 3,\quad (x^2 + 2)(x^2 - 2) + 7 = x^4 + 3$$ $$g(x^3) = x^6 - 2,\quad x^4(x^2 + 3) - 3x^2(x^2 - 2) - 6x^2 - 2 = x^6 - 2$$

ともに恒等式として成り立つ。よって

$$f(x) = x^2 + 3,\qquad g(x) = x^2 - 2$$

動く図解

$f$ の次数 $m$ を選ぶと（$n = 2m - 2$ が自動で決まります）、2 つ目の式の各項の次数が棒グラフで表示されます。左辺 $g(x^3)$ の次数（赤）と右辺の最大次数が一致するのは $m = 2$ のときだけです。

問題の背景

次数の比較と「打ち消し合い」

整式の恒等式では、まず次数を比べるのが定石です。ただし「和の次数」は、2 つの項の次数が等しいと最高次の係数が打ち消し合って下がることがあります。本問の $m = 4$ のケースがまさにそれで、chopin 先生も「2 番目の式の処理には注意が必要」「$m$ と $n$ の大小関係によって、右辺の次数が変化するのでそれぞれ検討が必要」とコメントしています。

必要条件と十分条件

(2) で $x = 0,\ \pm1$ を代入して得た式は、あくまで必要条件です。chopin 先生も「まだ必要条件であることに注意」「ちゃんと恒等式になることを確認し、十分条件でもあることを言いましょう」と強調しています。

恒等式の問題：①次数を比べて形を決める（打ち消しに注意）　②特別な値の代入で必要条件　③元の式に戻して十分性を確認。

類題紹介

$f(x^2) = (x + 1)f(x)$ を満たす $0$ でない整式 $f(x)$ をすべて求めよ。

（自作）

略解

次数を $m$ とすると $2m = m + 1$ より $m = 1$。$f(x) = px + q\ (p \neq 0)$ とおくと $px^2 + q = px^2 + (p + q)x + q$ より $q = -p$。よって $f(x) = p(x - 1)$（$p$ は $0$ でない定数）。

$f(x^2) = f(x)f(x + 1)$ を満たす 2 次式 $f(x)$ を求めよ。

（九大 2019　魔改造）

略解

$f(x) = ax^2 + bx + c\ (a \neq 0)$ とおく。$x^4$ の係数を比べて $a = a^2$ より $a = 1$。このとき $f(x)f(x + 1) = (x^2 + bx + c)\{x^2 + (b + 2)x + (1 + b + c)\}$。

$f(x^2) = x^4 + bx^2 + c$ と係数を比べる。$x^3$：$0 = 2b + 2$ より $b = -1$。$x^2$：$b = 1 + 3b + b^2 + 2c$ に $b = -1$ を代入して $c = 0$。このとき $x$ の係数・定数項も一致し、$f(x) = x^2 - x$。

確認：$f(x)f(x + 1) = x(x - 1)\cdot(x + 1)x = x^2(x^2 - 1) = f(x^2)$。（一般に $f(x) = (x^2 - x)^k$ が解になります。）
