三角関数 $\cos x,\ \sin x$ については加法定理が成立するが，逆に加法定理を満たす関数はどのようなものがあるだろうか。実数全体を定義域とする実数値関数 $f(x),\ g(x)$ が以下の条件を満たすとする。

(A)　すべての $x,\ y$ について $f(x + y) = f(x)f(y) - g(x)g(y)$
(B)　すべての $x,\ y$ について $g(x + y) = f(x)g(y) + g(x)f(y)$
(C)　$f(0) \neq 0$
(D)　$f(x),\ g(x)$ は $x = 0$ で微分可能で $f'(0) = 0,\ g'(0) = 1$

条件 (A), (B), (C) から $f(0) = 1,\ g(0) = 0$ がわかる。①　以上のことから $f(x),\ g(x)$ はすべての $x$ の値で微分可能で，$f'(x) = -g(x),\ g'(x) = f(x)$ が成立する②ことが示される。上のことから $\{f(x) + ig(x)\}(\cos x - i\sin x) = 1$ であることが，実部と虚部を調べることによりわかる。③　ただし $i$ は虚数単位である。よって条件 (A), (B), (C), (D) を満たす関数は三角関数 $f(x) = \cos x,\ g(x) = \sin x$ であることが示される。

さらに，$a,\ b$ を実数で $b \neq 0$ とする。このとき条件 (D) をより一般的な

(D)′　$f(x),\ g(x)$ は $x = 0$ で微分可能で $f'(0) = a,\ g'(0) = b$

におきかえて，条件 (A), (B), (C), (D)′ を満たす $f(x),\ g(x)$ はどのような関数になるか考えてみる。この場合でも，条件 (A), (B), (C) から $f(0) = 1,\ g(0) = 0$ が上と同様にわかる。ここで

$$p(x) = e^{-\frac{a}{b}x}f\left(\frac{x}{b}\right),\qquad q(x) = e^{-\frac{a}{b}x}g\left(\frac{x}{b}\right)$$

とおくと，条件 (A), (B), (C), (D) において，$f(x)$ を $p(x)$ に，$g(x)$ を $q(x)$ におきかえた条件が満たされる。④　すると前半の議論により，$p(x),\ q(x)$ がまず求まり，このことを用いると $f(x) = \fbox{ア}$，$g(x) = \fbox{イ}$ が得られる。

  1. (1)　下線部 ① について，$f(0) = 1,\ g(0) = 0$ となることを示せ。
  2. (2)　下線部 ② について，$f(x)$ がすべての $x$ の値で微分可能な関数であり，$f'(x) = -g(x)$ となることを示せ。
  3. (3)　下線部 ③ について，下線部 ①，下線部 ② の事実を用いることにより，$\{f(x) + ig(x)\}(\cos x - i\sin x) = 1$ となることを示せ。
  4. (4)　下線部 ④ について，条件 (B), (D) において，$f(x)$ を $p(x)$ に，$g(x)$ を $q(x)$ におきかえた条件が満たされることを示せ。つまり $p(x)$ と $q(x)$ が，
    　(B)　すべての $x,\ y$ について $q(x + y) = p(x)q(y) + q(x)p(y)$
    　(D)　$p(x),\ q(x)$ は $x = 0$ で微分可能で $p'(0) = 0,\ q'(0) = 1$
    を満たすことを示せ。また空欄 $\fbox{ア}$，$\fbox{イ}$ に入る関数を求めよ。

（2023 九州大学 前期 理系 第4問）

解答例

問題文が長いが、やることは誘導どおり。(1) は $x = y = 0$ を代入、(2) は微分の定義に戻って加法定理で展開、(3) は「導関数が $0$ なら定数」。(4) は代入して確かめるだけ。

解答例（タップで展開）

(1)

(A), (B) で $x = y = 0$ とすると

$$f(0) = f(0)^2 - g(0)^2\quad\cdots\text{(i)},\qquad g(0) = 2f(0)g(0)\quad\cdots\text{(ii)}$$

$g(0) \neq 0$ と仮定すると、(ii) より $f(0) = \frac12$。(i) に代入すると $g(0)^2 = \frac14 - \frac12 \lt 0$ となり、$g(0)$ が実数であることに反する。よって $g(0) = 0$。すると (i) より $f(0) = f(0)^2$ で、(C) より $f(0) = 1$。

(2)

(A) と (1) より、$h \neq 0$ のとき

$$\frac{f(x + h) - f(x)}{h} = f(x)\cdot\frac{f(h) - f(0)}{h} - g(x)\cdot\frac{g(h) - g(0)}{h}$$

$h \to 0$ のとき、(D) より右辺は $f(x)f'(0) - g(x)g'(0) = -g(x)$ に収束する。よって $f(x)$ はすべての $x$ で微分可能で $f'(x) = -g(x)$。（同様に (B) から $g'(x) = f(x)$。）

(3)

$F(x) = f(x)\cos x + g(x)\sin x$，$G(x) = g(x)\cos x - f(x)\sin x$ とおくと

$$\{f(x) + ig(x)\}(\cos x - i\sin x) = F(x) + iG(x)$$

(2) を用いて微分すると

$$\begin{aligned} F'(x) &= -g\cos x - f\sin x + f\sin x + g\cos x = 0 \\ G'(x) &= f\cos x - g\sin x - (-g)\sin x - f\cos x = 0 \end{aligned}$$

よって $F,\ G$ は定数で、(1) より $F(x) = F(0) = f(0) = 1$，$G(x) = G(0) = g(0) = 0$。したがって $\{f(x) + ig(x)\}(\cos x - i\sin x) = 1$。

（両辺に $\cos x + i\sin x$ をかけると $f(x) + ig(x) = \cos x + i\sin x$。実部・虚部を比べて $f(x) = \cos x,\ g(x) = \sin x$。）

(4)

$k = \dfrac{a}{b}$ とおく。(B) より

$$\begin{aligned} q(x + y) &= e^{-k(x+y)}g\left(\frac xb + \frac yb\right) = e^{-kx}e^{-ky}\left\{f\left(\frac xb\right)g\left(\frac yb\right) + g\left(\frac xb\right)f\left(\frac yb\right)\right\} \\ &= p(x)q(y) + q(x)p(y) \end{aligned}$$

また $f(x),\ g(x)$ は $x = 0$ で微分可能なので、$p(x),\ q(x)$ も $x = 0$ で微分可能で

$$p'(0) = -k f(0) + \frac1b f'(0) = -\frac ab + \frac ab = 0,\qquad q'(0) = -k g(0) + \frac1b g'(0) = 0 + \frac bb = 1$$

（(A), (C) も同様に成り立つ。$p(0) = f(0) \neq 0$。）よって前半の議論から $p(x) = \cos x,\ q(x) = \sin x$。$x = bt$ とおくと $f(t) = e^{kbt}p(bt) = e^{at}\cos bt$ なので

$$\fbox{ア} = e^{ax}\cos bx,\qquad \fbox{イ} = e^{ax}\sin bx$$

動く図解

$f(x) = e^{ax}\cos bx$，$g(x) = e^{ax}\sin bx$ のグラフ（左）と、点 $(f(x),\ g(x))$ が描く曲線（右）です。$a = 0,\ b = 1$ なら単位円（三角関数）、$a \neq 0$ なららせんになります。

　

問題の背景

加法定理 = 指数法則

(A), (B) は、複素数 $\varphi(x) = f(x) + ig(x)$ を使うと 1 本の式

$$\varphi(x + y) = \varphi(x)\varphi(y)$$

にまとまります（右辺を展開して実部・虚部を比べてみてください）。これは指数関数の性質そのものです。オイラーの公式 $e^{ix} = \cos x + i\sin x$ を認めれば、答えは

$$f(x) + ig(x) = e^{(a + bi)x} = e^{ax}(\cos bx + i\sin bx)$$

と一行で書けます。(3) の $\{f + ig\}(\cos x - i\sin x) = 1$ は、$\varphi(x)e^{-ix} = 1$ を高校の範囲で示していることになります。

関数方程式

「$f(x + y) = f(x)f(y)$ をみたす関数は指数関数」のように、関数の性質から関数そのものを決める問題を関数方程式と呼びます。微分可能性（本問では $x = 0$ だけ！）を仮定すると、微分の定義から $f'$ が計算でき、微分方程式に帰着できるのがポイントです。chopin 先生は「問題文が強制的に解法を誘導しているため解きにくい」とコメントしており、共通テスト風の読解型の出題でした。

「$x = 0$ で微分可能」しか仮定がなくても、加法定理で $f(x + h)$ を分解すれば、すべての $x$ での微分可能性が導ける。関数方程式の定番テクニックです。

類題紹介

実数全体で定義された関数 $f(x)$ が，すべての実数 $x,\ y$ について $f(x + y) = f(x)f(y)$ をみたし，$f(0) \neq 0$，さらに $x = 0$ で微分可能で $f'(0) = a$ であるとする。$f(x) = e^{ax}$ であることを示せ。

（自作）

略解

$x = y = 0$ として $f(0) = f(0)^2$、$f(0) \neq 0$ より $f(0) = 1$。$\dfrac{f(x + h) - f(x)}{h} = f(x)\dfrac{f(h) - 1}{h} \to af(x)$ より $f'(x) = af(x)$。$F(x) = e^{-ax}f(x)$ とおくと $F'(x) = e^{-ax}(f'(x) - af(x)) = 0$ で、$F(x) = F(0) = 1$。よって $f(x) = e^{ax}$。

実数全体で定義された関数 $f(x),\ g(x)$ が次の条件をみたすとする。$f(x),\ g(x)$ を求めよ。
(A)′　すべての $x,\ y$ について $f(x + y) = f(x)f(y) + g(x)g(y)$
(B)　すべての $x,\ y$ について $g(x + y) = f(x)g(y) + g(x)f(y)$
(C)　$f(0) \neq 0$，$f(0) + g(0) \neq 0$，$f(0) - g(0) \neq 0$
(D)　$f(x),\ g(x)$ は $x = 0$ で微分可能で $f'(0) = 0,\ g'(0) = 1$

（九大 2023　魔改造）

略解

(A)′ ± (B) より、$u = f + g$，$w = f - g$ はそれぞれ

$$u(x + y) = u(x)u(y),\qquad w(x + y) = w(x)w(y)$$

をみたす（右辺を展開して確かめられる）。$u(0),\ w(0) \neq 0$ で $u'(0) = 1$，$w'(0) = -1$ なので、類題（自作）より $u = e^x$，$w = e^{-x}$。よって

$$f(x) = \frac{e^x + e^{-x}}{2},\qquad g(x) = \frac{e^x - e^{-x}}{2}$$

これらは双曲線関数 $\cosh x,\ \sinh x$ と呼ばれ、点 $(f(x),\ g(x))$ は双曲線 $X^2 - Y^2 = 1$ の上を動きます。加法定理の符号を 1 つ変えると、円が双曲線に変わるわけです。
