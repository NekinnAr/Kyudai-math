曲線 $y = e^x$ 上を動く点 $P$ の時刻 $t$ における座標を $(x(t),\ y(t))$ と表し，$P$ の速度ベクトルと加速度ベクトルをそれぞれ $\vec v = \left(\dfrac{dx}{dt},\ \dfrac{dy}{dt}\right)$ と $\vec\alpha = \left(\dfrac{d^2x}{dt^2},\ \dfrac{d^2y}{dt^2}\right)$ とする。すべての時刻 $t$ で $|\vec v| = 1$ かつ $\dfrac{dx}{dt} > 0$ であるとして，次の問いに答えよ。

  1. (1)　$P$ が点 $(s,\ e^s)$ を通過する時刻における速度ベクトル $\vec v$ を $s$ を用いて表せ。
  2. (2)　$P$ が点 $(s,\ e^s)$ を通過する時刻における加速度ベクトル $\vec\alpha$ を $s$ を用いて表せ。
  3. (3)　$P$ が曲線全体を動くとき，$|\vec\alpha|$ の最大値を求めよ。

（2009 九州大学 前期 理系 第5問）

解答例

$\dfrac{dy}{dt} = e^x\dfrac{dx}{dt}$ と $|\vec v| = 1$ から $\dfrac{dx}{dt}$ が $x$ の式で書けます。加速度は「$x$ で微分してから $\frac{dx}{dt}$ を掛ける」（合成関数の微分）で求めます。

解答例（タップで展開）

(1)

$y = e^x$ より $\dfrac{dy}{dt} = e^x\dfrac{dx}{dt}$。$|\vec v|^2 = (1 + e^{2x})\left(\dfrac{dx}{dt}\right)^2 = 1$ と $\dfrac{dx}{dt} > 0$ より

$$\frac{dx}{dt} = \frac{1}{\sqrt{1 + e^{2x}}},\qquad \vec v = \left(\frac{1}{\sqrt{1 + e^{2s}}},\ \frac{e^s}{\sqrt{1 + e^{2s}}}\right)$$

(2)

$\vec v$ を $x$ の関数とみて $x$ で微分し、$\dfrac{dx}{dt}$ を掛ける。

$$\frac{d}{dx}(1 + e^{2x})^{-\frac12} = -e^{2x}(1 + e^{2x})^{-\frac32}$$ $$\frac{d}{dx}\left\{e^x(1 + e^{2x})^{-\frac12}\right\} = e^x(1 + e^{2x})^{-\frac12} - e^{3x}(1 + e^{2x})^{-\frac32} = e^x(1 + e^{2x})^{-\frac32}$$

これに $\dfrac{dx}{dt} = (1 + e^{2x})^{-\frac12}$ を掛けて

$$\vec\alpha = \left(-\frac{e^{2s}}{(1 + e^{2s})^2},\ \frac{e^s}{(1 + e^{2s})^2}\right)$$

（$\vec\alpha\cdot\vec v = 0$：速さ一定なら加速度は速度に垂直。）

(3)

$$|\vec\alpha|^2 = \frac{e^{4s} + e^{2s}}{(1 + e^{2s})^4} = \frac{e^{2s}}{(1 + e^{2s})^3}$$

$u = e^{2s}\ (> 0)$ とおき $g(u) = \dfrac{u}{(1 + u)^3}$ とすると

$$g'(u) = \frac{(1 + u) - 3u}{(1 + u)^4} = \frac{1 - 2u}{(1 + u)^4}$$

$u = \frac12$ で最大、$g\left(\frac12\right) = \dfrac{1/2}{27/8} = \dfrac{4}{27}$。よって

$$\max|\vec\alpha| = \frac{2}{3\sqrt3} = \frac{2\sqrt3}{9}\qquad\left(s = -\frac12\log2\ \text{のとき}\right)$$

動く図解

点の位置 $s$ を動かすと、速度ベクトル（青，長さ 1）と加速度ベクトル（赤，見やすいよう 3 倍に拡大）が表示されます。加速度はつねに速度と垂直で、曲線の曲がりが最もきつい $s = -\frac12\log2 \approx -0.347$ で最大になります。

問題の背景

速さ 1 で動くときの加速度 ＝ 曲率

曲線上を速さ 1 で動く点の加速度の大きさは、その点での曲線の曲率（曲率半径の逆数）に一致します。一般の曲線 $y = f(x)$ の曲率は $\dfrac{|f''(x)|}{(1 + f'(x)^2)^{3/2}}$ で、$f = e^x$ なら $\dfrac{e^x}{(1 + e^{2x})^{3/2}}$ ── (3) の $|\vec\alpha|$ と同じ式です。車でカーブを一定の速さで走るとき、ハンドルを最も大きく切る地点がここ、というイメージです。

chopin 先生は「(1)(2) 速さが 1 という条件から、$dx/dt$ が $x$ の式で表現できるので、これを使って速度と加速度の式を求めることができます」「(3) (2) の大きさを $s$ の式で表して増減を調べます」とコメントしています。

$\dfrac{d}{dt} = \dfrac{dx}{dt}\cdot\dfrac{d}{dx}$。速さ一定なら $\vec\alpha \perp \vec v$。$e^{2s}$ のかたまりは $u$ と置いて 1 変数の分数関数に。

類題紹介

円 $x^2 + y^2 = r^2$ 上を，速さ 1 で反時計回りに動く点の加速度ベクトルの大きさを求めよ。

（自作）

略解

角速度は $\frac1r$ なので $P = \left(r\cos\frac tr,\ r\sin\frac tr\right)$。$\vec\alpha = -\frac{1}{r^2}\overrightarrow{OP}$ で $|\vec\alpha| = \dfrac1r$（円の曲率）。

本問の曲線を放物線 $y = x^2$ に変えて，同じ条件（$|\vec v| = 1$，$\frac{dx}{dt} > 0$）で動くとき，点 $(s,\ s^2)$ における $|\vec\alpha|$ と，その最大値を求めよ。

（九大 2009　魔改造）

略解

$\frac{dx}{dt} = (1 + 4x^2)^{-\frac12}$，$\vec v = \dfrac{(1,\ 2x)}{\sqrt{1 + 4x^2}}$。$x$ で微分して $\frac{dx}{dt}$ を掛けると

$$\vec\alpha = \frac{(-4s,\ 2)}{(1 + 4s^2)^2},\qquad |\vec\alpha| = \frac{2}{(1 + 4s^2)^{\frac32}}$$

最大値は $s = 0$（頂点）で $2$。（曲率半径 $\frac12$ の円で頂点を近似できる。）
