整数 $a,\ b$ は 3 の倍数ではないとし，

$$f(x) = 2x^3 + a^2x^2 + 2b^2x + 1$$

とおく。以下の問いに答えよ。

  1. (1)　$f(1)$ と $f(2)$ を 3 で割った余りをそれぞれ求めよ。
  2. (2)　$f(x) = 0$ を満たす整数 $x$ は存在しないことを示せ。
  3. (3)　$f(x) = 0$ を満たす有理数 $x$ が存在するような組 $(a,\ b)$ をすべて求めよ。

（2018 九州大学 前期 理系 第4問）

解答例

3 の倍数でない整数の 2 乗は 3 で割って 1 余る。(2)(3) は「整数係数の方程式の有理数解 $\frac qp$ は、$p$ が最高次の係数の約数、$q$ が定数項の約数」という定理で候補を $\pm1,\ \pm\frac12$ に絞る。

解答例（タップで展開）

(1)

$a,\ b$ は 3 の倍数でないので $a \equiv \pm1$，$b \equiv \pm1 \pmod 3$、よって $a^2 \equiv b^2 \equiv 1 \pmod 3$。

$$f(1) = 3 + a^2 + 2b^2 \equiv 0 + 1 + 2 = 3 \equiv 0,\qquad f(2) = 17 + 4a^2 + 4b^2 \equiv 2 + 1 + 1 = 4 \equiv 1 \pmod 3$$

$f(1)$ を 3 で割った余りは $0$、$f(2)$ を 3 で割った余りは $1$。

(2)

整数 $x$ が $f(x) = 0$ をみたすとすると、$x(2x^2 + a^2x + 2b^2) = -1$ より $x$ は $-1$ の約数で $x = \pm1$。

  • $f(1) = 3 + a^2 + 2b^2 \gt 0$ なので $f(1) \neq 0$。
  • $f(-1) = a^2 - 2b^2 - 1 \equiv 1 - 2 - 1 = -2 \equiv 1 \pmod 3$ なので $f(-1) \neq 0$。

よって整数解は存在しない。

(3)

有理数解を $x = \frac qp$（$p \ge 1$，$p,\ q$ は互いに素な整数）とする。$f\left(\frac qp\right) = 0$ の両辺に $p^3$ をかけて

$$2q^3 + a^2q^2p + 2b^2qp^2 + p^3 = 0$$

$p^3 = -q(2q^2 + a^2qp + 2b^2p^2)$ より $q \mid p^3$、$p,\ q$ は互いに素なので $q = \pm1$。また $2q^3 = -p(a^2q^2 + 2b^2qp + p^2)$ より $p \mid 2q^3$、よって $p \mid 2$ で $p = 1,\ 2$。(2) より整数解はないので $p = 2$、$x = \pm\frac12$。

  • $x = \frac12$：$f\left(\frac12\right) = \frac14 + \frac{a^2}{4} + b^2 + 1 \gt 0$ で不適。
  • $x = -\frac12$：$f\left(-\frac12\right) = -\frac14 + \frac{a^2}{4} - b^2 + 1 = 0 \iff a^2 - 4b^2 = -3 \iff (2b - a)(2b + a) = 3$。

$(2b - a,\ 2b + a) = (1, 3),\ (3, 1),\ (-1, -3),\ (-3, -1)$ より $(a,\ b) = (1,\ 1),\ (-1,\ 1),\ (-1,\ -1),\ (1,\ -1)$。いずれも 3 の倍数でない。

$$(a,\ b) = (1,\ 1),\ (1,\ -1),\ (-1,\ 1),\ (-1,\ -1)$$

（このとき $f(x) = 2x^3 + x^2 + 2x + 1 = (2x + 1)(x^2 + 1)$。）

動く図解

$a,\ b$ を動かすと、有理数解の候補 $\pm1,\ \pm\frac12$ での $f$ の値と、$y = f(x)$ のグラフが表示されます。候補で $0$ になるのはどんなときか確かめましょう。

問題の背景

有理根定理

整数係数の方程式 $a_nx^n + \cdots + a_0 = 0$ の有理数解 $\frac qp$（既約）は、$p \mid a_n$，$q \mid a_0$ をみたします。これを有理根定理（有理数解の定理）といい、本問の (3) のように、候補を有限個に絞り込むのに使います。答案では、上の解答のように証明を添えるのが安全です。

chopin 先生は「(1) は、平方数を 3 で割った余りが 0 か 1 になることを利用」「(2) $f(x)$ が整数係数の 3 次式なので、$f(x) = 0$ の有理数解としてありえるのは $x = \pm1$ か $x = \pm\frac12$ のみ」とコメントしています。

平方数 $\bmod 3$ は $0,\ 1$、$\bmod 4$ は $0,\ 1$、$\bmod 8$（奇数）は $1$。有理数解は「分母は最高次係数の約数、分子は定数項の約数」。

類題紹介

方程式 $x^3 - 3x + 1 = 0$ は有理数解をもたないことを示せ。

（自作・頻出）

略解

有理数解 $\frac qp$（既約，$p \ge 1$）があるとすると、$q^3 - 3qp^2 + p^3 = 0$ より $q \mid p^3$，$p \mid q^3$ で $p = 1,\ q = \pm1$。しかし $1 - 3 + 1 = -1$，$-1 + 3 + 1 = 3$ でどちらも $0$ でない。（この方程式の解は $2\cos\frac{2\pi}{9}$ などで、正九角形の作図不可能性につながります。）

本問で「$a,\ b$ は 3 の倍数ではない」という条件をはずす。$f(x) = 0$ が整数解をもつような整数の組 $(a,\ b)$ のうち，$0 \lt b \lt 100$ をみたすものをすべて求めよ。

（九大 2018　魔改造）

略解

整数解の候補は $\pm1$ で、$f(1) \gt 0$。$f(-1) = a^2 - 2b^2 - 1 = 0 \iff a^2 - 2b^2 = 1$（ペル方程式）。最小解 $(3,\ 2)$ から $(a + b\sqrt2) = (3 + 2\sqrt2)^k$ で解が作られ、$(3,\ 2),\ (17,\ 12),\ (99,\ 70),\ (577,\ 408),\ \cdots$。$0 \lt b \lt 100$ より

$$(a,\ b) = (\pm3,\ 2),\ (\pm17,\ 12),\ (\pm99,\ 70)$$

（いずれも $a$ か $b$ が 3 の倍数。本問の条件は、このペル方程式の解を排除するためのものだったのです。）
